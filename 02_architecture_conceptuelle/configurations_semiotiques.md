# La configuration sémiotique

## L'inscription des différences disponibles

---

## Fonction de la page

Dans l’architecture de Protokin, la **configuration sémiotique** désigne l’ensemble des opérations par lesquelles des différences issues d’une interaction avec un milieu deviennent disponibles, partageables et réutilisables au sein d’une pratique collective.

Cette page établit le rôle de la configuration sémiotique comme condition intermédiaire entre le couplage perception-action et l’émergence d’une description structurée.

Elle ne traite pas encore :

- de la description elle-même ;
- des catégories appliquées aux différences ;
- des normes de justification ;
- des critères de validité.

Ces éléments appartiennent respectivement aux pages consacrées aux **configurations descriptives**, aux **fonctions descriptives** et aux **régimes descriptifs**.

La configuration sémiotique concerne donc un niveau préalable : celui de la **mise en disponibilité des différences**.

---

# 1. Problème inaugural : comment une différence devient-elle disponible ?

Une description ne surgit jamais d’une confrontation immédiate avec un monde déjà organisé en objets, propriétés et catégories.

Avant qu’une assertion puisse être formulée :

> « Cette plante est malade. »

ou :

> « Cette personne est dangereuse. »

il faut qu’un ensemble de différences ait déjà été distingué, retenu, inscrit et rendu accessible à une communauté de pratiques.

Le problème auquel répond la configuration sémiotique est donc le suivant :

> Comment des variations rencontrées dans un environnement deviennent-elles des différences disponibles, conservables et transmissibles pour une activité descriptive ?

Le couplage perception-action constitue le point d’ancrage initial.

Un organisme ou un collectif rencontre un environnement à travers des interactions situées. Ces interactions produisent des variations :

- contrastes visuels ;
- différences sonores ;
- variations thermiques ;
- traces matérielles ;
- comportements observables ;
- changements corporels.

Cependant, une variation n’est pas encore une différence descriptive.

Une différence devient pertinente lorsqu’elle peut être :

- distinguée ;
- retenue ;
- réidentifiée ;
- comparée ;
- transmise ;
- intégrée dans une pratique collective.

La configuration sémiotique désigne précisément cette transformation :

```
Variation rencontrée
        ↓
Différence discriminée
        ↓
Différence inscrite
        ↓
Différence disponible
        ↓
Possibilité de description
```

---

# 2. Définition fonctionnelle

Dans Protokin, on appelle **configuration sémiotique** :

> Une organisation située de différences inscrites, produites et stabilisées dans des pratiques matérielles, corporelles, techniques ou institutionnelles, qui rend certaines distinctions disponibles pour une activité descriptive collective.

Cette définition implique plusieurs dimensions.

---

## 2.1 Une organisation située

La configuration sémiotique n’existe jamais indépendamment d’une pratique.

Elle n’est pas un système abstrait de signes existant en dehors des usages.

Une différence sémiotique apparaît toujours dans une situation où certains acteurs disposent :

- d'intérêts ;
- d'objectifs ;
- de techniques ;
- d'instruments ;
- d'habitudes ;
- de formes d'attention.

Une même variation peut ainsi devenir pertinente dans une pratique et rester insignifiante dans une autre.

La configuration sémiotique dépend donc d’un agencement entre :

- un milieu ;
- des organismes ou des acteurs ;
- des supports ;
- des pratiques d’inscription.

---

## 2.2 Une organisation de différences inscrites

La configuration sémiotique ne concerne pas des choses en elles-mêmes.

Elle concerne des différences rendues accessibles.

Une différence peut être inscrite sous différentes formes :

- une marque graphique ;
- une trace matérielle ;
- une mesure ;
- un geste professionnel ;
- un signal sonore ;
- une classification spatiale ;
- un symbole ;
- une procédure institutionnelle.

L’inscription permet qu’une différence dépasse l’instant de son apparition.

Elle devient disponible pour d’autres moments, d’autres acteurs et d’autres opérations.

---

## 2.3 Une disponibilité pratique

La fonction principale de la configuration sémiotique n’est pas de représenter le monde.

Elle est de rendre certaines différences manipulables dans une pratique.

Une configuration sémiotique permet :

- d’attirer l’attention sur certaines différences ;
- d’en ignorer d’autres ;
- de conserver des traces ;
- de comparer des situations ;
- de transmettre des informations ;
- de coordonner des actions.

Elle constitue donc une condition pratique de la description.

---

# 3. Configuration sémiotique et support descriptif

Une distinction essentielle doit être maintenue entre :

- configuration sémiotique ;
- support descriptif.

Ces deux notions sont liées mais ne désignent pas le même niveau.

## Configuration sémiotique

Elle désigne :

> l’organisation relationnelle des différences rendues disponibles.

Elle concerne la structure de contraste.

---

## Support descriptif

Il désigne :

> le dispositif matériel, symbolique ou technique qui porte et transmet ces différences.

Il concerne le vecteur d’inscription.

---

La relation peut être représentée ainsi :

```
Couplage perception-action

        ↓

Différences discriminées

        ↓

Configuration sémiotique
(organisation des différences)

        ↓

Supports descriptifs
(dispositifs d'inscription)

        ↓

Configuration descriptive
(organisation conceptuelle)

        ↓

Régime descriptif
(normes d'évaluation)
```

Le support descriptif rend possible l'inscription.

La configuration sémiotique organise ce qui devient ainsi disponible.

---

# 4. Le refus du donné sémiotique brut

Protokin refuse l’idée selon laquelle les signes seraient simplement présents dans le monde et qu’il suffirait de les décoder.

Il n’existe pas de donné sémiotique brut.

Une différence ne devient pas un élément descriptivement pertinent uniquement parce qu’elle existe physiquement.

Elle devient pertinente parce qu’une pratique collective a développé :

- des manières de sélectionner ;
- des critères d’attention ;
- des instruments d’inscription ;
- des habitudes d’interprétation ;
- des possibilités de réutilisation.

Ainsi :

Une couleur n’est pas encore une catégorie chromatique.

Une trace n’est pas encore un indice.

Un comportement n’est pas encore une qualification morale.

Une variation biologique n’est pas encore un diagnostic.

Entre la rencontre et la description existe un espace d’organisation sémiotique.

---

# 5. Ce que la configuration sémiotique n’est pas

La configuration sémiotique n’est pas :

## Une description déjà constituée

Elle ne produit pas encore d’assertion.

Elle rend seulement possible l’apparition de différences descriptibles.

---

## Une catégorie

Elle ne classe pas encore les différences.

La catégorisation appartient aux configurations descriptives.

---

## Un régime normatif

Elle ne détermine pas encore ce qui est vrai, recevable ou justifié.

Ces dimensions appartiennent aux régimes descriptifs.

---

## Une représentation fidèle d’un monde déjà découpé

La configuration sémiotique ne copie pas une organisation préexistante.

Elle organise les conditions pratiques dans lesquelles certaines différences deviennent accessibles.

---

# 6. Les configurations sémiotiques comme pratiques collectives

Une configuration sémiotique est toujours liée à une communauté de pratiques.

Elle suppose des formes partagées de reconnaissance.

Une différence inscrite doit pouvoir être :

- reconnue par plusieurs acteurs ;
- utilisée dans différentes situations ;
- intégrée dans des chaînes d’action ;
- transmise à travers le temps.

Par exemple :

Un tracé d’électrocardiogramme n’est pas seulement une ligne imprimée.

Il devient une configuration sémiotique parce qu’une communauté médicale sait :

- comment le produire ;
- comment l’observer ;
- comment le comparer ;
- comment l’intégrer dans une pratique clinique.

La différence inscrite devient alors une ressource collective.

---

# 7. Exemples de configurations sémiotiques

## 7.1 Le vélo rouge

Avant l’assertion :

> « Le vélo est rouge »

il existe déjà une configuration sémiotique.

Des différences lumineuses, chromatiques et perceptives ont été rendues accessibles grâce :

- aux capacités perceptives ;
- aux contrastes du milieu ;
- aux pratiques linguistiques ;
- aux usages partagés des couleurs.

La configuration sémiotique ne contient pas encore la proposition :

> « ce vélo est rouge »

Elle rend seulement possible la disponibilité d’un contraste chromatique pouvant être ensuite qualifié.

---

## 7.2 La personne dangereuse

Avant l’assertion :

> « Cette personne est dangereuse »

une série d’inscriptions peut exister :

- signalements ;
- traces comportementales ;
- historiques ;
- documents institutionnels ;
- observations professionnelles.

Ces éléments ne constituent pas encore un jugement.

Ils forment une configuration sémiotique permettant qu’une différence comportementale devienne disponible pour une qualification ultérieure.

---

## 7.3 La personne mauvaise

Avant une qualification morale :

> « Cette personne est mauvaise »

existent souvent :

- récits ;
- témoignages ;
- traditions morales ;
- sanctions ;
- symboles d’approbation ou de rejet.

La configuration sémiotique fournit l’espace des traces à partir duquel une pratique morale pourra produire des descriptions.

Elle ne détermine cependant pas seule la validité morale de cette description.

---

## 7.4 Le botaniste et le bûcheron

Deux personnes peuvent parcourir le même environnement sans rencontrer la même configuration sémiotique.

Le botaniste peut rendre disponibles :

- des structures végétales ;
- des symptômes pathologiques ;
- des relations écologiques ;
- des variations morphologiques.

Le bûcheron peut rendre disponibles :

- la densité du bois ;
- la qualité du tronc ;
- la résistance mécanique ;
- la valeur économique.

Ils ne voient pas deux forêts différentes.

Ils participent à deux organisations sémiotiques différentes du même environnement.

---

## 7.5 Les urgences hospitalières

Lorsqu’un patient arrive aux urgences, une configuration sémiotique complexe se met immédiatement en place :

- constantes vitales ;
- électrocardiogrammes ;
- dossiers numériques ;
- classifications de tri ;
- observations infirmières.

Ces inscriptions ne sont pas encore des diagnostics.

Elles constituent une surface de disponibilité sémiotique permettant aux différents acteurs médicaux de produire leurs descriptions spécialisées.

## Ce que cette page établit

Cette page établit que :

- les descriptions ne commencent pas avec des propositions ;
- les différences doivent être rendues disponibles avant d’être qualifiées ;
- les signes n’existent pas indépendamment des pratiques ;
- les inscriptions matérielles et symboliques jouent un rôle constitutif ;
- toute description repose sur une organisation préalable des différences.

---

## Ce que cette page ne développe pas

Cette page ne développe pas :

- comment une différence devient une catégorie ;
- comment une proposition devient une assertion ;
- comment une description est justifiée ;
- comment un régime descriptif fonctionne.

Ces questions appartiennent aux pages suivantes :

- Configuration descriptive ;
- Fonctions descriptives ;
- Assertion ;
- Régime descriptif.

# Synthèse

La configuration sémiotique désigne le niveau où des différences issues d’un couplage avec le monde deviennent disponibles pour une pratique collective.

Elle constitue le passage entre une rencontre située et une possibilité de description.

Elle ne décrit pas encore.

Elle rend la description possible.
