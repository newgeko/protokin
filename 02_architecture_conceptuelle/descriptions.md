# Description

## L'actualisation d'une configuration descriptive

> Dans Protokin, une description n'est ni une représentation du monde, ni un simple énoncé linguistique. Elle est une **opération située** qui actualise une configuration descriptive en produisant un contenu susceptible d'être interprété, discuté, justifié et transformé au sein d'un régime descriptif.

---

# Fonction du concept

Cette page répond à une question centrale :

> **Qu'appelle-t-on exactement une description dans Protokin ?**

Une description ne se réduit pas au texte qui la formule.

Elle désigne l'opération par laquelle une configuration descriptive est rendue explicite selon des pratiques, des catégories et des normes déterminées.

Ainsi, Protokin distingue :

- les différences rendues disponibles par une configuration sémiotique ;
- l'organisation relationnelle de ces différences dans une configuration descriptive ;
- l'opération qui produit une description particulière ;
- les fonctions descriptives mobilisées dans cette opération ;
- le régime descriptif qui en détermine la recevabilité.

La description constitue donc le point d'articulation entre une organisation relationnelle et un engagement descriptif.

---

# 1. Définition

Une description est :

> **Une opération située qui actualise une configuration descriptive en produisant un contenu descriptif susceptible d'être engagé, interprété, évalué, contesté et transformé dans un régime descriptif.**

Cette définition implique plusieurs conséquences.

Une description :

- n'est jamais indépendante d'une configuration descriptive ;
- n'est jamais réductible à un énoncé linguistique ;
- n'est jamais produite hors d'une pratique ;
- n'est jamais évaluée indépendamment d'un régime descriptif.

Elle est toujours une activité inscrite dans un espace de relations.

---

# 2. Une description n'est pas une représentation

Protokin refuse d'identifier la description à une représentation fidèle d'un réel supposé déjà entièrement constitué.

Décrire ne consiste pas à copier le monde.

Décrire consiste à produire une organisation explicite de différences déjà rendues disponibles dans une configuration.

Une description est donc une pratique.

Elle sélectionne, articule, qualifie et relie certains éléments afin de les rendre intelligibles pour une communauté.

Ainsi :

> **Une description ne reproduit pas un monde déjà donné ; elle explicite une manière organisée de rendre certaines différences descriptivement accessibles.**

---

# 3. Une description actualise une configuration

Une configuration descriptive rend plusieurs descriptions possibles.

La description correspond à l'une des actualisations de cette organisation.

Par exemple, un même événement peut être décrit :

- juridiquement ;
- historiquement ;
- médicalement ;
- économiquement ;
- moralement ;
- politiquement.

Ces descriptions ne sont pas produites à partir de mondes différents.

Elles actualisent différemment une configuration descriptive en mobilisant des opérations et des normes distinctes.

Ainsi :

> **Une configuration ouvre un espace de possibilités descriptives ; une description réalise l'une de ces possibilités.**

---

# 4. Les fonctions descriptives

Toute description mobilise une ou plusieurs fonctions descriptives.

Ces fonctions qualifient ce qui est effectivement réalisé dans l'opération descriptive.

Parmi elles :

| Fonction descriptive | Opération réalisée |
|----------------------|--------------------|
| Prédication | Attribuer une propriété ou une qualification |
| Configuration | Organiser des relations entre des éléments |
| Assertion | Engager publiquement une description |
| Inférence | Déduire des conséquences descriptives |
| Justification | Soutenir la recevabilité d'une description |

Une même description mobilise généralement plusieurs fonctions simultanément.

L'analyse protokinienne ne consiste donc pas seulement à examiner ce qui est dit, mais aussi ce qui est fait en décrivant.

---

# 5. Exemple

Considérons l'énoncé :

> « Cette personne est dangereuse. »

Cet énoncé ne constitue pas, à lui seul, la description.

La description comprend également :

- les critères retenus ;
- les distinctions mobilisées ;
- les observations sélectionnées ;
- les catégories utilisées ;
- les pratiques qui rendent cette qualification pertinente.

Plusieurs fonctions descriptives sont ici mobilisées.

Une prédication attribue une qualification.

Une assertion engage un locuteur.

Des inférences deviennent possibles (prudence, surveillance, intervention...).

Une justification pourra être demandée.

La description dépasse donc largement son expression linguistique.

---

# 6. Description et espace des raisons

Produire une description consiste également à entrer dans un espace de raisons.

Toute description peut être :

- interrogée ;
- discutée ;
- justifiée ;
- corrigée ;
- reformulée ;
- contestée.

Décrire ne consiste donc pas uniquement à produire un contenu.

Décrire consiste aussi à assumer les engagements qu'implique cette production.

Une description ouvre ainsi un espace de responsabilités descriptives.

---

# 7. Place dans l'architecture de Protokin

La description occupe une position intermédiaire dans l'architecture générale.

```text
Configuration sémiotique
        ↓
des différences deviennent disponibles

Configuration descriptive
        ↓
des descriptions deviennent possibles

Description
        ↓
une description particulière est produite

Fonctions descriptives
        ↓
on qualifie ce qui est fait
(prédication, assertion, inférence…)

Régime descriptif
        ↓
on évalue la recevabilité de cette opération

Audit
        ↓
on examine l'ensemble du fonctionnement
```

Cette représentation ne décrit ni des étapes chronologiques, ni des niveaux du réel.

Elle représente les différentes fonctions conceptuelles mobilisées dans l'analyse protokinienne.

---

# 8. Ce que la description ne détermine pas

Une description ne garantit jamais :

- sa vérité ;
- sa validité ;
- sa recevabilité ;
- sa stabilité ;
- sa puissance explicative.

Ces propriétés dépendent des régimes descriptifs dans lesquels elle est produite et évaluée.

La description constitue donc un objet d'analyse, non un critère de légitimité.

---

# 9. Relations avec les autres concepts

## Configuration sémiotique

La configuration sémiotique organise les différences inscrites qui deviennent disponibles pour une pratique.

Elle constitue la condition matérielle et pratique de toute description.

---

## Configuration descriptive

La configuration descriptive organise ces différences en un espace relationnel dans lequel plusieurs descriptions deviennent possibles.

La description en est une actualisation particulière.

---

## Fonctions descriptives

Les fonctions descriptives permettent de qualifier les opérations effectivement réalisées dans une description.

Elles analysent ce que fait une description plutôt que son seul contenu.

---

## Régime descriptif

Le régime descriptif détermine les conditions selon lesquelles une description peut être comprise, évaluée, justifiée et stabilisée.

---

## Audit

L'audit protokinien examine l'ensemble de cette architecture.

Il ne juge pas seulement les descriptions produites.

Il analyse également :

- les configurations mobilisées ;
- les fonctions descriptives réalisées ;
- les régimes invoqués ;
- les conditions qui rendent certaines descriptions possibles, recevables ou exclues.

---

# Ce que cette page établit

Cette page établit que la description constitue l'opération centrale de l'architecture de Protokin.

Elle ne se réduit ni à un énoncé, ni à une représentation, ni à une simple proposition linguistique.

Elle est l'actualisation située d'une configuration descriptive, réalisée au moyen de fonctions descriptives et soumise aux normes d'un régime descriptif.

Elle constitue ainsi le point de passage entre les différences rendues disponibles par les pratiques et les engagements descriptifs susceptibles d'être examinés, justifiés et transformés.

---

# Principe final

> **Une description est une opération située qui actualise une configuration descriptive en rendant explicites certaines différences organisées. Elle mobilise des fonctions descriptives, engage un locuteur dans un espace de raisons et demeure toujours évaluée selon les normes d'un régime descriptif.**
