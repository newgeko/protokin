# Introduction

Une même situation peut être décrite selon plusieurs niveaux d'analyse.

Dans la pratique, les difficultés d'interprétation proviennent souvent moins d'un désaccord sur le contenu d'une description que d'une confusion entre les niveaux auxquels cette description appartient.

Un article de presse peut être pris pour une théorie.

Une théorie peut être prise pour un régime descriptif.

Un objet descriptif peut être confondu avec le support qui le véhicule.

Une institution peut être confondue avec les engagements qu'elle attribue.

La fonction de cette page est de distinguer les principaux niveaux descriptifs mobilisés par Protokin.

Elle ne cherche pas à établir le contenu de chacun de ces concepts.

Elle vise à clarifier leurs différences et leurs relations.

---

# Pourquoi distinguer les niveaux ?

L'enquête protokinienne ne porte pas sur un seul type d'entité.

Elle peut porter simultanément sur :

- des textes ;
- des pratiques ;
- des catégories ;
- des objets ;
- des institutions ;
- des régimes ;
- des engagements.

Ces éléments n'occupent pas la même position dans l'architecture descriptive.

Les distinguer permet d'éviter les déplacements implicites d'un niveau à un autre.

---

# Les principaux niveaux descriptifs

## Support descriptif

Le support descriptif est le milieu par lequel une description devient accessible.

Exemples :

- article ;
- livre ;
- archive ;
- image ;
- graphique ;
- base de données ;
- instrument.

Le support transporte ou conserve des descriptions.

Il n'est pas lui-même ce qui est décrit.

Voir :

- [Supports descriptifs](supports_descriptifs.md)

---

## Configuration descriptive

La configuration descriptive correspond à une organisation possible de l'intelligibilité.

Elle établit :

- des catégories ;
- des distinctions ;
- des relations ;
- des problèmes.

Une configuration organise une manière de décrire.

Elle n'est pas réductible à un support particulier.

Voir :

- [Configurations descriptives](configurations.md)

---

## Régime descriptif

Le régime descriptif désigne les normes qui gouvernent une pratique de description.

Il détermine notamment :

- les critères de recevabilité ;
- les formes d'inférence ;
- les procédures de correction ;
- les incompatibilités reconnues.

Le régime organise les conditions de validité des descriptions.

Voir :

- [Régimes de description](regimes.md)

---

## Engagement descriptif

Un engagement descriptif correspond à ce qu'un locuteur assume lorsqu'il adopte ou produit une description.

Il concerne :

- les conséquences reconnues ;
- les responsabilités assumées ;
- les incompatibilités acceptées ;
- les justifications mobilisables.

L'engagement ne doit pas être confondu avec le contenu de la description elle-même.

Voir :

- [Engagements descriptifs](engagements.md)

---

## Objet descriptif

L'objet descriptif correspond à ce qui devient suffisamment stable pour être identifié, repris et reconnu à travers différentes situations.

Il ne se réduit ni à un support, ni à une formulation particulière.

L'objet descriptif est ce qui conserve une continuité au sein des pratiques descriptives.

Voir :

- [Objets descriptifs : invariants et stabilisations](objets_descriptifs.md)

---

## Stabilisation

La stabilisation désigne les processus par lesquels certaines descriptions deviennent plus durables que d'autres.

Elle concerne :

- la transmission ;
- la répétition ;
- l'institutionnalisation ;
- l'apprentissage ;
- la reproduction.

La stabilisation n'est pas un objet supplémentaire.

Elle correspond à un processus.

Voir :

- [Stabilisation et effet cliquet](stabilisation.md)

---

# Relations entre les niveaux

Les niveaux descriptifs ne constituent pas des compartiments isolés.

Ils entretiennent des relations constantes.

Une enquête peut par exemple rencontrer :

```text
Support descriptif

↓

Configuration descriptive

↓

Régime descriptif

↓

Engagements descriptifs

↓

Objet descriptif

↓

Stabilisation
```

Cette séquence ne représente pas une procédure obligatoire.

Elle indique simplement des distinctions analytiques fréquemment mobilisées dans l'audit.

---

# Exemple

Considérons l'affirmation :

> « Cette personne est dangereuse. »

L'enquête peut distinguer plusieurs niveaux.

### Support

L'affirmation apparaît dans :

- un article ;
- une émission ;
- un rapport ;
- un réseau social.

---

### Configuration

Elle mobilise une organisation descriptive opposant :

- sécurité ;
- menace ;
- protection ;
- risque.

---

### Régime

La description peut être évaluée selon :

- un régime juridique ;
- un régime politique ;
- un régime médiatique ;
- un régime scientifique.

---

### Engagement

Le locuteur assume certaines conséquences :

- alerter ;
- accuser ;
- justifier une mesure ;
- attribuer une responsabilité.

---

### Objet

La catégorie :

> « personne dangereuse »

peut devenir un objet descriptif stabilisé dans certaines pratiques.

---

### Stabilisation

Cette catégorie peut ensuite être :

- enseignée ;
- institutionnalisée ;
- reprise ;
- transmise.

---

# Fonction méthodologique

La distinction des niveaux descriptifs permet de guider l'enquête.

Face à une description, plusieurs questions peuvent être posées :

- Quel est le support ?
- Quelle configuration est mobilisée ?
- Quel régime la rend recevable ?
- Quels engagements produit-elle ?
- Quel objet contribue-t-elle à stabiliser ?
- Comment cette stabilisation est-elle maintenue ?

Ces questions ne reçoivent pas toujours des réponses distinctes dans la pratique.

Elles servent avant tout à orienter l'analyse.

---

# Limite de la distinction

Les niveaux descriptifs ne constituent pas des couches indépendantes du réel.

Ils correspondent à des distinctions analytiques utilisées par Protokin.

Selon les situations, certaines frontières peuvent devenir difficiles à tracer.

L'objectif n'est pas de produire une classification rigide.

Il consiste à rendre l'enquête plus explicite et plus lisible.

---

# Définition protokinienne

> Les niveaux descriptifs désignent les différents plans d'analyse mobilisés par une enquête protokinienne afin de distinguer ce qui porte une description, ce qui l'organise, ce qui la rend recevable, ce qu'elle engage, ce qu'elle stabilise et les processus qui assurent sa continuité.
