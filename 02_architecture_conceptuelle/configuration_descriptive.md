# Configurations descriptives

## L'espace relationnel des descriptions possibles

> Dans Protokin, une configuration descriptive n'est ni un objet, ni une description particulière. Elle est une **organisation relationnelle** qui ouvre un espace dans lequel des descriptions peuvent être produites, articulées, comparées et analysées.

---

# Fonction du concept

Cette page répond à une question fondamentale :

> **À partir de quoi une enquête protokinienne peut-elle commencer ?**

La réponse est la suivante :

> **Une enquête ne commence jamais à partir d'un donné brut, mais à partir d'une configuration descriptive déjà organisée.**

Toute description suppose déjà un ensemble de différences, de catégories, de pratiques et de relations qui rendent certaines descriptions possibles.

La configuration descriptive désigne précisément cette organisation.

Elle constitue **l'unité relationnelle minimale de l'analyse protokinienne**.

---

# 1. Définition

Une configuration descriptive est :

> **Une organisation relationnelle de différences rendues disponibles, de catégories, de pratiques, d'inscriptions et de relations qui constitue l'espace dans lequel des descriptions peuvent être produites.**

Elle ne correspond pas à une simple juxtaposition d'éléments.

Elle organise les relations qui rendent certaines descriptions possibles.

Une configuration descriptive peut ainsi comprendre notamment :

- des distinctions pertinentes ;
- des catégories ;
- des concepts ;
- des pratiques d'observation ;
- des formes d'inscription ;
- des instruments ;
- des modèles ;
- des classifications ;
- des institutions ;
- des dispositifs techniques.

Ces composantes ne valent pas isolément.

Elles acquièrent leur fonction descriptive par les relations qui les unissent.

---

# 2. Il n'existe pas de donné descriptif brut

Protokin adopte un principe méthodologique fondamental :

> **Tout ce qui devient descriptible apparaît déjà dans une configuration descriptive.**

Cela ne signifie pas que le monde serait construit arbitrairement.

Cela signifie que toute description suppose déjà :

- des différences rendues disponibles ;
- des critères d'identification ;
- des catégories ;
- des pratiques d'observation ;
- des formes d'inscription ;
- des moyens d'interprétation.

Une enquête ne commence donc jamais depuis un point zéro.

Elle commence toujours depuis une configuration déjà active.

---

# 3. Configuration et description

Une configuration descriptive ne doit jamais être confondue avec une description particulière.

La configuration descriptive désigne :

> **L'espace relationnel dans lequel plusieurs descriptions deviennent possibles.**

La description désigne :

> **L'actualisation située d'une possibilité offerte par cette configuration.**

Une même configuration peut ainsi donner lieu à plusieurs descriptions différentes.

Par exemple, un même événement pourra être décrit :

- scientifiquement ;
- historiquement ;
- juridiquement ;
- politiquement ;
- moralement ;
- économiquement.

La configuration n'impose donc pas une description unique.

Elle ouvre un espace de possibilités descriptives.

---

# 4. Configuration et fonctions descriptives

Une configuration descriptive constitue le milieu dans lequel des fonctions descriptives peuvent être réalisées.

Ces fonctions correspondent aux opérations effectivement accomplies lorsqu'une description est produite.

| Fonction descriptive | Opération réalisée |
|-----------------------|--------------------|
| Prédication | Attribuer une qualification |
| Configuration | Organiser des relations entre éléments |
| Assertion | Engager une description dans un espace de raisons |
| Inférence | Produire des conséquences descriptives |
| Justification | Soutenir la recevabilité d'une description |

Une configuration descriptive ne réalise aucune de ces opérations par elle-même.

Elle fournit l'organisation relationnelle dans laquelle elles deviennent possibles.

Ainsi :

> **Les fonctions descriptives n'engendrent pas la configuration ; elles en actualisent certaines possibilités.**

---

# 5. Configuration et pluralité des descriptions

Une même configuration descriptive peut être actualisée de plusieurs manières.

Différents locuteurs, différentes disciplines ou différents régimes peuvent produire des descriptions distinctes à partir d'une même organisation relationnelle.

L'analyse protokinienne cherche alors à comprendre :

- quelles descriptions deviennent possibles ;
- quelles opérations descriptives sont effectivement réalisées ;
- quelles descriptions sont privilégiées ;
- quelles descriptions sont marginalisées ou exclues ;
- selon quelles normes elles sont évaluées.

La configuration constitue ainsi un espace de possibilités plutôt qu'un contenu déterminé.

---

# 6. Configuration et régime descriptif

La distinction entre configuration descriptive et régime descriptif est fondamentale.

La configuration descriptive désigne :

> **L'organisation relationnelle qui rend des descriptions possibles.**

Le régime descriptif désigne :

> **Les conditions normatives selon lesquelles ces descriptions deviennent recevables, justifiables et stabilisables.**

Les deux concepts répondent à des questions différentes.

| Question | Concept |
|----------|----------|
| Quel espace descriptif est organisé ? | Configuration descriptive |
| Quelle description est produite ? | Description |
| Quelle opération est réalisée ? | Fonction descriptive |
| Selon quelles normes cette opération est-elle évaluée ? | Régime descriptif |

Le régime ne crée donc pas la configuration.

Il détermine les conditions de recevabilité des descriptions qui y sont produites.

---

# 7. Configuration et stabilisation

Une configuration descriptive n'est jamais une structure immuable.

Elle possède une stabilité relative produite par les pratiques qui la reproduisent.

Cette stabilité dépend notamment :

- des pratiques collectives ;
- des supports matériels ;
- des institutions ;
- des procédures de validation ;
- des transmissions historiques.

Une configuration est donc :

- située ;
- historique ;
- reproductible ;
- transformable.

Elle demeure suffisamment stable pour être analysée, sans jamais être définitivement fixée.

---

# 8. Place dans l'architecture de Protokin

La configuration descriptive occupe une position intermédiaire entre les différences rendues disponibles par les configurations sémiotiques et les descriptions effectivement produites.

```text
Configuration sémiotique
        ↓
des différences deviennent disponibles

Configuration descriptive
        ↓
des descriptions deviennent possibles

Description
        ↓
une description particulière est produite

Fonctions descriptives
        ↓
on qualifie l'opération réalisée
(prédication, configuration,
assertion, inférence,
justification)

Régime descriptif
        ↓
on évalue la recevabilité
de cette opération

Audit
        ↓
on examine l'ensemble
de l'architecture descriptive
```

Cette représentation ne décrit :

- ni des étapes chronologiques ;
- ni des niveaux du réel ;
- ni une hiérarchie ontologique.

Elle présente l'architecture fonctionnelle de l'analyse protokinienne.

---

# 9. Ce que la configuration descriptive n'est pas

Une configuration descriptive ne doit pas être comprise comme :

- une chose en soi ;
- une substance ;
- une couche du réel ;
- une représentation complète du monde ;
- une ontologie implicite.

Elle constitue un concept méthodologique.

Son rôle est de désigner l'organisation relationnelle à partir de laquelle Protokin analyse la production, l'évaluation et la transformation des descriptions.

---

# Relations avec les autres concepts

## Configuration sémiotique

Les configurations sémiotiques organisent les différences rendues disponibles dans une pratique.

Les configurations descriptives organisent ces différences comme un espace de descriptions possibles.

---

## Description

La description est l'actualisation particulière d'une possibilité ouverte par une configuration descriptive.

---

## Fonctions descriptives

Les fonctions descriptives qualifient les opérations effectivement réalisées lors de cette actualisation.

---

## Régime descriptif

Le régime descriptif définit les conditions normatives selon lesquelles ces opérations deviennent recevables, justifiables et stabilisables.

---

## Audit

L'audit examine les relations entre configurations, descriptions, fonctions descriptives et régimes afin d'analyser le fonctionnement global d'une pratique descriptive.

---

# Ce que cette page établit

Cette page établit que l'analyse protokinienne ne prend jamais pour point de départ un objet isolé ni une description déjà constituée.

Elle commence par une configuration descriptive : une organisation relationnelle qui ouvre un espace de descriptions possibles.

Cette configuration constitue l'unité relationnelle minimale de l'analyse. Les descriptions en sont les actualisations, les fonctions descriptives qualifient les opérations qui les produisent, les régimes descriptifs en évaluent la recevabilité et l'audit examine l'ensemble de cette architecture.

---

# Principe final

> **Une configuration descriptive est l'organisation relationnelle qui rend des descriptions possibles. Elle ne produit aucune description par elle-même, mais constitue l'espace dans lequel des descriptions peuvent être actualisées, analysées, évaluées et transformées selon les normes d'un régime descriptif.**
