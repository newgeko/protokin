# Taxonomies descriptives

## Organisation des distinctions, catégories et critères dans un régime descriptif

> **Dans Protokin, une taxonomie désigne une organisation structurée de distinctions permettant à un régime descriptif de qualifier, comparer, évaluer et organiser certains éléments selon des normes déterminées.**
>
> Une taxonomie ne constitue pas une classification du réel en soi.
>
> Elle constitue un dispositif descriptif par lequel certains éléments deviennent identifiables, comparables et analysables dans une pratique donnée.

---

# Introduction

Toute activité descriptive implique des distinctions.

Pour décrire quelque chose, il faut nécessairement établir :

- des catégories ;
- des différences pertinentes ;
- des relations entre éléments ;
- des critères d'évaluation.

Ces distinctions ne sont jamais neutres.

Elles dépendent d'un régime descriptif, de ses objectifs, de ses pratiques et de ses normes de recevabilité.

Protokin ne considère donc pas les taxonomies comme de simples listes de catégories.

Une taxonomie est une organisation fonctionnelle des distinctions qui rend possible une certaine manière de décrire.

La question protokinienne n'est pas :

> « Cette classification correspond-elle simplement au réel ? »

mais :

> **« Quelles distinctions cette taxonomie rend-elle possibles, selon quelles normes, et avec quelles conséquences descriptives ? »**

---

# 1. Fonction générale d'une taxonomie

Une taxonomie remplit plusieurs fonctions descriptives.

Elle permet :

- d'identifier des éléments ;
- de distinguer des cas ;
- de regrouper des phénomènes ;
- d'établir des comparaisons ;
- d'orienter des pratiques ;
- de produire des évaluations.

Une taxonomie ne se réduit donc pas à un classement.

Elle constitue une infrastructure descriptive.

Elle détermine :

- ce qui peut être distingué ;
- ce qui peut être rapproché ;
- ce qui peut être considéré comme pertinent ;
- ce qui peut devenir un objet d'analyse.

---

# 2. Taxonomie et configuration descriptive

Une taxonomie n'existe jamais isolément.

Elle appartient toujours à une configuration descriptive.

Elle implique :

- des objets rendus pertinents ;
- des pratiques d'identification ;
- des instruments ;
- des institutions ;
- des utilisateurs ;
- des critères de validation.

Exemple :

Une classification médicale suppose :

- des observations cliniques ;
- des catégories diagnostiques ;
- des procédures ;
- des institutions de soin ;
- des critères de reconnaissance.

La taxonomie n'est donc pas seulement une représentation.

Elle participe à l'organisation même du domaine qu'elle rend descriptible.

---

# 3. Taxonomie et régime descriptif

Les taxonomies sont toujours liées à un régime descriptif.

Un régime détermine :

- quelles catégories sont pertinentes ;
- quelles distinctions sont acceptables ;
- quels critères permettent une évaluation.

Une même configuration peut donc recevoir plusieurs taxonomies selon le régime mobilisé.

Exemple :

Une personne peut être catégorisée :

| Régime | Taxonomie possible |
|---|---|
| Juridique | auteur, victime, responsable |
| Médical | patient, symptôme, diagnostic |
| Psychologique | comportement, trait, processus |
| Moral | responsable, innocent, fautif |
| Politique | citoyen, acteur, groupe |

Aucune de ces taxonomies n'épuise la configuration.

Elles correspondent à des régimes descriptifs différents.

---

# 4. Structure interne d'une taxonomie

Une taxonomie peut être analysée selon plusieurs dimensions.

## 4.1 Les catégories

Les catégories déterminent les classes ou distinctions utilisées.

Elles répondent à la question :

> Qu'est-ce qui est distingué ?

Exemples :

- espèce ;
- maladie ;
- infraction ;
- rôle social ;
- statut juridique.

---

## 4.2 Les critères

Les critères déterminent les conditions permettant l'appartenance à une catégorie.

Ils répondent à la question :

> Selon quoi cette distinction est-elle effectuée ?

Exemples :

- critères biologiques ;
- critères juridiques ;
- critères comportementaux ;
- critères statistiques ;
- critères normatifs.

---

## 4.3 Les relations entre catégories

Une taxonomie organise également des relations :

- hiérarchie ;
- inclusion ;
- opposition ;
- succession ;
- dépendance.

Ces relations permettent une structuration du domaine décrit.

---

# 5. Taxonomies constitutives et taxonomies situées

Protokin distingue deux types de taxonomies.

---

## 5.1 Taxonomies constitutives

Les taxonomies constitutives appartiennent à l'architecture générale d'analyse.

Elles permettent d'étudier les descriptions elles-mêmes.

Exemples :

### Taxonomie des fonctions descriptives

| Fonction | Opération |
|---|---|
| Prédication | qualifier |
| Configuration | organiser les relations |
| Assertion | engager une position |
| Inférence | produire des conséquences |
| Justification | soutenir une description |

---

### Taxonomie des positions épistémiques

| Position | Fonction |
|---|---|
| Expert | mobiliser un savoir spécialisé |
| Témoin | engager une expérience située |
| Juge | produire une qualification normative |
| Chercheur | produire une description scientifique |

---

## 5.2 Taxonomies situées

Les taxonomies situées appartiennent aux configurations étudiées.

Elles deviennent elles-mêmes des objets d'analyse.

Exemples :

- classification biologique des espèces ;
- classifications médicales ;
- catégories juridiques ;
- classifications sociales ;
- catégories économiques.

Protokin n'adopte pas automatiquement ces taxonomies.

Il analyse :

- leur origine ;
- leurs conditions de production ;
- leurs effets ;
- leurs transformations.

---

# 6. Taxonomie et normativité

Toute taxonomie implique une forme de normativité.

Classer signifie toujours déterminer :

- ce qui compte comme différence pertinente ;
- ce qui peut être regroupé ;
- ce qui devient visible ;
- ce qui reste marginal ou invisible.

Une taxonomie ne produit donc pas seulement de l'information.

Elle organise un espace de pertinence.

La question protokinienne devient :

> **Quelles normes permettent à cette taxonomie de fonctionner comme organisation descriptive ?**

---

# 7. Taxonomies et injustice épistémique

Les taxonomies peuvent participer à des formes d'injustice épistémique.

Une injustice peut apparaître lorsque :

- certaines expériences ne disposent pas de catégories adéquates ;
- certaines positions épistémiques ne peuvent pas imposer leurs distinctions ;
- certaines classifications rendent invisibles certains phénomènes ;
- certaines catégories diminuent la recevabilité de certains locuteurs.

Dans cette perspective, l'analyse ne porte pas seulement sur les individus.

Elle porte sur les structures descriptives qui organisent les possibilités de reconnaissance.

---

# 8. Place dans l'architecture Protokin

La taxonomie se situe à l'intersection de plusieurs concepts :

Configuration descriptive ↓ Taxonomie ↓ Catégories et critères ↓ Fonctions descriptives ↓ Régime descriptif ↓ Recevabilité

Elle constitue un outil par lequel un régime organise ce qui peut être décrit et évalué.

---

# 9. Limites du concept

Une taxonomie ne doit pas être comprise comme :

- une copie parfaite du réel ;
- une classification naturelle définitive ;
- une simple convention arbitraire ;
- une hiérarchie ontologique absolue.

Elle constitue une organisation descriptive située.

Elle peut donc :

- être contestée ;
- être révisée ;
- être transformée ;
- être remplacée par une autre organisation.

---

# Conclusion

Dans Protokin, les taxonomies sont des dispositifs d'organisation descriptive.

Elles permettent à un régime de déterminer :

- quelles distinctions sont pertinentes ;
- quelles catégories sont disponibles ;
- quels critères permettent une évaluation ;
- quelles positions peuvent mobiliser ces distinctions.

Elles ne décrivent pas simplement un monde déjà découpé.

Elles participent aux conditions selon lesquelles certaines choses deviennent descriptibles.

---

# Formule synthétique

> **Une taxonomie est une organisation normative de distinctions par laquelle un régime descriptif rend certains éléments identifiables, comparables et évaluables dans une pratique donnée.**
