# Fonctions descriptives : prédication, configuration et assertion

## Introduction

Dans Protokin, les productions descriptives ne sont pas analysées comme de simples représentations du monde.

Une description est une opération située dans un régime descriptif : elle sélectionne, organise, qualifie et engage des éléments selon des conditions particulières de recevabilité.

Pour éviter de réduire l'analyse à la structure grammaticale des phrases, Protokin distingue plusieurs fonctions descriptives.

Les trois fonctions fondamentales sont :

- la prédication ;
- la configuration ;
- l'assertion.

Elles correspondent à trois opérations différentes : qualifier, organiser, engager.

---

# 1. La prédication : fonction de qualification

La prédication est l'opération par laquelle un élément reçoit une qualification déterminée.

Forme minimale :

> X est Y

Elle établit une relation entre un objet, un événement ou une personne et une propriété, une catégorie ou un statut.

Exemples :

> Cette personne est agressive.

> Cette organisation est dangereuse.

> Cette action est injuste.

La prédication ne constitue pas encore une description complète. Elle produit une qualification locale.

La question protokinienne n'est donc pas seulement :

> Cette propriété est-elle vraie de l'objet ?

mais :

> Dans quel régime cette qualification devient-elle disponible, pertinente et recevable ?

Une même prédication peut changer de fonction selon le régime :

- psychologique : « agressif » comme trait comportemental ;
- juridique : « violent » comme qualification d'un acte ;
- moral : « mauvais » comme évaluation normative ;
- médical : « pathologique » comme catégorie clinique.

La prédication produit donc une possibilité de qualification, dont le statut dépend du régime qui l'accueille.

---

# 2. La configuration : fonction d'organisation relationnelle

La configuration est l'opération par laquelle plusieurs éléments sont articulés dans une structure intelligible.

Elle ne consiste pas seulement à attribuer des propriétés, mais à organiser :

- des acteurs ;
- des événements ;
- des relations ;
- des temporalités ;
- des causes ;
- des contraintes ;
- des normes.

Exemple :

Prédication :

> Cette personne est agressive.

Configuration :

> Cette personne manifeste des comportements agressifs dans un contexte de conflit prolongé, de pression institutionnelle et d'isolement social.

La configuration ne nie pas la prédication, mais elle la replace dans un ensemble de relations.

Elle répond à la question :

> Comment une situation devient-elle intelligible comme ensemble organisé ?

Dans Protokin, une configuration n'est pas une image complète du réel. Elle est une manière de rendre certains éléments pertinents ensemble à partir d'un régime descriptif donné.

---

# 3. L'assertion : fonction d'engagement

L'assertion est l'opération par laquelle un locuteur engage une description dans un espace de raisons.

Une assertion ne consiste pas simplement à produire une phrase.

Elle implique :

- une prise de position ;
- un responsable de l'engagement ;
- des conséquences inférentielles ;
- une possibilité de justification ou de contestation.

Exemple :

> Cette personne est mauvaise.

La phrase devient une assertion lorsque quelqu'un la soutient comme une position susceptible d'être évaluée.

L'analyse protokinienne porte alors sur :

- qui affirme ;
- dans quel régime ;
- avec quelles normes ;
- avec quelles conséquences pratiques.

---

# 4. Fonctions complémentaires

Les trois fonctions fondamentales peuvent être complétées par d'autres opérations descriptives.

## L'interprétation : fonction de stabilisation du sens

L'interprétation détermine comment une configuration devient compréhensible dans un contexte donné.

Elle répond à :

> Que signifie cette configuration ici et maintenant ?

---

## L'inférence : fonction de prolongement

L'inférence désigne les conséquences qu'une description autorise.

À partir de :

> Cette personne est dangereuse.

peuvent suivre différentes conséquences selon le régime :

- surveillance ;
- exclusion ;
- accompagnement ;
- intervention juridique.

L'inférence révèle la dimension opératoire des descriptions.

---

## L'évaluation : fonction de qualification normative

L'évaluation applique des critères permettant de déterminer :

- acceptable / inacceptable ;
- valide / invalide ;
- recevable / irrecevable.

Elle ne produit pas seulement un jugement : elle mobilise un espace normatif.

---

## La justification : fonction de stabilisation publique

La justification correspond aux pratiques permettant de soutenir une assertion auprès d'autres locuteurs.

Elle transforme une position individuelle en engagement discutable collectivement.

---

# Architecture fonctionnelle

On peut représenter les fonctions ainsi :

PRÉDICATION ↓ Qualification d'un élément

CONFIGURATION ↓ Organisation relationnelle d'une situation

INTERPRÉTATION ↓ Stabilisation du sens

ASSERTION ↓ Engagement d'un locuteur

INFÉRENCE ↓ Conséquences produites

ÉVALUATION ↓ Critères de recevabilité

JUSTIFICATION ↓ Stabilisation collective

---

# Ce que cette page établit

Cette page établit que, dans Protokin, une description n'est jamais une simple correspondance entre un énoncé et un état du monde.

Toute description implique plusieurs fonctions :

- qualifier ;
- configurer ;
- engager ;
- inférer ;
- évaluer ;
- justifier.

L'objet de Protokin n'est donc pas seulement le contenu des descriptions, mais les opérations par lesquelles certaines descriptions deviennent possibles, recevables et stabilisées dans un régime donné.

Je pense qu'il faut toutefois garder une hiérarchie : prédication / configuration / assertion sont les trois fonctions primaires. Les autres (interprétation, inférence, évaluation, justification) sont plutôt des fonctions secondaires ou transversales.

Le terme qui me semble particulièrement important pour Protokin est configuration, car il fait le pont entre :

le « space of causes » de Sellars (les éléments qui composent une situation),

le « space of reasons » (les engagements et justifications),

et l'idée protokinienne de régime descriptif.
