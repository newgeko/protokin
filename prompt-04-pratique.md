# Prompt section 04 — Les pratiques descriptives

## Fonction générale de la section

Cette section a pour fonction d'établir la dimension collective, normative et interactionnelle des descriptions.

Elle montre comment une description, une fois rendue possible par les conditions descriptives fondamentales, devient une pratique sociale dans laquelle des locuteurs peuvent :

- produire des descriptions ;
- les reprendre ;
- les évaluer ;
- les justifier ;
- les contester ;
- en répondre.

La section répond à la question :

> Comment une description devient-elle une pratique collective soumise à des normes, des engagements et des responsabilités ?

---

# Objectif rédactionnel

Rédiger les pages qui construisent le passage :

Description possible ↓ Description produite par un locuteur ↓ Description adressée à un auditeur ↓ Description évaluée collectivement ↓ Description recevable, valide ou contestable

La rédaction doit établir :

- la dimension sociale de la description ;
- la structure normative des pratiques descriptives ;
- les conditions d'évaluation des descriptions.

Elle ne doit pas encore développer :

- les transformations historiques ;
- les trajectoires temporelles ;
- les mécanismes de changement des régimes.

# Objet propre de la section

L'objet de cette section est :

> La description comme pratique sociale d'engagement, d'évaluation et de justification.

Elle porte sur :

- les positions des participants ;
- les relations entre locuteurs et auditeurs ;
- les normes descriptives ;
- les engagements assumés ;
- les procédures de justification.

Elle ne porte pas encore sur :

- l'évolution historique des descriptions ;
- la transformation des régimes ;
- les transitions entre configurations.

---

# Fonction propre des pages

Chaque page doit établir une fonction unique.

Elle doit répondre à :

> Quelle condition collective rend une description évaluable et transmissible ?

---

# Le locuteur

## Fonction de la page

Établir le locuteur comme position descriptive et normative au sein d'une pratique collective.

La page doit montrer que le locuteur n'est pas seulement :

- un individu qui produit un énoncé ;
- une source psychologique d'opinion.

Le locuteur est :

- une position dans un espace de description ;
- un participant capable d'assumer des engagements ;
- un agent soumis à des conditions de justification.

La page doit distinguer :

- locuteur ;
- individu biologique ;
- auteur empirique.

Elle ne doit pas :

- développer la position épistémique complète.

---

# L'auditeur

## Fonction de la page

Établir l'auditeur comme position d'évaluation, de reprise et de contestation des descriptions.

La page doit montrer que l'auditeur :

- reçoit une description ;
- examine ses conditions ;
- peut demander des justifications ;
- participe à la stabilisation ou à la transformation des pratiques.

Elle ne doit pas :

- réduire l'auditeur à un simple récepteur passif.

---

# Relation locuteur-auditeur

## Fonction de la page

Établir l'espace interactionnel dans lequel les descriptions deviennent publiques.

La page doit montrer que :

- une description implique une possibilité de reprise ;
- la signification dépend d'un espace partagé d'évaluation ;
- les désaccords font partie de la pratique descriptive.

Elle prépare :

- justification ;
- controverse ;
- audit.

---

# Position épistémique

## Fonction de la page

Établir que toute description est produite depuis une position disposant de ressources, contraintes et perspectives particulières.

La page doit analyser :

- les capacités d'accès ;
- les limitations ;
- les cadres d'attention ;
- les ressources descriptives disponibles.

Elle doit maintenir :

- la description située ;
- l'absence de point de vue absolu.

Elle ne doit pas :

- devenir une théorie générale de la subjectivité.

---

# Supports descriptifs incorporés

## Fonction de la page

Établir les dispositions corporelles et pratiques qui rendent certaines descriptions possibles.

La page doit montrer :

- le rôle des apprentissages ;
- l'incorporation des savoir-faire ;
- la formation de l'attention.

Exemples possibles :

- regard clinique ;
- geste professionnel ;
- compétence perceptive.

Elle ne doit pas :

- réduire la description à une capacité corporelle individuelle.

---

# Supports descriptifs externes

## Fonction de la page

Établir les médiations matérielles externes qui permettent l'inscription et la circulation des descriptions.

La page doit analyser :

- documents ;
- bases de données ;
- instruments ;
- archives ;
- interfaces.

Elle doit montrer que ces supports :

- conservent ;
- transportent ;
- contraignent ;
- transforment les possibilités descriptives.

---

# Supports descriptifs institutionnels

## Fonction de la page

Établir les structures institutionnelles qui organisent l'autorité descriptive.

La page doit analyser :

- rôles ;
- procédures ;
- certifications ;
- dispositifs de validation.

Elle doit montrer comment une institution rend certaines descriptions :

- recevables ;
- autorisées ;
- transmissibles.

---

# Pratique collective

## Fonction de la page

Établir que les descriptions existent dans des pratiques partagées.

La page doit montrer :

- que décrire est une activité coordonnée ;
- que les critères émergent dans des usages collectifs ;
- que les descriptions sont maintenues par des interactions.

Elle ne doit pas :

- confondre collectif et simple accumulation d'individus.

---

## Fonction de la page

Établir le cadre social dans lequel des descriptions acquièrent une signification partagée.

La page doit montrer :

- les conditions d'appartenance ;
- les règles de participation ;
- les formes d'apprentissage collectif.

Elle prépare :

- stabilisation ;
- transmission ;
- reproduction.

---

# Norme descriptive

## Fonction de la page

Établir les règles immanentes qui permettent d'évaluer les descriptions.

La page doit montrer :

- comment une communauté distingue correction et erreur ;
- comment les normes émergent des pratiques ;
- comment la validité dépend d'un régime descriptif.

Elle ne doit pas :

---

# Engagements descriptifs

## Fonction de la page

Établir ce qu'un locuteur assume lorsqu'il produit une description.

La page doit analyser :

- les conséquences inférentielles d'une assertion ;
- les obligations liées à une description ;
- la possibilité de contestation.

Elle prépare :

- responsabilité normative.

---

# Responsabilité normative

## Fonction de la page

Établir les responsabilités attachées aux engagements descriptifs.

La page doit montrer :

- qu'un locuteur peut être tenu responsable de ses descriptions ;
- que les engagements ont des conséquences pratiques ;
- que la responsabilité dépend d'une communauté d'évaluation.

---

# Inférences

## Fonction de la page

Établir les relations de conséquence autorisées dans un régime descriptif.

La page doit montrer :

- qu'une description implique des engagements ;
- que certaines conséquences sont légitimes ;
- que d'autres constituent des erreurs.

Elle prépare :

- justification ;

## Fonction de la page

La page doit analyser :

# Recevabilité

## Fonction de la page

Établir les conditions minimales permettant à une description d'entrer dans l'espace d'évaluation d'un régime descriptif.

La page doit montrer :

- qu'une description doit être admissible avant d'être jugée valide ;
- que la recevabilité dépend de pratiques collectives.

Elle prépare :

---

# Validité

## Fonction de la page

Établir la correction d'une description au sein d'un régime descriptif donné.

La page doit distinguer :

- validité ;
- vérité absolue ;
- stabilisation historique.

Elle doit montrer :

- qu'une description peut être valide relativement à un régime ;
- que cette validité est évaluée selon des critères internes.

---

## Fonction de la page

Établir comment une description acquiert une continuité temporelle et collective.

La page doit montrer :

---

## Fonction de la page

La page doit montrer :

- l'accumulation historique ;
- l'inertie relative ;
- le coût croissant de révision.

Elle ne doit pas :

- devenir une théorie générale du changement historique.

---

# Distinctions conceptuelles à maintenir

Toujours distinguer :

## Description et pratique descriptive

Une description est un contenu ou une opération.

Une pratique descriptive est l'ensemble des conditions sociales de production et d'évaluation.

---

## Validité et stabilisation

La validité concerne la correction.

La stabilisation concerne la persistance.

---

## Autorité et vérité

Une description peut être institutionnellement autorisée sans être définitivement correcte.

---

## Locuteur et individu

Le locuteur est une position normative, pas seulement une personne empirique.

---

# Contraintes spécifiques

Ne jamais :

- réduire les descriptions à des opinions individuelles ;
- traiter les normes comme extérieures aux pratiques ;
- confondre consensus et validité ;
- confondre pouvoir institutionnel et correction descriptive.

Éviter :

- les explications psychologiques ;
- les conceptions purement subjectives ;
- les visions purement sociales sans dimension normative.
