Protokin 🧭

Une démarche d’enquête pragmatiste, inférentialiste, réflexive et non-ontologique sur les pratiques descriptives.

Version : 26.08.212
Architecture : PROTO / KIN

Protokin en une phrase

Protokin enquête sur les conditions, fonctions et transformations par lesquelles des pratiques collectives rendent des différences descriptibles, discutables, justifiables, stabilisables, contestables et révisables.

Protokin ne produit pas une description de premier ordre du monde. Il enquête sur les pratiques par lesquelles des descriptions sont produites, utilisées, discutées, justifiées, stabilisées, contestées et transformées.

Protokin ne décrit rien. Il enquête sur la manière dont des pratiques rendent quelque chose descriptible.

L’enquête

Protokin ne part pas d'une ontologie générale destinée à déterminer ce que les choses sont en elles-mêmes.

Il part de problèmes rencontrés dans les pratiques descriptives : une distinction devient contestable, une description change de fonction, une explication est confondue avec une justification, une cause est prise pour une raison, une stabilisation est traitée comme une immobilité, ou encore une description est confondue avec ce qu'elle décrit.

L'enquête consiste alors à reconstruire les conditions dans lesquelles une pratique produit et maintient ses distinctions.

Elle demande notamment :

- dans quelle configuration corporelle et matérielle une pratique prend place ;
- sous quelles relations une différence devient pertinente ;
- pour quelle fonction une distinction est mobilisée ;
- sous quelle forme elle peut être justifiée, discutée ou contestée.

L'enquête ne cherche donc pas à remplacer une description par une autre. Elle cherche à déterminer ce que fait une description, dans quelles conditions elle peut fonctionner et ce qui permet de la transformer.

Une enquête réflexive

L'enquête porte également sur ses propres opérations.

Lorsqu'elle analyse une pratique descriptive, Protokin produit elle-même des distinctions, utilise des critères, sélectionne des relations et construit des descriptions.

Elle ne peut donc pas se placer hors de toute pratique descriptive pour en fournir le fondement absolu.

La réflexivité consiste à intégrer cette condition dans l'enquête :

«L'analyse des pratiques descriptives est elle-même une pratique descriptive.»

Cela implique notamment de distinguer :

- description et objet décrit ;
- analyse et justification ;
- condition d'une description et validité de cette description ;
- fonction d'une distinction et vérité de ce qu'elle permet de décrire.

La réflexivité n'est donc pas une introspection individuelle. Elle est une attention portée aux conditions et aux opérations de l'enquête elle-même.

Objet

Protokin porte sur les pratiques descriptives : les pratiques par lesquelles des différences deviennent descriptibles selon des fonctions, des relations, des critères et des formes de justification déterminés.

Une même configuration peut ainsi faire l'objet de descriptions différentes sans que ces descriptions aient la même fonction, le même statut ou les mêmes conditions de justification.

L'enquête porte alors moins sur la question :

«« Qu'est-ce que cette chose est réellement ? »»

que sur des questions telles que :

«« Comment cette configuration devient-elle descriptible ? »»

«« Quelle distinction la pratique produit-elle ? »»

«« Quelle fonction cette distinction accomplit-elle ? »»

«« Sous quelles conditions cette description peut-elle être maintenue, discutée ou révisée ? »»

Non-ontologie

Protokin ne choisit pas entre matérialisme, idéalisme, réalisme ou relativisme ontologique.

Il ne pose pas une ontologie première à partir de laquelle les différentes formes de description devraient être dérivées.

La question est plutôt :

«Sous quelles conditions une configuration peut-elle être décrite comme réelle, matérielle, causale, vivante, sociale, normative ou rationnelle dans une pratique déterminée ?»

Cette question ne suspend pas l'existence de ce qui est décrit.

Elle suspend l'attribution à une description particulière d'un privilège ontologique qui permettrait d'en dériver toutes les autres.

Protokin ne cherche donc pas à établir la description ultime d'une configuration, mais à examiner les conditions, fonctions et transformations des pratiques qui la rendent descriptible.

Principe de non-conversion

Les dépendances entre différents plans d'une pratique n'impliquent pas l'identité de leurs fonctions.

L'enquête maintient notamment les distinctions suivantes :

- cause ≠ raison ;
- genèse ≠ justification ;
- condition ≠ critère ;
- trace ≠ signification ;
- description ≠ objet décrit ;
- capacité ≠ performance ≠ validité ;
- fonction ≠ justification ;
- incarnation ≠ réduction biologique.

Une même configuration peut donc être prise dans plusieurs descriptions sans que les fonctions de ces descriptions soient convertibles les unes dans les autres.

Continuité des dépendances, discontinuité des fonctions, non-conversion.

La quadripartition

Toute enquête distingue quatre questions :

«Corps : dans quelle configuration corporelle et matérielle ?»

«Relation : sous quelles relations ?»

«Fonction : pour quelle fonction ?»

«Justification : sous quelle justification ?»

Aucune réponse à l'une de ces questions ne vaut, par elle-même, réponse aux trois autres.

La quadripartition constitue une matrice d'enquête et d'audit.

Elle n'organise ni une genèse, ni une hiérarchie, ni une succession de niveaux.

Corps ≠ Relation ≠ Fonction ≠ Justification.

PROTO / KIN

PROTO désigne le versant des contraintes corporelles, matérielles, biologiques et écologiques dans lesquelles les pratiques prennent place.

KIN désigne le versant des pratiques descriptives dans lesquelles des descriptions sont produites, utilisées, discutées, justifiées, transmises, stabilisées et révisées.

PROTO et KIN ne constituent ni deux substances, ni deux mondes, ni deux étapes d'une genèse.

PROTO n'est pas l'espace des causes et KIN n'est pas l'espace des raisons.

La continuité des dépendances n'implique pas la continuité des fonctions.

Règle architecturale

Chaque page de Protokin doit pouvoir répondre à sept questions :

1. Quelle fonction unique accomplit-elle ?
2. Où cette fonction est-elle établie dans l'architecture ?
3. Que s'interdit-elle d'établir ?
4. Quelles dimensions de la quadripartition met-elle au travail ?
5. Quelle conversion ou réduction neutralise-t-elle ?
6. De quelles fonctions établies dépend-elle ?
7. Quelles fonctions rend-elle ensuite possibles ?

Cette règle maintient la non-substitution des fonctions, évite les doublons et empêche les anticipations conceptuelles entre sections.

Elle constitue une règle de construction et d'audit du projet, non une nouvelle catégorie théorique.
