Le principe de la description située

Qui décrit, et avec quelles ressources ?

Fonction de ce principe

Le principe de la description située constitue le quatrième principe fondamental de Protokin.

Après avoir établi que toute activité descriptive s'enracine dans un couplage perception-action et que notre rapport au monde est toujours médiatisé par des descriptions, il devient nécessaire de répondre à une nouvelle question :

«Qui décrit, et avec quelles ressources une description devient-elle possible ?»

Protokin affirme qu'aucune description n'est produite depuis un point de vue abstrait, neutre ou universel.

Toute description est située.

Elle est toujours portée par un locuteur qui occupe une position au sein d'une pratique collective et qui mobilise un ensemble de ressources corporelles, matérielles, conceptuelles et sociales.

Décrire n'est jamais l'acte d'un esprit isolé.

C'est une activité située dans une trajectoire, au sein d'un réseau de pratiques et d'engagements.

---

Il n'existe pas de point de vue de nulle part

La philosophie a souvent recherché un point de vue parfaitement objectif, indépendant de toute situation particulière.

Protokin suspend cette hypothèse.

Toute description est produite depuis une position déterminée.

Cette position n'est pas une limitation qu'il faudrait dépasser.

Elle constitue la condition même de toute activité descriptive.

Décrire suppose toujours :

- une histoire ;
- une trajectoire ;
- des apprentissages ;
- des catégories disponibles ;
- des pratiques déjà stabilisées ;
- des instruments ;
- un langage ;
- une communauté capable d'en comprendre les usages.

Le locuteur ne décrit donc jamais depuis l'extérieur du monde qu'il décrit.

Il décrit toujours depuis une pratique dont il participe déjà.

---

Le locuteur est une fonction descriptive

Dans Protokin, le locuteur ne désigne pas simplement un individu biologique.

Il désigne la position depuis laquelle une description est effectivement produite.

Le locuteur est celui qui engage une description.

Cette fonction peut être assumée par :

- une personne ;
- un collectif ;
- une institution ;
- ou un dispositif technique reconnu comme participant à une pratique descriptive.

Ce qui définit le locuteur n'est pas son identité, mais sa capacité à produire une description susceptible d'être reconnue, discutée, corrigée ou transformée.

Le locuteur est ainsi une fonction descriptive avant d'être une identité psychologique.

---

Décrire, c'est mobiliser des ressources

Aucune description n'est produite à partir de rien.

Le locuteur mobilise continuellement un ensemble de ressources qui rendent son activité possible.

Ces ressources comprennent notamment :

Des ressources organiques

Le corps, les systèmes perceptifs, les capacités motrices, les habitudes incorporées et les mémoires biologiques constituent le premier support de toute activité descriptive.

Le locuteur ne perçoit ni n'agit indépendamment de cette organisation vivante.

---

Des ressources matérielles

Les descriptions s'appuient sur des instruments, des documents, des technologies, des dispositifs de mesure, des archives, des images, des textes et de multiples supports d'inscription.

Ces médiations rendent les différences détectables, conservables, comparables et transmissibles.

---

Des ressources conceptuelles

Le locuteur mobilise également des catégories, des distinctions, des concepts, des taxonomies et des régimes descriptifs hérités de sa pratique.

Ces ressources définissent ce qu'il est possible de distinguer, de qualifier et d'articuler.

---

Des ressources collectives

Aucune description n'est purement individuelle.

Le langage, les normes, les critères de recevabilité, les procédures de justification et les habitudes d'interprétation sont le produit de pratiques collectives.

Le locuteur hérite toujours d'un monde déjà organisé par d'autres descriptions.

---

La mémoire comme ressource descriptive

Les ressources mobilisées par le locuteur possèdent une dimension temporelle.

Protokin distingue notamment deux grandes formes de mémoire.

La mémoire organique désigne l'ensemble des dispositions incorporées dans l'organisme : apprentissages, habitudes perceptives, coordinations sensori-motrices, compétences acquises et traces biologiques.

La mémoire collective désigne les ressources stabilisées dans les pratiques sociales : langages, archives, techniques, classifications, institutions, traditions, normes et savoirs transmis.

Ces mémoires n'appartiennent pas au locuteur comme des propriétés privées.

Elles constituent des ressources descriptives auxquelles il participe et qu'il actualise au cours de sa trajectoire.

Le locuteur ne transporte donc pas son monde descriptif en lui.

Il traverse un monde déjà peuplé de descriptions auxquelles il contribue à son tour.

---

Toute description est un engagement situé

Parce qu'elle est située, une description engage toujours celui qui la produit.

Cet engagement ne porte pas seulement sur le contenu de la description.

Il engage également :

- les ressources mobilisées ;
- les critères retenus ;
- les catégories utilisées ;
- les inférences acceptées ;
- les responsabilités assumées.

Décrire revient ainsi à prendre position au sein d'un espace partagé de raisons.

La description est toujours une manière de participer à une pratique collective.

---

Une situation n'est pas une limitation

Qualifier une description de située ne signifie pas qu'elle serait arbitraire, subjective ou relative.

La situation désigne l'ensemble des conditions concrètes qui rendent une description possible.

Loin d'affaiblir la rationalité, cette reconnaissance permet de comprendre comment des descriptions peuvent être produites, évaluées, corrigées et transformées.

Ce ne sont pas les descriptions qui flottent au-dessus des pratiques.

Ce sont les pratiques qui rendent les descriptions possibles.

---

Conséquences pour Protokin

Le principe de la description située conduit à plusieurs conséquences fondamentales.

Le locuteur décrit toujours depuis une position.

Toute description mobilise des ressources organiques, matérielles, conceptuelles et collectives.

Les capacités descriptives sont historiquement acquises et socialement transmises.

Les engagements descriptifs sont inséparables des pratiques qui les rendent possibles.

Comprendre une description exige donc de reconstruire les conditions de sa production autant que son contenu.

---

Principe fondamental

Une description n'est jamais l'expression d'un sujet abstrait contemplant le monde depuis un point de vue extérieur.

Elle est l'activité située d'un locuteur qui mobilise, dans une trajectoire singulière, des ressources organiques, matérielles, conceptuelles et collectives afin de produire une description, d'en assumer les engagements et de participer à une pratique commune.

Comprendre une description, ce n'est donc pas seulement analyser ce qu'elle dit, mais aussi reconstruire la situation, les ressources et les pratiques qui rendent possible son énonciation.
