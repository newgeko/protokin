Ce que je trouve particulièrement réussi dans cette architecture

Elle suit une progression très naturelle :

1. Pourquoi ? (Introduction)


2. Avec quels engagements ? (Principes)


3. Quels sont les concepts ? (Architecture)


4. Comment une description se construit-elle ? (Fondements)


5. Qui décrit ? (Pratiques)


6. Comment les descriptions évoluent-elles ? (Dynamique)


7. Comment s'inscrivent-elles dans le temps ? (Temporalité)


8. Comment expliquent-elles ? (Explication)


9. Comment les analyser ? (Méthode)


10. Comment Protokin s'analyse-t-il lui-même ? (Réflexivité)


11. D'où vient-il ? (Héritages)


12. À quoi sert-il ? (Applications)
