Le principe de réflexivité

Comment les pratiques descriptives deviennent-elles elles-mêmes objets d'analyse ?

Fonction de ce principe

Toute description peut devenir à son tour l'objet d'une nouvelle description.

Cette propriété constitue l'un des principes fondamentaux de Protokin.

Contrairement à une conception où les méthodes d'analyse occuperaient un point de vue extérieur ou supérieur aux pratiques qu'elles examinent, Protokin affirme qu'aucune description n'échappe à la possibilité d'être décrite, discutée, justifiée ou révisée.

Le principe de réflexivité exprime cette possibilité.

Il établit que les pratiques descriptives possèdent la capacité de se prendre elles-mêmes pour objet d'analyse.

Cette réflexivité n'est pas un supplément facultatif de la pensée.

Elle constitue une propriété normale des pratiques descriptives dès lors que celles-ci disposent des ressources nécessaires pour rendre explicites leurs propres conditions de fonctionnement.

---

Décrire les descriptions

La réflexivité apparaît lorsqu'une pratique cesse momentanément de décrire son objet pour examiner la manière dont elle le décrit.

Le déplacement est fondamental.

Il ne consiste plus à demander :

«« Que décrit cette pratique ? »»

mais :

«« Comment cette pratique rend-elle cette description possible ? »»

L'analyse porte alors sur :

- les différences retenues ;
- les catégories mobilisées ;
- les critères de pertinence ;
- les formes de justification ;
- les engagements assumés ;
- les normes utilisées ;
- les supports matériels ;
- les pratiques collectives qui rendent cette description possible.

La description devient ainsi elle-même un objet de description.

---

La réflexivité est immanente

La réflexivité ne suppose aucun point de vue extérieur aux pratiques.

Elle ne repose pas sur une métathéorie située hors des régimes descriptifs.

Elle est exercée depuis une pratique descriptive particulière.

Autrement dit, toute analyse est elle-même produite :

- par un locuteur ;
- dans un régime descriptif ;
- avec certaines catégories ;
- selon certains critères ;
- à partir de certains engagements.

La réflexivité ne suspend donc jamais complètement les conditions de sa propre production.

Elle les rend progressivement explicites.

C'est pourquoi Protokin parle d'une réflexivité immanente.

---

L'audit comme forme organisée de la réflexivité

Dans Protokin, la réflexivité trouve sa forme méthodologique dans l'audit.

L'audit consiste à reconstruire les conditions de fonctionnement d'une pratique descriptive.

Il ne cherche pas à déterminer si une description correspond à un réel absolu.

Il examine notamment :

- les différences mobilisées ;
- les configurations descriptives ;
- les fonctions accomplies ;
- les engagements produits ;
- les régimes descriptifs ;
- les positions occupées ;
- les pratiques collectives ;
- les formes de stabilisation.

L'audit constitue ainsi une pratique réflexive organisée.

Il rend explicites les dépendances fonctionnelles qui soutiennent une description.

---

Toute méthode peut être auditée

La réflexivité possède une conséquence décisive.

Si toute description peut être auditée, alors les méthodes d'analyse elles-mêmes peuvent devenir l'objet d'un audit.

Cette possibilité interdit de transformer une méthode en fondement absolu.

Elle vaut également pour Protokin.

Les catégories de Protokin :

- peuvent être discutées ;
- peuvent être révisées ;
- peuvent être complétées ;
- peuvent être remplacées si une enquête le justifie.

Protokin ne revendique donc aucun privilège méthodologique définitif.

Il accepte de devenir lui-même l'objet des principes qu'il applique aux autres pratiques descriptives.

---

La réflexivité n'est pas une régression infinie

On pourrait croire que cette possibilité conduit à une succession infinie d'audits :

l'audit de l'audit,

puis l'audit de cet audit,

et ainsi de suite.

Protokin refuse cette conclusion.

La réflexivité n'exige pas que chaque analyse soit continuellement réanalysée.

Elle signifie simplement qu'aucune analyse n'est, en principe, soustraite à l'examen.

L'arrêt d'une enquête n'est donc pas déterminé par un fondement absolu.

Il est déterminé par les besoins de la pratique.

Lorsque les objectifs de l'enquête sont atteints, le collectif peut provisoirement suspendre la réflexivité et reprendre l'activité descriptive ordinaire.

La réflexivité est donc potentiellement illimitée, sans être pratiquement infinie.

---

Une condition de l'évolution des pratiques

La réflexivité joue un rôle essentiel dans la transformation des régimes descriptifs.

Une pratique ne peut évoluer que si elle devient capable d'examiner :

- ses propres catégories ;
- ses propres critères ;
- ses propres habitudes ;
- ses propres limites.

Cette explicitation permet :

- d'identifier des tensions ;
- de reconnaître des angles morts ;
- de diagnostiquer des incompatibilités ;
- d'imaginer de nouvelles configurations descriptives.

La réflexivité constitue ainsi l'une des principales sources de transformation des pratiques collectives.

Elle permet à une communauté de réorganiser progressivement ses propres conditions de description.

---

Conséquences pour Protokin

Le principe de réflexivité entraîne plusieurs conséquences importantes.

Il implique que :

- toute description peut devenir un objet d'analyse ;
- toute norme descriptive peut être explicitée ;
- tout régime descriptif peut être audité ;
- toute méthode peut être discutée ;
- aucune théorie ne possède une immunité critique.

Il implique également que Protokin lui-même constitue un régime descriptif particulier.

Il ne décrit pas les autres régimes depuis un point de vue absolu.

Il propose une manière située d'en reconstruire les dépendances fonctionnelles.

Ses propres concepts restent donc ouverts à la critique, à la révision et à la transformation.

Cette réflexivité constitue moins une faiblesse qu'une condition de cohérence avec les principes mêmes que Protokin défend.

---

Réflexion

La réflexivité ne consiste pas à sortir des pratiques descriptives pour les contempler depuis un point de vue supérieur.

Elle consiste à rendre progressivement explicites les conditions selon lesquelles ces pratiques fonctionnent, se stabilisent et se transforment.

En reconnaissant que ses propres catégories peuvent être examinées, discutées et révisées, Protokin applique à lui-même le principe qu'il reconnaît à toute pratique descriptive : aucune description n'est au-dessus de l'enquête.
