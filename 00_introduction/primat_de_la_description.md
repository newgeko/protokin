Le primat de la description

Deuxième principe fondamental de Protokin

Pourquoi la description est-elle première ?

Le premier principe de Protokin établit que toute activité descriptive s'enracine dans le couplage entre un organisme et son environnement.

Mais ce couplage ne suffit pas à produire un monde intelligible.

Les différences qui émergent de l'interaction avec le milieu ne deviennent descriptibles qu'à travers des pratiques collectives qui les organisent, les stabilisent et les rendent partageables.

Le second principe affirme ainsi que la description précède l'objet décrit comme objet de connaissance.

Cela ne signifie pas que le monde dépend des descriptions pour exister.

Cela signifie que le monde ne devient descriptible qu'au sein de pratiques qui rendent possibles certaines distinctions, certaines catégories et certaines inférences.

Protokin ne demande donc pas :

«« Comment décrire correctement un objet déjà constitué ? »»

Il demande :

«« Quelles sont les conditions qui rendent quelque chose descriptible dans une pratique donnée ? »»

La description devient ainsi l'unité fondamentale de l'enquête.

---

Décrire n'est pas représenter

La tradition représentationnaliste considère généralement qu'une description est une image plus ou moins fidèle d'une réalité préexistante.

Dans cette perspective, la description est seconde.

L'objet existerait d'abord.

La description viendrait ensuite le représenter.

Protokin inverse cette manière de poser le problème.

Une description n'est pas une copie.

Elle est une opération.

Décrire consiste à :

- sélectionner certaines différences ;
- les articuler entre elles ;
- les qualifier ;
- les inscrire dans un régime descriptif ;
- produire des engagements ;
- ouvrir certaines possibilités d'inférence ;
- fermer d'autres possibilités.

Une description transforme ainsi un ensemble de différences disponibles en une organisation intelligible pour un collectif.

---

Le monde devient descriptible

Le monde ne se présente jamais sous la forme d'un inventaire déjà organisé d'objets.

Chaque pratique descriptive construit un espace particulier de distinctions.

Selon les régimes descriptifs mobilisés, une même situation pourra devenir :

- un phénomène physique ;
- une maladie ;
- une infraction ;
- une œuvre d'art ;
- une émotion ;
- un fait économique ;
- un risque environnemental.

Il ne s'agit pas de dire que ces descriptions sont arbitraires.

Il s'agit de reconnaître qu'elles reposent sur des organisations différentes des possibilités descriptives.

Le monde descriptible est toujours le produit d'une pratique située.

---

La description comme prise de position

Décrire ne consiste jamais à enregistrer passivement une information.

Toute description engage celui qui la produit.

Décrire, c'est prendre position.

Cette prise de position mobilise :

- une trajectoire descriptive ;
- une mémoire organique et collective ;
- des catégories disponibles ;
- des instruments ;
- des supports matériels ;
- des habitudes d'enquête ;
- un régime descriptif particulier.

Une description possède donc toujours une dimension normative.

Elle ouvre certains engagements tout en excluant d'autres possibilités.

---

Les descriptions organisent les pratiques

Les descriptions ne servent pas uniquement à parler du monde.

Elles organisent également les pratiques collectives.

Une description permet notamment :

- d'orienter l'attention ;
- de coordonner des actions ;
- de distribuer des responsabilités ;
- de produire des classifications ;
- d'élaborer des institutions ;
- de transmettre des savoirs ;
- de construire des techniques.

Les pratiques humaines ne reposent jamais directement sur les choses.

Elles reposent sur des descriptions suffisamment stabilisées pour permettre une coordination collective.

---

Les descriptions sont historiques

Aucune description n'est définitive.

Chaque description possède une histoire.

Elle apparaît dans un contexte particulier.

Elle est transmise.

Elle est enseignée.

Elle est corrigée.

Elle est contestée.

Elle peut être remplacée ou réorganisée.

Le travail de Protokin consiste précisément à reconstruire cette dynamique historique des pratiques descriptives.

Ce ne sont pas seulement les connaissances qui évoluent.

Ce sont également les conditions permettant de décrire.

---

La pluralité des régimes descriptifs

Le primat de la description conduit à reconnaître qu'il existe plusieurs manières légitimes d'organiser un même domaine d'expérience.

Un phénomène peut être décrit selon différents régimes descriptifs.

Ces régimes ne sont pas nécessairement concurrents.

Ils peuvent être :

- compatibles ;
- complémentaires ;
- partiellement traduisibles ;
- incommensurables sur certains points.

L'objectif de Protokin n'est pas d'établir quel régime décrit enfin le monde tel qu'il est.

Son objectif est de reconstruire les conditions selon lesquelles chaque régime produit ses descriptions, ses engagements, ses critères de recevabilité et ses possibilités de transformation.

---

La description précède l'évaluation

Avant de demander si une description est recevable, valide ou justifiée, encore faut-il comprendre comment elle est produite.

C'est pourquoi Protokin accorde une priorité méthodologique à la description elle-même.

L'enquête protokinienne commence toujours par reconstruire :

- les différences mobilisées ;
- les configurations descriptives ;
- les catégories utilisées ;
- les fonctions accomplies ;
- les engagements produits ;
- les pratiques collectives impliquées.

Ce n'est qu'après cette reconstruction qu'il devient possible d'examiner les critères de justification propres au régime étudié.

La description précède ainsi l'évaluation, non parce qu'elle serait plus fondamentale ontologiquement, mais parce qu'elle constitue la condition d'intelligibilité de toute enquête.

---

Une conséquence réflexive

Le primat de la description vaut également pour Protokin.

Protokin ne décrit pas le monde depuis un point de vue extérieur.

Il produit lui-même des descriptions portant sur les pratiques descriptives.

Ses propres catégories peuvent être :

- explicitées ;
- discutées ;
- comparées ;
- révisées ;
- transformées.

Il ne constitue donc pas un méta-régime échappant à toute critique.

Il est un régime descriptif réflexif qui accepte d'être soumis aux mêmes exigences d'analyse que les autres régimes qu'il étudie.

Cette réflexivité constitue l'une des garanties méthodologiques de Protokin contre toute prétention au fondement absolu.

---

Réflexion

Nous n'habitons pas directement un monde d'objets déjà constitués.

Nous habitons des pratiques descriptives qui rendent certaines différences intelligibles, organisent nos engagements et rendent possibles nos formes de vie collectives.

Le projet de Protokin consiste à reconstruire la dynamique de ces pratiques, sans leur attribuer un fondement extérieur ni leur reconnaître un privilège définitif sur les autres.
