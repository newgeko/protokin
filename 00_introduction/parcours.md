# Parcours de lecture

> **Protokin peut être abordé selon plusieurs parcours de lecture.**
>
> Cette page n’établit pas les concepts du projet.
>
> Elle indique uniquement les chemins possibles entre les différentes parties de l’architecture.

---

# Fonction de cette page

La documentation Protokin est organisée selon plusieurs fonctions conceptuelles :

- introduction du projet ;
- définition de son statut ;
- présentation de son architecture ;
- méthode d’enquête ;
- analyse des tensions ;
- étude des transformations ;
- comparaison des puissances descriptives ;
- héritages philosophiques ;
- réflexivité ;
- applications.

Chaque parcours propose une manière différente d’entrer dans cette architecture.

Il ne s’agit pas d’un ordre obligatoire.

Les parcours indiquent des relations de dépendance et des chemins de compréhension.

# Principe général de lecture

Les parcours proposés ne constituent pas une hiérarchie entre les pages.

Ils indiquent seulement différentes manières de parcourir une même architecture conceptuelle.

Chaque page possède une fonction propre :

- certaines établissent des concepts ;
- certaines présentent des relations ;
- certaines proposent des méthodes ;
- certaines montrent des applications.

La compréhension globale de Protokin repose sur l’articulation progressive de ces fonctions.

---

# Formule synthétique

> **Il n’existe pas un seul ordre obligatoire pour lire Protokin.**
>
> **Les différents parcours permettent d’explorer une même architecture selon plusieurs entrées, sans modifier la fonction propre de chaque page.**
>
> **La documentation forme ainsi un réseau conceptuel où chaque page établit son objet, tandis que les autres pages préparent, relient ou prolongent son analyse.**
