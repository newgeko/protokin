# Prompt section 02 — Architecture générale

## Fonction générale de la section

Cette section a pour fonction de présenter l'organisation générale de Protokin avant l'élaboration détaillée de ses concepts.

Elle ne construit pas encore les notions particulières de l'architecture.

Elle établit la manière dont les différents éléments de Protokin s'articulent dans un ensemble fonctionnel cohérent.

La section répond à la question :

> Comment les différentes composantes de Protokin s'organisent-elles pour former une architecture d'analyse des pratiques descriptives ?

---

# Objectif rédactionnel

Rédiger une présentation architecturale permettant au lecteur de comprendre :

- les grands niveaux d'organisation de Protokin ;
- les relations fonctionnelles entre les concepts ;
- la progression générale de l'enquête protokinienne ;
- la logique de dépendance entre les sections.

La rédaction doit montrer une architecture.

Elle ne doit pas encore produire les développements conceptuels détaillés.

---

# Statut architectural de la section

Cette section appartient au niveau :

**Cartographie conceptuelle et organisation fonctionnelle.**

Elle intervient après :

- 00 — Se repérer ;
- 01 — Principes fondamentaux.

Elle prépare :

- 03 — Fondements descriptifs ;
- 04 — Pratiques descriptives ;
- 05 — Dynamique descriptive ;
- 06 — Temporalité ;
- 07 — Explication ;
- 08 — Méthode Protokin.

---

# Objet propre de la section

L'objet de cette section est :

> La structure relationnelle de l'architecture Protokin.

Elle porte sur :

- les niveaux d'organisation ;
- les relations entre concepts ;
- la circulation des opérations descriptives ;
- la progression de l'analyse.

Elle ne porte pas encore sur :

- la définition détaillée des concepts ;
- les exemples d'application ;
- les procédures d'audit.

---

# Fonction propre des pages

Chaque page doit établir une fonction architecturale unique.

Elle doit répondre à la question :

> Quelle organisation générale cette page rend-elle intelligible ?

---

# Architecture conceptuelle

## Fonction de la page

Établir la carte des principaux concepts de Protokin et leurs relations.

La page doit montrer :

- les grands ensembles conceptuels ;
- les dépendances entre niveaux ;
- la manière dont les concepts forment un réseau.

Elle doit présenter notamment :

- les conditions descriptives ;
- les pratiques descriptives ;
- les dynamiques de transformation ;
- les dimensions temporelles ;
- les modes d'explication ;
- les opérations d'enquête.

---

## Contraintes spécifiques

Cette page ne doit pas :

- définir complètement chaque concept ;
- remplacer les pages conceptuelles spécialisées ;
- produire un glossaire général.

Elle répond à :

> Où se situe chaque concept dans l'ensemble ?

et non :

> Que signifie précisément chaque concept ?

---

# Architecture fonctionnelle

## Fonction de la page

Établir la dynamique opératoire de Protokin.

La page doit montrer :

- comment une description apparaît ;
- comment elle devient partageable ;
- comment elle est évaluée ;
- comment elle se stabilise ;
- comment elle peut être transformée.

Elle doit présenter la logique générale :

Configuration rencontrée ↓ Couplage perception-action ↓ Configuration sémiotique ↓ Configuration descriptive ↓ Pratique collective ↓ Recevabilité ↓ Validité ↓ Stabilisation ↓ Transformation ↓ Audit

---

# Distinction fondamentale à maintenir

La section doit distinguer :

## Architecture conceptuelle

Elle répond à :

> Quels concepts composent Protokin ?

Elle organise :

- les notions ;
- les relations ;
- les dépendances.

---

## Architecture fonctionnelle

Elle répond à :

> Comment les opérations descriptives s'enchaînent-elles ?

Elle organise :

- les processus ;
- les transformations ;
- les séquences d'enquête.

---

# Niveaux architecturaux à respecter

La rédaction doit maintenir la distinction entre plusieurs niveaux.

## Niveau descriptif

Ce qui concerne :

- les descriptions ;
- les catégories ;
- les critères ;
- les objets descriptifs.

## Niveau pratique

Ce qui concerne :

- les locuteurs ;
- les auditeurs ;
- les communautés ;
- les engagements.

## Niveau temporel

Ce qui concerne :

- la stabilisation ;
- la sédimentation ;
- les trajectoires ;
- les transformations.

## Niveau méthodologique

Ce qui concerne :

- l'enquête ;
- l'audit ;
- l'examen réflexif.

---

# Relations fonctionnelles à expliciter

La section doit montrer que :

## Les principes rendent possible l'architecture

Les engagements philosophiques de la section 01 conditionnent l'organisation générale.

---

## Les fondements descriptifs constituent la base opératoire

Les concepts descriptifs rendent possible l'analyse des pratiques.

---

## Les pratiques descriptives introduisent la dimension normative

Les descriptions deviennent des engagements évaluables dans une communauté.

---

## La dynamique descriptive explique les transformations

Les descriptions ne sont pas seulement produites mais maintenues, contestées et modifiées.

---

## La temporalité décrit leur inscription historique

Les configurations descriptives acquièrent une durée et une trajectoire.

---

# Contraintes spécifiques

Ne jamais :

- transformer l'architecture en résumé complet de Protokin ;
- introduire les exemples avant les concepts ;
- développer une théorie générale du réel ;
- présenter les concepts comme des objets indépendants.

Éviter :

- les listes sans relations ;
- les classifications statiques ;
- les cartes purement descriptives.

L'architecture doit montrer des dépendances fonctionnelles.

---

# Relation avec les autres sections

Cette section :

## Suppose

- le statut du projet ;
- les principes fondamentaux.

## Prépare

- la construction progressive des concepts ;
- la lecture des sections suivantes.

## Ne remplace pas

- les pages spécialisées de chaque concept.

# Critère final de validation

Une page de la section 02 est réussie si le lecteur peut répondre :

- Quels sont les grands composants de Protokin ?
- Comment sont-ils reliés ?
- Pourquoi cette organisation est-elle nécessaire ?
- Quelle différence existe entre architecture conceptuelle et architecture fonctionnelle ?
- Comment les sections suivantes s'insèrent-elles dans l'ensemble ?

La section 02 doit fournir une carte de navigation conceptuelle sans se substituer aux constructions théoriques ultérieures.
