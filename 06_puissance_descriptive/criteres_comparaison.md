# Critères de comparaison descriptive

## Introduction

Comparer des descriptions ne consiste pas à déterminer simplement laquelle serait la plus vraie indépendamment de tout contexte.

Dans Protokin, une comparaison descriptive porte sur les capacités respectives de configurations descriptives à rendre certains aspects d’un domaine accessibles, articulables et stabilisables.

La comparaison nécessite donc des critères explicites.

Cette page présente les critères permettant d’analyser les puissances descriptives relatives.

> Elle ne définit pas la puissance descriptive elle-même.
>
> Elle établit uniquement les dimensions selon lesquelles différentes descriptions peuvent être comparées.

---

## Pourquoi comparer des descriptions ?

Des descriptions différentes peuvent porter sur un même domaine tout en poursuivant des fonctions distinctes.

Une comparaison descriptive ne cherche donc pas nécessairement à remplacer une description par une autre.

Elle cherche à examiner :

- ce qu’une description permet de rendre accessible ;
- les opérations qu’elle autorise ;
- les limites qu’elle rencontre ;
- les conditions dans lesquelles elle conserve sa pertinence.

Voir :

- [Puissance descriptive](puissance_descriptive.md)

---

## Critère d’extension descriptive

Un premier critère concerne l’étendue du domaine rendu descriptible.

L’analyse examine :

- combien de dimensions sont accessibles ;
- quels phénomènes peuvent être intégrés ;
- quelles relations peuvent être établies.

Une description possédant une extension plus large n’est pas nécessairement supérieure dans tous les contextes.

L’extension doit toujours être rapportée au domaine où la description opère.

---

## Critère de résolution descriptive

Une description peut également être comparée selon son niveau de résolution.

La résolution concerne la capacité à produire des distinctions fines.

Elle examine notamment :

- la précision des catégories mobilisées ;
- la capacité à différencier des situations proches ;
- la sensibilité aux variations pertinentes.

Une forte résolution peut cependant augmenter la complexité de la description.

---

## Critère d’articulation descriptive

Une description possède une puissance particulière lorsqu’elle permet d’articuler plusieurs dimensions d’un domaine.

L’analyse examine :

- les relations qu’elle établit ;
- les niveaux qu’elle peut relier ;
- les descriptions avec lesquelles elle peut entrer en relation.

Voir :

- [Relations entre descriptions](../02_architecture_conceptuelle/relations_descriptions.md)

La puissance descriptive dépend ainsi aussi de la capacité d’une description à participer à des articulations plus larges.

---

## Critère de stabilité descriptive

Une description peut être évaluée selon sa capacité à maintenir des distinctions et des relations dans le temps.

L’analyse porte notamment sur :

- la continuité des catégories utilisées ;
- la transmission des pratiques descriptives ;
- la conservation des engagements associés.

Voir :

- [Stabilisation et effet cliquet](../02_architecture_conceptuelle/stabilisation.md)

La stabilité ne constitue toutefois pas à elle seule une preuve de puissance.

Une description peut être fortement stabilisée tout en possédant un domaine limité.

---

## Critère d’adaptabilité descriptive

Une description peut également être comparée selon sa capacité à intégrer de nouvelles situations.

L’analyse examine :

- sa capacité de révision ;
- son ouverture à de nouvelles distinctions ;
- sa possibilité d’articulation avec d’autres descriptions.

Une description trop rigide peut perdre sa pertinence lorsque son environnement descriptif change.

Voir :

- [Innovation descriptive](../05_transformations/innovation.md)

---

## Critère de justification

La puissance descriptive dépend également des formes de justification qu’une description rend possibles.

L’analyse examine :

- les engagements associés ;
- les inférences autorisées ;
- les critères de recevabilité mobilisés.

Voir :

- [Engagements descriptifs](../02_architecture_conceptuelle/engagements.md)
- [Inférences et justifications](../02_architecture_conceptuelle/inferences_justifications.md)

Une description puissante n’est donc pas seulement une description riche en contenu, mais une configuration capable d’organiser des justifications cohérentes.

---

## Critère de portée pratique

Les descriptions peuvent enfin être comparées selon les pratiques qu’elles permettent d’orienter.

L’analyse examine :

- les actions rendues possibles ;
- les décisions qu’elles permettent d’organiser ;
- les transformations qu’elles peuvent accompagner.

Voir :

- [Primat du couplage perception-action](../02_architecture_conceptuelle/primat_perception_action.md)

La puissance descriptive possède ainsi une dimension pragmatique.

---

## Comparaison et absence de hiérarchie absolue

Les critères de comparaison ne conduisent pas nécessairement à établir une hiérarchie unique entre descriptions.

Une description peut être :

- plus précise dans un domaine ;
- plus intégratrice dans un autre ;
- plus stable historiquement ;
- plus adaptée à une pratique particulière.

La comparaison porte donc sur des capacités descriptives situées.

---

## Ce que cette page établit

Cette page établit que :

- comparer des descriptions nécessite des critères explicites ;
- la puissance descriptive possède plusieurs dimensions ;
- aucune dimension isolée ne suffit à établir une supériorité générale ;
- une description doit être évaluée selon son domaine de pertinence ;
- la comparaison descriptive porte sur des capacités d’accès, d’articulation, de stabilisation et de transformation.
