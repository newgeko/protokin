# Descriptions — statut et fonction dans Protokin

## Rôle des descriptions

Une description désigne une configuration stabilisée d’engagements portant sur un domaine donné.

Elle n’est ni une copie du réel, ni une représentation neutre, ni une simple formulation linguistique.

Elle constitue une organisation de distinctions, d’inférences et de critères de justification.

---

## Statut

Une description :

- n’est pas le réel ;
- n’est pas un régime ;
- n’est pas une vérité indépendante de toute condition ;
- n’est pas une interprétation arbitraire.

Elle est une configuration d’engagements descriptifs stabilisée dans un régime donné.

---

## Structure d’une description

Une description articule :

- un domaine visé ;
- des invariants sélectionnés ;
- des distinctions pertinentes ;
- des inférences autorisées ;
- des critères de justification.

---

## Relation avec les régimes

Un régime ne produit pas une description.

Il définit les conditions sous lesquelles une description peut être considérée comme valide, pertinente ou insuffisante.

Plusieurs régimes peuvent donc stabiliser plusieurs descriptions d’une même configuration.

---

## Relation avec le Content Layer

Le Content Layer fournit les configurations susceptibles d’être décrites.

La description constitue la forme stabilisée que prend cette configuration dans un cadre donné.

---

## Description et vérité

Protokin ne réduit pas la vérité à une description.

Il analyse les conditions sous lesquelles une description peut être tenue pour justifiée dans un espace normatif donné.

---

## Description et tensions

Une tension apparaît lorsque plusieurs descriptions d’une même configuration mobilisent des régimes dont les contraintes ne sont pas immédiatement compatibles.

---

## Description et transitions

Une transition ne modifie pas nécessairement le contenu décrit.

Elle modifie les conditions sous lesquelles une description peut être stabilisée.

---

## Principe final

Une description n’est pas une image du monde.

Elle est une stabilisation normative et inférentielle permettant à quelque chose de devenir descriptivement intelligible.
