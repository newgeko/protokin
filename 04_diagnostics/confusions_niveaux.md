# Introduction

Une grande partie des difficultés descriptives ne provient pas nécessairement d'informations incorrectes.

Elle provient souvent d'un déplacement non explicité entre plusieurs niveaux d'analyse.

Une description peut être parfaitement cohérente dans le niveau où elle fonctionne et devenir problématique lorsqu'elle est transférée dans un autre cadre sans justification.

Protokin nomme **confusion de niveaux descriptifs** toute opération dans laquelle des éléments appartenant à des plans d'analyse différents sont traités comme s'ils relevaient du même type de description.

L'objectif du diagnostic n'est donc pas de supprimer les différences entre niveaux.

Il consiste à identifier :

- quel niveau produit une description ;
- quel niveau reçoit cette description ;
- quelles transformations sont nécessaires pour passer de l'un à l'autre.

---

# 1. Principe général

Une description n'existe jamais indépendamment de son niveau d'inscription.

Elle possède :

- un domaine d'application ;
- des critères de correction ;
- des formes d'inférence ;
- des pratiques de validation.

Une confusion apparaît lorsque l'on effectue un passage implicite d'un niveau à un autre sans expliciter la transformation nécessaire.

Le problème n'est pas le passage lui-même.

Les passages entre niveaux sont indispensables.

Le problème est l'absence de médiation.

---

# 2. La confusion entre explication et justification

Une première forme fréquente de confusion concerne la relation entre causes et raisons.

Une explication causale répond généralement à une question du type :

> « Comment ce phénomène se produit-il ? »

Une justification normative répond plutôt à une question du type :

> « Pour quelle raison cette position est-elle acceptable ? »

Ces deux dimensions peuvent concerner une même situation.

Cependant, elles ne sont pas interchangeables.

---

## Exemple

Considérons l'énoncé :

> « Cette personne est responsable de son acte. »

Une analyse causale peut examiner :

- les processus cérébraux ;
- les conditions biologiques ;
- les mécanismes cognitifs.

Une analyse normative peut examiner :

- les engagements du locuteur ;
- les règles sociales ;
- les critères de responsabilité.

La confusion apparaît lorsque l'on conclut :

> « Puisque l'acte possède une explication causale, il n'existe plus de responsabilité normative. »

Le passage entre les deux niveaux n'est pas justifié.

---

# 3. La confusion entre objet descriptif et support descriptif

Un objet descriptif n'est pas identique au support matériel qui permet sa stabilisation.

Un texte, une image, un instrument ou une institution peuvent soutenir une description sans être eux-mêmes l'objet décrit.

---

## Exemple

Un article scientifique publié dans une revue constitue un support descriptif.

La théorie qu'il présente constitue une configuration descriptive.

Les deux sont liés mais ne doivent pas être confondus.

Dire :

> « La théorie est vraie parce qu'elle est publiée »

constitue une confusion entre :

- le support institutionnel de circulation ;
- les critères de validité propres au régime scientifique.

---

# 4. La confusion entre configuration et régime

Une configuration descriptive correspond à une organisation possible du sens.

Un régime descriptif correspond aux conditions selon lesquelles cette organisation devient recevable.

Une même configuration peut exister dans plusieurs régimes.

---

## Exemple

La configuration :

> « Intelligence artificielle »

peut apparaître dans :

- un régime scientifique ;
- un régime industriel ;
- un régime médiatique ;
- un régime politique ;
- un régime philosophique.

La confusion consiste à supposer que le simple fait de partager une configuration implique le partage du même régime de justification.

---

# 5. La confusion entre description et objet décrit

Toute description possède une relation avec ce qu'elle décrit.

Mais elle n'est jamais simplement identique à son objet.

Une confusion apparaît lorsque les propriétés d'une description sont attribuées directement à ce qu'elle décrit.

---

## Exemple : « Cette personne est mauvaise »

L'énoncé :

> « Cette personne est mauvaise »

semble être une description directe d'un individu.

Cependant, l'audit doit distinguer plusieurs niveaux :

- les comportements observés ;
- les interprétations produites ;
- les normes morales mobilisées ;
- la catégorie utilisée pour qualifier la personne.

La phrase peut fonctionner comme jugement moral dans un régime normatif.

Elle devient problématique si elle est traitée comme une propriété naturelle comparable à une caractéristique physique.

La confusion consiste alors à transformer une qualification normative en propriété descriptive objective.

---

# 6. La confusion entre niveau individuel et niveau collectif

Une autre confusion fréquente consiste à attribuer à un individu des propriétés qui émergent d'une organisation collective, ou inversement.

---

## Exemple

Une institution peut produire des comportements réguliers.

Mais il serait incorrect d'en déduire immédiatement :

> « Chaque individu possède naturellement les propriétés de l'institution. »

Inversement, expliquer un phénomène institutionnel uniquement par les intentions individuelles peut ignorer les mécanismes collectifs.

L'audit cherche alors à distinguer :

- les positions de locuteurs ;
- les pratiques collectives ;
- les structures institutionnelles ;
- les contraintes historiques.

---

# 7. La confusion entre histoire d'une description et description de l'histoire

Les descriptions possèdent une histoire.

Mais cela ne signifie pas que toute description historique est uniquement une construction arbitraire.

---

## Exemple

Dire :

> « Cette catégorie sociale possède une histoire »

signifie qu'elle a émergé dans des pratiques, des institutions et des usages particuliers.

Cela ne signifie pas nécessairement :

> « Cette catégorie est fictive et sans effets réels. »

La confusion vient d'un passage abusif entre :

- l'analyse historique d'une catégorie ;
- la négation de son efficacité pratique.

---

# 8. Relation avec les réductions descriptives

Les confusions de niveaux sont souvent associées aux réductions descriptives.

Une réduction apparaît lorsqu'un niveau est entièrement absorbé par un autre.

Exemples :

- réduire une norme à un mécanisme biologique ;
- réduire une institution à des intentions individuelles ;
- réduire une théorie scientifique à un simple discours social.

La confusion de niveaux constitue souvent le mécanisme permettant cette réduction.

Voir :

- [Réductions descriptives](reductions.md)

---

# 9. Relation avec l'éclectisme descriptif

L'erreur inverse existe également.

Elle consiste à juxtaposer des concepts appartenant à des niveaux différents sans expliciter leurs relations.

Exemple :

Utiliser simultanément :

- un concept biologique ;
- un concept moral ;
- un concept juridique ;

sans préciser comment ils s'articulent.

Cette opération produit un mélange descriptif plutôt qu'une véritable traduction entre régimes.

Voir :

- [Éclectisme descriptif](eclectisme.md)

---

# 10. Diagnostic protokinien

Lorsqu'une confusion de niveaux apparaît, l'audit pose plusieurs questions :

1. Quel niveau produit initialement cette description ?
2. Quel niveau reçoit cette description ?
3. Quelle transformation permet le passage ?
4. Les critères de validité restent-ils compatibles ?
5. Une traduction explicite est-elle possible ?

L'objectif n'est pas d'empêcher les déplacements.

Les déplacements sont nécessaires à l'activité descriptive.

L'objectif est de rendre visibles leurs conditions.

---

# 11. Principe de vigilance

Une description peut circuler entre plusieurs niveaux.

Mais elle ne conserve pas automatiquement :

- le même sens ;
- les mêmes critères de correction ;
- les mêmes engagements.

Tout déplacement descriptif demande donc une opération de traduction.

---

# Conclusion

Les confusions de niveaux descriptifs constituent un diagnostic central de Protokin.

Elles apparaissent lorsque des descriptions appartenant à des plans différents sont traitées comme si elles relevaient d'un même espace de justification.

L'audit protokinien ne cherche pas à isoler définitivement les niveaux.

Il cherche à comprendre :

- leurs différences ;
- leurs articulations ;
- leurs possibilités de traduction ;
- les erreurs produites par leurs déplacements implicites.

Une description devient plus robuste lorsque ses conditions de passage entre niveaux sont rendues explicites.

---

# Formule synthétique

> **Une confusion de niveaux descriptifs apparaît lorsqu'une description conserve son apparence de validité après avoir changé de niveau sans que les conditions de cette transformation soient explicitées.**

> **L'audit protokinien ne cherche pas à empêcher les passages entre niveaux, mais à rendre visibles les médiations nécessaires pour qu'ils deviennent intelligibles.**
