# Contraintes descriptives

## Introduction

Toute description possède des capacités propres, mais également des limites liées à son organisation interne.

Une configuration descriptive ne peut pas rendre tout élément également accessible, ni mobiliser indifféremment toutes les distinctions possibles.

Ces limitations ne constituent pas nécessairement des erreurs.

Elles correspondent aux conditions selon lesquelles une description fonctionne comme description déterminée.

Cette page examine les contraintes descriptives qui structurent l'espace des possibilités ouvert par une configuration.

> Elle ne constitue pas une théorie générale des limites.
>
> Elle identifie uniquement les contraintes internes qui orientent ce qu'une description peut produire, distinguer ou maintenir.

---

## Qu'est-ce qu'une contrainte descriptive ?

Une contrainte descriptive désigne une condition qui limite ou oriente les possibilités d'une configuration descriptive.

Toute description repose sur des choix de pertinence :

- certaines distinctions deviennent disponibles ;
- certains éléments deviennent comparables ;
- certains enchaînements inférentiels deviennent possibles ;
- certains objets deviennent identifiables.

Ces conditions rendent une description efficace, mais déterminent également son domaine d'application.

---

## Contraintes et fonctionnement descriptif

Les contraintes descriptives ne doivent pas être comprises uniquement comme des obstacles.

Elles participent aussi à la cohérence d'une description.

Sans certaines contraintes :

- aucune distinction stable ne pourrait être maintenue ;
- aucune catégorie ne pourrait être utilisée ;
- aucune pratique descriptive ne pourrait être coordonnée.

Une description fonctionne donc toujours dans un espace délimité de possibilités.

---

## Contraintes de sélection

Toute configuration descriptive sélectionne certains éléments comme pertinents.

Cette sélection dépend notamment :

- des catégories disponibles ;
- des supports mobilisés ;
- des objectifs pratiques ;
- des critères de reconnaissance.

Ce qui n'entre pas dans ces critères peut devenir moins accessible ou secondaire.

Voir :

- [Zones de silence descriptif](zones_silence.md)

---

## Contraintes catégorielles

Une description organise son domaine à travers des catégories.

Ces catégories permettent :

- d'identifier des régularités ;
- de comparer des situations ;
- de produire des distinctions.

Mais elles imposent également une certaine manière d'organiser ce qui apparaît.

Une catégorie peut ainsi faciliter certaines analyses tout en rendant d'autres distinctions plus difficiles.

---

## Contraintes inférentielles

Les descriptions ne consistent pas seulement en des catégories.

Elles impliquent également des relations entre propositions, observations et justifications.

Voir :

- [Inférences et justifications](../02_architecture_conceptuelle/inferences_justifications.md)

Une configuration descriptive détermine ainsi quelles conclusions peuvent être tirées à partir de certains éléments.

Certaines inférences deviennent disponibles tandis que d'autres restent impossibles ou non pertinentes dans ce cadre.

---

## Contraintes liées aux supports

Les possibilités descriptives dépendent également des supports mobilisés.

Voir :

- [Supports descriptifs](../02_architecture_conceptuelle/supports_descriptifs.md)
- [Supports incorporés et dispositions corporelles](../02_architecture_conceptuelle/supports_incorpores.md)

Un support permet certaines opérations descriptives mais peut également en limiter d'autres.

Un instrument, un langage ou une pratique incorporée rendent certaines dimensions accessibles selon leurs propres caractéristiques.

---

## Contraintes historiques et temporelles

Les descriptions héritent également de trajectoires antérieures.

Voir :

- [Strates temporelles et irréversibilités](../02_architecture_conceptuelle/strates_temporelles.md)

Les catégories, supports et pratiques déjà stabilisés peuvent orienter les possibilités descriptives futures.

Une configuration actuelle n'apparaît donc jamais dans un espace entièrement ouvert.

---

## Contraintes et puissance descriptive

Les contraintes descriptives ne diminuent pas nécessairement la puissance d'une description.

Une description gagne souvent en précision grâce aux contraintes qui organisent son domaine.

La question n'est donc pas de supprimer toute contrainte, mais d'identifier :

- quelles contraintes sont mobilisées ;
- ce qu'elles rendent possible ;
- ce qu'elles rendent difficile ;
- dans quel domaine elles restent pertinentes.

Voir :

- [Puissance descriptive](../06_puissance_descriptive/puissance_descriptive.md)

---

## Contraintes et diagnostics

L'identification des contraintes descriptives permet de distinguer plusieurs situations.

Une contrainte peut être :

- constitutive du fonctionnement normal d'une description ;
- révélatrice d'une limite interne ;
- source d'une réduction abusive ;
- responsable d'une zone de silence.

L'analyse doit donc déterminer la fonction exacte de la contrainte observée.

---

## Ce que cette page établit

Cette page établit que :

- toute description fonctionne dans un espace de possibilités déterminé ;
- les contraintes descriptives orientent ce qui peut être distingué, relié ou justifié ;
- ces contraintes sont nécessaires au fonctionnement descriptif ;
- elles peuvent provenir des catégories, des inférences, des supports ou des trajectoires historiques ;
- l'analyse d'une contrainte doit distinguer fonctionnement normal, limitation interne et dysfonctionnement descriptif.
