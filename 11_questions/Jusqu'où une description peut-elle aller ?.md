Dans l'architecture de Protokin, une description peut aller exactement jusqu'au point où elle épuise ses propres ressources d'organisation pour maintenir sa stabilité. Ce point d'épuisement, qui répond directement à la question de l'étendue des possibilités d'une description, correspond à ce que la théorie nomme une **limite interne**. 

**1. Le périmètre défini par les ressources propres**
Une description ne possède pas une portée infinie ou universelle. Son rayon d'action est strictement délimité par les conditions qui rendent son fonctionnement possible. Une configuration descriptive peut aller aussi loin que le permettent :
*   Les **distinctions** qu'elle est capable de mobiliser pour découper son environnement.
*   Les **engagements** qu'elle permet d'assumer et de justifier publiquement.
*   Les **formes d'organisation** et les **possibilités d'application** qu'elle offre face à une situation donnée.

Tant que ces ressources internes sont suffisantes pour préserver la cohérence pratique et l'intelligibilité de la configuration, la description continue de fonctionner, d'être recevable et de s'étendre au sein de sa pratique.

**2. La confrontation à l'insuffisance (l'arrêt de la progression)**
Une description ne peut plus avancer sous sa forme actuelle lorsque ces conditions d'organisation deviennent insuffisantes pour intégrer de nouvelles contraintes ou résoudre de nouveaux problèmes. 
Cependant, atteindre cette limite n'équivaut pas à se heurter à un mur infranchissable du monde. Protokin précise explicitement qu'une telle limite n'est ni une frontière absolue du réel, ni une impossibilité absolue ou un mystère insondable, ni une simple erreur logique. Elle désigne plutôt une difficulté relationnelle et située : la description ne parvient plus à articuler de manière cohérente le domaine qu'elle tente d'organiser.

**3. Le devenir de la description à sa frontière**
Que se passe-t-il lorsqu'une description ne peut plus aller plus loin ? Elle ne disparaît pas instantanément. Ce point d'arrêt devient lui-même le point de départ d'une nouvelle enquête (souvent menée par l'audit Protokin). Arrivée à ce stade de saturation, la description est forcée de s'examiner elle-même pour identifier :
*   Ce qu'elle permet encore de maintenir fonctionnel.
*   Ce qu'elle ne permet décidément plus d'organiser.
*   Les domaines spécifiques où une réorganisation devient inévitable.

C'est précisément à cette frontière que s'ouvre le champ des transformations. Pour que l'intelligibilité puisse aller au-delà, la configuration doit muter. Selon les cas, cela peut déboucher sur un **maintien provisoire** malgré les lacunes, une **modification locale** de ses catégories, une **réorganisation profonde**, ou encore une **transition descriptive** ouvrant vers une toute nouvelle orientation.

En somme, **une limite protokinienne n'arrête pas définitivement une description**. Elle marque simplement le moment charnière où une configuration a épuisé le potentiel de son cadre actuel, révélant ainsi le point exact où elle doit examiner ses propres conditions de fonctionnement pour pouvoir se reconfigurer.
