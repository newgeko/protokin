Dans l'architecture de Protokin et sous l'influence de l'inférentialisme, **l'inférence** est le mécanisme central qui donne à une description sa signification et sa portée normative. Une description n'apparaît jamais seule et ne fonctionne pas comme une simple étiquette passive posée sur un objet. Formuler ou adopter une description consiste toujours à occuper une position relationnelle dans un espace de conséquences et de justifications. 

Voici comment fonctionne concrètement l'inférence dans le déploiement d'une description :

**1. L'inférence comme articulation du sens**
L'inférence n'est pas définie comme une simple déduction logique ou mathématique formelle. Elle désigne plus largement **toute relation normative par laquelle une description peut être mobilisée pour soutenir, autoriser ou rendre intelligible une autre description** au sein d'une pratique. 
Comprendre une description ne consiste donc pas simplement à savoir à quelle chose elle fait référence dans le monde, mais à maîtriser le réseau inférentiel dans lequel elle s'inscrit. Cela implique de comprendre :
*   **Ce qu'elle autorise à déduire :** les conséquences pratiques ou théoriques qui suivent logiquement de cette affirmation.
*   **Ce qu'elle interdit d'affirmer :** les incompatibilités qu'elle génère avec d'autres descriptions concurrentes.
*   **Ce qui la soutient :** les prémisses, conditions ou engagements préalables qui permettent de justifier son application.

**2. Le lien entre inférence, engagement et justification**
Lorsqu'un locuteur énonce une description, il ne transmet pas seulement une information : il prend position et s'engage. La description insère le locuteur dans le "jeu social de l'offre et de la demande de raisons". 
*   **Les engagements :** L'inférence détermine la responsabilité du locuteur vis-à-vis des conséquences de son affirmation. Il devient engagé à accepter les conclusions qui en découlent et à éviter de tenir des propos incompatibles.
*   **La justification :** Justifier une description consiste tout simplement à **rendre explicites les relations inférentielles** qui la soutiennent. C'est rattacher la description à d'autres descriptions déjà admises et stabilisées par la communauté de locuteurs.

**3. L'inférence est toujours dépendante d'un régime descriptif**
Il n'existe pas de logique universelle applicable de la même manière à toutes les situations. Les inférences permises par une description varient radicalement selon le **régime descriptif** dans lequel la configuration est mobilisée. 
Par exemple, face au constat "Cette personne présente un danger", les inférences autorisées seront très différentes :
*   Dans un *régime médical*, l'inférence orientera vers une évaluation clinique ou un diagnostic.
*   Dans un *régime juridique*, elle conduira à l'ouverture d'une procédure ou à une qualification pénale.
*   Dans un *régime politique*, elle justifiera une décision collective ou institutionnelle.

**4. La vigilance contre les transferts inférentiels illégitimes**
Parce que l'inférence dépend du régime descriptif, Protokin utilise l'analyse inférentielle pour repérer les **confusions de niveaux** ou les **réductions abusives**. Par exemple, tirer directement une conclusion normative ou politique (ce qui doit être institué socialement) à partir d'une description purement causale ou biologique (un mécanisme de l'espace des causes) constitue un déplacement problématique. L'inférence normative nécessite l'introduction de règles supplémentaires qui ne sont pas contenues dans la simple description causale initiale.

En résumé, l'inférence est le moteur dynamique de la description : elle transforme de simples énoncés en un **réseau de positions connectées**. La stabilité historique et la puissance d'une description dépendent ultimement de la solidité et de la cohérence de ce réseau inférentiel au sein des pratiques collectives.
