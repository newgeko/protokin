Dans l'architecture de Protokin, un support descriptif désigne le milieu matériel, sémiotique ou institutionnel par lequel une configuration descriptive devient accessible, transmissible et analysable. 

Ces supports ne sont pas de simples réceptacles neutres : leur nature influence directement ce qui devient visible, ce qui peut circuler, être conservé ou comparé. Les sources distinguent deux grandes familles de supports : les **supports externes** et les **supports incorporés**, qui se déclinent en plusieurs catégories spécifiques.

Voici les différents types de supports descriptifs existants :

**1. Les supports textuels**
Ils englobent les livres, les articles (de presse et scientifiques), les archives, les textes de lois et les rapports. Leur fonction principale est de permettre la conservation durable et la transmission différée des configurations descriptives.

**2. Les supports visuels**
Cette catégorie comprend les photographies, les cartes, les schémas, les graphiques et les images scientifiques. Ils ont pour caractéristique d'organiser des formes particulières de visibilité, rendant accessibles des relations spatiales ou structurelles.

**3. Les supports instrumentaux**
Il s'agit des appareils de mesure, des capteurs, des dispositifs expérimentaux et de divers outils techniques. Ces supports sont indispensables dans l'image scientifique, car ils participent activement à la détection et à la stabilisation des objets scientifiques.

**4. Les supports institutionnels**
Les institutions agissent elles-mêmes comme des environnements de soutien pour les descriptions : on y trouve les administrations, les tribunaux, les écoles, les laboratoires ou encore les organisations professionnelles. Leur rôle est de maintenir des pratiques collectives de reconnaissance et de validation.

**5. Les supports numériques**
Cette catégorie moderne inclut les bases de données, les algorithmes, les plateformes et les systèmes d'information. Ces supports informatiques introduisent de nouvelles manières de faire circuler, de sélectionner et de stabiliser les descriptions.

**6. Les supports incorporés (ou dispositions corporelles)**
Contrairement aux supports externes (matériels ou institutionnels), certaines stabilisations descriptives sont directement portées par le corps et l'expérience des locuteurs, sans nécessairement prendre la forme d'un document ou d'une règle formulée. Ces supports incluent :
*   **Les habitudes, les compétences et la mémoire corporelle**.
*   **Les ajustements perceptifs et comportementaux**, tels que l'orientation de l'attention vers certains éléments, la coordination motrice, l'interprétation automatique de signaux ou l'anticipation de situations récurrentes.
*   Ces dispositions sont le fruit de **trajectoires d'apprentissage** (formelles, informelles, techniques ou culturelles). À mesure qu'une pratique se répète, les manières de percevoir et d'agir deviennent habituelles et soutiennent la description de façon implicite.

Dans une enquête protokinienne, l'identification de ces supports est souvent le point de départ de l'audit. Une même configuration descriptive gagne généralement en stabilité lorsqu'elle parvient à s'appuyer simultanément sur plusieurs de ces types de supports combinés.
