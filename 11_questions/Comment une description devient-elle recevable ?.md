Dans l'architecture de Protokin, une description ne devient jamais recevable (ou valide) par elle-même, ni par sa simple correspondance avec un réel absolu ou indépendant. La recevabilité n'est pas une propriété intrinsèque de l'énoncé, mais un statut dynamique qui s'acquiert lorsqu'une description est intégrée dans des pratiques collectives et satisfait aux exigences d'un cadre normatif précis. 

Pour qu'une description devienne recevable, elle doit franchir plusieurs étapes et s'inscrire dans trois dimensions fondamentales : l'évaluation par un régime descriptif, la prise d'engagements inférentiels, et la validation par une communauté de locuteurs.

### 1. La satisfaction des critères d'un régime descriptif
La recevabilité d'une description dépend toujours du **régime descriptif** dans lequel elle est mobilisée. Un régime définit les conditions locales d'intelligibilité : il détermine ce qui compte comme un objet pertinent, ce qui constitue une preuve, et ce qui est qualifié d'erreur. 

Pour être reconnue comme recevable (ou posséder le statut de "validité"), la description doit répondre à trois exigences dictées par ce régime :
*   **La cohérence descriptive :** La description doit maintenir une compatibilité et une articulation logique entre les concepts qu'elle utilise, les distinctions qu'elle opère et les relations qu'elle établit.
*   **La pertinence descriptive :** La description ne doit pas simplement être exacte dans l'absolu ; elle doit surtout réussir à organiser les distinctions qui sont pertinentes pour résoudre le problème posé à l'intérieur de ce régime spécifique.
*   **La compatibilité avec les contraintes du régime :** Elle doit scrupuleusement respecter les règles d'inférence, les méthodes de preuve et les procédures de correction acceptées par le régime. Par exemple, une description causale valide dans un régime biologique ne sera pas automatiquement recevable comme justification dans un régime normatif ou juridique.

### 2. L'inscription dans un espace d'engagements et d'inférences
Une description devient recevable lorsqu'elle quitte le stade de simple "information" pour devenir une **position normative** assumée par un locuteur. S'inspirant de l'inférentialisme de Robert Brandom, Protokin établit que décrire, c'est prendre position dans un « espace des raisons ».

Pour que sa description soit recevable, le locuteur doit assumer une véritable **responsabilité discursive** :
*   Il doit être capable de fournir des **justifications** publiques s'il est contesté.
*   Il doit autoriser et assumer les **inférences** (les conséquences logiques et pratiques) qui découlent de sa description. 
*   Il doit exclure et reconnaître les descriptions alternatives qui deviennent **incompatibles** avec la sienne.

### 3. L'évaluation par la communauté de locuteurs (la pratique collective)
Enfin, une description ne devient jamais pleinement opératoire par son seul contenu isolé : elle doit pouvoir être reprise, évaluée et maintenue au sein d'une **pratique collective**. 

La recevabilité est le résultat d'un processus social d'évaluation mené par une **communauté de locuteurs**. C'est cette communauté qui opère le suivi des engagements (le *scorekeeping*) :
*   Elle évalue les justifications apportées.
*   Elle corrige les erreurs par des mécanismes partagés.
*   Elle assure la transmission de ce qui est jugé pertinent.

**En synthèse**, une description devient recevable lorsqu'elle ne se contente pas de pointer un état de fait, mais qu'elle **survit aux critères de correction d'un régime descriptif**, qu'elle **s'articule à un réseau d'inférences assumées par un locuteur responsable**, et qu'elle **est reconnue comme opératoire par les pratiques de justification d'une communauté**.
