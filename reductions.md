# Réductions — risques d’absorption entre régimes descriptifs

> La réduction désigne, dans Protokin, une tentative de stabilisation d’une configuration descriptive par l’absorption d’un régime dans un autre.
>
> Elle devient problématique lorsque cette absorption prétend supprimer les conditions propres du régime réduit et produire une description exhaustive à partir d’un seul cadre de validité.
>
> La réduction n’est donc pas définie comme une simple erreur.
>
> Elle constitue une opération descriptive dont il faut analyser les conditions, les usages et les conséquences.

---

# 1. Fonction générale de l’analyse des réductions

Les réductions apparaissent principalement dans les situations où plusieurs régimes descriptifs entrent en tension.

Face à une difficulté d’articulation, une stratégie consiste à considérer qu’un seul régime possède la véritable capacité explicative et que les autres doivent être reformulés dans son vocabulaire.

Protokin examine alors :

- ce qui est conservé lors du déplacement ;
- ce qui est perdu ;
- quels critères changent de statut ;
- si les engagements du régime initial restent visibles.

Voir :

- [`tensions.md`](tensions.md)
- [`traductions.md`](traductions.md)

# 2. Statut de la réduction

## 2.1 La réduction comme relation entre régimes

Une réduction n’est pas un objet du monde.

Elle désigne une relation particulière entre cadres descriptifs.

Elle apparaît lorsqu’un régime tente de rendre compte d’un autre régime en utilisant uniquement ses propres catégories.

Exemple général :

Une description normative est reformulée uniquement dans un vocabulaire causal.

Le problème n’est pas que des causes existent.

Le problème apparaît lorsque les causes sont considérées comme suffisantes pour remplacer l’espace des raisons.

Voir :

[`causes_raisons.md`](causes_raisons.md)

---

## 2.2 Réduction légitime et réduction abusive

Protokin distingue :

## Réduction méthodologique limitée

Une description peut simplifier certains aspects d’un phénomène pour une question précise.

Cette opération peut être pertinente si :

- son domaine d’application est explicite ;
- ses limites sont reconnues ;
- elle ne prétend pas remplacer tous les autres régimes.

---

## Réduction abusive

Elle apparaît lorsque :

- un régime est présenté comme fondamental ;
- les autres régimes sont traités comme de simples illusions ;
- les critères propres au régime réduit sont supprimés.

---

# 3. Principe général du risque réductionniste

Le risque central de la réduction est l’aplatissement des différences de fonction entre régimes.

Chaque régime possède :

- des objets stabilisés ;
- des critères de validité ;
- des formes d’inférence ;
- des engagements spécifiques.

Une réduction excessive transforme ces différences fonctionnelles en différences supposées illusoires.

Elle remplace alors une analyse des relations entre régimes par une hiérarchie implicite.

---

# 4. Réduction causaliste

## 4.1 Définition

La réduction causaliste consiste à expliquer entièrement un contenu appartenant à l’espace des raisons par des éléments appartenant à l’espace des causes.

Elle reformule :

- les engagements comme des états ;
- les justifications comme des effets ;
- les décisions comme des mécanismes.

Voir :

[`causes_raisons.md`](causes_raisons.md)

---

## 4.2 Problème protokinien

Le problème n’est pas qu’une action possède des conditions causales.

Toute pratique humaine possède des conditions matérielles et biologiques.

La difficulté apparaît lorsque l’explication causale prétend remplacer la dimension normative de l’action.

Elle rend alors invisibles :

- les raisons invoquées ;
- les responsabilités assumées ;
- les critères de justification.

---

## 4.3 Conséquence

La réduction causaliste produit une perte de visibilité de l’espace des engagements.

L’agent n’apparaît plus comme un participant à un espace de justification.

Il devient uniquement un point de passage de processus.

---

# 5. Réduction normativisante

## 5.1 Définition

La réduction normativisante consiste à transformer directement un fait descriptif en règle normative.

Elle produit un déplacement :

```
Ce qui est observé

↓

Ce qui doit être fait
```

sans justification intermédiaire.

---

## 5.2 Exemples de structure problématique

Une régularité empirique peut être transformée abusivement en prescription.

Exemples généraux :

- une tendance statistique devient une norme ;
- une efficacité mesurée devient une obligation ;
- une pratique existante devient une justification.

---

## 5.3 Problème protokinien

La réduction normativisante confond :

- description ;
- justification ;
- prescription.

Elle modifie le statut modal d’un contenu sans expliciter cette transformation.

---

# 6. Réduction ontologisante

## 6.1 Définition

La réduction ontologisante apparaît lorsqu’un régime descriptif est présenté comme révélant la structure ultime du réel.

Elle transforme :

```
Une manière de décrire

↓

Une manière d’être du monde
```

---

## 6.2 Risque

Le régime cesse d’être considéré comme une condition d’intelligibilité.

Il devient une prétendue description directe de ce qui existe indépendamment de toute pratique.

Cette opération contredit le principe général de Protokin :

> Les régimes organisent les conditions de descriptibilité ; ils ne constituent pas les structures du réel.

Voir :

[`architecture.md`](architecture.md)

---

# 7. Réduction et destruction sémantique de l’objet

Chaque régime stabilise certains objets selon ses propres contraintes.

Une réduction abusive peut faire disparaître l’objet qu’elle prétend expliquer.

Exemple général :

Une promesse peut être décrite comme :

- un engagement institutionnel ;
- une relation normative ;
- une interaction linguistique.

Si elle est entièrement réduite à un événement physique ou neuronal, les propriétés qui permettent de parler d’une promesse disparaissent.

Le phénomène n’est pas mieux expliqué.

Il est transformé en autre chose.

---

# 8. Réduction et perte des engagements

Les descriptions ne sont pas seulement des représentations.

Elles impliquent des engagements.

Une réduction abusive peut effacer :

- les responsabilités ;
- les conséquences reconnues ;
- les obligations discursives ;
- les critères de correction.

Voir :

[`engagements.md`](engagements.md)

---

# 9. Réduction et statut de l’agent

Une réduction excessive peut transformer l’agent en simple objet causal.

Le problème apparaît lorsque :

- une décision devient uniquement un résultat ;
- une justification devient uniquement un effet ;
- une responsabilité devient uniquement une conséquence mécanique.

Protokin cherche à maintenir la distinction entre :

- expliquer un comportement ;
- comprendre une action comme engagement.

---

# 10. Réduction et audit Protokin

L’audit permet d’identifier les réductions en examinant :

1. Le régime initial.
2. Le régime importé.
3. Le déplacement effectué.
4. Les critères conservés.
5. Les critères perdus.
6. Les conséquences sur les engagements.

Voir :

[`audit.md`](audit.md)

---

# 11. Réduction et traduction

La réduction doit être distinguée de la traduction.

## Traduction

Une relation entre régimes conserve une différence de statut tout en permettant une articulation.

Voir :

[`traductions.md`](traductions.md)

---

## Réduction

Une relation de réduction tend à supprimer cette différence.

Elle cherche une équivalence complète là où il existe seulement une relation partielle.

---

# 12. Réduction et transition

Une transition Protokinienne ne consiste pas à absorber un régime dans un autre.

Elle consiste à modifier les conditions permettant aux descriptions de fonctionner ensemble.

Voir :

[`transitions.md`](transitions.md)

---

# 13. Critère de vigilance

Pour identifier une réduction problématique, Protokin pose une question centrale :

> Le déplacement entre régimes conserve-t-il les conditions de validité du contenu transféré ?

Si la réponse est négative, une perte descriptive apparaît.

---

# Conclusion

La réduction constitue un risque majeur dans l’analyse des relations entre régimes.

Elle devient problématique lorsqu’elle :

- transforme un régime particulier en explication universelle ;
- efface les critères propres d’un autre régime ;
- réduit les engagements à des mécanismes ;
- transforme les faits en normes ;
- confond une condition de description avec une structure du réel.

Protokin ne cherche donc ni à éliminer toute réduction, ni à interdire toute simplification.

Il cherche à déterminer :

- ce qui est transféré ;
- ce qui est perdu ;
- quelles conditions de validité sont modifiées.

---

# Formule synthétique

> **Une réduction devient problématique lorsqu’elle ne traduit plus une description dans un autre cadre, mais efface les conditions qui rendaient cette description intelligible.**
