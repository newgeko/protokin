# Prompt section 01 — Principes fondamentaux

## Fonction générale de la section

Cette section a pour fonction d'établir les engagements philosophiques fondamentaux qui rendent possible et intelligible l'ensemble de l'architecture de Protokin.

Elle ne développe pas encore les concepts opérationnels de l'architecture.

Elle définit le cadre de possibilité dans lequel les notions ultérieures pourront être construites :

- description ;
- configuration descriptive ;
- régime descriptif ;
- pratique collective ;
- norme descriptive ;
- enquête ;
- transformation.

La section répond à la question :

> Quels principes doivent être admis pour qu'une analyse protokinienne des pratiques descriptives soit cohérente ?

---

# Objectif rédactionnel

Rédiger une série de pages établissant les orientations fondamentales de Protokin.

Chaque page doit montrer :

- pourquoi ce principe est nécessaire ;
- quel problème conceptuel il résout ;
- quelles confusions il permet d'éviter ;
- quels développements ultérieurs il rend possibles.

Un principe n'est pas une conclusion empirique.

Un principe n'est pas une théorie complète.

Un principe est une orientation architecturale qui organise la construction des concepts.

---

---

# Objet propre de la section

L'objet de cette section est :

> Les engagements directeurs qui déterminent la manière dont Protokin analyse les descriptions.

Elle porte sur :

- les conditions générales de possibilité d'une description ;
- la position philosophique de Protokin ;
- les orientations méthodologiques fondamentales.

Elle ne porte pas encore sur :

- les mécanismes internes des descriptions ;
- les acteurs particuliers ;
- les opérations descriptives détaillées.

---

# Fonction propre des pages

Chaque page doit établir un principe unique.

Elle doit répondre à la question :

> Quelle condition fondamentale ce principe introduit-il dans l'architecture ?

---

## Le primat du couplage organisme-milieu

Fonction :

Établir que toute activité descriptive apparaît dans une relation dynamique entre un organisme et son milieu.

La page doit montrer :

- que la description n'est pas une opération détachée du vivant ;
- que toute activité cognitive suppose une situation d'engagement ;
- que le milieu n'est pas un simple objet extérieur déjà constitué.

Elle ne doit pas :

- établir l'énaction complète ;
- développer la théorie du couplage structurel.

---

## Le primat du couplage perception-action

Fonction :

Établir que la description émerge d'une dynamique d'interaction entre perception, action et ajustement.

La page doit montrer :

- que percevoir implique déjà une orientation pratique ;
- que l'action transforme les conditions de perception ;
- que la description commence dans une coordination avec le milieu.

Elle ne doit pas :

- remplacer la page sur le couplage organisme-milieu.

---

## Le primat de la description

Fonction :

Justifier le choix de la description comme point de départ de Protokin.

La page doit établir :

- que Protokin analyse les conditions sous lesquelles quelque chose devient descriptible ;
- que l'accès aux objets passe toujours par des pratiques descriptives ;
- que l'objet n'est pas étudié indépendamment des conditions de description.

Elle ne doit pas :

- définir encore la notion technique de description.

---

## Le primat de l'enquête

Fonction :

Établir que les descriptions émergent de processus d'enquête.

La page doit montrer :

- qu'une description répond à une situation problématique ;
- qu'elle résulte d'opérations d'exploration, de comparaison et de justification ;
- qu'elle peut être transformée lorsque les conditions changent.

Elle ne doit pas :

- détailler la méthode d'enquête protokinienne.

---

## Le principe de la description située

Fonction :

Établir que toute description est produite depuis une position, une pratique et un contexte déterminés.

La page doit montrer :

- que le locuteur possède une position descriptive ;
- que les descriptions impliquent des ressources et des contraintes ;
- que l'objectivité n'est pas une absence de situation.

Elle ne doit pas :

- développer la notion de position épistémique.

---

## L'espace des causes et l'espace des raisons

Fonction :

Établir la distinction entre deux formes d'intelligibilité mobilisées par Protokin.

La page doit présenter :

- l'espace des causes ;
- l'espace des raisons ;
- leur articulation sans réduction.

Elle doit maintenir :

- PROTO comme dimension des conditions causales ;
- KIN comme dimension normative et discursive.

Elle ne doit pas :

- transformer cette distinction en dualisme métaphysique.

---

## Le principe d'immanence normative

Fonction :

Établir que les normes descriptives émergent des pratiques elles-mêmes.

La page doit montrer :

- que les critères de correction sont internes aux régimes descriptifs ;
- que les normes sont produites et maintenues par des pratiques ;
- que Protokin ne prend pas une position normative extérieure.

Elle ne doit pas :

- développer la norme descriptive comme concept technique.

---

## Le principe des dépendances fonctionnelles

Fonction :

Établir que les concepts de Protokin forment une architecture relationnelle.

La page doit montrer :

- qu'aucun concept n'existe isolément ;
- que chaque notion possède une fonction ;
- que l'ordre de construction dépend des relations fonctionnelles.

Elle ne doit pas :

- présenter toute l'architecture détaillée.

---

## Le principe du pluralisme descriptif

Fonction :

Établir que plusieurs régimes descriptifs peuvent porter sur une même configuration rencontrée.

La page doit montrer :

- qu'une pluralité de descriptions est possible ;
- que différence ne signifie pas nécessairement erreur ;
- que les régimes doivent être comparés selon leurs propres critères.

Elle ne doit pas :

- établir la théorie complète des régimes descriptifs.

---

## Le principe de réflexivité

Fonction :

Établir que Protokin doit pouvoir appliquer ses propres outils à lui-même.

La page doit montrer :

- que l'architecture est une pratique descriptive ;
- qu'elle peut être examinée et transformée ;
- qu'elle n'occupe pas une position extérieure absolue.

Elle ne doit pas :

- développer la section 09 — Réflexivité.

---

## Le principe d'humilité épistémique

Fonction :

Établir la limitation volontaire du statut de Protokin.

La page doit montrer :

- que Protokin n'est pas une description ultime ;
- qu'il constitue un régime descriptif parmi d'autres ;
- qu'il doit accepter l'examen critique.

Elle ne doit pas :

- devenir une critique générale de toute philosophie.

---

# Distinctions conceptuelles à maintenir

Toujours distinguer :

## Principe et concept

Un principe rend possible un concept.

Il ne le remplace pas.

## Orientation et démonstration

Un principe organise l'analyse.

Il ne constitue pas une preuve empirique.

## Héritage philosophique et construction interne

Les influences philosophiques peuvent éclairer un principe.

Elles ne constituent pas directement les concepts internes de Protokin.

---

# Contraintes spécifiques

Ne jamais :

- présenter les principes comme des vérités métaphysiques ;
- transformer Protokin en système philosophique fermé ;
- confondre principe et définition ;
- anticiper les pages conceptuelles ultérieures.

Éviter :

- les formulations absolues ;
- les généralisations sur « la réalité en soi » ;
- les oppositions simplistes.

# Critère final de validation

Une page de la section 01 est réussie si le lecteur peut répondre :

- Pourquoi ce principe est-il nécessaire ?
- Quelle confusion évite-t-il ?
- Quel déplacement philosophique introduit-il ?
- Quels concepts ultérieurs dépendent de lui ?
- Quelle limite empêche-t-il d'établir ?

La section 01 doit fournir le socle philosophique de Protokin sans encore construire son architecture opérationnelle.
