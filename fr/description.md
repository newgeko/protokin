# Description — L'actualisation d'une configuration descriptive

> **Fonction de la page**  
> Cette page existe pour établir ce qu'est une **description** dans l'architecture de Protokin. Elle montre comment une configuration descriptive est actualisée sous la forme d'un contenu situé, susceptible d'être compris, discuté, évalué, contesté et transformé au sein d'une pratique descriptive collective.

---

## 1. Problème conceptuel

Une conception classique du langage considère souvent la description comme une simple représentation d'un monde déjà organisé en objets, propriétés et relations. Décrire reviendrait alors à reproduire, au moyen du langage, une réalité préalablement découpée.

Protokin adopte une autre perspective.

Une description n'est pas la copie d'un état de choses déjà constitué. Elle constitue une opération située qui s'inscrit dans une pratique collective. Décrire suppose déjà qu'un ensemble de différences ait été rendu disponible, organisé, stabilisé et articulé au sein d'une configuration descriptive.

Le problème auquel répond cette page est donc le suivant :

> **Comment une configuration descriptive devient-elle une description effectivement produite par un locuteur dans une pratique descriptive ?**

Autrement dit, qu'est-ce qui distingue un ensemble de possibilités descriptives d'une description effectivement réalisée ?

---

## 2. Définition fonctionnelle

Dans l'architecture de Protokin, on appelle **description** :

> **L'opération située par laquelle une configuration descriptive est actualisée sous la forme d'un contenu descriptif pouvant être interprété, discuté, évalué, contesté, justifié et transformé au sein d'un régime descriptif.**

Cette définition implique plusieurs conséquences.

La description n'est jamais indépendante des pratiques qui la rendent possible.

Elle ne constitue pas un simple contenu linguistique mais une opération qui mobilise des catégories, des critères, des distinctions, des supports et une position de locuteur.

Produire une description consiste à transformer un ensemble de possibilités descriptives en un contenu effectivement engagé dans une pratique collective.

Une description ouvre ainsi un espace de discussion où pourront intervenir des accords, des désaccords, des demandes de justification ou des révisions.

---

## 3. Ce que la description n'est pas

Pour éviter plusieurs confusions fréquentes, il convient de distinguer la description des autres niveaux de l'architecture.

### La description n'est pas une représentation

La description ne reproduit pas un monde déjà structuré.

Elle constitue une manière située d'organiser et d'expliciter des différences rendues disponibles dans une pratique.

Le rapport entre description et monde est médiatisé par des opérations, des supports, des catégories et des normes.

---

### La description n'est pas une configuration sémiotique

La configuration sémiotique rend certaines différences disponibles grâce à des inscriptions, des traces, des indices ou des signaux.

La description intervient ensuite en mobilisant ces différences pour produire un contenu intelligible.

Les traces ne sont pas encore des descriptions.

---

### La description n'est pas une configuration descriptive

La configuration descriptive organise les relations entre catégories, incompatibilités, contrastes et possibilités d'inférence.

Elle définit ce qui peut être décrit.

La description correspond à l'actualisation particulière d'une de ces possibilités.

Une même configuration descriptive peut ainsi donner lieu à plusieurs descriptions différentes.

---

### La description n'est pas une fonction descriptive

Les fonctions descriptives analysent les opérations réalisées au cours de la description.

Elles permettent notamment d'étudier :

- la prédication ;
- la qualification ;
- l'assertion ;
- l'inférence ;
- la justification.

La présente page établit uniquement ce qu'est une description comme opération générale.

---

### La description n'est pas un régime descriptif

Le régime descriptif n'est pas l'opération qui produit une description.

Il désigne les normes collectives qui permettront ensuite d'en apprécier la recevabilité, la pertinence ou la justification.

Une description peut donc exister avant d'être reconnue comme recevable.

---

## 4. Décrire comme actualisation

La notion d'actualisation occupe une place centrale dans Protokin.

Une configuration descriptive ne contient pas une seule description.

Elle organise un ensemble de descriptions possibles.

Décrire consiste à sélectionner, articuler et produire l'une de ces possibilités dans une situation déterminée.

Cette actualisation dépend notamment :

- de la position du locuteur ;
- des objectifs poursuivis ;
- des catégories mobilisées ;
- des critères disponibles ;
- des supports descriptifs utilisés ;
- du régime descriptif dans lequel l'opération prend place.

Une description n'est donc jamais une conséquence mécanique d'une situation.

Elle est toujours une opération située.

---

## 5. Les dimensions constitutives de toute description

Toute description mobilise simultanément plusieurs dimensions.

### Une dimension sémiotique

Elle s'appuie sur des différences déjà rendues disponibles.

---

### Une dimension conceptuelle

Elle organise ces différences au moyen de catégories, de relations et de distinctions.

---

### Une dimension pratique

Elle répond toujours à une activité particulière.

On ne décrit jamais indépendamment d'une pratique.

---

### Une dimension normative

Décrire engage un locuteur.

Une description peut être interrogée, contestée ou justifiée.

Elle introduit donc immédiatement des responsabilités descriptives.

---

### Une dimension collective

Les descriptions n'acquièrent leur intelligibilité qu'au sein de pratiques partagées.

Leur compréhension suppose des catégories communes, des critères d'application et des normes d'évaluation.

---

## 6. Les fonctions descriptives

Toute description réalise plusieurs opérations qui seront étudiées dans les pages suivantes.

Parmi elles :

- la **prédication**, qui attribue une propriété ;
- la **qualification**, qui inscrit une situation dans une catégorie ;
- la **configuration**, qui articule plusieurs éléments dans une organisation cohérente ;
- l'**assertion**, par laquelle un locuteur s'engage publiquement ;
- l'**inférence**, qui ouvre des conséquences descriptives ;
- la **justification**, qui rend possible la défense publique d'une description.

Ces fonctions ne sont pas développées ici.

La présente page établit seulement le cadre général dans lequel elles deviennent possibles.

---

## 7. Éclairage par les fils rouges

### « Le vélo est rouge »

La description ne consiste pas simplement à prononcer une phrase.

Elle actualise une configuration descriptive où des catégories chromatiques, des critères perceptifs et des usages linguistiques rendent cette qualification possible.

---

### « Cette personne est dangereuse »

La description mobilise des observations, des critères institutionnels, des pratiques professionnelles et des responsabilités normatives.

Elle ouvre immédiatement des possibilités d'inférence, de contestation et de justification.

---

### « Cette personne est mauvaise »

Cette description actualise une configuration morale.

Elle ne constate pas une propriété naturelle.

Elle engage un jugement susceptible d'être discuté, défendu ou rejeté selon les normes du régime mobilisé.

---

### Le botaniste et le bûcheron

Les deux acteurs traversent le même environnement.

Pourtant, ils actualisent des descriptions différentes parce qu'ils mobilisent des configurations descriptives distinctes.

Le premier décrit selon des catégories botaniques.

Le second décrit selon des catégories sylvicoles et techniques.

---

### Le patient aux urgences

Les mêmes inscriptions sémiotiques peuvent donner lieu à plusieurs descriptions.

L'infirmier produit une description de tri.

Le cardiologue produit une description clinique.

L'administration produit une description de prise en charge.

Ces descriptions actualisent des configurations différentes tout en portant sur une même situation.

---

## 8. Place dans l'architecture

La description constitue le point de passage entre les possibilités descriptives et les pratiques normatives.

La trajectoire fonctionnelle est la suivante :

1. Configuration rencontrée.
2. Couplage perception-action.
3. Configuration sémiotique.
4. Support descriptif.
5. Configuration descriptive.
6. **Description.**
7. Fonctions descriptives.
8. Régime descriptif.

La description marque l'apparition d'un contenu effectivement engagé dans l'espace des raisons.

---

## 9. Limites du concept

La description ne possède pas de pouvoir autojustificatif.

Produire une description ne démontre jamais qu'elle est correcte.

Sa recevabilité dépend toujours des normes du régime descriptif dans lequel elle est évaluée.

Par ailleurs, toute description est sélective.

Décrire consiste nécessairement à privilégier certaines différences, certaines catégories et certaines relations.

Toute description laisse donc d'autres aspects de la situation dans des zones de silence.

Cette limitation n'est pas un défaut accidentel.

Elle constitue une propriété normale de toute pratique descriptive.

---

## 10. Synthèse

La description occupe une position centrale dans l'architecture de Protokin.

Elle ne constitue ni une représentation du réel, ni une simple proposition linguistique.

Elle est l'opération par laquelle une configuration descriptive est actualisée sous la forme d'un contenu situé, inscrit dans une pratique collective et engagé dans un espace de raisons.

Elle transforme un ensemble de possibilités descriptives en une description effectivement produite, susceptible d'être discutée, justifiée, contestée ou révisée.
