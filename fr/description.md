# Description — Distinguer pratique, contenu et situation décrite

## Fonction

Cette page définit la **description** comme une pratique située qui retient et organise certaines différences afin de caractériser un objet, un événement, une relation ou une situation.

Elle distingue trois dimensions : l’activité descriptive, le contenu descriptif et la situation décrite. Cette distinction permet d’examiner ce qui est fait, ce qui est formulé ou mobilisé et ce dont il est question, sans les confondre.

Elle précise également les rapports entre la description et les ressources qui la rendent possible, ainsi que les limites des conclusions que l’on peut tirer de sa cohérence, de son utilité ou de sa stabilité.

## 1. Problème et définition

Les pratiques humaines mobilisent continuellement des descriptions pour identifier des situations, différencier des cas, établir des relations, expliquer des phénomènes et soutenir des décisions.

Décrire suppose de retenir certaines différences plutôt que d’autres. Les différences retenues dépendent notamment du problème examiné, des ressources disponibles et de la pratique dans laquelle la description intervient.

Une description destinée à repérer une dégradation ne retient pas nécessairement les mêmes caractéristiques qu’une description destinée à comparer des matériaux. Cette différence de sélection ne suffit pas à établir que les descriptions sont incompatibles. Il faut examiner ce qu’elles caractérisent, les fonctions qu’elles remplissent et les critères auxquels elles répondent.

Dans Protokin, une **description** désigne une pratique située qui retient et organise certaines différences pour caractériser ce dont elle traite.

Cette pratique peut produire un énoncé, un rapport, un tableau, une représentation graphique ou un ensemble d’inscriptions. Elle peut également reprendre, utiliser ou réviser des descriptions déjà disponibles. Elle ne se réduit donc ni à une phrase isolée ni à un acte linguistique particulier.

Pour éviter les ambiguïtés, cette page distingue :

- **l’activité descriptive** : ce qui est fait lorsqu’une description est produite, reprise, utilisée ou révisée ;
- **le contenu descriptif** : ce qui est formulé, inscrit ou mobilisé pour caractériser une situation ;
- **la situation décrite** : ce sur quoi porte la description, dans les limites de l’examen considéré.

Ces dimensions sont liées, mais elles ne sont pas interchangeables. Leur distinction permet de préciser ce qui est effectivement contesté lorsqu’une description est mise en question.

## 2. Activité descriptive, contenu et situation décrite

### 2.1. L’activité descriptive

L’activité descriptive désigne le travail accompli lorsqu’une personne ou un dispositif produit, reprend, utilise ou révise une description dans une pratique déterminée.

Elle peut comprendre plusieurs activités :

- sélectionner des informations ;
- observer ou mesurer certaines caractéristiques ;
- comparer des occurrences ;
- appliquer des catégories ;
- formuler des qualifications ;
- organiser des relations entre des éléments ;
- consigner ou transmettre des résultats ;
- reprendre une description à la suite d’une contestation.

Ces activités ne sont pas toutes nécessaires dans chaque cas. Leur articulation dépend du problème traité et des ressources disponibles.

L’activité descriptive doit être distinguée de ses conditions de production. Expliquer pourquoi une personne produit une description ne suffit pas à déterminer ce que celle-ci signifie ni si elle est adéquate.

De même, décrire une activité ne revient pas à justifier les conclusions qui en sont tirées. L’examen de ces raisons relève d’une question distincte.

### 2.2. Le contenu descriptif

Le contenu descriptif correspond à ce qui est formulé, inscrit ou mobilisé pour caractériser une situation.

Il peut être exprimé dans un énoncé, réparti entre plusieurs énoncés, conservé dans un document ou présenté sous une forme graphique ou tabulaire. Il peut également être provisoire, hypothétique ou contesté.

La présence d’un contenu descriptif ne signifie donc pas qu’il est effectivement affirmé par un locuteur, accepté par une communauté ou justifié selon les critères pertinents.

Il faut distinguer le contenu mobilisé de l’acte accompli en le formulant, ainsi que des conséquences que d’autres peuvent en tirer. Un même contenu peut être interrogé, supposé, cité ou affirmé selon les circonstances.

La description ne se confond donc pas avec l’assertion. Un contenu descriptif peut être utilisé dans une enquête sans que la personne qui le mobilise en assume l’affirmation.

Voir [Assertion](fr/assertion.md).

### 2.3. La situation décrite

La situation décrite désigne ce sur quoi porte la description, dans les limites où cette situation est considérée.

Elle ne se confond ni avec l’activité descriptive ni avec le contenu qui la caractérise. Une description peut être reformulée alors que la situation n’a pas changé. Inversement, la situation peut évoluer sans que le contenu descriptif soit immédiatement actualisé.

Cette distinction ne suppose pas que la situation soit connue indépendamment de toute pratique d’observation, d’identification ou de description. Elle signifie que les moyens employés pour la caractériser ne suffisent pas, à eux seuls, à établir ce qu’il en est.

Décrire une situation ne signifie donc pas la constituer. Si une pratique descriptive contribue également à transformer une situation, cette contribution doit être examinée séparément.

## 3. Distinctions avec les notions voisines

### 3.1. Description et configuration descriptive

Une **configuration descriptive** désigne l’organisation des différences, des catégories, des qualifications et des relations inférentielles mobilisées dans une pratique descriptive.

La description désigne une pratique située qui retient et organise certaines différences en s’appuyant sur des ressources disponibles. Elle ne se confond donc pas avec l’organisation de ces ressources.

Une configuration descriptive peut rendre certaines caractérisations possibles sans qu’elles soient effectivement produites. Inversement, une description particulière ne permet pas de reconstituer à elle seule l’ensemble des distinctions et des relations mobilisées dans la pratique.

Le rapport entre description et configuration descriptive doit être examiné à partir de la pratique concernée. Il ne constitue pas une succession nécessaire entre deux états.

Voir [Configuration descriptive](fr/configuration-descriptive.md).

### 3.2. Description et objet descriptif

Un **objet descriptif** désigne une différence stabilisée comme identifiable et réutilisable dans une pratique descriptive.

La description est une pratique qui organise des différences pour caractériser ce dont elle parle. L’objet descriptif désigne une différence maintenue comme identifiable dans cette pratique ; il ne désigne ni l’activité de décrire ni le contenu particulier d’une description.

Une description peut contribuer à maintenir, préciser ou réviser un objet descriptif. Cette relation ne garantit pas que l’identification soit correcte ni que les caractéristiques attribuées soient adéquates.

Voir [Objet descriptif](fr/objet-descriptif.md).

### 3.3. Description et référent

Le **référent** désigne ce à quoi une pratique descriptive se rapporte ou prétend se rapporter. La description est la pratique par laquelle certaines différences sont retenues et organisées pour caractériser ce dont il est question.

Ces notions ne sont pas interchangeables. Une description peut viser un référent sans le caractériser correctement. Plusieurs descriptions peuvent porter sur un même référent tout en répondant à des questions différentes.

La situation décrite et le référent ne doivent pas non plus être assimilés sans examen. La première désigne ce qui est caractérisé dans les limites d'une description ; le second concerne ce à quoi la pratique entend se rapporter. Leur relation dépend des pratiques d'identification et du problème considéré.

Voir [Référent](fr/referent.md).

### 3.4. Description, assertion et justification

Une description peut être formulée sous la forme d’une assertion, mais décrire et asserter ne désignent pas la même fonction.

Un contenu descriptif peut être envisagé comme hypothèse, consigné provisoirement ou cité sans être affirmé par la personne qui le mentionne. L’assertion désigne l’acte par lequel un locuteur avance un contenu et en assume les engagements discursifs associés.

La justification relève d’une autre question : quelles raisons, quels critères et quelles inférences permettent de défendre ou de contester une description ou une conclusion ?

Une description peut être cohérente avec les catégories utilisées, utile pour une tâche ou largement acceptée sans que ces propriétés suffisent à établir son adéquation à la situation examinée. Inversement, l’origine d’une description ou les intérêts associés à son emploi ne suffisent pas à la déclarer inadéquate.

Il faut donc distinguer la production d’une description, l’acte éventuel d’asserter son contenu et les raisons avancées pour le maintenir.

Voir [Assertion](fr/assertion.md) et [Justifier](fr/justifier.md).

## 4. Exemple discriminant : décrire l’humidité d’un bâtiment

Un technicien examine un mur présentant des traces d’humidité. Il réalise des observations, utilise un instrument de mesure et consigne ses résultats dans un rapport.

Trois éléments doivent être distingués :

- **Activité descriptive :** le technicien observe le mur, effectue des mesures et consigne les résultats selon une procédure.
- **Contenu descriptif :** le rapport indique les mesures obtenues et caractérise les zones où l’humidité a été relevée.
- **Situation décrite :** l’état du mur et les conditions matérielles considérées dans les limites retenues pour l’inspection.

Ces éléments sont liés, mais aucun ne garantit automatiquement les autres. Une mesure peut avoir été réalisée selon une procédure sans que son interprétation soit correcte. Le rapport peut être cohérent tout en laissant de côté une information pertinente. Le mur peut également se modifier après l’inspection sans que le rapport soit immédiatement mis à jour.

La révision du rapport peut alors répondre à plusieurs problèmes distincts : une erreur de mesure, une interprétation contestable, une délimitation insuffisante de la zone examinée ou une transformation de la situation.

Il ne faut pas traiter ces difficultés comme équivalentes. Une erreur de mesure n’est pas nécessairement une erreur de formulation ; une formulation correcte ne garantit pas l’adéquation du rapport à la situation ; une modification du rapport ne prouve pas, à elle seule, que le mur a changé.

L’exemple montre pourquoi l’activité descriptive, le contenu produit et la situation décrite doivent être distingués pour déterminer ce qui est effectivement contesté et ce qui doit être réexaminé.

## 5. Limites et portée de la notion

La définition proposée permet d’examiner la description comme une pratique située, sans la réduire à une représentation transparente de la situation ni en faire ce qui constitue cette situation.

Elle n’établit pas :

- qu’une description retient toutes les différences pertinentes ;
- que le contenu descriptif reproduit intégralement la situation décrite ;
- que toute description prend la forme d’une proposition ou d’une assertion ;
- que les descriptions portant sur un même référent sont nécessairement compatibles ou incompatibles ;
- que la cohérence, l’utilité ou la stabilité d’une description garantissent son adéquation ;
- que les conditions de production d’une description suffisent à la justifier ou à la réfuter ;
- que la révision d’une description implique nécessairement une transformation de la situation décrite.

Ces limites ne rendent pas les descriptions arbitraires. Les observations, les contraintes matérielles, les critères d’application et les résultats des examens peuvent soutenir ou mettre en défaut une description. Leur portée doit cependant être établie dans le problème considéré.

La description ne garantit donc pas elle-même sa validité. Son adéquation doit être examinée en tenant compte de ce qu’elle prétend caractériser, des éléments disponibles et des critères pertinents.

## Synthèse

Une description est une pratique située qui retient et organise certaines différences afin de caractériser un objet, un événement, une relation ou une situation.

L’enquête distingue l’activité descriptive, le contenu descriptif et la situation décrite. Elle examine leurs rapports sans les confondre avec la configuration descriptive mobilisée, l’objet descriptif stabilisé, le référent visé ou les fonctions d’assertion et de justification.

Une description peut être cohérente, utile ou stabilisée sans que ces propriétés suffisent à établir son adéquation. Celle-ci reste examinable et révisable à partir du problème traité, des éléments disponibles et des critères pertinents.

**Décrire n’est ni reproduire intégralement une situation ni la constituer : c’est retenir et organiser certaines différences dans une pratique dont la portée doit pouvoir être examinée.**
