Configuration — Organiser les dépendances descriptives

Fonction

Configurer organise les distinctions et les relations établies au cours de l’enquête afin de produire une description suffisamment déterminée pour être examinée, comparée et justifiée.

L’opération ne consiste ni à juxtaposer des éléments ni à leur attribuer une unité présupposée. Elle consiste à expliciter leur organisation, les dépendances qui les relient et les fonctions différenciées qu’ils remplissent dans une situation donnée.

Problème

Des éléments peuvent être distingués et des relations identifiées sans que leur organisation soit encore suffisamment déterminée.

Une description peut, par exemple, relever plusieurs propriétés, dépendances ou fonctions sans préciser comment elles s’articulent, lesquelles sont pertinentes pour le problème rencontré, ni ce que leur organisation permet d’établir.

Le problème est alors celui de leur configuration descriptive : comment organiser les distinctions et les relations sans réduire leurs différences, confondre leurs fonctions ou introduire une unité qui n’a pas été établie ?

Définition

Une configuration désigne un agencement déterminé d’éléments, de relations et de dépendances, considéré relativement à une question d’enquête.

La configuration ne désigne pas nécessairement une réalité matérielle, un système clos ou une totalité autonome. Elle peut concerner une situation matérielle, un organisme, un événement, une pratique, une relation ou une construction représentationnelle.

L’opération Configurer consiste à élaborer ou à réviser une description de cet agencement à partir des distinctions et des relations disponibles.

Elle suppose notamment de préciser :

- les éléments retenus et les limites de la configuration étudiée ;
- les relations et les dépendances entre ces éléments ;
- les fonctions différenciées qu’ils remplissent dans la configuration considérée ;
- les conditions dans lesquelles cette organisation peut être maintenue, modifiée ou remise en question.

Ces déterminations dépendent du problème étudié. Elles ne constituent pas une liste de propriétés que toute configuration devrait nécessairement posséder.

Configuration et description

Il faut distinguer la configuration décrite de la description qui en propose une organisation.

La première désigne l’agencement auquel l’enquête se rapporte. La seconde sélectionne et organise des distinctions, des relations et des fonctions pour le rendre descriptible.

Cette distinction interdit deux réductions symétriques.

D’une part, la configuration ne se réduit pas à la description qui en est faite. Une modification descriptive ne constitue pas, à elle seule, une transformation de l’agencement décrit.

D’autre part, la description ne reproduit pas automatiquement cet agencement. Elle dépend des distinctions retenues, des relations établies, de la question posée et des moyens disponibles pour éprouver ses résultats.

Une même configuration peut ainsi faire l’objet de descriptions différentes, notamment lorsque les pratiques mobilisées, les fonctions considérées ou les questions posées diffèrent. Cette pluralité ne suffit toutefois pas à établir que toutes ces descriptions sont également adéquates.

Place dans l’enquête

Configurer intervient après Relier et avant Justifier.

Relier permet d’établir des relations et des dépendances entre des éléments distingués. Configurer organise ces relations en une description déterminée. Justifier examine ensuite les raisons et les critères permettant de défendre, de contester ou de réviser cette description.

Cette succession indique une orientation de l’enquête, non une chronologie obligatoire. Une difficulté rencontrée lors de la justification peut conduire à revoir la configuration, à réexaminer une relation ou à redélimiter le problème.

La configuration demeure donc provisoire au sens méthodologique : elle peut être reprise lorsque les épreuves de l’enquête font apparaître une distinction insuffisante, une dépendance négligée ou une incompatibilité entre descriptions.

Ce que l’opération n’établit pas

Configurer ne suffit pas à établir :

- que la configuration décrite constitue une totalité autonome ;
- que les éléments retenus sont les seuls pertinents ;
- que les relations établies sont des relations causales ;
- que l’organisation descriptive correspond adéquatement à ce qu’elle prétend décrire ;
- que la cohérence de la configuration justifie les affirmations formulées à son sujet ;
- que la configuration décrite est elle-même constituée par l’opération descriptive.

La cohérence interne d’une description est une condition possible de son examen, non une garantie de son adéquation.

Épreuve et révision

Une configuration peut être éprouvée en modifiant les éléments retenus, en comparant plusieurs descriptions, en examinant des cas différents ou en substituant une relation à une autre.

Ces opérations permettent notamment de rechercher :

- si une distinction est indispensable à la description proposée ;
- si une relation supposée nécessaire dépend en réalité d’un contexte particulier ;
- si plusieurs fonctions ont été confondues ;
- si une autre organisation des éléments rend mieux compte du problème ;
- si la description résiste aux contre-exemples et aux changements de situation.

Une révision peut conduire à modifier la configuration descriptive sans que l’enquête ait encore établi une transformation de la configuration décrite. Elle peut également conduire à reconnaître que l’agencement étudié a changé et que la description doit en tenir compte.

Synthèse

Configurer consiste à organiser des distinctions et des relations en une description déterminée, afin de la rendre justifiable et révisable.

La configuration est un résultat descriptif provisoire, non une garantie de vérité ni un principe de constitution du référent.

Configurer, c’est organiser ce qui a été distingué et relié, sans confondre l’organisation descriptive produite avec l’agencement qu’elle cherche à décrire.
