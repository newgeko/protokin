# Relation locuteur-auditeur — L'espace interactionnel des pratiques descriptives

## Fonction

| Fonction | Définir l'espace interactionnel dans lequel les descriptions deviennent évaluables, discutables, justifiables et transmissibles au sein d'une pratique collective. |
| :--- | :--- |
| **Prépare** | L'analyse des engagements descriptifs, des normes descriptives et des pratiques de justification. |
| **Mobilise** | La distinction entre locuteur et auditeur comme positions complémentaires au sein d'un espace de raisons. |
| **Permet** | De comprendre comment une description individuelle devient une pratique collective soumise à évaluation. |

---

# Définition générale

La relation locuteur-auditeur désigne, dans Protokin, l'espace interactionnel au sein duquel une description acquiert un statut public.

Une description ne constitue pas seulement une relation entre un individu et un objet. Elle implique également une relation entre des positions au sein d'une pratique descriptive :

- une position qui produit, formule et assume une description ;
- une position qui reçoit, examine, questionne et évalue cette description.

La relation locuteur-auditeur constitue ainsi la condition par laquelle une description peut devenir un engagement descriptif soumis à des normes.

Elle ne désigne pas une simple communication d'information entre un émetteur et un récepteur, mais une structure normative où les descriptions peuvent être :

- acceptées ;
- contestées ;
- reprises ;
- précisées ;
- corrigées ;
- justifiées.

---

# Une relation constitutive de la description

Dans Protokin, une description n'existe pas uniquement comme contenu exprimé.

Elle existe comme élément d'une pratique où certains participants peuvent demander :

- « Pourquoi cette description ? »
- « Quelles catégories sont mobilisées ? »
- « Quels critères permettent cette qualification ? »
- « Quelles conséquences cette description autorise-t-elle ? »

L'auditeur introduit ainsi une dimension d'examen qui transforme une production descriptive en engagement public.

Production descriptive ↓ Locuteur ↓ Formulation d'un engagement ↓ Relation locuteur-auditeur ↓ Évaluation, contestation ou justification ↓ Stabilisation ou transformation descriptive

---

# La symétrie fonctionnelle des positions

La relation locuteur-auditeur ne suppose pas une séparation fixe entre deux catégories d'individus.

Un même participant peut occuper alternativement :

- une position de locuteur lorsqu'il produit une description ;
- une position d'auditeur lorsqu'il examine la description d'un autre.

Les positions sont donc fonctionnelles et réversibles.

Elles appartiennent à une pratique collective plutôt qu'à des individus déterminés.

Participant A → locuteur lorsqu'il décrit

Participant B → auditeur lorsqu'il évalue

Puis :

Participant B → locuteur lorsqu'il propose une autre description

Participant A → auditeur lorsqu'il examine cette proposition

La relation locuteur-auditeur organise ainsi une circulation des engagements descriptifs.

---

# L'auditeur comme condition normative

L'auditeur n'est pas seulement celui qui reçoit une description.

Il constitue la position depuis laquelle une description peut être soumise à des exigences :

- cohérence interne ;
- compatibilité avec des critères partagés ;
- possibilité de justification ;
- capacité à produire des inférences acceptables.

Sans cette position d'auditeur, la description resterait une expression privée.

La relation locuteur-auditeur introduit donc l'espace dans lequel une description devient susceptible d'être évaluée comme :

- pertinente ;
- insuffisante ;
- recevable ;
- contestable.

---

# L'espace des raisons

La relation locuteur-auditeur correspond principalement à l'inscription d'une description dans l'espace des raisons.

Le locuteur ne fournit pas seulement une représentation d'un état de choses.

Il prend un engagement qui peut être repris dans un réseau d'inférences.

L'auditeur peut alors :

- demander les raisons soutenant cet engagement ;
- examiner les conséquences inférentielles ;
- accepter ou refuser les implications proposées.

Ainsi, la relation locuteur-auditeur constitue l'une des conditions pratiques de la normativité descriptive.

Description ↓ Engagement du locuteur ↓ Examen de l'auditeur ↓ Réseau d'inférences ↓ Normes descriptives

---

# Relation et communauté de locuteurs

La relation locuteur-auditeur ne se limite pas à une interaction entre deux participants.

Elle s'inscrit dans des communautés de locuteurs où les descriptions circulent, se transmettent et se transforment.

Une communauté descriptive existe précisément parce que ses membres peuvent :

- produire des descriptions ;
- demander des justifications ;
- reconnaître certaines descriptions comme recevables ;
- contester certaines catégories ou certains critères.

La communauté n'est donc pas seulement un ensemble d'individus partageant des représentations.

Elle est un espace organisé par des relations d'engagement et d'évaluation.

---

# Relation et normes descriptives

Les normes descriptives émergent dans cet espace interactionnel.

Elles ne sont pas simplement imposées extérieurement aux descriptions.

Elles apparaissent à travers les pratiques où les participants évaluent mutuellement leurs engagements.

La relation locuteur-auditeur rend possible :

- la correction d'une description ;
- la révision d'une catégorie ;
- la modification d'un critère ;
- la transformation d'un régime descriptif.

Ainsi, les normes descriptives sont liées aux interactions effectives entre positions descriptives.

---

# Relation et conflits descriptifs

La relation locuteur-auditeur est également l'espace où apparaissent les conflits descriptifs.

Un auditeur peut refuser :

- une qualification ;
- une catégorie utilisée ;
- un critère considéré comme inadéquat ;
- une inférence proposée.

Ces désaccords ne constituent pas nécessairement des erreurs individuelles.

Ils peuvent révéler :

- des différences de régimes descriptifs ;
- des incompatibilités de critères ;
- des tensions normatives.

L'analyse protokinienne porte alors sur les conditions qui rendent possible le désaccord.

---

# Relation locuteur-auditeur et injustice épistémique

La relation locuteur-auditeur permet également d'analyser les asymétries dans les pratiques descriptives.

Une description peut être ignorée, rejetée ou dévalorisée non pas en raison de ses critères descriptifs, mais en raison de la position sociale ou institutionnelle du locuteur.

La relation entre locuteur et auditeur devient alors un lieu d'analyse des conditions de participation aux pratiques de connaissance.

Cette dimension prépare l'étude de l'injustice épistémique.

---

# Distinctions fondamentales

| Concept | Fonction |
| :--- | :--- |
| **Locuteur** | Position depuis laquelle une description est produite et assumée. |
| **Auditeur** | Position depuis laquelle une description est examinée et évaluée. |
| **Relation locuteur-auditeur** | Espace interactionnel où les engagements descriptifs deviennent publics et normatifs. |
| **Communauté de locuteurs** | Ensemble des participants partageant des pratiques d'évaluation descriptive. |
| **Norme descriptive** | Critère immanent permettant l'évaluation des descriptions. |

---

# Place dans l'architecture de Protokin

La relation locuteur-auditeur appartient aux pratiques descriptives.

Elle articule :

Configuration descriptive ↓ Description ↓ Locuteur ↓ Relation locuteur-auditeur ↓ Auditeur ↓ Engagements descriptifs ↓ Normes descriptives ↓ Justifications ↓ Validation ou transformation

Elle constitue le passage entre la production d'une description et son inscription dans une pratique collective.
