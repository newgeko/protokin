# Fonctions descriptives — Les opérations constitutives d'une description

> **Fonction de la page**  
> Cette page existe pour établir la notion de **fonction descriptive** dans l'architecture de Protokin. Elle montre qu'une description n'est pas un simple contenu linguistique, mais une opération complexe qui accomplit plusieurs fonctions distinctes au sein d'une pratique descriptive. Elle établit la typologie générale de ces fonctions sans développer chacune d'entre elles, lesquelles font l'objet de pages spécifiques.

---

## 1. Problème conceptuel

Une description est souvent réduite à un énoncé linguistique ou à une représentation d'un état de choses. Dans cette perspective, analyser une description reviendrait principalement à étudier sa structure grammaticale ou son contenu sémantique.

Cette réduction laisse pourtant dans l'ombre une question essentielle :

> **Que fait effectivement une description lorsqu'elle est produite dans une pratique collective ?**

Décrire ne consiste pas uniquement à produire une phrase. Une description organise des relations, attribue des propriétés, engage un locuteur, ouvre des conséquences et peut être soumise à des demandes de justification.

Le problème auquel répond cette page est donc le suivant :

> **Quelles sont les opérations constitutives réalisées par une description au sein d'un espace des raisons ?**

Protokin répond à cette question en distinguant plusieurs fonctions descriptives qui caractérisent ce que réalise une description dans une pratique collective.

---

## 2. Définition fonctionnelle

Dans l'architecture de Protokin, on appelle **fonctions descriptives** :

> **Les opérations conceptuelles, pragmatiques et normatives réalisées par une description lorsqu'elle est actualisée dans une pratique descriptive collective.**

Les fonctions descriptives ne désignent pas des parties d'une phrase.

Elles décrivent les opérations qu'une description accomplit au sein d'un espace des raisons.

Elles permettent ainsi d'analyser une description non seulement selon ce qu'elle dit, mais selon ce qu'elle fait.

---

## 3. Les fonctions descriptives ne sont pas des structures

Les fonctions descriptives doivent être distinguées des autres niveaux de l'architecture.

Elles ne sont ni des supports matériels, ni des configurations descriptives, ni des régimes descriptifs.

Leur rôle consiste à caractériser les opérations effectivement réalisées lorsqu'une description est produite.

Ainsi :

- une **configuration descriptive** organise les possibilités descriptives ;
- une **description** actualise l'une de ces possibilités ;
- une **fonction descriptive** qualifie l'opération réalisée par cette actualisation ;
- un **régime descriptif** en évalue ensuite la recevabilité.

---

## 4. Les fonctions constitutives

Toute description mobilise trois fonctions constitutives.

### La fonction de configuration

Une description organise plusieurs éléments dans une structure cohérente.

Elle ne juxtapose pas simplement des informations.

Elle construit un ensemble de relations qui rendent une situation intelligible.

La fonction de configuration correspond à cette opération d'organisation.

La page **Configuration** développera cette fonction.

---

### La fonction de prédication

Une description attribue des propriétés, des catégories ou des qualifications.

Elle établit des relations du type :

> « X est Y ».

Cette attribution constitue la fonction de prédication.

La page **Prédication** analysera cette fonction.

---

### La fonction d'assertion

Une description ne devient publique qu'à travers un engagement du locuteur.

Produire une description revient à prendre position devant une communauté susceptible de demander des justifications.

La fonction d'assertion correspond à cet engagement normatif.

Elle sera étudiée dans la page **Assertion**.

---

## 5. Les fonctions de développement

Une fois une description produite, d'autres fonctions prolongent son activité dans l'espace des raisons.

### L'interprétation

Toute description doit être comprise dans une pratique donnée.

L'interprétation détermine la manière dont son contenu prend sens dans une situation particulière.

---

### L'inférence

Une description autorise certaines conséquences tout en en excluant d'autres.

L'inférence décrit les relations de conséquence qu'une description ouvre dans une pratique.

---

### L'évaluation

Les descriptions ne sont pas toutes recevables.

L'évaluation applique les critères propres à un régime descriptif afin d'apprécier leur correction.

---

### La justification

Lorsqu'une description est contestée, le locuteur peut être amené à produire des raisons permettant de soutenir sa recevabilité.

La justification constitue cette pratique publique de production de raisons.

---

## 6. Articulation des fonctions

Les fonctions descriptives ne sont pas des opérations indépendantes.

Elles s'articulent continuellement au cours de l'activité descriptive.

Une description organise une situation, attribue des propriétés, engage un locuteur, ouvre des conséquences, fait l'objet d'évaluations et peut être justifiée.

La distinction entre ces fonctions est donc analytique.

Elle permet de reconstruire les différentes dimensions d'une même opération descriptive.

---

## 7. Éclairage par un fil rouge

Considérons l'énoncé :

> **« Le vélo est rouge. »**

Cette description mobilise simultanément plusieurs fonctions.

La fonction de **configuration** organise une situation dans laquelle un objet, une propriété chromatique et un contexte perceptif deviennent pertinents.

La fonction de **prédication** attribue la propriété « rouge » au vélo.

La fonction d'**assertion** engage publiquement le locuteur qui produit cette description.

Cette description autorise ensuite diverses **inférences**, peut être **évaluée** par d'autres locuteurs et, si elle est contestée, demander une **justification**.

Cet exemple montre qu'une description accomplit toujours plusieurs opérations simultanément.

---

## 9. Limites du concept

Les fonctions descriptives constituent une reconstruction analytique.

Dans les pratiques effectives, elles ne sont jamais isolées les unes des autres.

Une description mobilise généralement plusieurs fonctions de manière simultanée.

Par ailleurs, ces fonctions ne possèdent pas de valeur indépendamment des pratiques qui les rendent possibles.

Leur portée dépend toujours des normes, des critères et des engagements propres aux régimes descriptifs dans lesquels elles sont exercées.

---

## 10. Synthèse

Les fonctions descriptives permettent d'analyser ce qu'accomplit effectivement une description.

Elles montrent que décrire ne consiste pas simplement à produire un contenu linguistique.

Toute description organise une situation, attribue des propriétés, engage un locuteur, ouvre des conséquences, peut être évaluée et exige parfois une justification.

Cette typologie constitue la grammaire fonctionnelle des opérations descriptives sur laquelle repose l'ensemble de l'architecture de Protokin.
