# Onboarding — Enquête protokinienne

«À quelle situation problématique l'enquête s'applique-t-elle, et que devient la description lorsqu'elle rencontre d'autres descriptions ?»

L'enquête protokinienne ne commence pas par l'exposition de Protokin.

Elle commence par une situation.

Une situation dans laquelle quelque chose résiste : une description ne suffit plus, plusieurs qualifications ne s'accordent pas, une pratique rencontre une difficulté, une catégorie devient contestée, ou plusieurs régimes semblent parler d'une même situation sans parvenir à se coordonner.

Protokin n'intervient alors ni pour imposer une description correcte, ni pour produire une ontologie supplémentaire.

Il cherche à rendre descriptibles les opérations par lesquelles les descriptions se construisent, s'articulent, se transforment et parfois se substituent les unes aux autres.

---

## 1. Identifier le trouble

Quelle est la situation de départ ?

Décrire d'abord la situation sans chercher à la faire entrer dans le vocabulaire protokinien.

- Quel événement, problème ou désaccord déclenche l'enquête ?
- Qu'est-ce qui résiste aux descriptions ou aux pratiques existantes ?
- Où se situe précisément le blocage ?
- Quel changement rend la situation problématique ?

Il ne s'agit pas encore de déterminer qui a raison.

Il s'agit d'identifier ce qui fait problème.

Qu'est-ce qui ne fonctionne plus ?

Le trouble peut prendre des formes très différentes :

- difficulté pratique ;
- désaccord entre acteurs ;
- incompatibilité entre qualifications ;
- impossibilité de coordonner plusieurs descriptions ;
- catégorie devenue insuffisante ;
- changement du milieu ;
- conflit entre critères de reconnaissance ;
- décalage entre ce qui est mesuré et ce qui peut être reconnu.

Aucune de ces formes n'est présupposée.

---

## 2. Cartographier les descriptions

Une même situation peut être prise en charge par plusieurs pratiques descriptives.

Quelles descriptions sont effectivement mobilisées ?

Identifier :

- les disciplines ;
- les institutions ;
- les pratiques professionnelles ;
- les acteurs concernés ;
- les instruments ;
- les classifications ;
- les procédures ;
- les discours ordinaires ;
- les dispositifs techniques.

Ne pas supposer qu'il s'agit simplement de plusieurs points de vue sur un même objet.

L'enquête demande d'abord ce que chaque description rend effectivement descriptible.

Sur quoi ces descriptions reposent-elles ?

Une description n'existe pas indépendamment des pratiques qui la soutiennent.

Examiner notamment :

- les mesures ;
- les instruments ;
- les documents ;
- les bases de données ;
- les logiciels ;
- les inscriptions ;
- les gestes ;
- les habitudes perceptives ;
- les savoir-faire ;
- les procédures collectives.

La question n'est pas seulement :

« Que dit cette description ? »

mais aussi :

« Dans quelle pratique cette description peut-elle fonctionner ? »

---

## 3. Identifier les régimes de description

Les descriptions mobilisées ne répondent pas nécessairement aux mêmes critères.

Quels régimes sont en présence ?

Identifier, lorsque cela est pertinent, les régimes concernés et leurs relations.

Un régime de description ne désigne pas simplement un domaine académique ou une discipline.

Il désigne une configuration dans laquelle certaines choses peuvent être décrites, certaines distinctions opérées et certaines assertions évaluées selon des contraintes déterminées.

Quels sont leurs critères de correction ?

Pour chaque régime :

- Qu'est-ce qui compte comme donnée ?
- Qu'est-ce qui compte comme preuve ?
- Qu'est-ce qui compte comme erreur ?
- Qu'est-ce qui autorise une assertion ?
- Quelles pratiques permettent de corriger une description ?
- Quelles contraintes ne peuvent pas être simplement remplacées par celles d'un autre régime ?

Cette étape permet d'éviter une erreur fondamentale :

évaluer une description avec les critères d'un régime qui n'est pas celui dans lequel elle fonctionne.

---

## 4. Examiner les relations entre régimes

L'enquête ne s'arrête pas à leur juxtaposition.

Il faut examiner ce qui se passe entre eux.

Où les descriptions s'accordent-elles ?

Identifier les éléments qui peuvent circuler entre plusieurs régimes sans modification substantielle de leur fonction.

Où divergent-elles ?

Identifier les différences portant sur :

- les objets ;
- les qualifications ;
- les critères ;
- les échelles ;
- les temporalités ;
- les relations causales ;
- les engagements normatifs.

Que se passe-t-il lors du passage d'un régime à l'autre ?

Une description peut être :

- articulée ;
- transformée ;
- traduite ;
- transduite ;
- limitée ;
- ou substituée.

L'enquête doit déterminer quelle opération a effectivement lieu.

---

## 5. Rechercher les conversions indues

Le principe de non-substitution devient ici central.

Une description produite dans un régime ne doit pas être automatiquement convertie en engagement propre à un autre régime.

Examiner notamment :

**Réduction**

Un régime prétend-il absorber ce qu'un autre régime rend descriptible ?

**Confusion de niveau**

Une différence entre données, fonctions, qualifications ou justifications est-elle effacée ?

**Équivalence indue**

Deux descriptions différentes sont-elles traitées comme si elles étaient strictement équivalentes ?

**Réification**

Une qualification produite dans une pratique est-elle transformée en propriété substantielle de l'objet ou de l'agent ?

**Substitution**

Les critères d'un régime sont-ils utilisés pour décider à la place d'un autre régime de ce qui doit y être reconnu ?

Ces opérations ne sont pas présupposées comme des erreurs.

Elles constituent des hypothèses à examiner.

---

## 6. Examiner la dynamique de la description

Une description n'est pas seulement une représentation statique.

Elle peut modifier les pratiques dans lesquelles elle intervient.

Demander :

- Qu'est-ce que cette description permet de faire ?
- Que transforme-t-elle dans la situation ?
- Quelles nouvelles distinctions rend-elle possibles ?
- Quelles pratiques stabilise-t-elle ?
- Quelles autres descriptions rend-elle plus ou moins accessibles ?
- Comment se modifie-t-elle au contact de nouvelles contraintes ?

L'enquête porte ainsi sur la dynamique descriptive plutôt que sur la seule correspondance entre une proposition et un objet supposé déjà constitué.

---

## 7. Déterminer ce que l'audit a effectivement établi

Cette étape ne demande pas nécessairement une résolution.

L'audit peut conduire à :

- une distinction ;
- une incompatibilité ;
- une articulation possible ;
- une conversion identifiée ;
- une limite descriptive ;
- une absence de correspondance ;
- une transformation de qualification ;
- ou simplement une meilleure détermination du problème.

Il n'est donc pas nécessaire que l'enquête « débloque » la situation au sens pratique.

L'absence de résolution peut elle-même constituer un résultat descriptif.

La question finale est simplement :

« Qu'est-ce que l'enquête permet désormais de décrire qui ne l'était pas au début ? »

Et si rien de nouveau n'apparaît, cette absence doit également pouvoir être maintenue comme résultat.

---

## Principe directeur

L'enquête protokinienne peut ainsi être résumée par une chaîne minimale :

**SITUATION → TROUBLE → DESCRIPTIONS → RÉGIMES → CRITÈRES → ARTICULATIONS → TRANSFORMATIONS / CONVERSIONS → AUDIT**

Cette chaîne n'est pas un protocole obligatoire.

Toutes les situations ne nécessitent pas toutes les étapes.

L'enquête doit suivre les opérations effectivement rencontrées, et non forcer la situation à reproduire l'architecture de Protokin.

---

## Le principe de non-substitution

L'onboarding protokinien repose sur une contrainte simple :

« Ne pas répondre à la place du régime que l'on examine. »

Protokin ne décide pas :

- ce que la géologie doit reconnaître ;
- ce que la médecine doit diagnostiquer ;
- ce que la biologie doit expliquer ;
- ce que le droit doit qualifier ;
- ce que les acteurs doivent faire.

Il examine les conditions, les transformations et les passages par lesquels ces descriptions deviennent articulables ou incompatibles.

Ainsi, l'audit protokinien ne remplace pas les pratiques de premier ordre.

Il porte sur leurs relations descriptives.

---

## Exemple d'entrée : l'Anthropocène

La question n'est pas d'abord :

« L'Anthropocène existe-t-il ? »

On peut commencer autrement :

« Comment une transformation du système Terre peut-elle être massivement décrite, mesurée et étudiée tout en faisant l'objet d'un désaccord sur sa qualification comme nouvelle époque géologique ? »

L'enquête peut alors demander :

1. Quelles transformations sont effectivement décrites ?
2. Par quelles disciplines et quelles pratiques ?
3. Que signifie leur reconnaissance dans chacune d'elles ?
4. Quels critères permettent à la géologie de reconnaître une unité stratigraphique ?
5. Ces critères sont-ils ceux des autres régimes concernés ?
6. Que devient la qualification « Anthropocène » lorsqu'elle passe de la stratigraphie à l'histoire, à l'écologie ou au discours politique ?
7. Le désaccord porte-t-il sur les transformations elles-mêmes, sur leur périodisation, sur leur statut stratigraphique ou sur leur qualification ?
8. Une non-reconnaissance dans un régime est-elle indûment convertie en non-existence dans un autre ?
9. Quelles transformations de description se produisent effectivement au cours de ces passages ?

L'objectif n'est alors pas de conclure que l'Anthropocène est « vrai » ou « faux ».

L'objectif est de déterminer ce qui est reconnu, sous quelles conditions, dans quel régime, et ce qui se transforme lorsque la qualification circule entre ces régimes.

---

## À quoi sert cet onboarding ?

Il ne sert pas à apprendre Protokin avant de commencer une enquête.

Il sert à entrer dans Protokin par une enquête.

Le lecteur n'a donc pas besoin d'adopter préalablement :

- PROTO ;
- KIN ;
- la typologie des régimes ;
- les fonctions descriptives ;
- ou l'ensemble du vocabulaire protokinien.

Ces concepts peuvent apparaître au moment où la situation les rend nécessaires.

« On n'applique pas d'abord Protokin à une situation pour ensuite découvrir ce qu'elle contient.

On part d'une situation et l'on examine jusqu'où une enquête protokinienne permet d'en suivre les transformations descriptives. »

C'est cette épreuve qui détermine la portée effective de l'outil.
