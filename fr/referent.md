Référent — Ce à quoi une description se rapporte

«Fonction : Déterminer ce que signifie, dans Protokin, dire qu'une pratique descriptive se rapporte à quelque chose.

Prépare : L'analyse de la référence, de l'identification, de l'anaphore et de la prédication.

Mobilise : La configuration rencontrée, le contexte descriptif et les ressources de référence.

Permet ensuite : L'examen de l'adéquation entre une description et ce à quoi elle prétend se rapporter.

N'établit pas : Une théorie métaphysique de l'objet, une théorie générale de la référence ni la constitution du référent par le langage.»

---

1. Problème

Lorsque nous disons :

«« Ce bateau est ancien. »»

nous semblons savoir immédiatement de quoi nous parlons.

Mais plusieurs éléments sont en réalité impliqués.

Il faut pouvoir déterminer :

- ce que désigne « ce » ;
- quelle configuration est prise en compte ;
- selon quels critères elle est identifiée ;
- ce qui permet de la maintenir comme étant la même configuration ;
- et ce que signifie ensuite lui attribuer le prédicat « ancien ».

Une difficulté apparaît alors.

Si l'on considère que le référent est simplement produit par les pratiques descriptives, on risque de confondre référence et constitution du référent.

Si, inversement, on considère que la référence est une relation immédiate entre un mot et une chose parfaitement déterminée indépendamment de toute pratique, on néglige les conditions concrètes qui permettent effectivement de référer.

Le problème protokinien est donc :

«Comment rendre compte de la référence sans réduire le référent ni à une construction descriptive, ni à un objet entièrement déterminé indépendamment des pratiques qui permettent de l'identifier et d'en parler ?»

---

2. Définition fonctionnelle

Dans Protokin, le référent désigne :

«ce à quoi une pratique descriptive se rapporte lorsqu'elle identifie quelque chose comme étant le sujet ou le terme d'une description.»

Le référent peut être :

- une configuration matérielle ;
- un organisme ;
- un événement ;
- une relation ;
- un processus ;
- une institution ;
- une représentation ;
- ou toute autre configuration susceptible de devenir le point de référence d'une pratique descriptive.

Le référent n'est donc pas défini par une substance particulière.

Il est défini par une relation de référence effectivement établie dans une pratique.

Cette définition ne signifie pas que la pratique crée ce à quoi elle se rapporte.

Elle signifie que le fait de référer est une opération qui doit pouvoir être accomplie dans des conditions déterminées.

---

3. Référent et configuration

Le référent doit être distingué de la description qui permet de l'identifier.

Une configuration peut présenter certaines continuités matérielles, biologiques, historiques ou relationnelles indépendamment de la manière dont elle est décrite.

Une pratique peut cependant la sélectionner, la délimiter et la désigner selon différents critères.

Par exemple, un même bateau peut être décrit comme :

«un objet matériel ;»

«un moyen de transport ;»

«un navire juridiquement enregistré ;»

«une épave historique ;»

«le même bateau qu'un navire identifié plusieurs décennies auparavant.»

Ces descriptions ne fabriquent pas nécessairement plusieurs objets matériels.

Elles peuvent déterminer différentes manières de référer à une même configuration.

Il faut donc distinguer :

«configuration référée ≠ description de la configuration»

et :

«référence ≠ constitution du référent.»

---

4. Référence et identification

Référer suppose généralement qu'une configuration puisse être distinguée d'autres configurations pertinentes.

Cette identification peut mobiliser :

- une position ;
- une perception ;
- un nom ;
- une description ;
- un document ;
- une mesure ;
- une continuité matérielle ;
- une histoire d'usage ;
- une relation institutionnelle ;
- une chaîne d'anaphores.

L'identification n'est cependant pas nécessairement une opération purement perceptive.

Dire :

«« Le même bateau qu'hier »»

ne repose pas uniquement sur ce qui est perceptuellement présent.

La référence peut dépendre d'une continuité reconstruite à partir de traces, de documents, d'usages ou d'autres pratiques.

Ainsi :

«identifier ≠ simplement percevoir.»

Et :

«référer ≠ simplement nommer.»

---

5. Référent et objet descriptif

Protokin distingue le référent de l'objet descriptif.

Un objet descriptif est :

«une différence stabilisée comme identifiable et réutilisable dans une pratique descriptive.»

Cette stabilisation permet à une pratique de parler de quelque chose de manière répétable.

Elle peut concerner :

- une catégorie ;
- une configuration ;
- un événement ;
- une relation ;
- une entité historique ;
- une représentation.

Mais cette stabilisation ne doit pas être convertie en constitution du référent.

Une pratique peut stabiliser :

«« le même bateau »»

sans avoir créé le bateau.

Elle peut également modifier les critères permettant de l'identifier sans modifier nécessairement la configuration à laquelle elle se rapporte.

La distinction est donc :

«référent = ce à quoi l'on se rapporte»

«objet descriptif = ce qui est stabilisé comme identifiable et réutilisable pour pouvoir s'y rapporter.»

---

6. Référent et prédication

La référence précède fonctionnellement la prédication au sens minimal.

Pour dire :

«« Ce bateau est rouge. »»

il faut pouvoir déterminer à quoi renvoie « ce bateau ».

La prédication peut alors appliquer le prédicat « rouge » à cette référence.

On peut donc distinguer :

«référence : de quoi parle-t-on ?»

«prédication : qu'en dit-on ?»

Cette distinction ne constitue pas nécessairement une succession temporelle.

Une même expression peut contribuer simultanément à identifier et à prédicer.

Elle permet simplement de distinguer deux fonctions.

La référence détermine le pôle auquel l'énoncé se rapporte.

La prédication détermine ce qui lui est attribué.

---

7. Référent et contexte

Le contexte joue un rôle déterminant dans la référence.

Dans :

«« Il est bleu. »»

le pronom « il » ne permet pas, pris isolément, de déterminer son référent.

La référence dépend de ce qui a été établi dans la situation.

Par exemple :

«— Tu vois Paul ?
— Oui.
— Il est bleu.»

Le contexte permet de déterminer que « il » renvoie à Paul.

Mais le contexte ne constitue pas Paul.

Il fournit les conditions permettant de comprendre à qui l'expression renvoie.

Il faut donc maintenir :

«contexte de référence ≠ référent»

et :

«conditions d'identification ≠ constitution de ce qui est identifié.»

---

8. Stabilisation sémantique et stabilisation référentielle

Une expression peut être stabilisée dans son usage sans que son référent soit pour autant constitué par cette stabilisation.

Une communauté peut stabiliser le sens et les conditions d'emploi d'un terme.

Elle peut également modifier ces conditions au cours du temps.

Cela ne signifie pas nécessairement que le référent change de la même manière.

La distinction est particulièrement importante pour les termes dont l'usage traverse plusieurs périodes historiques.

Un terme peut conserver une continuité référentielle tout en connaissant des transformations importantes de ses critères descriptifs.

Inversement, une expression peut conserver une forme linguistique stable alors que son usage ne renvoie plus exactement aux mêmes configurations.

Il faut donc distinguer :

«stabilisation sémantique ≠ stabilisation référentielle.»

Et également :

«continuité du terme ≠ continuité du référent.»

---

9. Le cas des catégories historiques

Une catégorie peut être héritée sans avoir été explicitement choisie par les utilisateurs actuels.

Dire aujourd'hui :

«« C'est le même bateau. »»

peut mobiliser une histoire du navire :

- son nom ;
- des documents ;
- des usages ;
- des transformations matérielles ;
- des pratiques juridiques ;
- des continuités institutionnelles ;
- des traces historiques.

La référence actuelle dépend alors d'une reconstruction de continuité.

Le terme « même » ne décrit pas nécessairement une propriété matérielle immédiatement observable.

Il exprime une manière déterminée de maintenir une référence à travers des transformations.

La référence historique doit donc être analysée comme une opération de stabilisation, sans que cette stabilisation soit confondue avec la fabrication du référent.

---

10. Référent et critères de correction

Une référence peut être correcte ou incorrecte.

Dire :

«« C'est Paul »»

suppose des critères permettant de déterminer dans quelles conditions cette identification est recevable.

Ces critères peuvent être perceptifs, documentaires, institutionnels, historiques ou relationnels.

Ils appartiennent à la pratique de référence.

Ils ne sont toutefois pas identiques au référent.

Ainsi :

«critère d'identification ≠ référent»

et :

«condition de correction ≠ propriété intrinsèque du référent.»

Une erreur d'identification ne crée pas un nouveau référent.

Elle constitue une erreur dans la pratique de référence.

---

11. Référent et inférence

Référer à quelque chose permet de maintenir une continuité dans les descriptions.

Si je dis :

«« Ce bateau est ancien. »»

puis :

«« Il a été construit en 1920. »»

le pronom « il » permet de maintenir la référence.

La chaîne descriptive peut ainsi être prolongée :

«ce bateau → il → le navire → celui construit en 1920.»

Cette continuité référentielle permet aux différentes prédications d'être rapportées au même terme ou à la même configuration selon les critères pertinents.

La référence possède donc une dimension inférentielle et anaphorique.

Mais les inférences produites par une pratique ne constituent pas pour autant le référent.

---

12. Ce que le référent n'est pas

Le référent ne doit être identifié avec aucune des notions suivantes.

Le mot

«expression ≠ référent»

Le terme qui sert à référer n'est pas la chose à laquelle il renvoie.

Le sens

«sens ≠ référent»

Une même configuration peut être présentée sous plusieurs modes de description.

La description

«description ≠ référent»

Une description peut être correcte ou incorrecte sans devenir la chose décrite.

Le concept

«concept ≠ référent»

Un concept fournit une ressource pour identifier, classer ou décrire ; il n'est pas pour autant ce à quoi il se rapporte.

Le critère

«critère ≠ référent»

Un critère détermine les conditions de correction d'une identification ou d'une description.

Le contexte

«contexte ≠ référent»

Le contexte rend certaines références possibles, pertinentes ou interprétables.

La fonction

«fonction descriptive ≠ référent»

Le rôle que joue une référence dans une pratique n'est pas la chose à laquelle elle se rapporte.

---

13. Principe de non-conversion

Le référent constitue un point central du principe de non-conversion.

Plusieurs transformations doivent être évitées :

«référence ≠ constitution»

«description ≠ référent»

«stabilisation sémantique ≠ constitution du référent»

«critère d'identification ≠ référent»

«contexte ≠ référent»

«fonction descriptive ≠ référent»

«continuité descriptive ≠ identité matérielle automatique»

Ces distinctions ne conduisent pas à nier l'existence de ce à quoi les descriptions se rapportent.

Elles empêchent seulement de conclure que les opérations permettant de référer produisent nécessairement leur propre objet.

---

14. La question de l'adéquation

La notion de référent devient particulièrement importante lorsque Protokin examine l'adéquation d'une description.

Une description peut être :

- cohérente ;
- grammaticalement correcte ;
- socialement stabilisée ;
- largement partagée ;

et pourtant ne pas être adéquate à ce à quoi elle prétend se rapporter.

Il faut donc maintenir la distinction fondamentale :

«cohérence de la description ≠ adéquation au référent.»

Cette distinction permet de poser la question proprement protokinienne :

«Dans quelles conditions une description est-elle adéquate à ce qu'elle prétend décrire ?»

La référence fournit ici le point de comparaison.

---

15. Place dans l'architecture de Protokin

La référence n'est pas une étape autonome de constitution d'un objet.

Elle constitue une fonction transversale de rattachement d'une description à ce dont elle prétend parler.

Schématiquement :

Configuration rencontrée
        ↓
Ressources d'identification
        ↓
Référence
        ↓
Prédication
        ↓
Description
        ↓
Évaluation de l'adéquation

Cette représentation est fonctionnelle et non génétique.

La référence peut être révisée à n'importe quel moment de l'enquête.

Une nouvelle information peut conduire à :

- maintenir la référence ;
- préciser son extension ;
- distinguer deux référents ;
- réidentifier une configuration ;
- abandonner une référence antérieure ;
- reconstruire une continuité historique.

La référence est donc révisable sans être arbitraire.

---

16. Synthèse

Le référent est ce à quoi une pratique descriptive se rapporte.

Il ne doit être identifié ni au mot, ni au sens, ni au concept, ni à la description qui permet de l'identifier.

Une pratique descriptive peut stabiliser des moyens de référence, des critères d'identification et des catégories sans constituer pour autant la configuration à laquelle elle se rapporte.

La référence suppose ainsi une double exigence :

«une pratique doit disposer de moyens pour identifier et maintenir ce dont elle parle ;»

«ces moyens ne doivent pas être confondus avec ce à quoi ils permettent de se rapporter.»

Le référent permet ainsi à Protokin de maintenir une distinction fondamentale :

«une description est une opération de la pratique ; le référent est ce à quoi cette opération prétend se rapporter.»

Cette distinction rend possible l'examen ultérieur de leur adéquation, sans présupposer une théorie métaphysique complète de ce qu'est un objet.
