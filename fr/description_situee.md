# Le principe de la description située — Qui décrit, et avec quelles ressources ?

| Fonction | Établir le principe selon lequel toute description est située au sein d'une pratique, portée par un locuteur occupant une position déterminée et mobilisant des ressources hétérogènes. |
| :--- | :--- |
| **Prépare** | L'analyse du locuteur, des supports descriptifs, des communautés de locuteurs et des engagements descriptifs. |
| **Mobilise** | Le primat du couplage perception-action, le primat de la description et la distinction entre l'espace des causes et l'espace des raisons. |
| **Permet ensuite** | D'analyser les positions épistémiques, les ressources descriptives et les conditions de recevabilité des descriptions. |
| **N'établit pas** | La théorie des régimes descriptifs, ni les critères propres aux différentes autorités épistémiques. |

---

## 1. Problème conceptuel inaugural

Une longue tradition philosophique a pensé la connaissance à partir de l'idéal d'un observateur neutre contemplant un monde déjà constitué.

Selon cette conception, une bonne description devrait être indépendante de la position de celui qui décrit. Les caractéristiques du locuteur seraient des contingences qu'il faudrait éliminer pour atteindre une représentation objective du réel.

Protokin adopte un point de départ différent.

La question n'est plus :

> Comment produire une description depuis un point de vue extérieur ?

Elle devient :

> Comment une description devient-elle possible depuis une position déterminée au sein d'une pratique ?

La situation du locuteur n'est pas un obstacle à la connaissance.

Elle constitue la condition même de toute activité descriptive.

---

## 2. Définition fonctionnelle du principe

Dans Protokin, le **principe de la description située** affirme que :

> **Toute description est produite depuis une position épistémique déterminée, au sein d'une pratique collective, en mobilisant des ressources organiques, matérielles, conceptuelles et sociales.**

Trois conséquences en découlent directement.

- Aucun locuteur ne décrit depuis un point de vue absolu.
- Toute description mobilise des ressources acquises au cours d'une trajectoire.
- Toute description engage son auteur dans un espace public de justification.

Décrire ne consiste donc jamais à transmettre passivement une information.

Décrire consiste à prendre position dans une pratique descriptive.

---

## 3. Distinctions conceptuelles nécessaires

Ce principe doit être distingué de plusieurs idées voisines.

### Description située et subjectivité

Être situé ne signifie pas que toute description serait une simple opinion personnelle.

La situation désigne les conditions objectives qui rendent une description possible : pratiques, apprentissages, instruments, catégories, institutions et communautés.

---

### Situation et relativisme

Le caractère situé d'une description n'implique pas que toutes les descriptions se valent.

Chaque régime descriptif possède ses propres critères de recevabilité, de justification et de correction.

La situation rend possible l'évaluation ; elle ne la supprime pas.

---

### Le locuteur comme fonction

Le locuteur ne désigne pas simplement un individu biologique.

Il désigne la position depuis laquelle une description est produite, assumée et justifiée dans une pratique collective.

---

## 4. Les ressources de la description

Toute description mobilise simultanément plusieurs familles de ressources.

### Les ressources organiques

Le corps constitue le premier support descriptif.

Les systèmes perceptifs, les coordinations motrices, les habitudes corporelles et les apprentissages issus du couplage perception-action rendent certaines différences perceptibles.

---

### Les ressources matérielles

Les descriptions reposent sur des supports matériels :

- instruments ;
- documents ;
- cartes ;
- images ;
- logiciels ;
- archives.

Ces supports permettent de conserver, partager et transformer les descriptions.

---

### Les ressources conceptuelles

Le locuteur mobilise des catégories, des critères, des distinctions et des taxonomies hérités des pratiques auxquelles il participe.

Ces ressources organisent ce qui peut être décrit et la manière dont cela peut l'être.

---

### Les ressources collectives

Toute description s'inscrit dans une mémoire collective.

Les langues, les classifications, les institutions, les traditions d'enquête et les communautés de pratique rendent possibles les descriptions contemporaines.

Le locuteur ne crée jamais seul son espace descriptif.

Il hérite d'un monde déjà structuré par des descriptions antérieures.

---

## 5. Illustrations

### Le vélo rouge

Dire :

> « Le vélo est rouge. »

suppose déjà :

- une perception rendue possible par le couplage avec le milieu ;
- une catégorie linguistique partagée ;
- une communauté capable d'accepter ou de contester cette description.

---

### Le botaniste et le bûcheron

Le botaniste et le bûcheron traversent la même forêt.

Ils ne mobilisent pourtant ni les mêmes catégories, ni les mêmes critères, ni les mêmes finalités.

Leurs descriptions sont situées dans des pratiques différentes.

---

### Les urgences hospitalières

La description d'un patient dépend de la position occupée dans l'organisation hospitalière.

Le médecin, l'infirmier, le radiologue ou l'administration ne décrivent pas exactement la même situation.

Leurs descriptions répondent à des fonctions différentes.

---

### « Cette personne est dangereuse »

Une telle qualification ne décrit pas une propriété immédiatement observable.

Elle mobilise des critères juridiques, médicaux ou sociaux élaborés collectivement.

Sa recevabilité dépend du régime descriptif dans lequel elle est produite.

---

Il prépare l'analyse du locuteur, des ressources descriptives, des engagements et des pratiques collectives.

---

## 7. Vigilances méthodologiques

L'audit d'une pratique descriptive doit permettre d'identifier plusieurs erreurs récurrentes.

### L'illusion neutraliste

Croire qu'une description pourrait être produite depuis un point de vue totalement extérieur aux pratiques qui la rendent possible.

---

### Le relativisme

Réduire toute description à une opinion individuelle sans reconnaître les critères publics qui organisent sa justification.

---

### L'effacement des supports

Oublier que toute description dépend de ressources corporelles, matérielles, techniques et collectives.

---

## 8. Synthèse

Le principe de la description située établit que toute description est inséparable des conditions qui la rendent possible.

Décrire n'est jamais l'activité d'un esprit isolé.

C'est une pratique située, portée par un locuteur, soutenue par des ressources multiples et évaluée au sein d'une communauté.

### Ce que ce principe suppose

- le primat du couplage perception-action ;
- le primat de la description.

### Ce qu'il rend possible

- l'analyse du locuteur ;
- l'étude des supports descriptifs ;
- la théorie des engagements descriptifs ;
- l'analyse des communautés de locuteurs ;
- l'audit des asymétries de participation aux pratiques descriptives.
