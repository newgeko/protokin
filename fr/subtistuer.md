La substitution — Éprouver les invariances et les transformations

Fonction

Définir la substitution comme une opération d'enquête permettant d'éprouver ce qui demeure invariant et ce qui se transforme lorsqu'un élément d'une pratique descriptive est remplacé par un autre.

La substitution ne constitue ni une théorie de la signification ni une méthode générale de preuve. Elle sert à distinguer les dimensions d'une configuration descriptive qui peuvent varier indépendamment les unes des autres.

---

Problème

Une pratique descriptive peut donner l'impression que plusieurs éléments sont liés de manière nécessaire :

- une expression et son référent ;
- une catégorie et une propriété ;
- un critère et une fonction ;
- une description et une inférence ;
- un nom et une manière d'identifier.

La substitution permet de mettre ces relations à l'épreuve.

Si un élément est remplacé sans que toutes les autres dimensions soient modifiées, leur identité supposée doit être réexaminée.

La question n'est donc pas seulement :

«« Par quoi peut-on remplacer cette expression ? »»

mais :

«« Qu'est-ce qui reste identique et qu'est-ce qui change lorsque nous la remplaçons ? »»

---

Définition

La substitution consiste à remplacer, dans une pratique descriptive déterminée, une expression, une catégorie, un critère ou une formulation par un autre élément, puis à examiner les conséquences de cette modification.

Elle permet d'observer les éventuelles variations concernant :

- la référence ;
- les critères d'application ;
- les inférences ;
- la fonction descriptive ;
- les conditions de justification ;
- les relations engagées dans la pratique.

La substitution est donc une opération comparative locale.

Elle n'établit pas à elle seule une équivalence générale entre les éléments substitués.

---

1. Substituer une expression

Considérons :

«« Vénus est l'étoile du matin. »»

On peut remplacer « étoile du matin » par « Vénus » :

«« Vénus est Vénus. »»

Le référent peut être maintenu, mais la fonction descriptive de l'expression change.

« Vénus » et « étoile du matin » peuvent ainsi être associés à un même référent sans être équivalents sous tous les aspects.

La substitution fait apparaître une première distinction :

«même référent ≠ même expression ≠ même fonction descriptive.»

---

2. Substituer une description

On peut également comparer :

«« Vénus est l'étoile du matin. »»

et :

«« Vénus est l'étoile du soir. »»

Dans les conditions appropriées, les deux descriptions peuvent être rapportées au même référent.

Mais elles ne sélectionnent pas nécessairement les mêmes relations pratiques.

La première description est liée à une apparition dans certaines conditions d'observation ; la seconde à une autre.

La substitution permet alors de distinguer :

- le référent ;
- les conditions d'identification ;
- la description mobilisée ;
- les inférences associées à cette description.

On obtient :

«même référent → descriptions différentes → relations descriptives différentes.»

---

3. Substitution et invariance

La substitution est particulièrement utile lorsqu'elle permet d'identifier une invariance.

Si le remplacement de X par Y conserve une dimension de la pratique, cette conservation constitue un élément à examiner.

Par exemple :

«X → Y
référence conservée
critères partiellement modifiés
fonction modifiée»

La substitution permet alors de ne pas confondre :

«ce qui est conservé»

avec :

«ce qui est identique.»

Une même référence peut être maintenue alors que les critères, les inférences ou la fonction descriptive changent.

---

4. Substitution et transformation

La substitution ne sert pas uniquement à rechercher des équivalences.

Elle peut au contraire révéler une transformation.

Une substitution peut modifier :

- la catégorie sous laquelle une configuration est décrite ;
- les propriétés considérées comme pertinentes ;
- les inférences autorisées ;
- les conditions de correction ;
- la fonction de la description.

L'enquête demande alors :

«Quelle dimension a effectivement été transformée par la substitution ?»

Cette question empêche d'attribuer à une seule modification toutes les transformations observées.

---

5. Substitution et référence

La substitution permet notamment d'éprouver le rapport entre expression et référence.

Mais elle ne permet pas de conclure automatiquement :

«deux expressions substituables → même signification ;»

ni :

«deux expressions différentes → référents différents.»

La substituabilité est toujours relative à un contexte, à une pratique et à une dimension déterminée.

Il faut donc distinguer :

«substituabilité dans un contexte ≠ équivalence générale.»

Et :

«conservation du référent ≠ conservation de toutes les propriétés sémantiques.»

---

6. Substitution et critères

Une substitution peut également porter sur un critère.

Supposons qu'une pratique utilise le critère X pour identifier une catégorie et qu'une enquête introduise le critère Y.

Il faut alors demander :

- la même configuration est-elle encore identifiée ?
- les mêmes cas sont-ils inclus ?
- les mêmes cas sont-ils exclus ?
- les inférences changent-elles ?
- la fonction de la catégorie reste-t-elle identique ?
- la justification de la substitution est-elle établie ?

La substitution devient ainsi un moyen d'identifier les dépendances entre critère, catégorie et fonction.

«Critère substitué ≠ référent nécessairement substitué.»

---

7. Substitution et temporalité

La substitution devient particulièrement importante lorsque l'enquête porte sur des descriptions historiques.

Une expression peut être remplacée par une expression actuelle sans que l'on puisse supposer que les deux expressions possèdent les mêmes critères d'application.

Inversement, une expression ancienne peut être conservée alors que sa fonction descriptive s'est transformée.

L'enquête doit donc distinguer :

- continuité de l'expression ;
- continuité des critères ;
- continuité des inférences ;
- continuité de la fonction ;
- continuité de la référence.

La substitution permet alors de tester une hypothèse de continuité plutôt que de la présupposer.

---

8. Substitution et anachronisme

La substitution peut également servir à détecter une projection rétrospective.

Remplacer une expression historique par une expression contemporaine peut donner l'impression que les deux pratiques décrivent exactement la même chose selon les mêmes critères.

Cette conclusion doit être examinée.

Une substitution rétrospective peut conserver une référence supposée tout en modifiant :

- la catégorie ;
- les critères ;
- les inférences ;
- la fonction ;
- la justification.

Ainsi :

«traduire une expression ancienne par une expression actuelle ≠ établir leur équivalence descriptive.»

La substitution devient ici un instrument de contrôle de l'anachronisme.

---

9. Substitution et non-conversion

La substitution prend sa pleine portée dans le principe général de Protokin :

«continuité des dépendances + discontinuité des fonctions + non-conversion.»

Une substitution peut conserver certaines relations et en modifier d'autres.

Elle permet donc de tester les conversions implicites :

«expression → référent
critère → propriété
usage → signification
fonction → propriété
description → configuration»

La substitution ne réfute pas directement ces conversions.

Elle permet de construire des situations dans lesquelles elles doivent être examinées.

---

10. Substitution et quadripartition

La substitution peut être examinée selon les quatre dimensions de l'enquête.

Condition

Quelles conditions permettent la substitution ?

Relation

Quelles relations sont conservées ou transformées ?

Fonction

Que fait la nouvelle expression, catégorie ou formulation dans la pratique ?

Justification

Selon quels critères la substitution peut-elle être défendue ?

La quadripartition ne fournit donc pas une procédure mécanique de substitution.

Elle permet d'en examiner les conséquences sans réduire la transformation à une seule dimension.

---

11. La substitution comme épreuve locale

La substitution n'est pas une étape obligatoire de toute enquête.

Elle devient pertinente lorsqu'une enquête rencontre une identité supposée ou une dépendance qu'il faut éprouver.

Elle peut être utilisée pour tester une proposition telle que :

«« Ces deux expressions désignent la même chose. »»

ou :

«« Cette catégorie peut être remplacée par celle-ci sans conséquence descriptive. »»

ou encore :

«« Ce critère décrit la même configuration. »»

La substitution permet alors de demander :

«Qu'est-ce qui est effectivement conservé ?»

et :

«Qu'est-ce qui doit être reconstruit ?»

Elle constitue ainsi une épreuve locale, et non une étape supplémentaire de la chaîne d'enquête.

---

Ce que la substitution permet

La substitution permet d'examiner :

- les invariances ;
- les variations ;
- les dépendances ;
- les changements de fonction ;
- les changements de critères ;
- les changements d'inférences ;
- les conditions de maintien d'une référence ;
- les risques d'anachronisme.

---

Ce que la substitution n'établit pas

La substitution n'établit pas à elle seule :

- l'identité de deux significations ;
- l'identité de deux référents ;
- l'adéquation d'une description ;
- la vérité d'une proposition ;
- l'existence d'une configuration ;
- la constitution du référent par le langage.

Elle fournit une épreuve comparative dont les résultats doivent être repris dans l'enquête.

---

Synthèse

La substitution consiste à remplacer un élément d'une pratique descriptive afin d'examiner les conséquences de ce remplacement.

Son intérêt ne réside pas principalement dans la possibilité de remplacer X par Y, mais dans l'analyse de ce qui demeure et de ce qui se transforme.

Elle permet ainsi de distinguer :

«référence, expression, critère, fonction, inférence et justification.»

La substitution ne produit pas automatiquement une identité ou une différence entre ces dimensions.

Elle permet de les mettre à l'épreuve séparément.

«Substituer, dans Protokin, c'est éprouver une identité supposée en observant ce qui reste invariant et ce qui doit être reconfiguré.»
