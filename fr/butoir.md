# Butoir

Fonction

Le butoir désigne une résistance rencontrée dans une configuration donnée qui limite la poursuite d'une pratique, d'une opération ou d'une description.

Il permet à Protokin de prendre en compte les contraintes matérielles, corporelles, techniques et environnementales sans les transformer en descriptions déjà constituées du réel.

Le butoir n'est donc ni une vérité fournie par le monde, ni une raison discursive, ni un critère de justification.

---

Problème

Une description peut être cohérente avec les autres énoncés auxquels elle est associée tout en cessant de fonctionner dans une situation donnée.

Un instrument ne produit pas le résultat attendu. Une opération ne peut pas être réalisée. Une continuité supposée ne se maintient pas. Une configuration matérielle résiste à l'action prévue.

Cette résistance crée une situation problématique, mais elle ne détermine pas par elle-même la manière dont cette situation doit être décrite.

Le risque consiste alors à convertir directement la résistance rencontrée en information déjà catégorisée :

«« Le monde nous montre que telle description est vraie. »»

Protokin refuse cette conversion.

---

Définition

Un butoir est une résistance matérielle, corporelle, technique ou environnementale qui limite les opérations effectivement réalisables ou les descriptions pouvant continuer à fonctionner dans une configuration donnée.

Le butoir peut prendre la forme d'une impossibilité pratique, d'une rupture, d'un dysfonctionnement, d'une incompatibilité ou d'une opacité.

Il n'est pas nécessairement spectaculaire. Une différence qui empêche une substitution, un instrument qui ne permet plus une mesure attendue ou une opération qui échoue dans certaines conditions peuvent constituer des butoirs.

Le butoir ne porte pas, par lui-même, la signification de l'échec.

Il ne fournit donc pas directement la description qui doit remplacer celle qui ne fonctionne plus.

---

Résistance et incompatibilité

Il faut distinguer la résistance matérielle du constat d'incompatibilité.

La résistance appartient à la configuration dans laquelle l'action ou l'opération se déroule.

Le constat d'incompatibilité apparaît lorsque cette résistance est rapportée à une attente, une opération ou une description déterminée.

On peut ainsi distinguer :

résistance matérielle → incompatibilité constatée → enquête

La première ne contient pas la seconde.

Une même résistance peut recevoir plusieurs descriptions possibles selon le problème que l'enquête cherche à résoudre.

L'enquête doit donc déterminer si l'échec tient, par exemple, à une condition matérielle non prise en compte, à une erreur de description, à une catégorie inadéquate, à un instrument défaillant ou à une modification de la configuration.

---

Le butoir dans l'enquête

Le butoir intervient principalement du côté de la Condition et de l'Ancrage, mais son rôle se prolonge dans les opérations d'épreuve et de reconstruction.

Condition

La configuration matérielle, corporelle, technique ou environnementale impose certaines contraintes.

Ces contraintes ne constituent pas encore des raisons de décrire la situation d'une manière plutôt que d'une autre.

Ancrage

L'enquête identifie les résistances auxquelles la pratique est effectivement confrontée.

L'Ancrage empêche ainsi de reconstruire une pratique indépendamment des conditions dans lesquelles elle peut réellement être réalisée.

Problème

Une résistance devient problématique lorsqu'elle entre en conflit avec une attente, une opération ou une description déterminée.

Le problème ne se réduit donc pas au butoir lui-même : il apparaît dans la relation entre une configuration, une pratique et ce qui était attendu d'elle.

Éprouver

L'épreuve permet de déterminer ce que l'échec met effectivement en question.

Il peut être nécessaire de modifier les conditions, de contrôler l'instrument, de substituer un cas, de comparer plusieurs configurations ou de reprendre la description.

Le butoir ne tranche donc pas seul entre ces possibilités.

Justifier et Reconstituer

Lorsque l'enquête établit qu'une description ne peut plus être maintenue, sa révision doit être justifiée selon des critères et des raisons.

La résistance matérielle contribue alors à la situation d'enquête, mais elle n'est pas convertie en justification.

---

Non-conversion

Le butoir doit être maintenu dans une distinction stricte entre plusieurs fonctions.

Condition matérielle ≠ critère de justification

Une contrainte peut rendre une opération impossible sans déterminer le critère permettant d'évaluer la description de cette impossibilité.

Cause ≠ raison

Une cause peut expliquer pourquoi une résistance survient sans constituer pour autant une raison de soutenir une proposition.

Résistance ≠ signification

Une résistance peut provoquer un échec sans contenir une signification descriptive déjà constituée.

Échec ≠ diagnostic

Le fait qu'une opération échoue ne détermine pas immédiatement pourquoi elle échoue.

Butoir ≠ justification

Le butoir limite ce qui peut être maintenu ou réalisé dans une configuration donnée ; il ne justifie pas, à lui seul, une description.

---

Ce que le butoir permet d'établir

Le butoir permet d'établir qu'une certaine pratique, opération ou description rencontre une limite dans une configuration déterminée.

Il peut donc contribuer à exclure certaines possibilités pratiques ou descriptives.

Mais il ne permet pas, à lui seul, d'établir :

- quelle description doit être retenue ;
- quel critère doit être utilisé ;
- quelle catégorie est adéquate ;
- quelle raison doit être avancée ;
- quelle reconstruction doit remplacer la précédente.

Ces déterminations appartiennent au travail de l'enquête.

La distinction est essentielle :

«Une résistance peut mettre une description en échec sans déterminer, à elle seule, quelle description doit lui être substituée.»

---

N'établit pas

Le butoir n'établit pas :

- une description vraie fournie directement par le monde ;
- une signification indépendante de toute pratique descriptive ;
- une justification normative ;
- un critère d'identification ;
- une explication complète de l'échec ;
- une réduction du descriptif au physique.

Il ne constitue donc pas un substitut matériel au raisonnement.

---

Synthèse

Le butoir désigne une résistance rencontrée dans une configuration donnée.

Il introduit une contrainte dans l'enquête sans fournir directement le contenu de la description.

Son rôle peut être résumé par la chaîne :

résistance matérielle → incompatibilité constatée → épreuve → révision éventuelle

La règle de non-conversion est :

«Un butoir matériel ne justifie pas une description ; il limite les descriptions et les pratiques compatibles avec une configuration donnée.»

Et :

«La résistance du milieu n'est pas une raison ; elle devient pertinente pour le raisonnement lorsqu'elle est intégrée à une pratique d'enquête.»

Le butoir assure ainsi une prise sur les contraintes effectives du milieu sans transformer cette prise en accès immédiat à une description vraie du réel.
