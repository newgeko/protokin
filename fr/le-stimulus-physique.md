Le stimulus physique

Configuration matérielle, événement et affection d'un organisme

---

1. Problème

Avant qu'un événement puisse être décrit comme ayant une fonction comportementale, appétitive, aversive ou sociale, il peut être décrit selon ses propriétés physiques.

Une lumière possède une intensité et une longueur d'onde.

Un son possède une fréquence, une amplitude et une structure temporelle.

Une température correspond à un état thermodynamique mesurable.

Une pression exerce une force sur une surface.

Une molécule possède une structure et des propriétés physico-chimiques.

Ces descriptions ne disent cependant pas encore ce que l'événement fait pour un organisme.

La distinction fondamentale est donc :

«Une configuration physique peut affecter un organisme sans que sa description physique suffise à déterminer la fonction qu'elle exerce pour cet organisme.»

Cette distinction constitue le point de départ de l'analyse du stimulus.

---

2. Le stimulus comme terme d'interface

Le mot stimulus possède une histoire particulière.

Il désigne généralement un événement ou une configuration susceptible de produire une modification dans un organisme.

Mais cette définition contient déjà une ambiguïté.

Le stimulus peut être compris comme :

- un événement physique ;
- une configuration de l'environnement ;
- une énergie reçue par un système sensoriel ;
- un événement discriminable par un organisme ;
- un événement possédant une fonction comportementale.

Ces usages ne sont pas équivalents.

Pour Protokin, il est donc nécessaire de distinguer :

configuration physique
        ↓
affection de l'organisme
        ↓
fonction de stimulus

La première description ne doit pas être confondue avec les deux suivantes.

---

3. La configuration physique

Une configuration physique peut être décrite sans référence immédiate à son effet sur un organisme.

On peut mesurer :

- une intensité ;
- une fréquence ;
- une pression ;
- une température ;
- une concentration ;
- une durée ;
- une vitesse ;
- une position ;
- une composition chimique ;
- une organisation spatiale ou temporelle.

Cette description appartient au régime des phénomènes physiques et matériels.

Elle répond à des questions telles que :

«Quelle configuration présente le milieu ?»

ou :

«Quelles transformations physico-chimiques caractérisent cet événement ?»

Elle ne répond pas encore à :

«Quelle fonction cet événement exerce-t-il pour un organisme ?»

---

4. Le stimulus n'est pas nécessairement un objet

Il faut également éviter d'identifier stimulus et objet.

Un stimulus peut être :

- une variation de lumière ;
- une modification de pression ;
- une vibration ;
- un gradient chimique ;
- une température ;
- une différence de mouvement ;
- une configuration spatiale ;
- une variation temporelle.

Le stimulus peut donc être une différence, une variation ou un événement, plutôt qu'une chose stable.

Cette distinction est importante pour une conception dynamique du vivant.

L'organisme ne rencontre pas nécessairement des objets isolés.

Il rencontre des variations dans un milieu.

---

5. Du monde physique à l'organisme

Lorsqu'une configuration physique entre en interaction avec un organisme, elle peut produire une modification de son état.

On peut schématiser :

configuration physique
        ↓
interaction
        ↓
modification de l'organisme

Cette modification peut concerner :

- un récepteur ;
- une cellule ;
- un système sensoriel ;
- une activité neuronale ;
- une activité physiologique ;
- une orientation motrice.

Il s'agit alors d'une affection.

Le terme est important : il permet de décrire le fait qu'un organisme est modifié par son environnement sans attribuer immédiatement à cette modification une signification psychologique ou normative.

---

6. Affection et information

Une configuration physique peut produire une différence dans l'état d'un organisme.

Mais cette différence ne doit pas être immédiatement appelée « information » au sens cognitif ou sémantique.

Une cellule photosensible réagit à une certaine gamme de rayonnements.

Cette réaction constitue une interaction physico-biologique.

Elle ne constitue pas encore, à elle seule, une représentation de ce que signifie la lumière.

Il faut donc distinguer :

différence physique
        ↓
différence physiologique
        ↓
discrimination
        ↓
fonction comportementale
        ↓
signification éventuelle

Chaque étape introduit une description supplémentaire.

---

7. La sélectivité biologique

Les organismes ne sont pas affectés uniformément par toutes les configurations du milieu.

Ils possèdent des structures qui rendent certaines variations pertinentes pour leur fonctionnement.

Un organisme peut être sensible :

- à certaines longueurs d'onde ;
- à certaines molécules ;
- à certaines températures ;
- à certaines pressions ;
- à certaines vibrations.

Cette sélectivité n'est pas une propriété du stimulus seul.

Elle résulte de la relation entre :

configuration du milieu
+
organisation de l'organisme

Ainsi, ce qui constitue un stimulus pour un organisme peut ne pas l'être pour un autre.

---

8. Le seuil

La physiologie expérimentale montre également que les systèmes vivants présentent des seuils de sensibilité.

Une variation physique peut être trop faible pour produire une modification détectable dans certaines conditions.

À partir d'une certaine intensité ou d'une certaine configuration, elle devient discriminable.

Cela conduit à distinguer :

présence physique
≠
détection biologique

Une configuration peut physiquement exister sans exercer de fonction détectable pour un organisme particulier.

Cette distinction est essentielle.

Elle interdit de supposer que tout ce qui existe physiquement constitue automatiquement un stimulus.

---

9. Le stimulus dépend de l'organisme

Dire qu'un événement est un stimulus ne signifie donc pas simplement :

«« cette chose possède la propriété d'être un stimulus ».»

Cela signifie plutôt :

«cette configuration peut entrer dans une relation fonctionnelle avec un organisme donné.»

La notion de stimulus est ainsi relationnelle.

Cependant, cette relationnalité ne doit pas être comprise comme une projection subjective.

L'organisme ne crée pas arbitrairement les propriétés physiques.

Il existe une contrainte matérielle réelle :

configuration physique
        ↕
organisation biologique

La fonction émergera ensuite d'une histoire d'interaction.

---

10. Une même configuration, plusieurs organismes

Une même configuration physique peut affecter différemment plusieurs organismes.

Un son peut être :

- audible pour une espèce ;
- inaudible pour une autre.

Une molécule peut être :

- nutritive pour un organisme ;
- toxique pour un autre ;
- sans effet notable pour un troisième.

Cette différence ne signifie pas que les organismes vivent dans des mondes physiques séparés.

Elle signifie que la pertinence fonctionnelle d'une configuration dépend de l'organisation du vivant qui y est exposé.

---

11. Le stimulus physique n'est pas encore un stimulus fonctionnel

Cette distinction doit être maintenue avec précision.

Une configuration physique peut être appelée stimulus dans un sens physiologique minimal.

Mais elle n'est pas encore nécessairement un stimulus fonctionnel.

La fonction suppose une organisation comportementale.

Par exemple, une lumière peut être détectée par un organisme.

Mais savoir si cette lumière :

- signale une possibilité d'action ;
- déclenche une orientation ;
- annonce une conséquence ;
- acquiert une valeur appétitive ;
- devient aversive ;

nécessite des informations supplémentaires.

La distinction peut être formulée ainsi :

stimulus physique
        ↓
stimulus fonctionnel

Le second ne se réduit pas au premier.

---

12. Propriété physique et fonction

Une propriété physique peut contribuer à une fonction sans la déterminer entièrement.

Deux événements physiquement différents peuvent exercer une fonction similaire.

Inversement, un même événement physique peut exercer des fonctions différentes.

On obtient :

P1 ─────→ F
P2 ─────→ F

mais aussi :

P ─────→ F1
  └────→ F2

La fonction n'est donc pas une simple copie de la structure physique.

Elle dépend de la manière dont l'événement est inséré dans une organisation du comportement.

---

13. Le rôle de l'histoire

La fonction d'un stimulus dépend notamment de l'histoire de l'organisme.

Un événement auparavant indifférent peut devenir pertinent à travers :

- l'apprentissage ;
- le conditionnement ;
- l'exposition répétée ;
- les contingences ;
- l'interaction avec d'autres événements.

Il faut alors distinguer :

configuration actuelle
+
histoire passée
        ↓
fonction actuelle

Cette historicité sera centrale dans l'analyse de la fonction de stimulus.

Elle permet de comprendre pourquoi deux organismes exposés à une configuration physiquement identique peuvent y répondre différemment.

---

14. Le contexte

La fonction d'une configuration dépend également du contexte.

Une même lumière peut être :

- simplement visible ;
- un signal ;
- un indice ;
- une alerte ;
- un élément d'une tâche ;
- un événement socialement institué.

Le contexte ne constitue donc pas nécessairement une propriété supplémentaire du stimulus.

Il constitue une partie de l'organisation relationnelle dans laquelle celui-ci est pris.

La fonction peut ainsi varier sans modification de la configuration physique elle-même.

---

15. Une première limite du modèle stimulus-réponse

Le schème :

stimulus → réponse

possède une utilité historique considérable.

Il permet de rechercher des relations régulières entre environnement et comportement.

Mais il devient insuffisant si le stimulus est considéré comme une cause fixe produisant mécaniquement une réponse déterminée.

Le comportement dépend également :

- de l'état de l'organisme ;
- de son histoire ;
- du contexte ;
- des conséquences ;
- des relations apprises.

Il faut donc passer d'une causalité linéaire à une analyse fonctionnelle.

---

16. Le stimulus comme différence pertinente

Une conception plus dynamique peut considérer le stimulus comme une différence qui devient pertinente pour un système vivant.

Il ne s'agit pas de dire que l'organisme invente la différence.

La différence physique existe indépendamment de lui.

Mais sa pertinence fonctionnelle dépend de la relation entre cette différence et l'organisation du vivant.

On peut alors distinguer :

différence physique
        ↓
différence détectable
        ↓
différence fonctionnelle

Cette progression constitue un point d'entrée vers une conception relationnelle du comportement.

---

17. Ce que cette page n'établit pas

Cette page ne cherche pas à établir :

- la théorie de la fonction de stimulus ;
- la théorie du conditionnement ;
- la théorie de l'appétit et de l'aversion ;
- la RFT ;
- la théorie des pratiques sociales ;
- la normativité.

Elle prépare ces développements.

Sa fonction est plus limitée :

«distinguer la configuration physique d'un événement de la fonction qu'il peut acquérir dans une dynamique biologique et comportementale.»

Cette limitation est essentielle pour respecter l'architecture documentaire de Protokin.

---

18. Position dans PROTO

Le stimulus physique appartient au niveau matériel et biologique de l'analyse.

Il peut être situé ainsi :

CONFIGURATION PHYSIQUE
        ↓
INTERACTION
        ↓
AFFECTION
        ↓
DÉTECTION / DISCRIMINATION
        ↓
FONCTION DE STIMULUS
        ↓
ORIENTATION
        ↓
TRANSFORMATION RELATIONNELLE

Cette séquence ne constitue pas une ontologie du vivant.

Elle constitue une progression descriptive.

Elle permet de distinguer les fonctions exercées par les descriptions sans supposer qu'un niveau soit la substance réelle des niveaux suivants.

---

19. Principe de non-conversion

Une propriété physique ne doit pas être convertie directement en fonction comportementale.

Inversement, une fonction comportementale ne doit pas être réifiée comme une propriété physique supplémentaire.

On peut donc poser :

«Une configuration physique contraint les possibilités d'interaction, mais ne détermine pas à elle seule la fonction qu'elle exercera pour un organisme.»

Cette formulation permet de maintenir ensemble deux exigences :

réalisme matériel
+
non-réduction fonctionnelle

Le stimulus physique n'est donc ni une illusion produite par l'organisme, ni une cause suffisante du comportement.

---

20. Vers la fonction de stimulus

La page suivante peut alors poser la question proprement fonctionnelle :

«Dans quelles conditions une configuration physique devient-elle un stimulus exerçant une fonction déterminée dans une organisation comportementale ?»

Cette question introduit :

- l'histoire ;
- les contingences ;
- le contexte ;
- l'état de l'organisme ;
- les conséquences ;
- l'apprentissage.

C'est à ce niveau que peuvent ensuite être étudiés :

fonction de stimulus
        ↓
appétit / aversion
        ↓
transformation des fonctions
        ↓
cadres relationnels
        ↓
RFT

---

21. Formule synthétique

«Le stimulus physique est une configuration matérielle susceptible d'entrer en interaction avec un organisme ; sa fonction comportementale n'est pas contenue dans sa seule description physique.»

La physique décrit la configuration.

La physiologie décrit certaines interactions avec l'organisme.

L'analyse comportementale décrit les fonctions acquises dans les contingences.

La RFT décrit certaines transformations relationnelles de ces fonctions.

Les pratiques sociales introduisent ensuite d'autres régimes de description.

---

22. Formule Protokin

«Une configuration physique peut affecter un organisme sans être encore une raison, une signification ou même une fonction comportementale déterminée.»

Le stimulus physique constitue ainsi un seuil descriptif.

Il marque le point à partir duquel une configuration matérielle peut devenir pertinente pour un vivant, sans que cette pertinence soit encore confondue avec une signification, une valeur ou une normativité.
