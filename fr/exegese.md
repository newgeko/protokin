Exégèse

Fonction : Définir l'exégèse comme opération d'enquête portant sur une description théorique, philosophique ou conceptuelle, et distinguer la restitution d'une configuration descriptive de son utilisation dans une nouvelle enquête.

---

1. Fonction de l'exégèse

L'exégèse désigne, dans Protokin, une opération d'enquête portant sur une description déjà constituée.

Elle ne consiste pas simplement à résumer un texte ni à attribuer une signification générale à son auteur. Elle cherche à reconstruire les opérations descriptives par lesquelles un texte produit ses distinctions, organise ses concepts, établit ses relations et autorise certaines inférences.

L'exégèse prend ainsi le texte comme configuration descriptive à examiner.

Son objet n'est donc pas de déterminer ce que le texte « dit en soi », mais de reconstruire les conditions descriptives dans lesquelles ses énoncés prennent fonction.

Elle doit notamment permettre d'identifier :

- les distinctions mobilisées ;
- les catégories utilisées ;
- les critères d'application de ces catégories ;
- les relations entre les concepts ;
- les engagements descriptifs assumés ;
- les inférences autorisées ;
- les transformations opérées au cours de l'argumentation ;
- les limites internes de la configuration reconstruite.

L'exégèse constitue ainsi une opération de reconstruction située.

---

2. Exégèse passive

L'exégèse passive désigne l'opération par laquelle une configuration descriptive est reconstruite sans déplacement de son régime d'organisation.

Elle cherche prioritairement à restituer les relations internes au texte :

«Que décrit l'auteur ?
Avec quelles catégories ?
Selon quels critères ?
Quelles inférences ces catégories autorisent-elles ?
Quelles distinctions rendent son argumentation possible ?»

L'exégèse passive suspend provisoirement l'utilisation externe du texte afin de reconstruire sa cohérence propre.

Elle ne signifie donc pas une lecture dépourvue d'activité. Elle désigne plutôt une retenue transformationnelle : l'enquêteur limite volontairement les déplacements qu'il fait subir à la configuration étudiée.

Cette opération permet notamment d'éviter plusieurs réductions :

- réduire un concept à son équivalent contemporain ;
- attribuer à un auteur une distinction produite par un autre régime ;
- interpréter une proposition à partir de catégories étrangères à son fonctionnement ;
- confondre une conséquence reconstruite avec une proposition explicitement établie ;
- transformer une analogie en identité conceptuelle.

L'exégèse passive constitue ainsi une condition de possibilité de l'exégèse active : on ne peut transformer correctement une configuration que si l'on a d'abord identifié ce qui la constitue.

---

3. Exégèse active

L'exégèse active intervient lorsque la configuration reconstruite devient à son tour opératoire dans une nouvelle enquête.

Le texte n'est alors plus seulement considéré comme une configuration à restituer. Ses concepts, distinctions ou relations peuvent être mobilisés pour examiner une autre configuration descriptive.

L'enquête change alors de fonction :

«Que permet cette configuration lorsqu'elle est mise en relation avec une autre ?»

L'exégèse active peut ainsi :

- mettre deux configurations en relation ;
- transférer une distinction dans une autre enquête ;
- tester la portée d'un concept ;
- faire apparaître une compatibilité ou une incompatibilité ;
- produire une nouvelle articulation entre des descriptions ;
- transformer une relation descriptive ;
- utiliser un concept comme opérateur de reconfiguration.

Elle ne consiste cependant pas à faire dire au texte ce que l'on souhaite lui faire dire.

L'activité porte sur l'usage de la configuration reconstruite, non sur la modification rétrospective de ce que le texte établit.

L'exégèse active doit donc maintenir une distinction entre :

«ce que le texte permet d'établir
et
ce que l'enquête permet de faire à partir de lui.»

---

4. De la restitution à la reconfiguration

La distinction entre exégèse passive et exégèse active correspond ainsi à deux opérations successives qui ne doivent pas être confondues.

Opération| Fonction
Exégèse passive| Reconstruire une configuration descriptive
Exégèse active| Mettre cette configuration en opération dans une nouvelle enquête

La première établit les relations internes pertinentes.

La seconde explore les possibilités de transformation ou de déplacement.

Cette distinction permet d'éviter deux erreurs symétriques.

La première consiste à figer le texte : considérer qu'une fois son sens reconstruit, aucune opération nouvelle ne peut être effectuée à partir de lui.

La seconde consiste à dissoudre le texte dans son interprétation : utiliser un concept sans maintenir la distinction entre son fonctionnement initial et son fonctionnement dans la nouvelle configuration.

L'exégèse active ne supprime donc pas l'exigence de fidélité descriptive. Elle la transforme en condition de possibilité de l'opération.

---

5. Exégèse et transformation relationnelle

Dans Protokin, l'exégèse active peut rencontrer les opérations de transformation relationnelle étudiées dans la dynamique descriptive.

Un concept philosophique peut être extrait de la configuration dans laquelle il fonctionne, puis mis en relation avec une autre configuration. Ce déplacement ne constitue pas nécessairement une traduction directe.

Il peut produire une reconfiguration relationnelle : les relations entre les éléments changent alors que certains éléments ou certaines propriétés relationnelles sont conservés.

L'exégèse active doit par conséquent expliciter le statut de cette opération.

Elle doit distinguer :

1. la relation telle qu'elle est reconstruite dans le texte ;
2. l'opération par laquelle cette relation est déplacée ;
3. la nouvelle configuration dans laquelle elle fonctionne ;
4. les effets produits par ce déplacement.

Cette distinction empêche de confondre exégèse d'un auteur et appropriation théorique d'un concept.

---

6. L'exégèse comme opération d'enquête

L'exégèse ne constitue donc pas un régime descriptif supplémentaire.

Elle constitue une opération appliquée à une description déjà constituée.

Elle peut porter sur :

- un texte philosophique ;
- une théorie scientifique ;
- une doctrine ;
- une catégorie ;
- un système conceptuel ;
- une pratique argumentative ;
- une configuration descriptive historique.

Son intérêt méthodologique est de permettre à l'enquête protokinienne de travailler sur des descriptions sans les réduire immédiatement à ses propres catégories.

L'exégèse passive reconstruit la configuration.

L'exégèse active examine ce que cette configuration permet de transformer.

L'enquête protokinienne peut ainsi maintenir simultanément deux exigences :

«comprendre une description selon ses propres relations ;»

«examiner ce que ces relations permettent lorsqu'elles sont engagées dans une autre pratique descriptive.»

---

7. Position dans la méthode Protokin

L'exégèse trouve ainsi sa place dans la méthode Protokin entre la comparaison des descriptions et leur diagnostic.

Elle peut être schématiquement située ainsi :

Identifier un régime
        ↓
Comparer deux descriptions
        ↓
Exégèse
   ↙          ↘
Passive      Active
   ↓            ↓
Reconstruire   Reconfigurer
   ↘          ↙
Diagnostiquer
        ↓
Évaluer une traduction

L'exégèse fournit ainsi une opération intermédiaire : elle permet de passer de l'identification d'une configuration descriptive à son examen approfondi, puis éventuellement à sa mise en relation avec une autre configuration.

Elle constitue donc une méthode de lecture opératoire des descriptions, et non une théorie générale de l'interprétation.
