# Architecture du système Protokin

## 1. Point de départ : le problème

Protokin ne part pas d'une ontologie préalable ni d'un ensemble de catégories déjà constituées.

L'enquête commence lorsqu'une pratique descriptive rencontre une difficulté :

une distinction devient insuffisante ;

une catégorie devient instable ;

plusieurs descriptions semblent incompatibles ;

une fonction se transforme ;

un critère de justification devient contestable ;

plusieurs registres sont confondus ;

une condition est prise pour un critère ;

une description est confondue avec ce qu'elle décrit.


Le problème rend nécessaire une enquête sur les conditions, relations, fonctions et justifications qui permettent de le traiter.

## 2. Orientation : la quadripartition

La quadripartition fournit une orientation minimale :

Condition — dans quelles conditions corporelles, matérielles et environnementales ?

Relation — sous quelles relations et dépendances ?

Fonction — que fait cette configuration dans la pratique ?

Justification — selon quels critères peut-elle être défendue, contestée ou révisée ?


Ces quatre termes ne constituent ni des niveaux, ni des phases, ni des catégories ontologiques.

Au début de l'enquête, leur contenu est pratiquement indéterminé. Il se précise au cours de l'enquête et peut lui-même être reconfiguré.

La temporalité traverse les quatre dimensions au lieu de constituer une cinquième dimension.

# 3. Mouvement de l'enquête

La quadripartition oriente l'enquête ; elle n'en constitue pas la séquence.

Les opérations structurantes sont :

Délimiter → Ancrer → Distinguer → Relier → Configurer → Justifier → Reconstituer → Redélimiter

Délimiter

Rendre le problème enquêtable en déterminant provisoirement ce qui est en jeu.

Délimiter ne signifie pas résoudre.

Ancrer

Identifier les conditions corporelles, matérielles, écologiques et historiques pertinentes pour le problème.

Ancrer n'implique pas de réduire la pratique à ses conditions.

Distinguer

Séparer les éléments dont la confusion produit le problème.

Distinguer ne signifie pas isoler.

Relier

Examiner les relations, dépendances et articulations entre les éléments distingués.

Relier ne signifie pas convertir une relation en cause, une dépendance en fonction ou une fonction en justification.

Configurer

Examiner comment une différence devient identifiable, réutilisable et opératoire dans une pratique descriptive.

L'objet descriptif peut ainsi être compris comme une différence stabilisée comme identifiable et réutilisable dans une pratique descriptive.

Décrire une configuration n'est pas la constituer.

Justifier

Examiner les critères selon lesquels une description ou une distinction peut être défendue, contestée, corrigée ou révisée.

La justification ne se réduit pas à la genèse de la description.

Reconstituer

Reconstruire la configuration du problème à partir des distinctions, relations, fonctions et critères établis au cours de l'enquête.

Reconstituer ne signifie pas revenir à une totalité initiale.

Il s'agit de déterminer comment les éléments peuvent tenir ensemble sans supprimer les distinctions nécessaires.

Redélimiter

Reprendre les frontières initiales du problème à partir de ce que l'enquête a rendu visible.

La redélimitation peut conduire à une nouvelle formulation du problème et donc à une nouvelle enquête.

# 4. Fonctions transversales

Certaines opérations ne constituent pas des étapes supplémentaires de la chaîne.

Elles traversent l'ensemble de l'enquête :

Temporaliser — examiner les transformations, continuités, ruptures et déplacements dans le temps.

Auditer — contrôler les distinctions, les inférences et les éventuelles conversions entre registres.

Réfléchir — appliquer l'enquête à ses propres conditions et opérations.

Éprouver — confronter les distinctions et les relations établies à des cas, substitutions, comparaisons ou reprises.


Ces fonctions peuvent intervenir à tout moment.

# 5. Registres à distinguer

L'enquête peut rencontrer plusieurs registres dont les relations doivent être examinées sans les convertir les uns dans les autres :

Cognitif — discrimination, prise en compte, réactivité différentielle, capacité à traiter une différence.

Sémantique — expressions, usages, inférences, critères d'application et fonctions descriptives.

Référentiel — ce à quoi une description prétend renvoyer.


Ces registres peuvent être interdépendants sans être identiques.

Quelques distinctions structurantes :

relation cognitive ≠ relation sémantique ;

relation sémantique ≠ référence ;

stabilisation sémantique ≠ stabilisation référentielle ;

dépendance sociale de la pratique descriptive ≠ constitution sociale du référent ;

critère de correction ≠ propriété du référent ;

contexte descriptif ≠ constitution du référent.


# 6. Instruments d'épreuve

L'enquête dispose d'opérations locales permettant d'éprouver les distinctions établies.

Substitution

Remplacer un élément d'une pratique descriptive afin d'examiner ce qui reste invariant et ce qui se transforme.

La substitution peut porter sur :

une expression ;

une catégorie ;

un critère ;

une formulation ;

une inférence ;

une fonction descriptive.


La substituabilité dans un contexte ne constitue pas une équivalence générale.

Cas

Confronter une distinction à une situation déterminée afin d'identifier ce qu'elle permet effectivement de distinguer.

Comparaison

Mettre en relation plusieurs configurations afin d'identifier des continuités, différences ou transformations pertinentes.

Reprise

Réexaminer une distinction, une description ou une inférence à partir de ce que l'enquête a produit ultérieurement.

Ces instruments ne constituent pas des étapes obligatoires.

# 7. Reconfiguration

L'enquête doit pouvoir transformer ses propres distinctions.

Une distinction peut être :

conservée ;

précisée ;

déplacée ;

reconfigurée ;

révisée ;

abandonnée.


La reconfiguration n'est donc pas une étape finale ajoutée à l'enquête. Elle désigne la possibilité permanente de modifier les instruments conceptuels lorsque ceux-ci ne permettent plus de traiter adéquatement le problème.

# 8. Principe de non-conversion

L'ensemble du système est organisé par un principe de non-conversion :

continuité des dépendances + discontinuité des fonctions + non-conversion

Les éléments d'une configuration peuvent être interdépendants sans être réductibles les uns aux autres.

Ainsi :

condition ≠ critère ;

cause ≠ raison ;

genèse ≠ justification ;

relation ≠ fonction ;

fonction ≠ justification ;

trace ≠ signification ;

capacité ≠ performance ;

description ≠ objet décrit ;

contexte ≠ référent ;

incarnation ≠ réduction biologique.


L'architecture de Protokin n'est donc ni une chaîne de constitution ni une hiérarchie de niveaux.

Elle organise les déplacements de l'enquête tout en permettant leur reprise et leur reconfiguration.

Distinguer sans isoler.

Articuler sans convertir.
