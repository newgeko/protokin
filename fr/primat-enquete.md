| Fonction | Établir que, dans Protokin, une description n'est jamais une donnée immédiate mais le résultat d'une enquête, explicite ou implicite, par laquelle des différences sont identifiées, sélectionnées, organisées et justifiées. |

## 1. Problème conceptuel inaugural

Une description apparaît souvent comme un simple constat.

Nous disons :

> « Le vélo est rouge. »

> « Cette personne est dangereuse. »

> « Cette plante appartient à cette espèce. »

Ces énoncés donnent l'impression de rapporter immédiatement une réalité déjà disponible.

Pourtant, aucune description n'est produite sans qu'un travail de sélection, de comparaison, de catégorisation et d'évaluation ait déjà été accompli.

Le problème auquel répond ce principe est donc le suivant :

> **Comment une description devient-elle possible si elle ne consiste jamais en une simple copie du réel ?**

Protokin répond que toute description résulte d'une enquête.

Cette enquête peut être extrêmement brève ou très élaborée, individuelle ou collective, consciente ou largement incorporée, mais elle précède toujours la stabilisation d'une description.

---

## 2. Définition fonctionnelle

Dans l'architecture de Protokin, le **primat de l'enquête** désigne le principe méthodologique selon lequel :

> **Toute description procède d'un processus d'investigation par lequel un collectif ou un locuteur identifie des différences, mobilise des ressources descriptives, sélectionne des critères, construit une qualification et la rend publiquement justifiable.**

Ce principe implique plusieurs conséquences fondamentales.

### Une description est une reconstruction

Décrire ne consiste jamais à reproduire directement le monde.

Décrire consiste à reconstruire une situation selon certains critères, certaines catégories et certaines finalités.

Toute description est ainsi le résultat d'un travail descriptif.

### L'enquête précède la stabilisation

Avant qu'une description puisse être reconnue comme recevable, elle doit être construite.

Cette construction mobilise notamment :

- des observations ;
- des comparaisons ;
- des distinctions ;
- des classifications ;
- des instruments ;
- des pratiques collectives.

### L'enquête peut être invisible

Les enquêtes les plus ordinaires passent souvent inaperçues.

Les habitudes perceptives, les apprentissages, les savoir-faire incorporés et les pratiques institutionnelles condensent des enquêtes antérieures.

Une description ordinaire prolonge ainsi une histoire d'investigations déjà stabilisées.

---

## 3. Distinctions conceptuelles nécessaires

### Enquête et observation

Observer ne suffit pas à produire une description.

Une observation devient descriptive lorsqu'elle est interprétée à partir de critères permettant d'organiser les différences rencontrées.

L'enquête dépasse donc la simple observation.

### Enquête et démonstration

L'enquête précède la démonstration.

Elle construit les descriptions qui pourront ensuite être discutées, justifiées ou contestées.

### Enquête et audit

L'enquête produit une description.

L'audit examine les conditions qui rendent cette description possible, recevable ou transformable.

L'audit constitue ainsi une enquête de second ordre portant sur des pratiques descriptives déjà constituées.

---

## 4. Les opérations fondamentales de l'enquête

Toute enquête descriptive mobilise, selon des formes variables, plusieurs opérations complémentaires :

- rencontrer une situation ;
- identifier des différences pertinentes ;
- mobiliser des supports descriptifs ;
- sélectionner des catégories ;
- appliquer des critères ;
- produire une description ;
- justifier cette description ;
- la confronter aux pratiques collectives ;
- la réviser si nécessaire.

Ces opérations ne constituent pas une chronologie rigide.

Elles décrivent les dépendances fonctionnelles qui rendent une description possible.

---

## 5. Éclairage par les fils rouges pédagogiques

### « Le vélo est rouge »

La couleur n'est pas simplement reçue.

Le locuteur distingue une propriété, mobilise les catégories ordinaires de couleur, suppose des conditions perceptives adéquates et produit une qualification partageable.

Même la description la plus simple résulte ainsi d'une enquête pratique.

### « Cette personne est dangereuse »

L'enquête devient ici beaucoup plus exigeante.

Quels faits sont retenus ?

Quels critères sont mobilisés ?

Dans quel régime descriptif ?

Quelles conséquences cette qualification autorise-t-elle ?

La description dépend directement de l'enquête qui la construit.

### Le botaniste et le bûcheron

Les deux enquêtent sur une même forêt.

Ils ne sélectionnent pourtant ni les mêmes différences, ni les mêmes critères, ni les mêmes finalités.

Leurs descriptions divergent parce que leurs enquêtes sont organisées différemment.

## 6. Place dans l'architecture fonctionnelle

Le primat de l'enquête constitue l'un des engagements fondamentaux de Protokin.

Il prolonge le primat du couplage organisme-milieu et le primat de la description.

Il prépare directement :

- les configurations descriptives ;
- les critères ;
- les régimes descriptifs ;
- les engagements du locuteur ;
- la justification ;
- l'audit.

Il rappelle que les descriptions ne sont jamais des données premières mais les produits de pratiques d'investigation.

---

## 7. Vigilances d'audit

### Le mythe de l'immédiateté

Erreur consistant à croire qu'une description reproduit directement le réel.

Toute description suppose une enquête préalable.

### Le mythe de la neutralité absolue

Erreur consistant à croire que l'enquête pourrait être indépendante de toute pratique, de tout critère ou de toute finalité.

Toute enquête est située.

### Le relativisme intégral

Erreur consistant à conclure que toutes les enquêtes se valent.

Les enquêtes peuvent être comparées, discutées, corrigées et évaluées selon les normes propres aux régimes descriptifs concernés.

---

## 8. Synthèse et ouvertures

Le primat de l'enquête établit que toute description résulte d'un travail de reconstruction plutôt que d'une simple réception du monde.

Décrire consiste toujours à enquêter.

Cette enquête peut être ordinaire ou scientifique, individuelle ou collective, explicite ou incorporée, mais elle demeure la condition de possibilité de toute pratique descriptive.

**Ce qu'il suppose :** le primat du couplage organisme-milieu, le primat de la description et la description située.

**Ce qu'il rend possible :** l'étude de l'enquête protokinienne, des régimes descriptifs, de la justification, de l'audit et des transformations des pratiques descriptives.
