# Les niveaux descriptifs

| Fonction | Établir et distinguer les différents plans d'analyse mobilisés par Protokin afin de structurer l'enquête descriptive et de rendre possible l'audit des confusions de niveaux. |
| :--- | :--- |
| **Prépare** | Le diagnostic des réductions descriptives, des naturalisations, des confusions de plans et des déplacements illégitimes entre espaces d'analyse. |
| **Mobilise** | Les configurations sémiotiques, les supports descriptifs, les configurations descriptives, les taxonomies, les objets descriptifs, les régimes et les engagements. |
| **Permet ensuite** | L'analyse méthodique des pratiques collectives de description, des processus de stabilisation et des transformations historiques des régimes descriptifs. |
| **N'établit pas** | Une hiérarchie ontologique du réel ni une théorie générale des objets existants indépendamment des pratiques descriptives. |

---

# 1. Problème conceptuel inaugural

Toute description implique plusieurs dimensions simultanées :

- des inscriptions matérielles ;
- des formes sémiotiques ;
- des catégories ;
- des critères ;
- des engagements normatifs ;
- des objets stabilisés ;
- des processus historiques de maintien.

Une difficulté majeure apparaît lorsque ces dimensions sont confondues.

Une erreur fréquente consiste par exemple à expliquer une justification normative uniquement par ses conditions matérielles, ou à traiter un objet institutionnel comme une propriété naturelle.

Le problème auquel répond la notion de **niveaux descriptifs** est donc :

> Comment distinguer les différents plans impliqués dans une pratique descriptive afin de pouvoir analyser leurs relations sans les réduire les uns aux autres ?

Les niveaux descriptifs constituent ainsi une grille d'analyse.

Ils ne décrivent pas différentes parties d'un monde déjà constitué.

Ils permettent de reconstruire les opérations par lesquelles un collectif produit, maintient et évalue des descriptions.

---

# 2. Définition fonctionnelle

Dans l'architecture de Protokin, on appelle **niveau descriptif** :

> **Un plan analytique permettant d'identifier une dimension particulière de la constitution, de la circulation, de la justification ou de la stabilisation d'une description au sein d'une pratique collective.**

Les niveaux descriptifs sont donc :

- des outils méthodologiques ;
- des distinctions d'enquête ;
- des repères pour l'audit.

Ils ne sont pas :

- des couches ontologiques ;
- des degrés d'existence ;
- des parties séparées du réel.

---

# 3. Principe général

Une description complète peut être examinée selon plusieurs plans :

```text
Comment une description circule ?
        ↓
Support descriptif

Comment devient-elle intelligible ?
        ↓
Configuration sémiotique

Comment devient-elle descriptible ?
        ↓
Configuration descriptive

Comment est-elle appliquée ?
        ↓
Qualification

Comment est-elle justifiée ?
        ↓
Régime descriptif

Comment devient-elle durable ?
        ↓
Stabilisation historique
```

Ces plans ne forment pas une échelle de valeur.

Ils constituent une cartographie des opérations descriptives.

---

# 4. Les six niveaux descriptifs fondamentaux

## 4.1 Le support descriptif
### Plan matériel d'inscription et de circulation

Le support désigne les moyens matériels par lesquels une description est conservée, transmise et rendue disponible.

Exemples :

- document ;
- archive ;
- base de données ;
- instrument de mesure ;
- image ;
- graphique.

Le support permet la circulation d'une description.

Il ne constitue cependant pas sa validité.

Un document peut transporter une assertion sans garantir sa correction.

---

## 4.2 La configuration sémiotique
### Plan des traces et des différences perceptibles

La configuration sémiotique désigne l'organisation des signes, traces, mesures et contrastes à partir desquels une différence devient perceptible.

Elle concerne :

- les signaux ;
- les inscriptions ;
- les données ;
- les variations observables.

Elle rend possible une prise en compte sémiotique d'une situation.

Elle ne constitue pas encore une description pleinement justifiée.

---

## 4.3 La configuration descriptive
### Plan de l'intelligibilité conceptuelle

La configuration descriptive organise les catégories, les distinctions et les relations permettant de rendre une situation dicible.

Elle comprend :

- des catégories ;
- des critères ;
- des taxonomies ;
- des relations d'inférence.

Elle définit l'espace des descriptions possibles.

---

## 4.4 Le régime descriptif
### Plan normatif de justification

Le régime descriptif désigne les règles selon lesquelles une description peut être évaluée.

Il détermine :

- les critères de correction ;
- les formes de preuve recevables ;
- les procédures de justification ;
- les conditions de critique.

Il appartient à l'espace des raisons.

---

## 4.5 L'engagement descriptif
### Plan déontique de responsabilité

Lorsqu'un locuteur produit une assertion, il assume des engagements.

Ces engagements déterminent :

- ce qu'il doit pouvoir défendre ;
- les conséquences inférentielles acceptées ;
- les objections auxquelles il doit répondre.

L'engagement descriptif concerne donc la position du locuteur dans l'espace des raisons.

---

## 4.6 La stabilisation historique
### Plan diachronique de maintien

La stabilisation désigne les processus par lesquels une description devient durable.

Elle implique :

- apprentissage ;
- institutionnalisation ;
- répétition ;
- transmission ;
- inscription dans des dispositifs matériels.

La stabilisation produit des effets de continuité et parfois d'inertie.

---

# 5. L'objet descriptif comme point de convergence

L'objet descriptif traverse plusieurs niveaux.

Il apparaît lorsque :

- une configuration descriptive organise des distinctions ;
- des critères permettent des qualifications répétées ;
- une communauté maintient une référence commune.

L'objet descriptif n'est donc pas un niveau supplémentaire indépendant.

Il est un **invariant stabilisé produit par l'articulation des différents niveaux**.

# 6. Éclairage par les fils rouges

## « Cette personne est dangereuse »

### Support

Un dossier administratif, un rapport d'expertise ou une base de données.

### Configuration sémiotique

Des traces :

- comportements observés ;
- antécédents ;
- évaluations.

### Configuration descriptive

Une organisation des catégories :

- risque ;
- menace ;
- dangerosité.

### Régime

Selon le contexte :

- régime judiciaire ;
- régime clinique ;
- régime sécuritaire.

### Engagement

L'assertion engage des conséquences :

- surveillance ;
- restriction ;
- décision institutionnelle.

### Stabilisation

La catégorie peut être intégrée dans des procédures et des systèmes durables.

---

## Le patient aux urgences

### Support

Moniteurs, dossiers médicaux, examens.

### Configuration sémiotique

Signaux :

- rythme cardiaque ;
- douleur ;
- constantes biologiques.

### Configuration descriptive

Catégories :

- urgence ;
- gravité ;
- diagnostic.

### Régime

Critères médicaux de décision.

### Engagement

Responsabilité clinique d'intervention.

### Stabilisation

Protocoles et apprentissages professionnels.

---

# 7. Pathologies de glissement entre niveaux

## Naturalisation

Une qualification produite dans un régime descriptif est transformée en propriété naturelle.

Exemple :

« Cette personne est dangereuse » devient une essence biologique.

---

## Réduction matérielle

Les conditions matérielles d'inscription sont confondues avec les conditions de validité.

Exemple :

Un résultat informatique est pris comme preuve suffisante indépendamment du régime de justification.

---

## Confusion normative

Une cause explicative est utilisée comme justification normative.

Exemple :

Expliquer pourquoi quelqu'un agit ne suffit pas à déterminer s'il doit être tenu responsable.

---

## Effacement du support

Une description apparaît comme indépendante des dispositifs matériels qui la rendent possible.

---

# 8. Place dans l'architecture fonctionnelle

Les niveaux descriptifs fournissent une grille transversale d'analyse.

Ils permettent d'examiner les différentes pages de Protokin sans les confondre.

```text
Configuration sémiotique

        ↓

Configuration descriptive

        ↓

Catégories / Critères / Taxonomies

        ↓

Qualification

        ↓

Engagement descriptif

        ↓

Objet descriptif

        ↓

Régime descriptif

        ↓

Stabilisation historique

        ↓

Audit
```

---

# 9. Synthèse

Les niveaux descriptifs ne sont pas des degrés d'existence.

Ils sont des plans d'analyse permettant de reconstruire les conditions par lesquelles une description devient :

- possible ;
- intelligible ;
- justifiable ;
- stabilisée.

Dans Protokin :

- le **support** rend la description transportable ;
- la **configuration sémiotique** rend les différences perceptibles ;
- la **configuration descriptive** rend les distinctions intelligibles ;
- le **régime descriptif** rend les descriptions évaluables ;
- l'**engagement descriptif** situe le locuteur dans l'espace des raisons ;
- la **stabilisation** explique la durée historique des descriptions.

Les niveaux descriptifs constituent ainsi l'instrument méthodologique permettant d'éviter les confusions de plans et de conduire un audit rigoureux des pratiques descriptives.
