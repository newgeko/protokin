# Page : une-meme-configuration-des-fonctions-descriptives-non-equivalente.md

Une même configuration, des fonctions descriptives non équivalentes

«Les mêmes configurations peuvent être prises dans des descriptions différentes sans que les fonctions de ces descriptions soient équivalentes.»

1. Une configuration n'impose pas une description unique

Protokin ne suppose pas qu'à chaque configuration corresponde une description privilégiée qui en révélerait l'essence.

Une même configuration peut être saisie selon plusieurs régimes descriptifs.

Un comportement peut ainsi être décrit comme :

- une transformation corporelle ;
- une modification d'un état biologique ;
- une interaction avec un milieu ;
- une conduite située dans une pratique sociale ;
- une assertion ;
- une justification ;
- une réponse à une raison.

Ces descriptions peuvent porter sur une même configuration matérielle ou événementielle sans pour autant accomplir la même opération.

La pluralité descriptive ne signifie donc pas nécessairement pluralité ontologique.

Elle signifie que la même configuration peut être engagée dans des fonctions descriptives différentes.

---

2. La différence porte sur la fonction

La question protokinienne n'est pas seulement :

«De quoi parle cette description ?»

Elle est aussi :

«Que fait cette description lorsqu'elle décrit cette configuration ?»

Une description causale peut identifier des conditions de production, des contraintes, des dépendances ou des transformations.

Une description normative peut identifier ce qui compte comme raison, ce qui justifie une assertion, ce qui autorise une inférence ou ce qui peut être contesté dans une pratique.

Même lorsqu'elles portent sur la même configuration, ces descriptions n'ont donc pas la même fonction.

La différence ne vient pas nécessairement de leurs objets.

Elle vient de ce qu'elles permettent d'établir.

---

3. Exemple : une assertion

Considérons une personne qui affirme :

«« Il va pleuvoir. »»

Cette assertion peut faire l'objet de plusieurs descriptions.

On peut décrire les conditions physiologiques de sa production, les processus neuronaux impliqués, l'histoire de son apprentissage, les conditions météorologiques qui ont provoqué certaines perceptions ou encore les interactions sociales dans lesquelles l'énoncé apparaît.

Ces descriptions peuvent expliquer pourquoi cette personne produit cette assertion.

Mais une autre question apparaît :

«Qu'est-ce qui compte comme raison de tenir cette assertion pour vraie ?»

Les données météorologiques, une observation, une inférence à partir de certaines informations peuvent fonctionner comme des raisons dans l'espace normatif.

Le processus causal qui a conduit la personne à prononcer la phrase ne constitue pas, par lui-même, la justification de cette phrase.

La même configuration peut donc être décrite causalement et normativement sans que les deux descriptions soient convertibles.

---

4. Cause et raison ne sont pas deux objets

Cette distinction ne doit cependant pas conduire à poser deux réalités séparées.

Protokin ne soutient pas :

«un monde des causes d'un côté et un monde des raisons de l'autre.»

Il soutient une séparation fonctionnelle des descriptions.

La causalité et la normativité ne sont pas ici deux substances ou deux régions de l'Être.

Ce sont deux manières irréductibles de prendre une configuration dans une enquête.

Ainsi :

espace des causes
→ produire, contraindre, maintenir, transformer

espace des raisons
→ justifier, inférer, contester, autoriser, répondre

La distinction est franche au niveau de la fonction, sans devenir une distinction ontologique.

---

5. Le principe de non-conversion

Cette distinction conduit à un principe central :

«Une description ne peut pas être convertie dans une autre simplement parce qu'elles portent sur une même configuration.»

Une cause n'est pas une raison simplement parce qu'elle explique la production d'une assertion.

Une raison n'est pas une cause simplement parce qu'elle peut produire des effets matériels.

Une condition biologique peut rendre possible une capacité de justification sans constituer elle-même une justification.

Une justification peut entraîner une transformation corporelle ou sociale sans devenir pour autant une explication causale de cette transformation.

La relation entre les régimes doit donc être pensée comme une articulation sans conversion.

---

6. L'erreur réductionniste

Le réductionnisme apparaît lorsque la fonction d'un régime est absorbée par celle d'un autre.

Une forme de réductionnisme consiste à dire :

«« Puisque nous pouvons expliquer causalement pourquoi quelqu'un affirme quelque chose, nous avons expliqué ce qui justifie son affirmation. »»

Une autre consiste à dire :

«« Puisque les raisons produisent des effets dans le monde, elles peuvent être entièrement décrites comme des causes. »»

Dans les deux cas, une fonction descriptive est remplacée par une autre.

Le problème n'est donc pas simplement une erreur de vocabulaire.

C'est une erreur de régime.

---

7. L'irréductibilité n'est pas l'incommunicabilité

Dire que les fonctions descriptives ne sont pas équivalentes ne signifie pas qu'elles soient isolées.

Une configuration peut être suivie à travers plusieurs régimes.

Une transformation corporelle peut conditionner l'apparition d'une capacité discursive.

Une pratique sociale peut modifier les conditions matérielles d'une activité.

Une raison peut conduire à une action qui produit ensuite des transformations matérielles.

Il existe donc des enchaînements, des dépendances et des transductions entre les régimes.

Mais le passage d'un régime à un autre ne transforme pas automatiquement la fonction de la description.

La condition matérielle d'une justification n'est pas la justification elle-même.

La conséquence matérielle d'une raison n'est pas la raison elle-même.

---

8. Même configuration, autre question

On peut alors formuler le problème autrement.

Ce n'est pas nécessairement :

«Quelle est la véritable description de cette configuration ?»

Mais :

«Quelle question cette description permet-elle de poser à cette configuration ?»

La même configuration peut ainsi répondre à plusieurs enquêtes :

Que produit-elle ?
→ description causale.

Qu'est-ce qui la maintient ?
→ description fonctionnelle ou dynamique.

Dans quelle pratique prend-elle sens ?
→ description sociale ou sémantique.

Qu'est-ce qui peut être invoqué pour la défendre ?
→ description normative.

Quelles transformations rend-elle possibles ?
→ description transductive.

Aucune de ces descriptions n'est simplement « la même description avec un vocabulaire différent ».

Elles accomplissent des opérations différentes.

---

9. Conséquence non-ontologique

C'est ici que le non-ontologisme protokinien devient décisif.

Si Protokin choisissait une ontologie fondamentale — matérialiste, idéaliste, naturaliste ou autre — il pourrait être tenté de réduire les autres descriptions à celle qui aurait été déclarée fondamentale.

Le refus ontologique empêche cette hiérarchisation préalable.

Protokin ne décide pas que la description causale est plus réelle que la description normative.

Il ne décide pas davantage que la description normative est plus profonde que la description causale.

Il examine la fonction que chacune remplit dans une pratique descriptive donnée.

La question n'est donc pas :

«Quelle description dit finalement ce que la configuration est ?»

Mais :

«Que devient la configuration lorsqu'elle est prise dans tel régime descriptif plutôt que dans tel autre ?»

---

10. Formulation générale

On peut condenser le principe ainsi :

«Une même configuration peut traverser plusieurs régimes descriptifs sans que ces régimes soient ontologiquement distincts ni fonctionnellement équivalents.»

Ou, plus fortement :

«L'identité de la configuration ne garantit pas l'identité de la fonction descriptive.»

Et la conséquence méthodologique :

«Articuler des descriptions ne signifie jamais les convertir les unes dans les autres.»

C'est précisément cette distinction qui permet à Protokin de maintenir une séparation franche entre l'espace des causes et l'espace des raisons, tout en refusant d'en faire deux domaines ontologiques du réel.
