# Configuration descriptive — L'organisation relationnelle des possibilités descriptives

## Fonction de la page

Cette page existe pour établir la fonction conceptuelle de la **configuration descriptive** dans l'architecture de Protokin.

Elle explique comment des différences devenues disponibles grâce aux configurations sémiotiques et aux supports descriptifs s'organisent en un réseau relationnel permettant l'apparition de descriptions possibles.

La configuration descriptive constitue l'espace intermédiaire dans lequel des distinctions, des catégories, des relations et des possibilités d'inférence deviennent articulables avant leur actualisation dans une description particulière.

---

# 1. Problème conceptuel inaugural

Une description ne surgit jamais directement à partir d'une perception ou d'une inscription isolée.

Une différence visible, mesurée ou enregistrée ne constitue pas encore une description.

Entre une trace disponible et une proposition descriptive existe une étape intermédiaire : l'organisation relationnelle des possibilités descriptives.

Le problème auquel répond cette page est donc :

> Comment des différences disponibles deviennent-elles un espace structuré dans lequel certaines descriptions peuvent être formulées, comparées, reliées ou contestées ?

Une configuration sémiotique permet qu'une différence soit retenue et rendue disponible.

Un support descriptif permet qu'elle soit conservée et transmise.

Mais il faut encore une organisation relationnelle qui permette de déterminer :

- quelles distinctions sont pertinentes ;
- quelles catégories peuvent être mobilisées ;
- quelles relations peuvent être établies ;
- quelles inférences deviennent possibles ;
- quelles descriptions deviennent intelligibles.

La configuration descriptive désigne cette étape d'organisation.

---

# 2. Définition fonctionnelle

Dans l'architecture de Protokin, on appelle **configuration descriptive** :

> Une organisation relationnelle de différences disponibles, de catégories, de contrastes et de relations inférentielles qui structure un espace de possibilités descriptives au sein duquel certaines descriptions peuvent être formulées, comparées et évaluées.

Cette définition implique plusieurs propriétés fondamentales.

---

## 2.1 Une organisation relationnelle

Une configuration descriptive n'est pas une collection d'éléments indépendants.

Elle existe par les relations qu'elle établit entre :

- des catégories ;
- des propriétés ;
- des oppositions ;
- des ressemblances ;
- des incompatibilités ;
- des conséquences pratiques.

Une couleur n'est pas seulement une perception isolée.

Elle appartient à un espace chromatique où existent :

- des différences ;
- des comparaisons ;
- des exclusions ;
- des possibilités de qualification.

Une catégorie médicale n'existe pas seulement comme un terme.

Elle appartient à un réseau reliant :

- des symptômes ;
- des observations ;
- des hypothèses ;
- des traitements ;
- des décisions.

---

## 2.2 Un espace de dicibilité

La configuration descriptive définit ce qui peut être dit d'une situation.

Elle ne produit pas encore une description particulière.

Elle rend certaines descriptions possibles.

Elle détermine un espace dans lequel peuvent apparaître :

- des prédications ;
- des assertions ;
- des classifications ;
- des explications ;
- des justifications.

Elle ne répond donc pas encore à la question :

> Que dit-on effectivement ?

Elle répond à la question :

> Qu'est-il possible de dire dans cette organisation descriptive ?

---

## 2.3 Une structure inférentielle

Une configuration descriptive organise également des possibilités d'inférence.

Elle établit des relations du type :

- si telle propriété est présente, certaines conséquences deviennent pertinentes ;
- si telle catégorie est utilisée, certaines distinctions deviennent nécessaires ;
- si telle description est avancée, certaines justifications peuvent être demandées.

La configuration descriptive prépare ainsi l'entrée dans l'espace des raisons.

Elle constitue l'armature relationnelle permettant aux descriptions d'être discutables et évaluables.

---

# 3. Distinctions conceptuelles nécessaires

Afin d'éviter les confusions de niveaux, la configuration descriptive doit être distinguée des autres concepts de Protokin.

---

## 3.1 Configuration descriptive et configuration sémiotique

La configuration sémiotique concerne l'organisation des différences disponibles.

Elle répond à la question :

> Quelles différences peuvent être retenues comme traces ou signes ?

La configuration descriptive intervient ensuite.

Elle répond à la question :

> Comment ces différences peuvent-elles être organisées dans un réseau de relations permettant des descriptions ?

Passage :

Configuration rencontrée ↓ Configuration sémiotique ↓ Configuration descriptive ↓ Description

La configuration sémiotique rend les différences disponibles.

La configuration descriptive les rend articulables.

---

## 3.2 Configuration descriptive et support descriptif

Le support descriptif concerne les médiations matérielles, techniques ou institutionnelles permettant l'inscription et la circulation des différences.

La configuration descriptive concerne l'organisation relationnelle de ces différences.

Exemple :

Un dossier médical est un support descriptif.

La classification des symptômes, diagnostics possibles et relations causales mobilisées par les médecins constitue une configuration descriptive.

Le support conserve.

La configuration organise.

---

## 3.3 Configuration descriptive et description

La configuration descriptive n'est pas une description particulière.

Elle constitue l'espace dans lequel plusieurs descriptions peuvent être produites.

Une même configuration peut permettre différentes actualisations.

Exemple :

Une personne peut être décrite selon :

- une configuration juridique ;
- une configuration médicale ;
- une configuration morale ;
- une configuration administrative.

La configuration descriptive rend ces descriptions possibles sans imposer une seule actualisation.

---

## 3.4 Configuration descriptive et régime descriptif

La configuration descriptive organise les possibilités de description.

Le régime descriptif détermine les conditions selon lesquelles certaines descriptions deviennent recevables.

La distinction est donc :

Configuration descriptive ↓ Possibilités de description ↓ Régime descriptif ↓ Critères de recevabilité

Le régime n'est pas la structure des possibilités.

Il constitue l'espace normatif dans lequel ces possibilités sont évaluées.

---

# 4. La configuration descriptive comme espace des possibles

Une configuration descriptive constitue un espace de possibilités.

Elle permet plusieurs actualisations selon les pratiques, les intérêts et les normes mobilisées.

Elle ne détermine jamais mécaniquement une seule description.

Une même situation peut être organisée selon plusieurs configurations descriptives.

Cette pluralité explique pourquoi des acteurs peuvent produire des descriptions différentes sans nécessairement être en contradiction immédiate.

Le conflit peut porter :

- sur les catégories utilisées ;
- sur les relations établies ;
- sur les critères mobilisés ;
- sur le régime descriptif adopté.

---

# 5. Éclairage par les fils rouges pédagogiques

## 5.1 « Le vélo est rouge »

L'assertion :

> « Le vélo est rouge »

ne repose pas uniquement sur une différence perceptive.

Elle suppose une configuration descriptive comprenant :

- une catégorie d'objet (« vélo ») ;
- une catégorie chromatique (« rouge ») ;
- des oppositions avec d'autres couleurs ;
- des critères permettant d'identifier cette couleur.

La configuration descriptive rend l'assertion possible.

Elle organise l'espace dans lequel cette assertion peut être formulée et contestée.

---

## 5.2 Le botaniste et le bûcheron

Dans une même forêt, le botaniste et le bûcheron ne mobilisent pas la même configuration descriptive.

Le botaniste organise les différences selon :

- des espèces ;
- des caractéristiques morphologiques ;
- des relations écologiques.

Le bûcheron organise les différences selon :

- la résistance ;
- la densité ;
- la qualité matérielle ;
- l'utilité pratique.

Ils ne disposent pas seulement de données différentes.

Ils articulent les différences disponibles dans des réseaux descriptifs différents.

---

## 5.3 Le patient aux urgences

Les mêmes inscriptions médicales peuvent entrer dans plusieurs configurations descriptives.

Un rythme cardiaque élevé peut être organisé comme :

- un signe clinique ;
- une urgence administrative ;
- un indicateur physiologique ;
- un élément statistique.

Chaque configuration ouvre un espace d'inférences différent.

---

## 5.4 « Cette personne est dangereuse »

La qualification :

> « Cette personne est dangereuse »

présuppose une configuration descriptive reliant :

- des comportements observés ;
- des catégories de risque ;
- des critères institutionnels ;
- des conséquences possibles.

Sans cette organisation relationnelle, aucune qualification durable ne pourrait être formulée.

---

# 6. Place dans l'architecture fonctionnelle

La configuration descriptive appartient à :

03 — Fondements descriptifs

Elle occupe une position centrale dans la trajectoire de production des descriptions.

La chaîne fonctionnelle est :

Configuration rencontrée ↓ Couplage perception-action ↓ Configuration sémiotique ↓ Support descriptif ↓ Configuration descriptive ↓ Description ↓ Régime descriptif

Elle constitue le niveau où les différences deviennent des possibilités organisées de description.

---

# 7. Limites internes du concept

## 7.1 La clôture relative

Toute configuration descriptive sélectionne certaines relations plutôt que d'autres.

Elle rend visibles certaines distinctions et en laisse d'autres dans l'ombre.

Elle possède donc nécessairement :

- des exclusions ;
- des zones de silence ;
- des limites internes.

---

## 7.2 La dépendance historique

Les configurations descriptives ne sont jamais fixes.

Elles évoluent avec :

- les transformations techniques ;
- les découvertes ;
- les controverses ;
- les changements institutionnels ;
- les pratiques collectives.

Une configuration descriptive est toujours une stabilisation historique relative.

---

## 7.3 Le risque de naturalisation

Une configuration descriptive peut être prise à tort comme une organisation naturelle du monde.

Protokin refuse cette confusion.

Une configuration descriptive n'est pas une structure ultime du réel.

Elle est une organisation fonctionnelle permettant à une communauté de produire des descriptions.

# Synthèse fonctionnelle

La configuration descriptive désigne l'espace relationnel dans lequel des différences disponibles deviennent des possibilités descriptives organisées.

Elle n'est ni une trace, ni un support, ni une description particulière.

Elle constitue l'architecture intermédiaire qui permet à une communauté de produire des descriptions intelligibles, comparables et contestables.

Elle établit ainsi un principe central de Protokin :

> Une description n'apparaît jamais directement à partir d'une différence isolée ; elle devient possible dans une configuration relationnelle qui organise les conditions de sa dicibilité.
