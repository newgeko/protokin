# Exemples — Applications de l'analyse protokinienne

## 1. Rôle du fichier

Ce fichier présente des exemples d'application de l'architecture Protokin.

Il ne constitue pas une collection d'objets étudiés pour eux-mêmes.

Son objectif est de montrer comment une même opération analytique peut être appliquée à des configurations descriptives différentes.

Un exemple protokinien n'est donc pas une illustration secondaire d'une théorie déjà constituée.

Il constitue un dispositif d'épreuve permettant d'observer :

- comment une description se stabilise ;
- quels engagements elle produit ;
- quelles incompatibilités elle organise ;
- quelles justifications elle exige ;
- dans quels régimes elle devient opératoire ;
- quelles tensions apparaissent lors de sa traduction vers d'autres régimes.

---

2. Principe général : l'exemple comme opération d'audit

Une description ordinaire semble souvent transparente.

Dire :

«« Le vélo est rouge »»

«« Cette pièce est une monnaie »»

«« Cette personne est médecin »»

«« Cette action est illégale »»

semble simplement identifier une réalité existante.

L'analyse protokinienne suspend cette évidence.

Elle ne demande pas immédiatement :

«« Cette description est-elle vraie ? »»

mais :

«« Quelles sont les conditions qui permettent à cette description d'être stabilisée comme recevable dans un espace de pratiques ? »»

Toute description est alors analysée comme une opération qui :

- positionne un locuteur ;
- distribue des engagements ;
- ouvre certaines inférences ;
- ferme certaines possibilités ;
- mobilise un régime de validation ;
- peut entrer en tension avec d'autres régimes.

---

3. Grille commune d'analyse

Chaque exemple suit une même structure.

3.1 La prédication comme engagement

Une description n'est pas une simple étiquette.

Elle engage celui qui l'utilise.

Affirmer quelque chose signifie accepter certaines conséquences et devenir responsable de la position adoptée.

---

3.2 La prédication comme différenciation

Toute description stabilisée crée simultanément un espace d'inclusion et d'exclusion.

Un concept existe également par les descriptions qu'il rend incompatibles.

---

3.3 La prédication comme responsabilité justificative

Une assertion peut être contestée.

Elle doit donc pouvoir être soutenue par des raisons publiques :

- critères ;
- procédures ;
- institutions ;
- pratiques reconnues.

---

3.4 La stabilisation par régimes descriptifs

Une même configuration peut être décrite selon plusieurs régimes :

- perceptif ;
- scientifique ;
- institutionnel ;
- juridique ;
- économique ;
- politique.

L'analyse ne cherche pas à réduire ces régimes à un seul niveau.

Elle étudie leurs relations.

---

4. Exemple 1 — Le vélo est rouge

Type d'opération

Classification perceptive ordinaire.

Énoncé

«« Le vélo est rouge. »»

Analyse

Cette description semble attribuer une propriété au vélo.

Cependant, dans une perspective protokinienne, le prédicat « rouge » n'est pas analysé comme une substance présente dans l'objet.

Il est analysé comme une position dans un réseau d'inférences.

Dire que le vélo est rouge implique :

- qu'il appartient à une catégorie chromatique reconnue ;
- qu'il peut être distingué d'autres couleurs ;
- que certaines descriptions alternatives deviennent incompatibles.

Régimes mobilisés

Régime perceptif

Le vélo est identifié selon une expérience visuelle ordinaire.

Régime scientifique

La couleur peut être traduite en termes de propriétés optiques.

Régime industriel

La couleur peut être stabilisée par une référence technique.

Thèse

«La couleur n'est pas seulement une propriété observée ; elle est une description stabilisée par des pratiques de reconnaissance.»

---

5. Exemple 2 — Cette pièce est une monnaie

Type d'opération

Fonction-statut institutionnelle.

Énoncé

«« Cette pièce est une monnaie. »»

Analyse

La monnaie ne résulte pas simplement des propriétés physiques du support.

Un morceau de métal peut être :

- une pièce en circulation ;
- un objet historique ;
- un fragment métallique ;
- un jeton.

Le statut monétaire apparaît lorsque certaines pratiques institutionnelles stabilisent l'objet comme intermédiaire d'échange.

Engagements produits

Reconnaître une pièce comme monnaie implique :

- qu'elle puisse être utilisée dans certaines transactions ;
- qu'elle représente une valeur reconnue ;
- qu'elle soit intégrée à un système d'obligations économiques.

Régimes mobilisés

Régime économique

La pièce fonctionne comme unité d'échange.

Régime physico-chimique

Elle est décrite comme objet matériel.

Régime historique

Elle peut devenir un artefact patrimonial.

Thèse

«La monnaie n'est pas une propriété du métal ; elle est une configuration institutionnelle stabilisée entre matérialité et reconnaissance collective.»

---

6. Exemple 3 — Cette personne est médecin

Type d'opération

Statut agentif normatif.

Énoncé

«« Cette personne est médecin. »»

Analyse

Le statut de médecin ne correspond pas à une propriété naturelle de l'individu.

Il résulte d'une articulation entre :

- formation ;
- certification ;
- reconnaissance institutionnelle ;
- pratiques professionnelles.

Engagements produits

Dire qu'une personne est médecin implique :

- une autorisation d'agir ;
- une responsabilité professionnelle ;
- une compétence reconnue ;
- des obligations déontologiques.

Régimes mobilisés

Régime juridico-institutionnel

Le médecin est titulaire d'un statut reconnu.

Régime clinique

Le médecin interprète des signes et produit des diagnostics.

Régime économique

Le médecin participe à une organisation des actes de soin.

Thèse

«Le médecin n'est pas une essence professionnelle ; il est une position normative stabilisée dans un réseau de pratiques.»

---

7. Exemple 4 — Cette action est illégale

Type d'opération

Qualification normative.

Énoncé

«« Cette action est illégale. »»

Analyse

L'illégalité n'est pas une propriété physique de l'acte.

Une action matérielle devient illégale lorsqu'elle est rapportée à un système de règles.

Engagements produits

Cette qualification implique :

- absence d'autorisation juridique ;
- possibilité de sanction ;
- intervention légitime des institutions compétentes.

Régimes mobilisés

Régime juridique

L'action devient une infraction.

Régime stratégique

L'illégalité peut être traitée comme un risque.

Régime politique

L'action peut être revendiquée comme contestation d'un ordre juridique.

Thèse

«L'illégalité est une stabilisation normative d'un événement matériel dans un régime de raisons juridiques.»

---

8. Exemple 5 — Cette personne est propriétaire

Type d'opération

Distribution de droits.

Analyse

La propriété n'est pas une relation physique entre une personne et un objet.

Elle constitue une configuration de droits :

- usage ;
- exclusion ;
- transmission ;
- responsabilité.

Régimes mobilisés

- droit civil ;
- économie ;
- histoire sociale.

Thèse

«Posséder n'est pas seulement avoir ; c'est occuper une position normative reconnue.»

---

9. Exemple 6 — Cette personne est citoyen

Type d'opération

Appartenance politique.

Analyse

La citoyenneté transforme un individu en sujet politique.

Elle produit :

- des droits ;
- des devoirs ;
- une participation reconnue.

Régimes mobilisés

- juridique ;
- administratif ;
- politique ;
- historique.

Thèse

«Le citoyen est une stabilisation institutionnelle de l'appartenance politique.»

---

10. Exemple 7 — Cette personne est expert

Type d'opération

Autorité épistémique.

Analyse

L'expertise ne consiste pas seulement à posséder des connaissances.

Elle correspond à une reconnaissance publique d'une capacité à produire des jugements fiables.

Régimes mobilisés

- scientifique ;
- professionnel ;
- institutionnel.

Thèse

«L'expert est une position dans un réseau de responsabilités justificatives.»

---

11. Exemple 8 — Cette œuvre est de l'art

Type d'opération

Classification culturelle.

Analyse

L'art ne réside pas uniquement dans les propriétés matérielles d'un objet.

Une œuvre est stabilisée par des pratiques :

- d'interprétation ;
- d'exposition ;
- d'évaluation.

Régimes mobilisés

- esthétique ;
- institutionnel ;
- marchand.

Thèse

«L'art est une stabilisation collective des conditions d'attention et d'évaluation.»

---

12. Exemple 9 — Cette maladie existe

Type d'opération

Classification scientifique et médicale.

Analyse

Une maladie n'est pas seulement une anomalie biologique.

Elle implique une articulation entre :

- signes corporels ;
- catégories médicales ;
- pratiques thérapeutiques ;
- normes de santé.

Régimes mobilisés

- biologique ;
- clinique ;
- statistique ;
- institutionnel.

Thèse

«Une maladie existe comme configuration stabilisée entre phénomènes biologiques et pratiques descriptives.»

14. Conclusion générale

Les exemples montrent une thèse centrale de Protokin :

«Une description n'est jamais une simple copie du monde. Elle est une opération de stabilisation qui organise des engagements, des exclusions, des responsabilités et des possibilités d'action.»

Qu'il s'agisse d'une couleur, d'une monnaie, d'un métier, d'une loi, d'une maladie ou d'une œuvre d'art, l'analyse protokinienne porte toujours sur les conditions qui permettent à une description de devenir opératoire dans un régime donné.

Le problème fondamental n'est donc pas :

«« Qu'est-ce que cette chose est réellement ? »»

mais :

«« Comment cette description parvient-elle à tenir, à circuler et à produire des effets dans un espace de raisons ? »»
