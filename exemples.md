# Exemples — applications de l’analyse Protokin

> Ce fichier présente des applications de l’architecture Protokin à différentes configurations descriptives.
>
> Il ne constitue pas un catalogue d’exemples particuliers, mais un modèle d’utilisation de la méthode d’enquête.

---

# 1. Fonction des exemples dans Protokin

Les exemples ont une fonction méthodologique.

Ils permettent de montrer comment l’architecture Protokin peut être mobilisée pour analyser une situation dans laquelle plusieurs descriptions coexistent, se complètent ou entrent en tension.

Un exemple protokinien ne cherche pas à :

- démontrer une théorie générale ;
- fournir une explication ultime ;
- identifier une description supérieure aux autres.

Il cherche à rendre visibles :

- les descriptions mobilisées ;
- les régimes auxquels elles appartiennent ;
- les engagements qu’elles impliquent ;
- les tensions qu’elles rencontrent ;
- les transformations possibles.
