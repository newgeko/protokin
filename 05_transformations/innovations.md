# Innovation descriptive

## Introduction

Les transformations descriptives ne consistent pas uniquement à modifier des descriptions déjà existantes.

Elles peuvent également conduire à l'apparition de nouvelles possibilités descriptives : de nouvelles distinctions, de nouveaux supports, de nouveaux modes d'organisation ou de nouvelles relations entre éléments.

Cette émergence constitue une dimension particulière des transformations descriptives.

Cette page examine le phénomène d'innovation descriptive.

> Elle ne décrit pas les mécanismes complets de transformation.
>
> Elle identifie uniquement comment de nouvelles capacités descriptives peuvent apparaître au sein d'une configuration existante.

---

## Qu'est-ce qu'une innovation descriptive ?

Une innovation descriptive désigne l'apparition d'une nouvelle manière de rendre un domaine intelligible.

Elle ne correspond pas nécessairement à la découverte d'un nouvel objet.

Elle peut concerner :

- une nouvelle distinction ;
- une nouvelle catégorie ;
- une nouvelle relation entre éléments ;
- un nouveau support descriptif ;
- une nouvelle manière d'organiser des descriptions existantes.

L'innovation porte donc sur les conditions de description elles-mêmes.

---

## Innovation et modification descriptive

Toute modification d'une description ne constitue pas une innovation.

Une transformation peut simplement :

- préciser une description existante ;
- corriger une erreur ;
- ajuster une catégorie ;
- adapter une pratique connue.

Une innovation apparaît lorsque la transformation introduit une possibilité descriptive qui n'était pas disponible auparavant.

Elle modifie alors l'espace des descriptions possibles.

---

## Apparition de nouvelles distinctions

Une forme importante d'innovation descriptive concerne la création de nouvelles distinctions.

Une configuration peut devenir capable de différencier des éléments qui étaient auparavant regroupés.

Cette nouvelle distinction peut permettre :

- de nouveaux diagnostics ;
- de nouvelles comparaisons ;
- de nouvelles pratiques ;
- de nouvelles formes de justification.

L'innovation consiste alors dans l'ouverture d'un nouvel espace de pertinence.

---

## Apparition de nouveaux supports

L'innovation descriptive peut également dépendre de nouveaux supports.

Voir :

- [Supports descriptifs](../02_architecture_conceptuelle/supports_descriptifs.md)
- [Supports incorporés et dispositions corporelles](../02_architecture_conceptuelle/supports_incorpores.md)

Un nouveau support peut rendre accessibles des dimensions auparavant difficiles à observer, transmettre ou stabiliser.

Les instruments, les langages, les dispositifs techniques ou les pratiques incorporées peuvent ainsi contribuer à l'apparition de nouvelles descriptions.

---

## Innovation et régimes descriptifs

Les innovations descriptives peuvent modifier les relations entre régimes.

Voir :

- [Régimes de description](../02_architecture_conceptuelle/regimes.md)

Une nouvelle description peut :

- prolonger un régime existant ;
- déplacer ses frontières ;
- rendre possible une articulation avec un autre régime ;
- contribuer à l'émergence d'une nouvelle organisation descriptive.

L'innovation ne signifie donc pas nécessairement rupture totale.

Elle peut apparaître comme une réorganisation progressive des possibilités descriptives.

---

## Innovation et trajectoire historique

Les innovations descriptives apparaissent toujours dans des configurations déjà constituées.

Elles dépendent notamment :

- des supports disponibles ;
- des pratiques existantes ;
- des tensions rencontrées ;
- des héritages transmis.

Voir :

- [Strates temporelles et irréversibilités](../02_architecture_conceptuelle/strates_temporelles.md)

Une innovation descriptive ne surgit donc pas hors contexte.

Elle émerge à partir de conditions historiques et pratiques particulières.

---

## Innovation et limites internes

Les innovations descriptives peuvent apparaître lorsque certaines configurations rencontrent des difficultés à organiser leur propre domaine.

Voir :

- [Limites internes](limites.md)

Une limite interne peut révéler :

- une distinction insuffisante ;
- un manque de support ;
- une tension entre descriptions ;
- une difficulté de justification.

Ces situations peuvent ouvrir un espace pour de nouvelles possibilités descriptives.

---

## Innovation et stabilisation

Une innovation descriptive ne devient pas automatiquement un régime établi.

Son apparition doit être distinguée de sa stabilisation.

Voir :

- [Stabilisation et effet cliquet](../02_architecture_conceptuelle/stabilisation.md)

Une nouvelle description peut rester locale, provisoire ou contestée avant de devenir durablement intégrée dans des pratiques collectives.

---

## Ce que cette page établit

Cette page établit que :

- les transformations descriptives peuvent produire de nouvelles possibilités descriptives ;
- l'innovation descriptive concerne les conditions permettant de rendre quelque chose intelligible autrement ;
- une innovation peut porter sur des distinctions, des supports ou des organisations descriptives ;
- les innovations apparaissent toujours dans des configurations historiques déjà constituées ;
- l'apparition d'une innovation doit être distinguée de sa stabilisation.
