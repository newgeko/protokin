# Unité d’analyse protokinienne

## Introduction

Toute enquête nécessite de déterminer ce qui constitue son objet d’analyse.

Dans Protokin, l’enquête ne prend pas comme unité première un individu isolé, une théorie particulière ou un ensemble d’énoncés.

Elle porte sur une organisation de relations entre descriptions, supports, pratiques et engagements.

L’unité d’analyse protokinienne désigne ainsi la structure minimale à partir de laquelle une configuration descriptive peut être étudiée.

> Elle ne décrit pas la méthode complète d’audit.
>
> Elle établit uniquement ce sur quoi porte l’analyse protokinienne.

---

## Pourquoi définir une unité d’analyse ?

Une analyse descriptive peut échouer si elle choisit une unité inadéquate.

Réduire l’analyse :

- à un énoncé isolé ;
- à une intention individuelle ;
- à un objet supposé indépendant ;
- à une théorie séparée de ses pratiques ;

risque de perdre les conditions qui rendent une description possible.

L’unité d’analyse protokinienne vise donc à conserver l’organisation relationnelle dans laquelle une description fonctionne.

---

## L’unité fondamentale : la configuration descriptive

L’unité d’analyse principale de Protokin est la configuration descriptive.

Elle correspond à l’agencement dans lequel sont reliés :

- des distinctions ;
- des objets descriptifs ;
- des supports ;
- des engagements ;
- des pratiques de justification.

Voir :

- [Configurations descriptives](../02_architecture_conceptuelle/configurations.md)

Une configuration descriptive constitue ainsi le niveau minimal permettant d’analyser comment quelque chose devient descriptible.

---

## Ce qui n’est pas l’unité d’analyse première

L’analyse protokinienne ne prend pas comme unité fondamentale :

### L’objet seul

Un objet n’est pas analysé indépendamment des conditions descriptives qui permettent de l’identifier.

Voir :

- [Objets descriptifs : invariants et stabilisations](../02_architecture_conceptuelle/objets_descriptifs.md)

---

### Le locuteur seul

Le locuteur n’est pas considéré comme une origine autonome de la description.

Il est analysé comme participant à une configuration normative.

Voir :

- [Locuteur normatif](../02_architecture_conceptuelle/locuteur.md)

---

### L’énoncé seul

Un énoncé possède une fonction descriptive dans un réseau d’engagements et de justifications.

Voir :

- [Inférences et justifications](../02_architecture_conceptuelle/inferences_justifications.md)

---

### Le régime seul

Un régime descriptif constitue une organisation générale de possibilités descriptives.

Mais son analyse nécessite son inscription dans des configurations concrètes.

Voir :

- [Régimes de description](../02_architecture_conceptuelle/regimes.md)

---

## Les dimensions constitutives de l’unité d’analyse

L’unité d’analyse protokinienne peut être étudiée selon plusieurs dimensions.

### Dimension descriptive

Elle concerne :

- les distinctions mobilisées ;
- les catégories produites ;
- les objets rendus accessibles.

---

### Dimension normative

Elle concerne :

- les engagements assumés ;
- les justifications possibles ;
- les critères de recevabilité.

Voir :

- [Engagements descriptifs](../02_architecture_conceptuelle/engagements.md)

---

### Dimension matérielle et incorporée

Elle concerne :

- les supports utilisés ;
- les pratiques corporelles ;
- les dispositifs techniques.

Voir :

- [Supports descriptifs](../02_architecture_conceptuelle/supports_descriptifs.md)

---

### Dimension collective

Elle concerne :

- les communautés de locuteurs ;
- la circulation des descriptions ;
- les formes collectives de stabilisation.

Voir :

- [Communauté de locuteurs](../02_architecture_conceptuelle/communaute_locuteurs.md)

---

## Unité d’analyse et changement descriptif

L’unité d’analyse protokinienne permet également d’étudier les transformations.

Lorsqu’une description change, l’analyse ne cherche pas seulement un nouvel énoncé ou une nouvelle théorie.

Elle examine les modifications de la configuration :

- nouvelles distinctions ;
- nouveaux objets ;
- nouveaux supports ;
- nouveaux engagements.

Voir :

- [Transitions descriptives](../05_transformations/transitions.md)

---

## Unité d’analyse et comparaison

La comparaison entre descriptions nécessite également une unité commune d’analyse.

Deux descriptions peuvent être comparées lorsqu’elles peuvent être rapportées à des configurations analysables selon des dimensions communes.

Voir :

- [Comparer des descriptions](comparer_descriptions.md)

La comparaison ne porte donc pas seulement sur les contenus produits, mais sur les organisations descriptives qui les rendent possibles.

---

## Ce que cette page établit

Cette page établit que :

- l’enquête protokinienne possède une unité d’analyse spécifique ;
- cette unité n’est ni un objet isolé, ni un individu, ni un énoncé séparé ;
- l’unité fondamentale est la configuration descriptive ;
- cette configuration articule dimensions descriptives, normatives, matérielles et collectives ;
- l’analyse porte sur les conditions d’apparition, de stabilisation et de transformation des descriptions.
