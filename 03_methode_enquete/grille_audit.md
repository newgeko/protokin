# Grille d’audit et questions directrices

## Introduction

L’audit Protokin constitue une démarche d’examen des conditions sous lesquelles une description devient intelligible, stabilisée, justifiable ou transformable.

La présente page ne définit pas l’audit lui-même.

Voir :

- [Audit Protokin](audit.md)

Elle fournit une grille pratique permettant d’orienter l’enquête sur une configuration descriptive donnée.

Son objectif est de guider l’observation sans réduire l’analyse à une procédure mécanique.

> Une grille d’audit ne produit pas une description supplémentaire.
>
> Elle organise les questions permettant d’examiner comment une description fonctionne.

---

## Fonction de la grille d’audit

Toute enquête Protokin cherche à identifier les conditions de fonctionnement d’une description.

La grille permet de structurer cette enquête autour de plusieurs dimensions :

- ce qui est décrit ;
- les supports mobilisés ;
- les distinctions produites ;
- les engagements associés ;
- les formes de stabilisation ;
- les possibilités de transformation.

Ces dimensions ne constituent pas des étapes obligatoires.

Elles forment un ensemble de points d’attention permettant d’éviter les réductions trop rapides.

---

# 1. Identifier la configuration descriptive

## Question directrice

> Quelle configuration descriptive est analysée ?

Avant toute analyse, il convient de déterminer l’unité descriptive examinée.

Questions associées :

- Quel phénomène, objet ou situation fait l’objet d’une description ?
- Dans quel contexte cette description apparaît-elle ?
- Quels éléments sont rendus pertinents par cette description ?
- Quels éléments restent en dehors de son champ d’attention ?

Cette première identification permet de délimiter l’espace dans lequel l’enquête sera menée.

---

# 2. Identifier les supports mobilisés

## Question directrice

> Sur quels supports la description repose-t-elle ?

Une description peut mobiliser différents types de supports.

Questions associées :

- Quels supports matériels sont utilisés ?
- Quels langages ou systèmes symboliques interviennent ?
- Quelles pratiques incorporées participent à son fonctionnement ?
- Quels dispositifs techniques ou institutionnels la soutiennent ?

Voir :

- [Supports descriptifs](../02_architecture_conceptuelle/supports_descriptifs.md)
- [Supports incorporés et dispositions corporelles](../02_architecture_conceptuelle/supports_incorpores.md)

---

# 3. Identifier les distinctions produites

## Question directrice

> Quelles différences deviennent pertinentes dans cette description ?

Toute description organise un espace de distinctions.

Questions associées :

- Qu’est-ce qui est distingué ?
- Qu’est-ce qui est rapproché ?
- Quelles catégories sont utilisées ?
- Quelles alternatives deviennent visibles ou invisibles ?

Voir :

- [Configurations sémiotiques](../02_architecture_conceptuelle/configurations_semiotiques.md)

---

# 4. Identifier le régime descriptif mobilisé

## Question directrice

> Quel régime de description rend cette configuration possible ?

Une configuration descriptive peut mobiliser un ou plusieurs régimes.

Questions associées :

- Quelles contraintes descriptives orientent l’analyse ?
- Quelles formes d’intelligibilité sont privilégiées ?
- Quels critères de pertinence sont utilisés ?

Voir :

- [Régimes de description](../02_architecture_conceptuelle/regimes.md)
- [Identifier les régimes mobilisés](identifier_regimes.md)

---

# 5. Identifier les engagements descriptifs

## Question directrice

> Que faut-il accepter pour maintenir cette description ?

Une description implique des engagements.

Questions associées :

- Quelles affirmations sont rendues nécessaires ?
- Quelles conséquences sont acceptées ?
- Quelles justifications deviennent disponibles ?
- Quelles contradictions apparaissent éventuellement ?

Voir :

- [Engagements descriptifs](../02_architecture_conceptuelle/engagements.md)
- [Inférences et justifications](../02_architecture_conceptuelle/inferences_justifications.md)

# 6. Identifier les collectifs concernés

## Question directrice

> Qui porte, transmet ou évalue cette description ?

Une description peut être soutenue par différents collectifs.

Questions associées :

- Quels locuteurs participent à sa production ?
- Quelle communauté reconnaît cette description ?
- À quelle échelle collective fonctionne-t-elle ?
- Quels mécanismes de transmission existent ?

Voir :

- [Locuteur normatif](../02_architecture_conceptuelle/locuteur.md)
- [Communauté de locuteurs](../02_architecture_conceptuelle/communaute_locuteurs.md)

# 7. Identifier les formes de stabilisation

## Question directrice

> Comment cette description se maintient-elle dans le temps ?

Questions associées :

- Quels éléments rendent sa reproduction possible ?
- Quels supports renforcent sa continuité ?
- Quels mécanismes limitent sa transformation ?
- Quels verrouillages apparaissent ?

Voir :

- [Stabilisation et effet cliquet](../02_architecture_conceptuelle/stabilisation.md)

# 8. Identifier les tensions et limites

## Question directrice

> Où cette description rencontre-t-elle ses propres limites ?

Questions associées :

- Quelles difficultés internes apparaissent ?
- Quels phénomènes résistent à son organisation descriptive ?
- Quels autres régimes entrent en concurrence ?
- Quelles exclusions ou zones de silence apparaissent ?

Voir :

- [Tensions entre régimes](../04_diagnostics/tensions.md)
- [Zones de silence descriptif](../04_diagnostics/zones_silence.md)

# 9. Identifier les possibilités de transformation

## Question directrice

> Quelles modifications deviennent possibles ?

L’analyse ne cherche pas uniquement à constater une stabilité.

Elle examine également les conditions de transformation.

Questions associées :

- Quelles limites internes apparaissent ?
- Quelles nouvelles descriptions peuvent émerger ?
- Quels éléments doivent être réorganisés ?
- Quelles transitions deviennent envisageables ?

Voir :

- [Limites internes](../05_transformations/limites.md)
- [Transitions descriptives](../05_transformations/transitions.md)

# Organisation générale de l’enquête

La grille peut être résumée par une série de questions :

1. **Quelle description est analysée ?**
2. **Sur quels supports repose-t-elle ?**
3. **Quelles distinctions produit-elle ?**
4. **Quel régime la rend possible ?**
5. **Quels engagements implique-t-elle ?**
6. **Quels collectifs la portent ?**
7. **Comment se stabilise-t-elle ?**
8. **Quelles limites rencontre-t-elle ?**
9. **Quelles transformations deviennent possibles ?**

Cette organisation permet de suivre la trajectoire complète d’une configuration descriptive sans confondre ses différentes dimensions.

---

## Ce que cette page établit

Cette page établit que :

- l’audit Protokin peut être orienté par des questions directrices ;
- une configuration descriptive peut être examinée selon plusieurs dimensions complémentaires ;
- chaque dimension correspond à un domaine conceptuel spécifique ;
- la grille sert d’outil d’orientation et non de modèle explicatif fermé ;
- l’analyse conserve une séparation entre description, stabilisation, justification et transformation.
