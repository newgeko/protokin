# Prompt section 05 — Dynamique descriptive

## Fonction générale de la section

Cette section a pour fonction d'établir comment les descriptions évoluent, se maintiennent, se transforment, se confrontent et se reproduisent au sein des pratiques descriptives.

Elle constitue le passage entre :

- l'analyse synchronique des pratiques descriptives ;
- l'analyse diachronique de leurs transformations.

La section répond à la question :

> Comment une configuration descriptive peut-elle persister, rencontrer des tensions, se transformer ou être remplacée par une autre configuration ?

---

# Objectif rédactionnel

Rédiger les pages qui construisent le passage :

Configuration descriptive établie ↓ Maintien des pratiques ↓ Apparition de tensions internes ↓ Traduction entre descriptions ↓ Transition ↓ Transformation ↓ Innovation descriptive

La rédaction doit établir :

- les mécanismes internes de variation descriptive ;
- les conditions de continuité ;
- les modalités de changement.

Elle ne doit pas encore développer :

- les formes temporelles des trajectoires ;
- les rythmes historiques ;
- les notions d'allure ou de temporalité descriptive.

---

**Dynamique des descriptions et transformations des configurations.**

- 03 — Fondements descriptifs ;

---

# Objet propre de la section

L'objet de cette section est :

> Les opérations par lesquelles des descriptions sont maintenues, confrontées, traduites et transformées.

Elle porte sur :

- les tensions internes ;
- les limites d'un régime ;
- les processus de traduction ;
- les transitions ;
- les transformations ;
- les innovations.

Elle ne porte pas encore sur :

- les trajectoires historiques complètes ;
- les vitesses d'évolution ;
- les formes temporelles.

---

# Fonction propre de la section

Cette section existe pour établir :

> Comment une description n'est jamais simplement conservée ou remplacée, mais évolue à travers des opérations de maintien, de tension et de transformation.

---

# Principe directeur

La dynamique descriptive ne doit jamais être comprise comme :

- une évolution linéaire vers une meilleure représentation ;
- un progrès nécessaire ;
- un simple changement d'opinion.

Elle doit être comprise comme :

- une transformation des conditions de description ;
- une réorganisation des engagements ;
- une modification des relations entre catégories, supports et pratiques.

---

# Tension

## Fonction de la page

Établir la tension comme moteur interne des dynamiques descriptives.

La page doit montrer que :

- toute configuration descriptive rencontre des situations qui mettent à l'épreuve ses catégories ;
- les tensions apparaissent lorsque les ressources disponibles deviennent insuffisantes ;
- les contradictions internes peuvent ouvrir des possibilités de transformation.

Elle doit distinguer :

- tension ;
- contradiction logique ;
- conflit social ;
- erreur descriptive.

Elle ne doit pas :

- présenter toute tension comme une crise.

---

# Limite interne

## Fonction de la page

Établir les limites propres à un régime descriptif.

La page doit montrer que :

- chaque régime possède des capacités descriptives déterminées ;
- certaines situations excèdent ses catégories disponibles ;
- une limite interne n'est pas une absence de réalité mais une insuffisance du cadre descriptif mobilisé.

Elle prépare :

- traduction ;
- transition ;
- transformation.

---

# Traduction

## Fonction de la page

Établir la traduction comme opération permettant la mise en relation de descriptions appartenant à des cadres différents.

La page doit montrer que traduire n'est pas :

- remplacer un vocabulaire par un autre ;
- trouver une correspondance parfaite.

La traduction est :

- une opération de médiation ;
- une reconstruction des relations entre régimes ;
- une négociation des engagements descriptifs.

Elle doit distinguer :

- traduction ;
- réduction ;
- équivalence.

---

# Transition

## Fonction de la page

Établir les passages entre configurations descriptives.

La page doit montrer que :

- les transformations ne sont pas instantanées ;
- les transitions impliquent des phases intermédiaires ;
- plusieurs descriptions peuvent coexister durant une période.

Elle doit analyser :

- continuité ;
- rupture ;
- réorganisation.

Elle ne doit pas :

- développer encore la notion de trajectoire temporelle.

---

# Transformation

## Fonction de la page

Établir les modifications internes ou externes d'une configuration descriptive.

La page doit montrer que transformer une description implique :

- une modification des catégories ;
- une modification des critères ;
- une modification des pratiques d'évaluation.

Elle doit distinguer :

- transformation interne ;
- remplacement complet ;
- simple reformulation.

---

# Maintien

## Fonction de la page

Établir les mécanismes qui permettent à une configuration descriptive de continuer à fonctionner.

La page doit analyser :

- répétition des pratiques ;
- reproduction des usages ;
- entretien des supports ;
- transmission des compétences.

Elle doit préparer :

- stabilisation ;
- reproduction.

---

# Reproduction

## Fonction de la page

Établir comment une pratique descriptive transmet ses structures au-delà des situations individuelles.

La page doit montrer :

- apprentissage ;
- institutionnalisation ;
- transmission intergénérationnelle.

Elle doit distinguer :

- reproduction ;
- copie mécanique ;
- répétition identique.

---

# Controverse

## Fonction de la page

Établir la controverse comme situation de confrontation entre descriptions concurrentes.

La page doit montrer que la controverse implique :

- des critères divergents ;
- des engagements incompatibles ;
- des négociations sur les conditions de justification.

Elle ne doit pas :

- réduire la controverse à un simple désaccord d'opinion.

---

# Innovation

## Fonction de la page

Établir l'émergence de nouvelles possibilités descriptives.

La page doit montrer que l'innovation :

- n'apparaît pas ex nihilo ;
- réorganise des ressources existantes ;
- dépend d'un environnement descriptif favorable.

Elle doit distinguer :

- nouveauté ;
- invention ;
- innovation stabilisée.

---

# Distinctions conceptuelles à maintenir

## Maintien et stabilisation

Le maintien désigne les opérations continues de reproduction.

La stabilisation désigne l'acquisition d'une continuité suffisante pour durer.

---

## Transformation et remplacement

Une transformation modifie une configuration.

Un remplacement substitue une configuration par une autre.

---

## Traduction et réduction

La traduction conserve la pluralité des régimes.

La réduction ramène un régime à un autre.

---

## Innovation et vérité

Une innovation descriptive n'est pas automatiquement une description correcte.

Elle doit entrer dans un processus d'évaluation.

---

# Contraintes spécifiques

Ne jamais :

- présenter les transformations comme un progrès automatique ;
- supposer qu'un nouveau régime est nécessairement supérieur ;
- réduire les changements descriptifs à des découvertes du réel ;
- expliquer les conflits descriptifs uniquement par des intérêts sociaux.

Éviter :

- les métaphores évolutionnistes simplistes ;
- les modèles linéaires ;
- les explications téléologiques.

# Critère final de validation

Une page de la section 05 est réussie si le lecteur peut répondre :

- Comment une description se maintient-elle ?
- Comment rencontre-t-elle ses limites ?
- Comment entre-t-elle en relation avec d'autres descriptions ?
- Comment peut-elle se transformer ?
- Quelles conditions rendent une innovation descriptive possible ?

La section 05 doit montrer que les descriptions sont des processus dynamiques et non des objets fixes.
