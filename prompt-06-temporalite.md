# Prompt section 06 — Temporalité descriptive

## Fonction générale de la section

Cette section a pour fonction d'établir l'inscription temporelle des descriptions et d'analyser comment les configurations descriptives existent, persistent, évoluent et se transforment dans des trajectoires historiques.

Elle constitue le passage entre :

- l'analyse des opérations dynamiques de transformation ;
- l'analyse des formes temporelles selon lesquelles ces transformations prennent place.

La section répond à la question :

> Comment une description acquiert-elle une histoire, une trajectoire et une forme temporelle propre ?

---

# Objectif rédactionnel

Rédiger les pages qui construisent le passage :

Configuration descriptive ↓ Position dans une situation ↓ Trajectoire de transformation ↓ Allure temporelle ↓ Historicité ↓ Sédimentation ↓ Réorganisation

La rédaction doit établir :

- la dimension temporelle des descriptions ;
- les formes de continuité et de rupture ;
- les modalités historiques de transformation.

Elle ne doit pas encore développer :

- les modes d'explication ;
- la méthode d'enquête ;
- les procédures d'audit.

---

---

# Objet propre de la section

L'objet de cette section est :

> La manière dont les descriptions s'inscrivent dans le temps par des trajectoires, des rythmes, des accumulations et des transformations.

Elle porte sur :

- les positions descriptives ;
- les trajectoires ;
- les allures ;
- l'historicité ;
- la sédimentation ;
- les réorganisations.

Elle ne porte pas sur :

- l'explication causale des phénomènes ;
- la justification normative des descriptions ;
- la vérité historique des événements.

---

# Fonction propre de la section

Cette section existe pour établir :

> Comment les descriptions ne sont pas seulement produites dans un présent, mais existent comme des processus temporels ayant une histoire propre.

---

# Principe directeur

La temporalité descriptive ne doit jamais être comprise comme :

- un simple ordre chronologique d'événements ;
- une accumulation quantitative de changements ;
- un progrès nécessaire.

Elle doit être comprise comme :

- une organisation des transformations ;
- une dynamique de persistance et de variation ;
- une forme d'inscription historique des pratiques descriptives.

---

# Position

## Fonction de la page

Établir la position comme point situé dans une trajectoire descriptive.

La page doit montrer que :

- toute description intervient depuis une configuration particulière ;
- une position n'est pas seulement spatiale mais relationnelle et temporelle ;
- une pratique descriptive possède un état relatif dans son évolution.

Elle doit distinguer :

- position ;
- état fixe ;
- identité permanente.

Elle prépare :

- trajectoire ;
- historicité.

---

# Trajectoire

## Fonction de la page

Établir la trajectoire comme organisation temporelle des transformations descriptives.

La page doit montrer que :

- une description possède une histoire ;
- cette histoire est constituée d'étapes, de bifurcations et de transformations ;
- une trajectoire n'est pas une simple succession d'événements.

Elle doit analyser :

- continuités ;
- ruptures ;
- transitions ;
- bifurcations.

Elle ne doit pas :

- réduire la trajectoire à une causalité linéaire.

---

# Allure

## Fonction de la page

Établir l'allure comme propriété temporelle interne d'une trajectoire descriptive.

La page doit montrer que deux trajectoires peuvent suivre des formes temporelles différentes :

- accélération ;
- ralentissement ;
- stabilité ;
- oscillation ;
- rupture.

L'allure qualifie :

- le rythme ;
- la dynamique ;
- la manière dont une transformation se déploie.

Elle doit distinguer :

- allure ;
- trajectoire ;
- vitesse physique.

Elle ne doit pas :

- devenir une théorie générale du temps.

---

# Historicité

## Fonction de la page

Établir que les descriptions possèdent une dimension historique irréductible.

La page doit montrer que :

- les catégories descriptives ont une genèse ;
- les pratiques qui les soutiennent évoluent ;
- aucune description collective n'existe hors d'un contexte historique.

Elle doit distinguer :

- historicité ;
- relativisme absolu ;
- simple chronologie.

---

# Temporalité descriptive

## Fonction de la page

Établir la spécificité de la temporalité propre aux pratiques descriptives.

La page doit montrer que la temporalité descriptive implique :

- mémoire ;
- transmission ;
- anticipation ;
- transformation.

Elle doit articuler :

- passé sédimenté ;
- présent d'usage ;
- futur possible.

Elle ne doit pas :

- être réduite au temps psychologique individuel.

---

# Sédimentation

## Fonction de la page

Établir les processus par lesquels des descriptions accumulent des traces historiques.

La page doit analyser :

- inscriptions documentaires ;
- habitudes collectives ;
- institutions ;
- apprentissages.

Elle doit montrer que la sédimentation :

- conserve des acquis ;
- produit des contraintes ;
- structure les possibilités futures.

Elle prépare :

- effet cliquet ;
- audit des inerties.

---

# Réorganisation

## Fonction de la page

Établir les processus par lesquels une configuration descriptive réorganise ses éléments internes.

La page doit montrer que les transformations peuvent porter sur :

- les catégories ;
- les critères ;
- les relations entre descriptions ;
- les pratiques d'évaluation.

Elle doit distinguer :

- réorganisation ;
- rupture totale ;
- simple remplacement.

---

# Distinctions conceptuelles à maintenir

## Stabilisation et sédimentation

La stabilisation concerne le processus de consolidation.

La sédimentation concerne l'accumulation historique des traces et contraintes.

---

## Trajectoire et allure

La trajectoire décrit le parcours.

L'allure décrit la forme temporelle de ce parcours.

---

## Histoire et historicité

L'histoire désigne une succession d'événements.

L'historicité désigne la condition temporelle des descriptions.

---

## Transformation et réorganisation

La transformation concerne le changement.

La réorganisation concerne la redistribution interne des relations.

---

# Contraintes spécifiques

Ne jamais :

- traiter le temps comme un simple contenant extérieur ;
- supposer que l'histoire suit une direction nécessaire ;
- confondre ancienneté et validité ;
- considérer la persistance comme preuve de correction.

Éviter :

- les modèles évolutionnistes simplifiés ;
- les métaphores biologiques non contrôlées ;
- les explications téléologiques.

# Critère final de validation

Une page de la section 06 est réussie si le lecteur peut répondre :

- Comment une description existe-t-elle dans le temps ?
- Comment une configuration conserve-t-elle des traces du passé ?
- Comment les transformations prennent-elles une forme temporelle ?
- Pourquoi certaines descriptions deviennent-elles difficiles à modifier ?
- Comment une trajectoire descriptive peut-elle être analysée ?

La section 06 doit montrer que les descriptions ne sont pas seulement des structures, mais des processus historiques en mouvement.
