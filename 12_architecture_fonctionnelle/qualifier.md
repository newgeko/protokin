# Qualifier

## Identifier le régime descriptif qui rend une description possible

---

## Introduction

Dans Protokin, **Qualifier** constitue la deuxième opération de l'enquête descriptive.

Après avoir identifié une description, il ne s'agit pas encore de déterminer si elle est vraie, correcte ou justifiée.

Il faut d'abord analyser **dans quel régime descriptif elle fonctionne**.

Qualifier consiste à déterminer les conditions qui rendent une description intelligible :

- quelles distinctions elle mobilise ;
- quelles preuves elle reconnaît ;
- quelles inférences elle autorise ;
- quelles limites elle rencontre.

La question centrale est donc :

> **Selon quel régime cette description devient-elle intelligible ?**

---

# Fonction analytique

La fonction **Qualifier** consiste à identifier le régime descriptif dans lequel une description prend sens.

Elle permet de répondre à une question fondamentale :

> Une description n'est jamais seulement une phrase ; elle appartient à un espace de possibilités descriptives.

Qualifier analyse donc :

- les permissions descriptives ;
- les contraintes descriptives ;
- les critères de pertinence ;
- les formes d'argumentation admises.

---

# 1. Qualifier n'est pas classer

Une première erreur serait de comprendre la qualification comme une simple classification.

Classer consiste à placer un élément dans une catégorie préexistante.

Qualifier, dans Protokin, signifie autre chose :

> déterminer les conditions selon lesquelles une description fonctionne.

Une qualification ne dit pas seulement :

> « Cette chose appartient à telle catégorie ».

Elle demande :

> « Dans quel régime cette manière de la décrire devient-elle possible ? »

---

# 2. Le régime descriptif

Le concept central de la fonction Qualifier est celui de **régime descriptif**.

Un régime descriptif désigne un ensemble organisé de contraintes et de permissions qui déterminent :

- ce qui peut être décrit ;
- comment cela peut être décrit ;
- ce qui compte comme une preuve ;
- ce qui compte comme une erreur ;
- ce qui peut être justifié.

Un régime n'est donc pas une théorie particulière.

C'est une organisation des conditions de description.

---

# 3. Les permissions descriptives

Chaque régime ouvre certaines possibilités descriptives.

Ces permissions déterminent :

- les objets pertinents ;
- les distinctions utilisables ;
- les relations acceptables ;
- les formes d'explication possibles.

Exemple :

Dans un régime médical, certains éléments deviennent pertinents :

- symptômes ;
- signes cliniques ;
- diagnostics ;
- trajectoires thérapeutiques.

Dans un régime juridique, d'autres éléments deviennent centraux :

- normes ;
- responsabilités ;
- obligations ;
- procédures.

La différence ne porte pas seulement sur les réponses produites.

Elle porte sur ce qui compte comme une question pertinente.

---

# 4. Les contraintes descriptives

Un régime ne permet pas seulement certaines descriptions.

Il en limite également certaines autres.

Toute qualification implique donc l'analyse de contraintes.

Ces contraintes peuvent concerner :

- les catégories disponibles ;
- les méthodes admises ;
- les formes de preuve ;
- les types d'inférence autorisés.

Un régime descriptif produit donc toujours un double effet :

- il rend certaines descriptions possibles ;
- il rend d'autres descriptions difficiles ou impossibles.

---

# 5. Qualification et pluralité des régimes

Une même configuration peut être qualifiée selon plusieurs régimes.

Cette pluralité n'est pas nécessairement une contradiction.

Elle indique que différentes organisations descriptives peuvent rendre une même situation intelligible.

---

## Exemple : la fatigue professionnelle

### Configuration

Une personne présente :

- une fatigue persistante ;
- une diminution de ses capacités ;
- des difficultés dans son activité professionnelle.

---

## Régime médical

Qualification :

> Situation relevant d'une analyse clinique.

Ce régime privilégie :

- symptômes ;
- diagnostics ;
- mécanismes physiologiques ou psychologiques.

---

## Régime organisationnel

Qualification :

> Situation révélant une tension dans l'organisation du travail.

Ce régime privilégie :

- conditions de travail ;
- structures collectives ;
- processus organisationnels.

---

## Régime juridique

Qualification :

> Situation susceptible d'engager des responsabilités.

Ce régime privilégie :

- normes ;
- obligations ;
- procédures.

---

La fonction Qualifier ne choisit pas immédiatement le « bon » régime.

Elle identifie les régimes présents et leurs conditions respectives.

---

# 6. Qualification et articulation

Qualifier prépare nécessairement la fonction suivante : **Articuler**.

En effet, reconnaître plusieurs régimes ne signifie pas encore comprendre leurs relations.

La qualification demande :

> Quels régimes sont mobilisés ?

L'articulation demandera :

> Comment ces régimes peuvent-ils coexister, se traduire ou entrer en conflit ?

---

# 7. Qualification et non-ontologie

La fonction Qualifier protège Protokin contre une dérive ontologique.

Un régime descriptif ne révèle pas une couche fondamentale du réel.

Il ne dit pas :

> « Voici ce que cette chose est réellement ».

Il dit :

> « Voici selon quelles conditions cette chose peut être décrite de cette manière ».

Un régime est donc une condition d'intelligibilité, pas une structure du monde.

---

# 8. Cartographie des régimes descriptifs

La fonction Qualifier accueille la cartographie des régimes R1-R17.

Cette cartographie ne constitue pas une classification du réel.

Elle constitue une cartographie des manières possibles de produire des descriptions.

Chaque régime doit être analysé selon :

- ses objets privilégiés ;
- ses critères de preuve ;
- ses formes d'inférence ;
- ses limites ;
- ses zones de silence.

---

# 9. Erreurs fréquentes

## Confondre régime et réalité

Erreur :

> Le régime décrit la vraie nature de l'objet.

Correction :

Le régime définit une manière possible de rendre l'objet descriptible.

---

## Confondre régime et opinion

Erreur :

> Chaque régime serait une simple perspective subjective.

Correction :

Les régimes possèdent des contraintes collectives et des critères internes.

---

## Confondre pluralité et relativisme

Erreur :

> Plusieurs régimes impliquent que toutes les descriptions se valent.

Correction :

Chaque régime possède ses propres conditions d'évaluation.

---

## Confondre qualification et jugement

Erreur :

> Qualifier revient à dire si une description est bonne ou mauvaise.

Correction :

Qualifier identifie d'abord son mode de fonctionnement.

---

# 10. Place dans l'architecture fonctionnelle

La fonction **Qualifier** intervient après Décrire et avant Articuler.

Le mouvement est :

Configuration ↓ Description ↓ Qualification ↓ Articulation

---

Elle prépare :

## Articuler

Comparer les relations entre régimes.

## Reproduire

Analyser comment un régime maintient certaines descriptions.

## Transformer

Analyser comment un régime évolue.

## Délimiter

Identifier ses frontières et ses silences.

## Auditer

Évaluer ses usages et ses effets.

---

# Ce que cette page établit

Qualifier est l'opération par laquelle Protokin identifie le régime descriptif d'une description.

Elle établit que :

- une description fonctionne toujours dans un cadre ;
- un cadre ouvre certaines possibilités et en ferme d'autres ;
- les régimes ne sont pas des ontologies mais des conditions d'intelligibilité.

La question fondamentale de cette fonction est donc :

> **Selon quel régime cette description devient-elle possible, et quelles contraintes organisent son fonctionnement ?**
