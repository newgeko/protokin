# Justifier

## Analyser les raisons qui rendent une description recevable

---

## Introduction

Dans Protokin, **Justifier** constitue la neuvième opération de l'enquête descriptive.

Après avoir analysé :

- comment une description apparaît (**Décrire**) ;
- selon quel régime elle fonctionne (**Qualifier**) ;
- comment elle s'articule avec d'autres descriptions (**Articuler**) ;
- comment elle est reproduite (**Reproduire**) ;
- comment elle se transforme (**Transformer**) ;
- quelles sont ses limites (**Délimiter**) ;
- quelle trajectoire l'a rendue possible (**Retracer**) ;
- quelles conditions expliquent sa production (**Expliquer**) ;

il faut analyser les raisons qui permettent de l'accepter.

La question centrale devient :

> **Pourquoi cette description peut-elle être tenue pour recevable dans un espace de raisons donné ?**

---

# Fonction analytique

La fonction **Justifier** analyse les conditions normatives d'acceptation d'une description.

Elle étudie :

- les raisons invoquées ;
- les engagements assumés ;
- les inférences produites ;
- les critères de recevabilité ;
- les formes d'autorité mobilisées.

Justifier ne cherche pas à expliquer pourquoi une description est apparue.

Elle cherche à comprendre **pourquoi des acteurs peuvent raisonnablement la soutenir, l'utiliser ou la contester**.

---

# 1. Justifier n'est pas expliquer

Cette distinction constitue une séparation fondamentale de Protokin.

Une explication répond :

> Comment cette description a-t-elle été produite ?

Une justification répond :

> Qu'est-ce qui permet de la soutenir ?

---

## Exemple

Une théorie scientifique peut être expliquée par :

- son contexte historique ;
- les instruments disponibles ;
- les institutions qui l'ont favorisée.

Mais elle est justifiée par :

- ses arguments ;
- ses observations ;
- ses procédures de validation ;
- sa capacité à répondre aux objections.

---

## Principe fondamental

> Une cause rend une description possible ; une raison la rend défendable.

---

# 2. La description comme engagement

Dans Protokin, une description n'est jamais un simple énoncé neutre.

Lorsqu'un acteur produit une description, il entre dans un réseau d'engagements.

Décrire implique de pouvoir répondre à des questions :

- Pourquoi cette catégorie ?
- Pourquoi cette distinction ?
- Pourquoi cette inférence ?
- Pourquoi cette conclusion ?

Une description devient alors un élément de l'espace des raisons.

---

# 3. L'espace des raisons

La fonction Justifier appartient principalement à l'espace **KIN**.

Elle concerne :

- les normes ;
- les arguments ;
- les engagements ;
- les pratiques discursives.

L'espace des raisons ne désigne pas un monde abstrait séparé des pratiques.

Il désigne l'ensemble des relations dans lesquelles une description peut être :

- défendue ;
- critiquée ;
- corrigée ;
- reconnue.

---

# 4. Les dimensions de la justification

## 4.1 Raisons

Une raison est un élément pouvant soutenir une description.

Elle peut prendre plusieurs formes :

- argument logique ;
- donnée empirique ;
- témoignage reconnu ;
- règle institutionnelle ;
- principe méthodologique.

Une raison n'est pas seulement une cause psychologique.

Elle est une contribution à un espace normatif partagé.

---

## Exemple

Dire :

> « Cette mesure est nécessaire car elle réduit statistiquement un risque »

n'est pas seulement donner une cause.

C'est fournir une raison pouvant être examinée collectivement.

---

# 4.2 Inférences

Une justification repose sur des relations d'inférence.

Une description engage certaines conséquences.

Lorsqu'un acteur affirme :

> « Cette situation est un burn-out »

il s'engage potentiellement à accepter certaines conséquences :

- nécessité d'une prise en charge ;
- existence d'un risque ;
- pertinence d'un dispositif particulier.

La justification analyse donc les relations entre :

- ce qui est affirmé ;
- ce qui est impliqué ;
- ce qui peut être contesté.

---

# 4.3 Acceptabilité

L'acceptabilité désigne la capacité d'une description à être reconnue dans un espace normatif donné.

Elle dépend :

- des critères du régime ;
- des pratiques collectives ;
- des possibilités de défense ;
- des réponses aux objections.

Une description acceptable n'est pas simplement populaire.

Elle est soutenable selon certaines normes.

---

# 4.4 Autorité

Toute justification mobilise des formes d'autorité.

Ces autorités peuvent être :

- scientifiques ;
- juridiques ;
- institutionnelles ;
- professionnelles ;
- collectives.

L'analyse protokinienne demande :

> Quelle autorité rend cette description recevable, et selon quelles règles ?

---

# 4.5 Révision normative

Une justification n'est jamais définitive.

Les critères d'acceptation peuvent changer.

Une communauté peut modifier :

- ses normes ;
- ses critères de preuve ;
- ses attentes ;
- ses catégories.

La justification est donc un processus dynamique.

---

# 5. Justification et régimes descriptifs

Chaque régime possède ses propres critères de justification.

Une description n'est pas justifiée de la même manière dans tous les régimes.

---

## Exemple

Une description médicale peut être justifiée par :

- des observations cliniques ;
- des études ;
- des protocoles.

Une description juridique peut être justifiée par :

- des textes ;
- des procédures ;
- des précédents.

Une description politique peut être justifiée par :

- des valeurs ;
- des objectifs collectifs ;
- des arguments publics.

---

# 6. Justification et pluralité des régimes

Protokin ne cherche pas une forme unique de justification valable partout.

Il cherche à analyser :

- quel régime justifie ;
- selon quelles normes ;
- avec quelles conséquences.

Une même description peut être :

- justifiée dans un régime ;
- contestée dans un autre.

L'enquête doit alors analyser les relations entre ces justifications.

---

# 7. Recevabilité et justification

La recevabilité désigne le fait qu'une description puisse être admise dans une pratique donnée.

La justification analyse les raisons qui rendent cette recevabilité possible.

Une description devient recevable lorsqu'elle entre dans un réseau où elle peut être :

- soutenue ;
- évaluée ;
- corrigée.

---

## Attention

Recevabilité ne signifie pas vérité absolue.

Elle indique une position dans un espace de raisons.

---

# 8. Exemple fil rouge : le burn-out

## Description

> Le burn-out comme phénomène lié à l'organisation du travail.

---

## Question de justification

Pourquoi accepter cette description ?

---

## Raisons mobilisées

- études scientifiques ;
- observations cliniques ;
- analyses organisationnelles ;
- témoignages professionnels ;
- cadres institutionnels.

---

## Analyse protokinienne

La question n'est pas seulement :

> Cette description existe-t-elle ?

Mais :

> Quelles raisons permettent de la soutenir et quelles objections doit-elle pouvoir affronter ?

---

# 9. Relation avec Expliquer

La distinction fondamentale :

| Expliquer | Justifier |
|-|-|
| D'où vient la description ? | Pourquoi l'accepter ? |
| Conditions de production | Conditions d'acceptation |
| Causes | Raisons |
| Espace PROTO | Espace KIN |
| Genèse | Validité pratique |

---

# 10. Relation avec Auditer

Justifier prépare directement l'audit.

L'audit protokinien examine :

- les raisons mobilisées ;
- les critères utilisés ;
- les engagements produits ;
- les exclusions éventuelles.

Une description peut être :

- bien expliquée mais mal justifiée ;
- bien justifiée dans un régime mais limitée dans un autre.

---

# 11. Erreurs fréquentes

## Réduire la justification à l'origine

Erreur :

> Une description est valable parce qu'on connaît son histoire.

Correction :

L'origine explique une description ; elle ne la justifie pas.

---

## Confondre acceptation sociale et justification

Erreur :

> Une majorité accepte une description donc elle est justifiée.

Correction :

L'acceptation collective doit être analysée selon les normes du régime.

---

## Confondre justification et certitude

Erreur :

> Justifier signifie rendre impossible toute contestation.

Correction :

Une justification organise une réponse aux objections.

---

## Confondre justification et opinion personnelle

Erreur :

> Une raison est seulement une croyance individuelle.

Correction :

Une raison appartient à un espace normatif partageable.

---

# 12. Place dans l'architecture fonctionnelle

La trajectoire complète devient :

Configuration ↓ Décrire ↓ Qualifier ↓ Articuler ↓ Reproduire ↓ Transformer ↓ Délimiter ↓ Retracer ↓ Expliquer ↓ Justifier

Justifier prépare les fonctions réflexives :

Justifier ↓ Auditer ↓ Examiner

---

# Ce que cette page établit

Justifier établit qu'une description n'est pas seulement produite et reproduite.

Elle doit pouvoir entrer dans un espace de raisons où elle devient :

- défendable ;
- critiquable ;
- révisable.

La question fondamentale de cette fonction est donc :

> **Quelles raisons permettent à cette description d'être reconnue comme recevable dans un régime donné ?**
