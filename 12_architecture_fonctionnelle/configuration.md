# Configuration

## Organisation relationnelle à partir de laquelle des descriptions deviennent possibles

---

## Introduction

Dans Protokin, l'analyse ne commence jamais par un objet isolé ni par une description déjà constituée.

Elle commence par une **configuration**.

La configuration désigne l'organisation relationnelle dans laquelle certains éléments deviennent susceptibles d'être décrits, distingués et articulés.

Elle n'est pas un donné brut qui existerait avant toute description.

Elle est une **unité d'analyse reconstruite** : un ensemble de relations, de pratiques, de contraintes et d'inscriptions à partir duquel différentes descriptions peuvent devenir possibles.

La configuration répond donc à une question préalable :

> **Quelle organisation relationnelle est soumise à l'enquête ?**

---

# Fonction analytique

La fonction du concept de **configuration** est de fournir le point d'entrée de l'analyse protokinienne.

Avant de demander :

- quelle description est produite ;
- quel régime est mobilisé ;
- quelles raisons la justifient ;

il faut identifier la configuration dans laquelle cette description apparaît.

La configuration permet d'éviter deux réductions :

- considérer la description comme une représentation directe d'un objet déjà constitué ;
- considérer la description comme une construction purement linguistique indépendante de toute situation.

---

# 1. Définition générale

Une configuration est une organisation provisoire de relations entre :

- des éléments matériels ;
- des pratiques ;
- des acteurs ;
- des dispositifs ;
- des inscriptions ;
- des distinctions ;
- des contraintes.

Elle ne désigne pas une chose.

Elle désigne une **composition relationnelle**.

---

## Exemple

Une situation médicale n'est pas seulement :

> un patient et une maladie.

La configuration comprend également :

- un corps observé ;
- des symptômes ;
- des instruments de mesure ;
- un vocabulaire clinique ;
- des institutions ;
- des pratiques professionnelles ;
- des critères diagnostiques.

C'est cette organisation relationnelle qui rend certaines descriptions possibles.

---

# 2. Configuration et objet

Une configuration ne doit pas être confondue avec un objet.

Un objet semble posséder une identité indépendante.

Une configuration possède une structure relationnelle.

La question protokinienne n'est donc pas :

> Qu'est-ce que cette chose ?

mais :

> Comment cette organisation permet-elle certaines manières de la décrire ?

---

## Conséquence

Une même configuration peut donner lieu à plusieurs descriptions.

La diversité des descriptions ne signifie pas nécessairement qu'une seule serait vraie et les autres fausses.

Elle indique souvent que plusieurs régimes descriptifs peuvent organiser différemment une même configuration.

---

# 3. Configuration et description

La relation entre configuration et description est fondamentale.

La configuration n'est pas encore une description.

Elle constitue l'espace relationnel dans lequel une description peut émerger.

Le passage de la configuration à la description implique plusieurs opérations :

1. sélection des éléments pertinents ;
2. organisation selon un régime descriptif ;
3. formulation d'engagements ;
4. insertion dans un espace de justification.

Ainsi :

Configuration ↓ Position descriptive ↓ Régime descriptif ↓ Description

Cette succession ne décrit pas une causalité mécanique.

Elle décrit les conditions d'une opération d'enquête.

---

# 4. Les dimensions d'une configuration

## 4.1 Dimension matérielle

Toute configuration possède une dimension d'inscription.

Elle implique :

- des corps ;
- des objets ;
- des dispositifs techniques ;
- des infrastructures.

Ces éléments ne déterminent pas une description unique, mais ils contraignent les descriptions possibles.

---

## 4.2 Dimension pratique

Une configuration comprend des pratiques.

Elle implique :

- des habitudes ;
- des procédures ;
- des manières d'agir ;
- des interactions.

Les pratiques contribuent à rendre certaines descriptions opérantes.

---

## 4.3 Dimension sémiotique

Une configuration comprend des signes et des distinctions.

Elle implique :

- des catégories ;
- des classifications ;
- des vocabulaires ;
- des schémas d'interprétation.

Ces éléments structurent ce qui peut être remarqué et formulé.

---

## 4.4 Dimension institutionnelle

Une configuration peut être soutenue par des institutions.

Elle implique :

- des règles ;
- des procédures ;
- des autorités ;
- des critères de validation.

Les institutions participent à la reproduction des descriptions.

---

# 5. Configuration et multiplicité des descriptions

Une propriété essentielle des configurations est leur ouverture descriptive.

Une configuration ne contient pas une description unique.

Elle constitue un champ de possibilités descriptives.

---

## Exemple : la fatigue professionnelle

Configuration :

- personne présentant une fatigue prolongée ;
- contexte professionnel ;
- observations médicales ;
- contraintes organisationnelles ;
- dispositifs institutionnels.

Descriptions possibles :

### Régime médical

> Symptômes indiquant un état clinique.

### Régime organisationnel

> Effet d'une structure de travail.

### Régime juridique

> Situation engageant des responsabilités.

La configuration est commune.

Les descriptions diffèrent.

---

# 6. Configuration et tension

Les configurations peuvent contenir des tensions.

Une tension apparaît lorsque plusieurs contraintes ou pratiques ne peuvent plus être maintenues simultanément.

Exemples :

- une catégorie médicale qui ne correspond plus aux observations ;
- une institution dont les règles entrent en conflit ;
- un régime descriptif incapable d'intégrer certaines situations.

La tension n'est pas encore une transformation.

Elle constitue une condition possible de transformation.

---

# 7. Configuration et dynamique

Une configuration n'est jamais totalement fixe.

Elle possède une dynamique propre.

Elle peut :

- se reproduire ;
- se modifier ;
- se décomposer ;
- produire de nouvelles possibilités descriptives.

La fonction **Reproduire** analysera comment une configuration maintient certaines descriptions.

La fonction **Transformer** analysera comment ces conditions changent.

---

# 8. Erreurs fréquentes

## Confondre configuration et réalité brute

Erreur :

> La configuration serait le monde tel qu'il est avant toute description.

Correction :

La configuration est déjà une organisation analysée, pas un donné absolu.

---

## Confondre configuration et description

Erreur :

> La configuration est simplement ce qui est dit.

Correction :

La configuration est ce à partir de quoi différentes descriptions peuvent être produites.

---

## Réduire la configuration à un contexte

Erreur :

> La configuration serait seulement un environnement extérieur.

Correction :

Une configuration comprend des relations internes entre pratiques, objets, signes et contraintes.

---

# Articulation avec les autres fonctions

## Décrire

La configuration est ce qui devient descriptible.

## Qualifier

Les régimes déterminent quelles descriptions sont possibles.

## Articuler

Les descriptions issues d'une configuration peuvent entrer en relation.

## Reproduire

Certaines descriptions peuvent être maintenues collectivement.

## Transformer

Les configurations peuvent changer lorsque leurs conditions de reproduction évoluent.

## Auditer

L'audit commence par reconstruire la configuration analysée.

---

# Ce que cette page établit

La configuration est l'unité relationnelle fondamentale de l'enquête protokinienne.

Elle n'est :

- ni un objet indépendant ;
- ni une simple représentation ;
- ni un discours.

Elle est une organisation dynamique de relations à partir de laquelle des descriptions deviennent possibles.

La question fondamentale n'est donc pas :

> « Quelle est la nature de cette chose ? »

mais :

> **« Quelle configuration rend possible cette manière de la décrire ? »**
