# Décrire

## Première opération de l'enquête descriptive

---

## Introduction

Dans Protokin, **Décrire** constitue la première opération analytique.

Elle ne consiste pas à produire une copie du réel, ni à appliquer une catégorie préexistante à un objet déjà constitué.

Décrire désigne l'opération par laquelle une configuration devient intelligible selon une certaine organisation descriptive.

Toute enquête commence donc par une question fondamentale :

> **Comment quelque chose devient-il descriptible ?**

Cette question précède toute évaluation de vérité, toute justification ou toute explication.

Avant de demander si une description est correcte, recevable ou justifiée, il faut comprendre comment elle a été produite.

---

# Fonction analytique

La fonction **Décrire** consiste à identifier les conditions minimales par lesquelles une configuration peut devenir une description déterminée.

Elle analyse :

- ce qui est rendu descriptible ;
- depuis quelle position ;
- selon quelles distinctions ;
- avec quels engagements.

La description n'est donc pas un résultat final.

Elle est une opération située dans une trajectoire d'enquête.

---

# 1. Décrire n'est pas représenter

Une conception classique considère la description comme une représentation :

> un sujet observe un objet et produit une image fidèle de celui-ci.

Protokin refuse cette conception.

Une description n'est jamais un simple miroir.

Elle implique toujours :

- une sélection ;
- une organisation ;
- un vocabulaire ;
- des critères de pertinence.

Décrire ne consiste pas seulement à enregistrer quelque chose.

Décrire consiste à rendre certaines différences significatives.

---

# 2. Le point de départ : la configuration

Toute description part d'une configuration.

La configuration désigne l'organisation relationnelle dans laquelle quelque chose peut devenir descriptible.

Elle comprend :

- des éléments matériels ;
- des pratiques ;
- des dispositifs ;
- des signes ;
- des contraintes ;
- des relations.

La configuration n'est pas encore une description.

Elle est ce qui ouvre un espace de descriptions possibles.

---

## Relation entre configuration et description

La relation peut être formulée ainsi :

Configuration ↓ Opération descriptive ↓ Description

Mais cette relation n'est pas une production mécanique.

Une configuration ne contient pas une description unique.

Elle rend possibles plusieurs descriptions selon les opérations et les régimes mobilisés.

---

# 3. L'opération descriptive

Décrire implique trois opérations fondamentales.

---

## 3.1 Sélectionner

Toute description sélectionne certains éléments comme pertinents.

Décrire signifie toujours :

- retenir certaines différences ;
- laisser d'autres éléments en arrière-plan ;
- organiser un champ d'attention.

Une description produit donc nécessairement un point de vue.

---

## 3.2 Organiser

Les éléments sélectionnés ne restent pas isolés.

Ils sont reliés par des relations :

- causales ;
- fonctionnelles ;
- normatives ;
- institutionnelles ;
- symboliques.

Une description n'est pas une liste d'informations.

Elle construit une intelligibilité.

---

## 3.3 Engager

Toute description produit des engagements.

Décrire quelque chose comme X implique :

- certaines conséquences ;
- certaines inférences ;
- certaines obligations de justification.

Une description peut donc être contestée, défendue ou révisée.

---

# 4. Description et position descriptive

Une description n'existe jamais depuis un point de vue neutre.

Elle est produite depuis une **position descriptive**.

Cette position détermine :

- ce qui est accessible ;
- ce qui est considéré comme pertinent ;
- ce qui doit être démontré ;
- ce qui peut être affirmé.

Un médecin, un juriste, un ingénieur ou un citoyen peuvent rencontrer une même configuration tout en produisant des descriptions différentes.

La différence ne vient pas seulement des informations disponibles.

Elle vient aussi de la position occupée dans l'espace descriptif.

---

# 5. Description et régime descriptif

Une description fonctionne toujours dans un régime descriptif.

Le régime détermine :

- les distinctions pertinentes ;
- les critères de preuve ;
- les formes d'inférence ;
- les possibilités de justification.

Ainsi, une même configuration peut être décrite différemment.

---

## Exemple : une fatigue professionnelle

### Configuration

Une personne présente :

- une fatigue prolongée ;
- des troubles du sommeil ;
- une baisse d'activité ;
- un contexte professionnel particulier.

---

### Description médicale

> Une situation pouvant relever d'une évaluation clinique.

Engagements :

- catégories médicales ;
- critères diagnostiques ;
- pratiques de soin.

---

### Description organisationnelle

> Une conséquence possible d'une organisation du travail.

Engagements :

- structure collective ;
- processus de production ;
- conditions professionnelles.

---

### Description juridique

> Une situation pouvant produire des obligations institutionnelles.

Engagements :

- normes ;
- responsabilités ;
- procédures.

---

La configuration est proche.

Les descriptions diffèrent parce que les régimes diffèrent.

---

# 6. Description et normativité

Une description n'est pas seulement informative.

Elle possède une dimension normative.

Lorsqu'une description est adoptée, elle transforme l'espace des possibilités :

- certaines actions deviennent pertinentes ;
- certaines critiques deviennent possibles ;
- certaines décisions deviennent justifiables.

Décrire n'est donc jamais seulement dire comment les choses sont.

C'est aussi contribuer à déterminer comment elles peuvent être traitées.

---

# 7. Description et engagement

Une description implique une responsabilité.

Celui qui décrit doit pouvoir répondre à des questions :

- Pourquoi cette description plutôt qu'une autre ?
- Quelles distinctions utilise-t-elle ?
- Quelles conséquences entraîne-t-elle ?
- Quelles alternatives exclut-elle ?

C'est cette dimension qui permettra ensuite l'analyse de la justification.

---

# 8. Description et différence avec l'explication

Protokin maintient une distinction fondamentale :

> Décrire n'est pas expliquer.

Une description répond à :

> Comment cette configuration est-elle rendue intelligible ?

Une explication répond à :

> Quelles conditions ont produit cette configuration ou cette description ?

Une description peut être correcte sans que son origine soit connue.

Une explication peut être connue sans que la description soit justifiée.

---

# 9. Description et différence avec la justification

Protokin distingue également :

> Décrire n'est pas justifier.

Une description établit une manière de rendre une situation intelligible.

Une justification établit pourquoi cette manière de la décrire peut être acceptée.

Cette distinction protège contre deux réductions :

- réduire toute description à un fait naturel ;
- réduire toute description à une construction arbitraire.

---

# 10. Place dans l'architecture fonctionnelle

La fonction **Décrire** ouvre l'ensemble du parcours protokinien.

Elle prépare :

## Qualifier

Quel régime rend cette description possible ?

## Articuler

Comment cette description se rapporte-t-elle à d'autres ?

## Reproduire

Comment cette description continue-t-elle d'exister ?

## Transformer

Comment ses conditions changent-elles ?

## Délimiter

Que rend-elle visible et que laisse-t-elle silencieux ?

## Retracer

Quelle trajectoire l'a rendue possible ?

## Expliquer

Quelles conditions ont contribué à sa production ?

## Justifier

Pourquoi peut-elle être acceptée ?

## Auditer

Comment l'évaluer ?

---

# Erreurs fréquentes

## La description comme miroir

Erreur :

> Une description révèle simplement une réalité déjà constituée.

Correction :

Une description organise une configuration selon certaines conditions.

---

## La description comme opinion

Erreur :

> Une description serait seulement subjective.

Correction :

Une description possède des engagements qui peuvent être évalués.

---

## La description comme simple langage

Erreur :

> Une description serait uniquement un phénomène linguistique.

Correction :

Une description articule des pratiques, des dispositifs et des normes.

---

# Ce que cette page établit

La description est la première opération de l'enquête protokinienne.

Elle n'est :

- ni une représentation passive ;
- ni une opinion individuelle ;
- ni une propriété d'un objet.

Elle est une opération située par laquelle une configuration devient intelligible.

La question inaugurale de Protokin est donc :

> **Comment une configuration devient-elle une description, et quelles conditions rendent cette description possible ?**
