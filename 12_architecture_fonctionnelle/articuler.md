# Articuler

## Analyser les relations entre régimes descriptifs

---

## Introduction

Dans Protokin, **Articuler** constitue la troisième opération de l'enquête descriptive.

Après avoir identifié une description et qualifié le régime dans lequel elle fonctionne, il faut analyser ses relations avec d'autres descriptions possibles.

Une description n'existe jamais isolément.

Elle s'inscrit dans un espace où plusieurs régimes peuvent :

- coexister ;
- se compléter ;
- se traduire ;
- entrer en tension ;
- se réduire mutuellement.

La question centrale est donc :

> **Comment plusieurs descriptions d'une même configuration peuvent-elles être mises en relation ?**

---

# Fonction analytique

La fonction **Articuler** consiste à analyser la topologie relationnelle entre descriptions et régimes descriptifs.

Elle ne cherche pas immédiatement à choisir la meilleure description.

Elle cherche à comprendre :

- comment plusieurs descriptions se rapportent ;
- quelles relations elles entretiennent ;
- quelles traductions sont possibles ;
- où apparaissent les conflits ou les incompatibilités.

Articuler répond donc à une question différente de Qualifier :

- **Qualifier :** selon quel régime cette description fonctionne-t-elle ?
- **Articuler :** comment ce régime se rapporte-t-il aux autres ?

---

# 1. Articuler n'est pas additionner

Une première erreur consiste à penser que plusieurs descriptions peuvent simplement être additionnées.

Or, deux descriptions peuvent porter sur une même configuration sans fonctionner selon les mêmes règles.

Elles ne sélectionnent pas nécessairement :

- les mêmes objets pertinents ;
- les mêmes critères ;
- les mêmes formes de preuve ;
- les mêmes conséquences.

Articuler ne consiste donc pas à créer une synthèse artificielle.

Il consiste à analyser les relations entre différences.

---

# 2. La topologie des régimes descriptifs

Chaque régime descriptif occupe une position dans un espace relationnel.

Il possède :

- des zones de compatibilité ;
- des zones de tension ;
- des frontières ;
- des possibilités de traduction.

L'analyse protokinienne cherche donc moins à établir une hiérarchie générale des régimes qu'à reconstruire leur organisation relationnelle dans une configuration donnée.

---

# 3. Les principales formes d'articulation

## 3.1 Compatibilité

Deux régimes sont compatibles lorsque leurs descriptions peuvent coexister sans contradiction fondamentale.

Ils peuvent porter sur des dimensions différentes d'une même configuration.

---

### Exemple

Une analyse médicale d'un patient et une analyse administrative de son dossier peuvent coexister.

La première décrit :

- un état clinique ;
- une évolution thérapeutique.

La seconde décrit :

- des procédures ;
- des obligations institutionnelles.

Les deux descriptions ne répondent pas à la même question.

---

## 3.2 Traduction

La traduction désigne l'opération permettant de rendre une description intelligible dans un autre régime.

Elle ne consiste pas à remplacer un vocabulaire par un autre.

Elle implique une transformation des relations conceptuelles.

---

### Exemple

Une observation médicale :

> « Épuisement professionnel »

peut être traduite dans un régime juridique :

> « Situation pouvant engager une responsabilité de l'employeur ».

La traduction ne conserve pas exactement le même sens.

Elle reconstruit une description selon d'autres contraintes.

---

## 3.3 Incompatibilité

Deux régimes peuvent produire des descriptions difficilement conciliables.

L'incompatibilité apparaît lorsque les conditions d'un régime empêchent l'autre de fonctionner correctement.

---

### Exemple

Une approche strictement biologique d'un comportement peut entrer en tension avec une approche juridique centrée sur la responsabilité.

Le conflit ne porte pas seulement sur les conclusions.

Il porte sur les conditions mêmes de description.

---

## 3.4 Réduction

La réduction apparaît lorsqu'un régime absorbe un autre régime en prétendant que sa propre description est suffisante.

Elle constitue un phénomène important pour l'audit protokinien.

---

### Exemple

Réduire une souffrance sociale à un simple mécanisme biologique.

Ou réduire une pratique scientifique à un simple produit culturel.

Dans les deux cas, une dimension descriptive est absorbée par une autre.

---

## 3.5 Recouvrement

Le recouvrement désigne les zones où plusieurs régimes décrivent partiellement une même dimension.

Ces zones peuvent permettre :

- des collaborations ;
- des conflits ;
- des négociations.

---

# 4. Articulation et non-réduction

Une fonction centrale d'Articuler est d'éviter les réductions abusives.

Protokin ne cherche pas à produire une description unique qui engloberait toutes les autres.

Il cherche à analyser :

- les conditions de chaque description ;
- leurs relations ;
- leurs limites.

La pluralité des régimes n'est donc pas un relativisme.

Elle est une organisation différenciée des pratiques descriptives.

---

# 5. Articulation et espaces PROTO / KIN

L'articulation permet également d'analyser la relation entre deux grands espaces :

## PROTO

Espace des conditions de possibilité :

- contraintes matérielles ;
- processus biologiques ;
- dynamiques physiques ;
- interactions causales.

## KIN

Espace des raisons :

- justifications ;
- normes ;
- engagements ;
- inférences.

L'articulation consiste à comprendre comment ces dimensions peuvent être reliées sans être réduites l'une à l'autre.

---

# Exemple fil rouge : le burn-out

## Configuration

Une personne présente :

- une fatigue importante ;
- une diminution de ses capacités professionnelles ;
- un contexte institutionnel.

---

## Régime médical

Description :

> Trouble nécessitant une prise en charge.

---

## Régime organisationnel

Description :

> Effet possible d'une organisation du travail.

---

## Régime juridique

Description :

> Situation pouvant engager une responsabilité.

---

## Analyse d'articulation

Protokin demande :

- Ces descriptions sont-elles compatibles ?
- Peuvent-elles être traduites ?
- L'une tente-t-elle de réduire les autres ?
- Quelles dimensions deviennent silencieuses ?

L'objectif n'est pas de choisir immédiatement une description gagnante.

L'objectif est de comprendre leur architecture relationnelle.

---

# 6. Articulation et zones de silence

Toute articulation révèle également des zones de silence.

Lorsqu'un régime organise une description, il rend certaines dimensions moins visibles.

L'analyse doit donc demander :

> Que devient difficilement descriptible lorsqu'un autre régime domine ?

Les silences ne sont pas seulement des absences.

Ils peuvent être des effets structuraux d'un régime descriptif.

---

# 7. Erreurs fréquentes

## Chercher une synthèse totale

Erreur :

> Toutes les descriptions doivent être réunies dans une seule description supérieure.

Correction :

Protokin analyse les relations sans supprimer les différences.

---

## Confondre articulation et relativisme

Erreur :

> Plusieurs régimes signifient que toutes les descriptions se valent.

Correction :

Chaque régime possède des contraintes internes.

---

## Confondre traduction et équivalence

Erreur :

> Traduire signifie dire exactement la même chose autrement.

Correction :

Une traduction transforme une description selon un autre régime.

---

## Confondre conflit et erreur

Erreur :

> Deux descriptions incompatibles signifient qu'une seule est fausse.

Correction :

Le conflit peut provenir de différences de régimes.

---

# 8. Place dans l'architecture fonctionnelle

La séquence initiale de Protokin est :

Configuration ↓ Description ↓ Qualification ↓ Articulation

Articuler ouvre ensuite vers les opérations dynamiques :

Articuler ↓ Maintenir ↓ Transformer ↓ Délimiter

---

# Ce que cette page établit

Articuler est l'opération qui analyse les relations entre descriptions.

Elle établit que :

- aucune description n'existe seule ;
- les régimes possèdent des frontières relationnelles ;
- les différences descriptives doivent être analysées avant d'être réduites.

La question fondamentale devient :

> **Comment plusieurs descriptions peuvent-elles coexister, se traduire ou entrer en tension dans une même configuration ?**
