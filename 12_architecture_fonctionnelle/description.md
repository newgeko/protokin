# Description

## Opération de mise en intelligibilité d'une configuration

---

## Introduction

Dans Protokin, une description n'est pas un simple énoncé qui représenterait un objet déjà constitué.

Elle désigne une **opération par laquelle une configuration devient intelligible selon certaines conditions descriptives**.

Décrire n'est donc pas reproduire passivement une réalité indépendante. C'est sélectionner, organiser et articuler des éléments dans un espace où certaines distinctions deviennent pertinentes et certaines inférences deviennent possibles.

Une description n'est jamais seulement ce qui est dit.

Elle implique également :

- une position depuis laquelle elle est produite ;
- un régime qui définit ses possibilités ;
- des engagements qu'elle rend nécessaires ;
- des conséquences qu'elle autorise ou exclut.

---

# Fonction analytique

La fonction **Décrire** répond à la question :

> **Comment une configuration devient-elle une description déterminée ?**

Elle constitue la première opération de l'enquête protokinienne.

Avant de qualifier un énoncé, d'analyser son régime ou d'évaluer sa justification, il faut déterminer :

- ce qui est décrit ;
- comment cela est décrit ;
- depuis quelle position ;
- avec quels engagements.

---

# 1. Description et configuration

La distinction entre configuration et description est fondamentale.

## La configuration

La configuration désigne l'organisation relationnelle soumise à l'enquête.

Elle comprend :

- des pratiques ;
- des dispositifs ;
- des inscriptions matérielles ;
- des distinctions déjà opérantes ;
- des interactions.

Elle constitue le champ à partir duquel plusieurs descriptions peuvent devenir possibles.

---

## La description

La description est l'opération qui rend cette configuration intelligible d'une manière déterminée.

Elle introduit :

- une sélection ;
- une perspective ;
- une organisation conceptuelle ;
- des engagements.

Une même configuration peut donc produire plusieurs descriptions selon le régime descriptif mobilisé.

---

# 2. La description comme opération

Une description n'est pas une propriété d'un objet.

Elle est une opération.

Elle transforme une configuration indéterminée ou ouverte en une forme intelligible.

Cette opération implique :

## Sélection

Toute description choisit certains éléments comme pertinents.

Décrire, c'est rendre certaines différences significatives.

---

## Organisation

Les éléments sélectionnés sont mis en relation.

Une description ne juxtapose pas des informations :

elle construit une structure d'intelligibilité.

---

## Engagement

Toute description engage celui qui la produit.

Décrire quelque chose comme X implique d'accepter certaines conséquences :

- certaines inférences deviennent possibles ;
- certaines critiques deviennent pertinentes ;
- certaines alternatives deviennent exclues.

---

# 3. Description et engagement normatif

Dans Protokin, une description appartient déjà partiellement à l'espace des raisons.

Elle n'est pas seulement causée par une situation.

Elle peut être :

- discutée ;
- contestée ;
- justifiée ;
- révisée.

C'est pourquoi une description possède une dimension normative.

Elle ne signifie pas seulement :

> "voici ce qui est observé".

Elle signifie :

> "voici une manière de rendre cette situation intelligible qui entraîne certaines conséquences".

---

# 4. Description et position descriptive

Une description n'existe jamais depuis nulle part.

Elle est produite depuis une position descriptive.

Cette position détermine :

- ce qui est accessible ;
- ce qui est pertinent ;
- ce qui peut être affirmé ;
- ce qui doit être justifié.

Un médecin, un juriste, un ingénieur ou un citoyen peuvent rencontrer une même configuration tout en produisant des descriptions différentes.

La différence ne provient pas uniquement des informations disponibles.

Elle provient aussi des positions occupées dans l'espace descriptif.

---

# 5. Description et régime descriptif

Une description n'est jamais autonome.

Elle dépend d'un régime descriptif qui définit :

- les critères de pertinence ;
- les formes de preuve ;
- les règles d'inférence ;
- les possibilités de justification.

Ainsi, une même configuration peut être décrite différemment :

## Configuration

Une personne présente une fatigue importante et une diminution de son activité professionnelle.

## Description médicale

> Trouble nécessitant une évaluation clinique.

## Description juridique

> Situation pouvant engager une responsabilité institutionnelle.

## Description organisationnelle

> Dysfonctionnement dans un système de travail.

La configuration ne détermine pas une description unique.

Elle ouvre un espace de descriptions possibles.

---

# 6. Erreur fréquente : confondre description et réalité

Une erreur classique consiste à considérer qu'une description révèle simplement un objet déjà constitué.

Protokin refuse cette conception.

Une description n'est pas :

- un miroir ;
- une copie ;
- une photographie du réel.

Elle est une opération située qui rend quelque chose descriptible selon certaines conditions.

---

# 7. Articulation avec les autres fonctions

La description prépare les opérations suivantes :

## Qualifier

Identifier le régime dans lequel la description fonctionne.

## Articuler

Analyser ses relations avec d'autres descriptions.

## Reproduire

Comprendre comment elle se maintient.

## Transformer

Analyser comment elle change.

## Auditer

Évaluer ses conditions de validité et ses effets.

---

# Exemple fil rouge

## Le "burn-out"

Une configuration :

- fatigue ;
- troubles du sommeil ;
- difficultés professionnelles ;
- discours institutionnels ;
- pratiques médicales.

Cette configuration ne contient pas encore une description unique.

Plusieurs descriptions deviennent possibles :

### Description médicale

Un état clinique nécessitant une prise en charge.

### Description organisationnelle

Une conséquence d'une organisation du travail.

### Description juridique

Une situation pouvant produire des obligations institutionnelles.

La fonction Décrire consiste à analyser comment cette configuration devient une description déterminée.

---

# Ce que cette page établit

La description n'est pas un objet mais une opération.

Elle est :

- située ;
- engagée ;
- relationnelle ;
- dépendante d'un régime.

Toute enquête protokinienne commence par cette question :

> Comment cette configuration est-elle devenue une description ?
