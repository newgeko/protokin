# Expliquer

## Analyser les conditions de production d'une description

---

## Introduction

Dans Protokin, **Expliquer** constitue la huitième opération de l'enquête descriptive.

Après avoir reconstruit :

- l'apparition d'une description (**Décrire**) ;
- son régime de fonctionnement (**Qualifier**) ;
- ses relations avec d'autres descriptions (**Articuler**) ;
- ses mécanismes de reproduction (**Reproduire**) ;
- ses transformations (**Transformer**) ;
- ses limites (**Délimiter**) ;
- sa trajectoire historique (**Retracer**) ;

il faut analyser les conditions qui ont rendu cette description possible.

La fonction **Expliquer** répond à une question génétique :

> **D'où vient cette description ?**

Mais cette question ne demande pas encore :

> Pourquoi cette description est-elle acceptable ?

Cette seconde question appartient à la fonction **Justifier**.

---

# Fonction analytique

La fonction **Expliquer** analyse les conditions de production d'une description.

Elle étudie :

- les causes ;
- les contraintes ;
- les mécanismes ;
- les interactions ;
- les conditions matérielles, biologiques, historiques ou sociales.

Expliquer cherche à reconstruire **comment une description a pu émerger**, sans transformer automatiquement cette explication en justification.

---

# 1. Expliquer n'est pas justifier

Cette distinction constitue un principe fondamental de Protokin.

Une description peut être expliquée sans être justifiée.

Inversement, une description peut être justifiée sans que son origine explique sa validité.

---

## Exemple

On peut expliquer l'apparition d'une théorie scientifique par :

- un contexte historique ;
- des instruments disponibles ;
- des institutions ;
- des intérêts sociaux.

Mais cette explication ne suffit pas à déterminer si la théorie est recevable dans son régime scientifique.

---

## Principe fondamental

> Une cause explique l'apparition d'une description ; une raison justifie son acceptation.

---

# 2. Explication et conditions de production

Une description n'apparaît jamais spontanément.

Elle dépend de conditions qui rendent son apparition possible.

Ces conditions peuvent être :

- matérielles ;
- techniques ;
- biologiques ;
- historiques ;
- institutionnelles ;
- cognitives.

---

## Exemple

Une classification scientifique dépend :

- d'instruments d'observation ;
- de pratiques expérimentales ;
- de communautés de recherche ;
- de catégories disponibles.

Ces éléments expliquent sa production.

---

# 3. Les niveaux d'explication

Protokin distingue plusieurs niveaux d'analyse.

---

# 3.1 Conditions matérielles

Une description dépend parfois de dispositifs matériels.

Cela inclut :

- instruments ;
- infrastructures ;
- technologies ;
- supports d'inscription.

---

## Exemple

Une nouvelle description du vivant devient possible grâce à de nouvelles techniques d'observation.

L'instrument ne justifie pas la description.

Il rend certaines descriptions possibles.

---

# 3.2 Conditions biologiques et cognitives

Certaines descriptions dépendent de capacités d'un organisme :

- perception ;
- mémoire ;
- attention ;
- apprentissage ;
- anticipation.

Ces conditions appartiennent à l'espace des causes.

Elles rendent possibles certaines pratiques descriptives.

---

# 3.3 Conditions sociales et institutionnelles

Les descriptions sont également produites dans des environnements collectifs.

Elles dépendent de :

- institutions ;
- organisations ;
- rôles sociaux ;
- pratiques partagées.

Une description individuelle devient souvent une description collective lorsqu'elle entre dans ces réseaux.

---

# 3.4 Conditions historiques

Une description dépend aussi d'un héritage.

Elle devient possible parce qu'une trajectoire antérieure a produit :

- des concepts ;
- des problèmes ;
- des méthodes ;
- des attentes.

---

# 4. Contraintes de production

Expliquer ne consiste pas seulement à chercher des causes positives.

Il faut aussi analyser les contraintes.

Une description apparaît dans un espace limité par :

- des ressources disponibles ;
- des techniques existantes ;
- des catégories héritées ;
- des normes institutionnelles.

Les contraintes déterminent ce qui peut apparaître comme descriptible.

---

# 5. Dynamiques de production

Une description n'est pas produite par une cause unique.

Elle résulte généralement d'une dynamique.

Cette dynamique peut inclure :

- interactions ;
- rétroactions ;
- sélection ;
- adaptation ;
- concurrence.

---

## Exemple

Une catégorie médicale peut émerger par interaction entre :

- observations cliniques ;
- recherches scientifiques ;
- institutions ;
- demandes sociales.

Il n'existe pas nécessairement une cause unique.

---

# 6. Couplages

Le concept de couplage désigne les relations entre plusieurs systèmes ou pratiques qui rendent une description possible.

Une description peut émerger d'un couplage entre :

- organisme et environnement ;
- technique et observation ;
- institution et pratique ;
- langage et action.

---

## Exemple

Une nouvelle catégorie juridique apparaît souvent par couplage entre :

- transformations sociales ;
- pratiques administratives ;
- décisions institutionnelles.

---

# 7. Sélection

Parmi les descriptions possibles, certaines persistent davantage que d'autres.

La sélection décrit les processus par lesquels certaines descriptions deviennent plus disponibles, plus utilisées ou plus reproductibles.

Elle peut dépendre :

- de leur efficacité pratique ;
- de leur compatibilité institutionnelle ;
- de leur capacité à résoudre un problème.

---

## Attention

La sélection n'est pas une justification.

Une description peut être sélectionnée parce qu'elle fonctionne socialement sans que cela suffise à établir sa validité.

---

# 8. Explication et espace PROTO

La fonction Expliquer est principalement liée à l'espace **PROTO**.

Elle concerne :

- les conditions matérielles ;
- les processus causaux ;
- les contraintes physiques ;
- les dynamiques biologiques ;
- les mécanismes de production.

Elle analyse ce qui rend une description possible comme événement.

---

# 9. Explication et espace KIN

Même si Expliquer relève principalement du registre des causes, elle peut contribuer à comprendre l'entrée d'une description dans l'espace des raisons.

Une pratique humaine possède souvent une double dimension :

- elle est produite par des causes ;
- elle peut être évaluée par des raisons.

Protokin maintient cependant leur distinction analytique.

---

# Exemple fil rouge : le burn-out

## Description

> Le burn-out comme problème organisationnel.

---

## Question explicative

D'où vient cette description ?

---

## Conditions de production possibles

- évolution du travail contemporain ;
- recherches psychologiques ;
- transformations économiques ;
- nouvelles pratiques managériales ;
- mobilisations sociales.

---

## Ce que l'explication établit

Elle montre pourquoi cette description a pu apparaître.

Elle ne répond pas encore à :

> Cette description est-elle scientifiquement ou normativement justifiée ?

---

# 10. Relation avec Justifier

La distinction fondamentale :

| Expliquer | Justifier |
|---|---|
| D'où cela vient-il ? | Pourquoi l'accepter ? |
| Causes | Raisons |
| Production | Validité normative |
| Espace des causes | Espace des raisons |
| Génétique | Inférentiel |

---

# 11. Erreurs fréquentes

## Réduire une description à ses causes

Erreur :

> Une description n'est rien d'autre que les conditions qui l'ont produite.

Correction :

L'origine d'une description ne suffit pas à déterminer sa portée.

---

## Naturaliser une justification

Erreur :

> Si une pratique existe biologiquement ou socialement, elle est justifiée.

Correction :

Une cause n'est pas une raison.

---

## Psychologiser une description collective

Erreur :

> Une description existe seulement parce que des individus la pensent.

Correction :

Les descriptions sont produites dans des réseaux de pratiques.

---

## Chercher une cause unique

Erreur :

> Toute description possède une origine simple.

Correction :

Les descriptions émergent généralement de dynamiques multiples.

---

# 12. Place dans l'architecture fonctionnelle

La trajectoire complète devient :

Configuration ↓ Décrire ↓ Qualifier ↓ Articuler ↓ Reproduire ↓ Transformer ↓ Délimiter ↓ Retracer ↓ Expliquer

Expliquer prépare la fonction suivante :

Expliquer ↓ Justifier ↓ Auditer ↓ Examiner

---

# Ce que cette page établit

Expliquer établit qu'une description possède toujours des conditions de production.

Elle n'apparaît pas hors contexte.

Elle dépend de :

- causes ;
- contraintes ;
- dynamiques ;
- couplages ;
- trajectoires.

Mais expliquer une description ne revient jamais à la justifier.

La question fondamentale de cette fonction est donc :

> **Quelles conditions ont rendu cette description possible ?**
