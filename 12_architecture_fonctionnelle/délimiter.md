# Délimiter

## Identifier les frontières, les extensions et les silences d'une description

---

## Introduction

Dans Protokin, **Délimiter** constitue la sixième opération de l'enquête descriptive.

Après avoir analysé :

- comment une configuration devient une description (**Décrire**) ;
- selon quel régime elle fonctionne (**Qualifier**) ;
- comment elle se rapporte à d'autres descriptions (**Articuler**) ;
- comment elle se maintient (**Reproduire**) ;
- comment elle se transforme (**Transformer**) ;

il faut déterminer **jusqu'où cette description peut fonctionner**.

Toute description possède une portée.

Elle rend certaines dimensions accessibles, mais elle rencontre également des limites.

La question centrale est donc :

> **Jusqu'où cette description vaut-elle, et que rend-elle difficilement descriptible ?**

---

# Fonction analytique

La fonction **Délimiter** consiste à analyser le domaine de validité pratique d'une description.

Elle identifie :

- son champ d'application ;
- ses frontières ;
- ses conditions d'extension ;
- ses limites internes ;
- ses zones de silence.

Délimiter ne signifie pas seulement fixer une frontière extérieure.

Cela signifie comprendre la structure d'une description :

- ce qu'elle permet de voir ;
- ce qu'elle permet d'articuler ;
- ce qu'elle laisse hors champ.

---

# 1. Délimiter n'est pas restreindre arbitrairement

Une première erreur consiste à penser qu'une limite est uniquement une faiblesse.

Dans Protokin, toute description possède nécessairement des limites parce qu'elle fonctionne grâce à des distinctions.

Pour rendre quelque chose intelligible, une description doit :

- sélectionner ;
- différencier ;
- organiser.

Cette opération produit toujours un intérieur et un extérieur descriptifs.

---

## Principe fondamental

> Une description devient efficace parce qu'elle délimite un espace de pertinence.

---

# 2. Domaine de validité

Le domaine de validité désigne l'ensemble des situations dans lesquelles une description conserve sa capacité à fonctionner.

Il dépend :

- du régime descriptif mobilisé ;
- des pratiques associées ;
- des critères de reconnaissance ;
- des conditions d'application.

Une description peut être valide dans un domaine précis sans être universelle.

---

## Exemple

Une description médicale d'un symptôme peut être pertinente dans un cadre clinique.

Elle peut devenir insuffisante lorsqu'il s'agit d'analyser :

- une organisation sociale ;
- une responsabilité juridique ;
- une trajectoire historique.

La limite n'est pas nécessairement une erreur.

Elle indique un changement de domaine.

---

# 3. Frontière descriptive

Toute description possède une frontière.

Cette frontière correspond au point où ses catégories cessent d'être suffisamment opérantes.

Une frontière peut apparaître lorsque :

- les critères deviennent insuffisants ;
- les objets changent de nature descriptive ;
- d'autres régimes deviennent nécessaires.

---

## Exemple

Une explication biologique d'un comportement humain peut être pertinente pour analyser certains mécanismes corporels.

Elle rencontre une frontière lorsqu'elle tente d'expliquer entièrement :

- des normes sociales ;
- des engagements ;
- des justifications.

La frontière indique une limite de régime, pas une impossibilité totale.

---

# 4. Extension descriptive

Une description peut parfois être étendue.

L'extension consiste à appliquer une description à de nouveaux domaines.

Mais toute extension doit être examinée.

Elle peut :

- enrichir un régime ;
- révéler sa puissance ;
- produire une réduction abusive.

---

## Question protokinienne

Lorsqu'une description est étendue :

> Les conditions qui la rendaient pertinente sont-elles encore présentes ?

---

# 5. Saturation descriptive

Une description atteint une saturation lorsque son extension produit une perte d'efficacité.

Elle continue d'être utilisée, mais elle explique ou organise de moins en moins correctement la configuration rencontrée.

La saturation peut apparaître lorsque :

- trop d'éléments sont forcés dans une même catégorie ;
- les exceptions deviennent nombreuses ;
- les tensions augmentent.

---

## Exemple

Une catégorie scientifique peut devenir insuffisante lorsque de nouveaux phénomènes apparaissent qu'elle ne permet plus d'articuler correctement.

---

# 6. Incommensurabilité

Certains régimes descriptifs peuvent présenter une faible traductibilité entre eux.

L'incommensurabilité désigne une difficulté à comparer directement deux descriptions utilisant :

- des critères différents ;
- des objets différents ;
- des formes de preuve différentes.

Elle ne signifie pas impossibilité absolue de communication.

Elle indique une absence de mesure commune immédiate.

---

## Exemple

Une description esthétique d'une œuvre et une description chimique de ses matériaux ne répondent pas à la même question.

Elles peuvent coexister sans être réduites l'une à l'autre.

---

# 7. Zones de silence

Le concept de **zone de silence** est central dans Protokin.

Une zone de silence désigne ce qu'une description rend difficilement articulable.

Elle n'est pas une absence d'information.

Elle est un effet structurel du régime descriptif.

---

## Toute description produit un double mouvement :

Elle crée :

- un domaine de visibilité ;
- une zone de silence.

---

## Exemple

Une description économique d'une activité peut rendre visibles :

- coûts ;
- échanges ;
- ressources.

Mais elle peut rendre moins visibles :

- expériences vécues ;
- relations symboliques ;
- dimensions affectives.

Le silence n'est pas nécessairement une erreur.

Il devient problématique lorsqu'il est ignoré.

---

# 8. Délimitation et audit

La fonction Délimiter prépare directement l'audit.

Un audit protokinien demande toujours :

- Où cette description fonctionne-t-elle ?
- Où cesse-t-elle d'être pertinente ?
- Quelles dimensions exclut-elle ?
- Quelles autres descriptions deviennent nécessaires ?

La délimitation constitue donc un garde-fou contre l'expansion illimitée d'un régime.

---

# Exemple fil rouge : le burn-out

## Description médicale

> Un syndrome nécessitant une prise en charge.

---

## Domaine de validité

Cette description fonctionne pour :

- l'évaluation clinique ;
- l'accompagnement thérapeutique.

---

## Frontière

Elle devient insuffisante lorsqu'elle prétend expliquer seule :

- les conditions organisationnelles ;
- les rapports institutionnels ;
- les normes professionnelles.

---

## Zone de silence possible

Une approche strictement clinique peut rendre moins visibles :

- l'organisation du travail ;
- les rapports hiérarchiques ;
- les dimensions collectives.

---

# 9. Erreurs fréquentes

## Confondre limite et échec

Erreur :

> Une description limitée est une mauvaise description.

Correction :

Toute description possède un domaine propre.

---

## Confondre extension et universalisation

Erreur :

> Une description efficace dans un domaine doit être appliquée partout.

Correction :

L'extension doit respecter les conditions du régime.

---

## Confondre silence et absence

Erreur :

> Ce qui n'est pas décrit n'existe pas.

Correction :

Une zone de silence indique une limite descriptive, pas une inexistence.

---

## Confondre incommensurabilité et relativisme

Erreur :

> Si deux régimes ne sont pas directement comparables, aucune évaluation n'est possible.

Correction :

Il faut analyser les conditions de comparaison et de traduction.

---

# 10. Place dans l'architecture fonctionnelle

La trajectoire dynamique devient :

Configuration ↓ Décrire ↓ Qualifier ↓ Articuler ↓ Reproduire ↓ Transformer ↓ Délimiter

Délimiter prépare les fonctions temporelles et génétiques :

Délimiter ↓ Tracer ↓ Expliquer ↓ Justifier ↓ Auditer

---

# Ce que cette page établit

Délimiter établit qu'une description ne vaut jamais partout et sans condition.

Toute description possède :

- un domaine de pertinence ;
- des frontières ;
- des possibilités d'extension ;
- des zones de silence.

La question fondamentale de cette fonction est donc :

> **Quelles sont les conditions dans lesquelles cette description fonctionne, et quelles dimensions deviennent silencieuses lorsqu'elle s'impose ?**
