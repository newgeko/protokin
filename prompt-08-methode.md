# Prompt section 08 — Méthode Protokin

## Fonction générale de la section

Cette section a pour fonction d'établir les opérations méthodologiques permettant d'étudier, d'analyser et d'auditer les pratiques descriptives.

Elle transforme Protokin d'une architecture conceptuelle en une pratique d'enquête applicable aux descriptions.

La section répond à la question :

> Comment conduire une enquête sur les conditions de production, d'évaluation, de stabilisation et de transformation d'une description ?

---

# Objectif rédactionnel

Rédiger les pages qui construisent le passage :

Situation descriptive ↓ Questionnement ↓ Enquête ↓ Identification du régime descriptif ↓ Analyse des conditions descriptives ↓ Comparaison et traduction ↓ Audit des limites et des tensions

La rédaction doit établir :

- les opérations d'enquête ;
- les outils d'analyse ;
- les procédures d'audit ;
- les critères de diagnostic.

Elle ne doit pas :

- transformer Protokin en méthode scientifique universelle ;
- proposer une procédure mécanique applicable à tout objet ;
- remplacer les analyses conceptuelles précédentes.

---

---

# Objet propre de la section

L'objet de cette section est :

> Les opérations par lesquelles une enquête protokinienne reconstruit les conditions d'une pratique descriptive.

Elle porte sur :

- l'enquête ;
- l'identification des régimes ;
- la comparaison ;
- la traduction ;
- l'audit ;
- le diagnostic des erreurs descriptives.

Elle ne porte pas sur :

- la définition des concepts fondamentaux ;
- l'histoire des philosophies mobilisées ;
- les études de cas elles-mêmes.

---

# Fonction propre de la section

Cette section existe pour établir :

> Comment utiliser Protokin pour analyser une description sans adopter une position extérieure ou absolue.

---

# Principe directeur

La méthode protokinienne ne doit jamais être comprise comme :

- une grille d'analyse imposée de l'extérieur ;
- une théorie permettant de classer définitivement les descriptions ;
- une procédure produisant automatiquement une vérité.

Elle doit être comprise comme :

- une enquête située ;
- une reconstruction des conditions descriptives ;
- un examen des relations entre pratiques, normes et supports.

---

# Qu'est-ce qu'une enquête ?

## Fonction de la page

Établir l'enquête comme processus de transformation d'une situation problématique en configuration intelligible.

La page doit montrer que l'enquête :

- part d'une difficulté ;
- reconstruit les conditions du problème ;
- transforme progressivement la situation.

Elle doit distinguer :

- enquête ;
- observation passive ;
- collecte d'informations.

Elle doit intégrer l'héritage pragmatiste de Dewey sans réduire Protokin au pragmatisme classique.

---

# Comment conduire une enquête

## Fonction de la page

Établir les étapes générales d'une enquête protokinienne.

La page doit présenter une dynamique possible :

Identifier la situation problématique ↓ Repérer les descriptions mobilisées ↓ Identifier les locuteurs et supports ↓ Reconstruire les critères ↓ Analyser les engagements ↓ Examiner les tensions ↓ Évaluer les possibilités de transformation

Elle ne doit pas :

- devenir un protocole rigide ;
- imposer une méthode quantitative.

---

# Comment réaliser un audit

## Fonction de la page

Établir l'audit comme examen critique immanent d'une pratique descriptive.

La page doit montrer que l'audit consiste à examiner :

- les conditions de production ;
- les supports ;
- les normes ;
- les exclusions ;
- les limites internes.

Elle doit distinguer :

- audit ;
- critique externe ;
- jugement moral.

---

# Identifier un régime

## Fonction de la page

Établir les critères permettant de reconnaître un régime descriptif.

La page doit montrer qu'un régime se caractérise par :

- des catégories ;
- des critères ;
- des supports ;
- des pratiques de validation ;
- des engagements spécifiques.

Elle ne doit pas :

- réduire un régime à un vocabulaire.

---

# Comparer deux descriptions

## Fonction de la page

Établir la comparaison entre configurations descriptives différentes.

La page doit montrer qu'une comparaison exige :

- d'identifier les objets constitués ;
- de reconstruire les critères ;
- d'analyser les fonctions respectives.

Elle doit éviter :

- la comparaison par simple correspondance lexicale.

---

# Diagnostiquer une réduction

## Fonction de la page

Établir les conditions permettant d'identifier une réduction abusive d'un régime descriptif à un autre.

La page doit montrer qu'une réduction apparaît lorsque :

- un régime est traité comme inférieur ;
- ses propres critères sont ignorés ;
- sa fonction descriptive est supprimée.

Elle doit distinguer :

- réduction ;
- traduction ;
- intégration.

---

# Diagnostiquer une confusion de niveau

## Fonction de la page

Établir les erreurs produites par un changement illégitime de niveau descriptif.

La page doit analyser les confusions entre :

- PROTO et KIN ;
- causes et raisons ;
- organisme et pratique collective ;
- objet descriptif et configuration descriptive.

Elle doit montrer comment une erreur de niveau produit une fausse explication.

---

# Diagnostiquer une erreur de catégorie

## Fonction de la page

Établir les erreurs produites par l'application inadéquate d'une catégorie descriptive.

La page doit montrer qu'une erreur de catégorie apparaît lorsqu'une catégorie :

- est appliquée hors de son régime ;
- change de fonction ;
- produit une confusion entre types d'objets.

Elle doit distinguer :

- erreur ;
- désaccord ;
- pluralité descriptive.

---

# Évaluer une traduction

## Fonction de la page

Établir les critères permettant d'évaluer une traduction entre régimes descriptifs.

La page doit analyser :

- ce qui est conservé ;
- ce qui est transformé ;
- ce qui devient incompatible.

Elle doit montrer que traduire n'est pas :

- fusionner les régimes ;
- éliminer les différences.

---

# Distinctions conceptuelles à maintenir

## Enquête et audit

L'enquête reconstruit une situation problématique.

L'audit examine les conditions de fonctionnement d'une pratique.

---

## Méthode et procédure

Une méthode organise une orientation d'analyse.

Une procédure impose une suite fixe d'opérations.

---

## Analyse et jugement

Analyser une description ne signifie pas nécessairement la condamner ou l'approuver.

---

## Comparaison et réduction

Comparer suppose plusieurs régimes.

Réduire supprime la différence fonctionnelle.

---

# Contraintes spécifiques

Ne jamais :

- présenter Protokin comme une méthode universelle ;
- produire une position d'observateur extérieur ;
- confondre audit et critique morale ;
- transformer les régimes descriptifs en simples opinions.

Éviter :

- les algorithmes rigides ;
- les classifications définitives ;
- les prescriptions normatives absolues.

- Comment enquêter sur une description ?
