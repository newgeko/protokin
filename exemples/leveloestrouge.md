Le vélo est rouge : analyse protokinienne d'une prédication ordinaire

Pourquoi cet exemple ?

L'énoncé :

«« Le vélo est rouge. »»

semble constituer une description simple et évidente du monde.

Dans une approche descriptive classique, cet énoncé est souvent compris comme l'attribution d'une propriété à un objet : le vélo posséderait une caractéristique appelée rougeur que le locuteur se contenterait de constater et de rapporter.

L'approche protokinienne propose un déplacement analytique.

L'enjeu n'est pas de déterminer si le rouge existe comme propriété intrinsèque de l'objet, mais d'examiner les conditions sous lesquelles cette description devient recevable, contestable, justifiable ou stabilisable au sein d'une pratique.

Ainsi, l'énoncé « le vélo est rouge » n'est pas analysé comme la simple représentation d'un état du monde mais comme une opération descriptive produisant des engagements normatifs.

---

1. La prédication comme prise de position

Dire :

«« Ce vélo est rouge »»

n'est jamais un acte neutre.

Le locuteur prend publiquement position dans un espace de raisons.

Cette prise de position modifie son statut déontique puisqu'il devient responsable des conséquences associées à cette description.

Dans une perspective inférentialiste, le contenu du prédicat « rouge » n'est pas déterminé par une relation directe entre un mot et une propriété mais par sa place dans un réseau d'inférences et d'incompatibilités.

L'acte de prédication constitue ainsi une entrée dans un système d'engagements.

---

2. Les engagements inférentiels

Attribuer le prédicat « rouge » au vélo engage le locuteur à reconnaître certaines conséquences.

Par exemple :

- le vélo possède une couleur ;
- cette couleur appartient à la catégorie des rouges ;
- certaines descriptions dérivées deviennent recevables.

Ces conséquences ne sont pas nécessairement logiques au sens formel.

Elles peuvent être matérielles, pratiques ou contextuelles.

Le contenu de la description apparaît ainsi dans les transitions inférentielles qu'elle autorise.

---

3. Les incompatibilités descriptives

Toute description délimite également un espace d'exclusion.

Dire :

«« Le vélo est rouge »»

conduit simultanément à rendre problématiques certaines autres descriptions.

Par exemple :

- le vélo est entièrement vert ;
- le vélo est entièrement bleu ;
- le vélo est entièrement jaune.

Ces incompatibilités ne sont pas de simples contradictions abstraites.

Elles participent à la détermination même du contenu descriptif.

Dans une perspective protokinienne, un concept est défini autant par les descriptions qu'il exclut que par celles qu'il autorise.

---

4. La responsabilité justificative

L'assertion produit également une responsabilité.

Le locuteur ne se contente pas d'émettre un son ou un signal.

Il revendique implicitement un droit à l'assertion.

Ce droit peut être contesté.

La communauté discursive peut alors demander :

- Pourquoi dites-vous que le vélo est rouge ?
- Dans quelles conditions l'avez-vous observé ?
- L'éclairage permet-il une identification fiable de la couleur ?
- Quels critères utilisez-vous ?

L'assertion ouvre ainsi un espace potentiel de justification.

---

5. Le contenu n'est pas dans l'objet

Une lecture réaliste naïve pourrait considérer que le contenu de l'énoncé est entièrement contenu dans l'objet lui-même.

L'analyse protokinienne adopte une autre orientation.

Le contenu descriptif n'est pas recherché dans une propriété cachée du vélo.

Il est recherché dans les pratiques qui rendent l'usage du prédicat possible, intelligible et stabilisable.

Autrement dit, ce qui intéresse l'analyse n'est pas la rougeur comme entité mais les conditions d'utilisation du terme « rouge ».

---

6. La pluralité des régimes descriptifs

La stabilisation de la description dépend toujours d'un régime de description.

Dans un régime perceptif ordinaire :

«« Le vélo est rouge »»

peut être parfaitement stabilisé.

Dans un régime scientifique portant sur les propriétés optiques :

«« Le vélo réfléchit principalement certaines longueurs d'onde du spectre visible »»

pourra devenir la description pertinente.

Dans un régime artistique :

«« Le vélo est vermillon »»

ou

«« Le vélo est écarlate »»

pourront remplacer la catégorie générale de rouge.

Dans un régime industriel :

«« Le vélo correspond à la référence RAL concernée »»

pourra constituer la description légitime.

Le contenu descriptif n'est donc jamais indépendant du régime dans lequel il est mobilisé.

---

7. Ce que Protokin analyse

Face à une prédication comme :

«« Le vélo est rouge »»

Protokin ne cherche pas à déterminer la nature réelle de la couleur.

L'analyse porte sur les opérations de stabilisation descriptives.

Les questions deviennent alors :

- Quels engagements cette description produit-elle ?
- Quelles incompatibilités organise-t-elle ?
- Quelles justifications permet-elle ?
- Dans quel régime est-elle recevable ?
- Comment réagit-elle lorsqu'elle rencontre d'autres régimes descriptifs ?
- Quelles tensions apparaissent lors de ces rencontres ?

---

8. Formulation générale

Dans une perspective protokinienne :

«Une prédication n'est pas l'attribution d'une propriété à une chose. Elle constitue une opération descriptive qui redistribue des engagements, des incompatibilités, des autorisations et des responsabilités justificatives au sein d'un espace de raisons.»

Ainsi, l'énoncé :

«« Le vélo est rouge »»

ne révèle pas simplement une caractéristique du monde.

Il participe à la stabilisation d'une configuration descriptive dont les conditions de validité, de contestation et de justification deviennent les véritables objets de l'analyse.
