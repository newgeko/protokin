Cette action est illégale : analyse protokinienne d'une qualification normative

Situation

Un locuteur affirme :

«« Cette action est illégale. »»

À première vue, cet énoncé semble simplement décrire une propriété de l'action.

Pourtant, une action ne porte pas en elle-même une qualité physique ou naturelle appelée « illégalité ».

Le même comportement matériel peut être :

- autorisé dans un contexte ;
- interdit dans un autre ;
- sanctionné juridiquement ;
- revendiqué politiquement.

L'illégalité n'est donc pas une propriété intrinsèque de l'acte.

Elle correspond à une qualification normative stabilisée dans un régime de règles.

---

1. Déplacement analytique : de l'acte matériel au statut normatif

Une description causale pourrait analyser une action selon ses propriétés physiques :

- un déplacement ;
- une appropriation ;
- une modification matérielle ;
- une interaction entre individus.

Cependant, ces caractéristiques ne suffisent jamais à déterminer son statut juridique.

Un même geste peut constituer :

- une transaction commerciale ;
- un don ;
- une appropriation illégitime ;
- une infraction.

La différence ne réside pas uniquement dans le comportement observable.

Elle dépend du régime normatif dans lequel l'action est inscrite.

L'analyse protokinienne porte donc sur les conditions qui permettent de stabiliser une action comme « illégale ».

---

2. Fonction analytique : engagements normatifs

Dire :

«« Cette action est illégale »»

constitue une prise de position publique.

Le locuteur modifie son score discursif en s'engageant à reconnaître certaines conséquences :

- l'acte ne bénéficie pas d'une autorisation juridique valide ;
- son auteur peut être exposé à une sanction ;
- certaines institutions sont habilitées à intervenir ;
- la communauté juridique peut traiter cette action comme une transgression.

Le prédicat « illégal » fonctionne donc comme un opérateur de redistribution des droits et obligations.

Son contenu apparaît dans les conséquences pratiques qu'il autorise.

---

3. Fonction analytique : incompatibilités matérielles et exclusion normative

Toute qualification normative trace une frontière.

Dire :

«« Cette action est illégale »»

rend incompatibles, sous le même rapport juridique :

- cette action est pleinement licite ;
- cette action constitue l'exercice normal d'un droit reconnu ;
- cette action est juridiquement neutre.

La description produit ainsi une exclusion déontique.

Elle retire au locuteur la possibilité de soutenir simultanément des positions incompatibles dans le même cadre normatif.

L'incompatibilité ne porte pas seulement sur une représentation du monde.

Elle protège la cohérence du système d'autorisations et d'interdictions.

---

4. Fonction analytique : score discursif et responsabilité justificative

Qualifier une action d'illégale n'est pas simplement exprimer une désapprobation morale.

Le locuteur revendique une autorité descriptive particulière.

Une contestation peut prendre la forme :

«« En vertu de quelle règle cette action serait-elle illégale ? »»

La justification doit alors mobiliser des éléments publics :

- une norme juridique applicable ;
- un texte codifié ;
- une décision institutionnelle ;
- une interprétation reconnue.

L'assertion doit établir une relation entre :

1. un cas particulier ;
2. une règle générale ;
3. une institution capable d'en assurer l'application.

L'autorité de la description dépend donc de sa capacité à être reconnue dans un espace juridique partagé.

---

5. Fonction analytique : articulation entre causes et raisons

Cet exemple permet de distinguer deux dimensions fondamentales.

Niveau causal : l'événement matériel

Le régime physique décrit :

- un comportement observable ;
- une succession d'événements ;
- des effets matériels.

Ces éléments constituent les conditions factuelles de l'action.

Ils ne déterminent cependant pas son statut normatif.

Niveau des raisons : la qualification juridique

Le régime normatif mobilise :

- des règles ;
- des catégories juridiques ;
- des responsabilités ;
- des sanctions.

L'action devient alors intelligible comme infraction, autorisation ou obligation.

La norme ne décrit pas seulement ce qui arrive.

Elle organise ce qui compte comme acceptable, interdit ou sanctionnable.

---

6. Pluralité des régimes descriptifs

Une même action peut être stabilisée selon plusieurs régimes.

Régime juridico-pénal

L'action est décrite comme :

- une infraction ;
- une violation d'une norme ;
- un comportement susceptible de poursuite.

La qualification dépend ici d'un système institutionnel de règles et de sanctions.

---

Régime éco-stratégique

L'action illégale peut être traduite en termes de :

- risque ;
- coût ;
- probabilité de sanction ;
- calcul d'opportunité.

Dans ce régime, la normativité juridique peut être réduite à une variable stratégique.

L'analyse protokinienne identifie alors une tension : une raison juridique est transformée en paramètre causal de décision.

---

Régime éthico-politique

Une action peut être juridiquement illégale tout en étant revendiquée comme moralement ou politiquement légitime.

Apparaît alors une tension inter-régimes :

- illégale selon le droit positif ;
- légitime selon un autre espace de raisons.

Cette situation montre que la stabilisation d'une description n'est jamais absolue.

Elle dépend du régime dans lequel elle opère.

---

7. Fonction analytique : traduction et tensions inter-régimes

L'analyse protokinienne ne cherche pas à résoudre immédiatement les conflits entre descriptions.

Elle cherche à comprendre leur structure.

Une même action peut simultanément être :

- illégale juridiquement ;
- rationnelle stratégiquement ;
- défendue politiquement.

La question devient :

«Comment plusieurs régimes de description peuvent-ils attribuer des statuts différents au même événement matériel ?»

La tension apparaît lorsque ces régimes prétendent fournir l'unique cadre de validité.

---

8. Résultat analytique

L'énoncé :

«« Cette action est illégale »»

ne révèle pas une propriété naturelle de l'acte.

Il réalise une opération de qualification normative.

Cette opération produit :

- des interdictions ;
- des exclusions ;
- des responsabilités ;
- des possibilités de sanction ;
- des conflits éventuels avec d'autres régimes de raisons.

L'illégalité est donc une stabilisation normative d'une pratique matérielle dans un système institutionnel.

---

Thèse protokinienne

«Dire « cette action est illégale » ne consiste pas à découvrir une propriété cachée dans un comportement. C'est effectuer une opération de positionnement normatif par laquelle un événement matériel est inscrit dans un réseau de règles, d'autorisations, de sanctions et de responsabilités.»

«L'illégalité n'est pas une substance sociale autonome ; elle est une configuration métastable où une pratique devient intelligible comme transgression au sein d'un régime juridique tout en pouvant entrer en tension avec d'autres espaces de raisons.»
