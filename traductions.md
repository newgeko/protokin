Traductions — relations contrôlées entre régimes descriptifs

«Ce fichier analyse la fonction de la traduction dans l’architecture Protokin.

Il répond à une question centrale :

Quand et sous quelles conditions deux régimes descriptifs peuvent-ils communiquer sans être réduits l’un à l’autre ni fusionnés arbitrairement ?»

---

1. Fonction de la traduction dans Protokin

Dans Protokin, la traduction désigne une opération d’articulation entre plusieurs régimes descriptifs.

Elle ne consiste pas à remplacer un régime par un autre.

Elle vise à expliciter les conditions permettant à une description appartenant à un régime donné d’être reformulée, comparée ou mise en relation avec une description appartenant à un autre régime.

La traduction est donc une opération de médiation.

Elle permet d’analyser :

- ce qui peut être conservé lors d’un déplacement conceptuel ;
- ce qui doit être transformé ;
- ce qui devient incompatible ;
- ce qui ne peut pas être transféré.

- "regimes.md" (regimes.md)
- "transitions.md" (transitions.md)

---

2. Principe général

Un régime descriptif possède ses propres :

- critères de validité ;
- règles d’inférence ;
- engagements ;
- conditions d’application.

Par conséquent, un concept ne peut pas être déplacé d’un régime à un autre comme un simple objet transportable.

Une traduction nécessite une analyse de la transformation opérée.

La question centrale n’est donc pas :

«Est-ce que deux descriptions utilisent les mêmes mots ?»

Mais :

«Les deux descriptions conservent-elles une relation fonctionnelle identifiable malgré leur changement de régime ?»

---

3. Traduction et différence entre régimes

La traduction présuppose une pluralité de régimes.

Si tous les régimes étaient identiques, aucune traduction ne serait nécessaire.

Si tous les régimes étaient totalement incommensurables, aucune traduction ne serait possible.

La traduction occupe donc une position intermédiaire.

Elle reconnaît simultanément :

- la différence des cadres descriptifs ;
- la possibilité de relations partielles entre eux.

Elle refuse deux positions opposées :

3.1 Le réductionnisme

Le réductionnisme affirme qu’un régime peut être entièrement traduit dans un autre.

Il transforme alors une relation de passage en absorption.

Voir :

- "reductions.md" (reductions.md)

---

3.2 L’éclectisme

L’éclectisme suppose que des concepts issus de plusieurs régimes peuvent être combinés immédiatement.

Il ignore alors les conditions qui rendent leur relation possible.

Voir :

- "eclectisme.md" (eclectisme.md)

---

4. Les opérations de traduction

4.1 Conservation partielle

Une traduction peut conserver certains éléments d’un régime initial.

Elle peut préserver :

- une structure relationnelle ;
- une fonction descriptive ;
- une relation entre variables ;
- une organisation conceptuelle.

Cependant, cette conservation n’implique jamais une identité complète.

---

4.2 Transformation fonctionnelle

Lorsqu’un concept passe dans un autre régime, sa fonction peut changer.

La traduction doit alors préciser :

- ce qui reste comparable ;
- ce qui acquiert un nouveau statut ;
- ce qui doit être abandonné.

Un même terme peut donc changer de rôle sans être simplement conservé ou supprimé.

---

4.3 Limitation du transfert

Certaines propriétés ne peuvent pas être traduites.

Dans ce cas, la traduction doit reconnaître une limite.

Cette limite n’est pas un échec.

Elle indique que les contraintes propres aux régimes empêchent une correspondance complète.

Voir :

- "limites.md" (limites.md)

---

5. Traduction et métaphore

La métaphore constitue une forme particulière de relation entre régimes.

Elle peut jouer un rôle heuristique lorsqu’elle permet :

- d’explorer une nouvelle description ;
- de produire une hypothèse ;
- de déplacer une perspective.

Cependant, une métaphore n’est pas automatiquement une traduction.

Elle devient une traduction seulement lorsque les conditions du passage sont explicitées.

Le danger apparaît lorsque la métaphore est utilisée pour produire une identité cachée entre deux domaines.

Dans ce cas :

- une analogie devient une affirmation ;
- une ressemblance devient une explication ;
- une image devient une ontologie implicite.

Voir :

- "eclectisme.md" (eclectisme.md)
- "reductions.md" (reductions.md)

---

6. Traduction et analogie

L’analogie constitue souvent le point de départ d’une traduction.

Elle permet d’identifier une possible relation entre deux descriptions.

Cependant, elle ne suffit pas à établir une équivalence.

Une analogie doit être soumise à un examen :

- Quels éléments sont réellement communs ?
- Quels éléments diffèrent ?
- Quelles inférences sont autorisées ?
- Quelles conséquences sont transférables ?

Une analogie contrôlée peut ouvrir une enquête.

Une analogie non contrôlée produit un éclectisme.

---

7. Traduction et métaphore scientifique

Dans les pratiques scientifiques, certaines métaphores ont permis des transformations importantes.

Cependant, leur valeur ne réside pas dans une correspondance magique entre domaines.

Elle dépend de leur capacité à produire des relations opératoires.

Une métaphore scientifique devient productive lorsqu’elle permet :

- de nouvelles questions ;
- de nouvelles observations ;
- de nouvelles organisations conceptuelles.

Elle doit néanmoins conserver une distinction entre :

- le domaine d’origine ;
- le domaine d’application ;
- les transformations introduites.

La métaphore devient alors une opération de transition contrôlée.

Voir :

- "transitions.md" (transitions.md)

---

8. Traduction et engagements

Toute traduction modifie potentiellement les engagements associés à une description.

Changer de régime peut modifier :

- ce qui est affirmé ;
- ce qui peut être inféré ;
- ce qui doit être justifié ;
- ce qui devient problématique.

La traduction doit donc être analysée au niveau des engagements et non seulement au niveau du vocabulaire.

Deux descriptions peuvent employer des termes proches tout en impliquant des engagements différents.

Voir :

- "engagements.md" (engagements.md)

---

9. Traduction et causes / raisons

Une difficulté majeure apparaît lorsque la traduction tente de passer entre :

- l’espace des causes ;
- l’espace des raisons.

Une explication causale décrit :

- des mécanismes ;
- des régularités ;
- des dépendances.

Une justification normative décrit :

- des raisons ;
- des engagements ;
- des responsabilités.

Une traduction entre ces domaines ne peut pas consister en une réduction complète.

Elle doit préserver la différence fonctionnelle entre expliquer et justifier.

- "causes_raisons.md" (causes_raisons.md)

10. Audit d’une traduction

Dans Protokin, toute opération de traduction peut être soumise à un audit.

L’analyse examine :

10.1 Les régimes concernés

Quels cadres descriptifs entrent en relation ?

---

10.2 Le contenu transféré

Quel concept, modèle ou engagement est déplacé ?

---

10.3 La transformation opérée

Le contenu conserve-t-il sa fonction initiale ?

---

10.4 Les nouvelles inférences

Quelles conséquences deviennent possibles après traduction ?

---

10.5 Les limites éventuelles

Quels éléments résistent au passage ?

Voir :

- "audit.md" (audit.md)
- "analyse.md" (analyse.md)

11. Traduction et transition

La traduction constitue souvent une condition préalable à une transition.

Une transition descriptive exige en effet de comprendre :

- ce qui peut être maintenu ;
- ce qui doit être transformé ;
- ce qui doit être abandonné.

La traduction fournit donc l’espace analytique permettant d’éviter deux erreurs :

- remplacer un régime par un autre ;
- mélanger tous les régimes.

Voir :

- "transitions.md" (transitions.md)

---

12. Principe central

«Traduire un régime dans un autre ne signifie pas supprimer leur différence.

Cela signifie reconstruire les conditions sous lesquelles une relation intelligible entre eux devient possible.»

---

Conclusion

Dans Protokin, la traduction est une fonction d’articulation entre régimes descriptifs.

Elle permet d’examiner comment plusieurs formes d’intelligibilité peuvent entrer en relation sans :

- réduction ;
- fusion abusive ;
- confusion des critères.

Elle constitue une opération centrale pour analyser :

- les déplacements conceptuels ;
- les métaphores ;
- les analogies ;
- les transformations descriptives.

La traduction ne produit pas une langue universelle.

Elle rend visibles les conditions locales permettant à différentes descriptions de communiquer.

---

Formule synthétique

«Une traduction protokinienne n’est pas une conversion d’un régime dans un autre.

Elle est l’analyse des conditions sous lesquelles une relation entre régimes peut être construite, maintenue ou limitée.»
