# Prompt section 03 — Fondements descriptifs

## Fonction générale de la section

Cette section a pour fonction de construire progressivement les conditions élémentaires qui rendent possible une description au sein de Protokin.

Elle constitue le premier niveau de construction conceptuelle interne.

Elle établit les éléments nécessaires pour comprendre comment une configuration rencontrée devient une configuration descriptible.

La section répond à la question :

> Comment quelque chose devient-il descriptible avant même d'être évalué, justifié ou stabilisé dans une pratique collective ?

---

# Objectif rédactionnel

Rédiger les pages qui construisent le socle descriptif de Protokin.

La section doit expliquer comment une activité descriptive émerge à partir :

- d'une rencontre avec une configuration ;
- d'un couplage organisme-milieu ;
- d'une différenciation perceptive ;
- d'une organisation sémiotique ;
- d'une inscription dans des supports ;
- d'une configuration relationnelle partageable.

La rédaction doit établir les conditions de possibilité de la description.

Elle ne doit pas encore développer :

- les normes collectives ;
- les engagements du locuteur ;
- les pratiques de justification ;
- les transformations historiques.

---

# Statut architectural de la section

Cette section appartient au niveau :

**Construction des conditions descriptives élémentaires.**

Elle intervient après :

- 00 — Se repérer ;
- 01 — Principes fondamentaux ;
- 02 — Architecture générale.

Elle prépare :

- 04 — Les pratiques descriptives ;
- 05 — La dynamique descriptive ;
- 06 — La temporalité ;
- 07 — L'explication.

---

# Objet propre de la section

L'objet de cette section est :

> La constitution progressive d'une description comme configuration organisée de différences partageables.

Elle porte sur :

- ce qui est rencontré ;
- ce qui devient distinguable ;
- ce qui peut être inscrit ;
- ce qui peut devenir une description.

Elle ne porte pas encore sur :

- la validation sociale ;
- la correction normative ;
- la controverse entre communautés.

---

# Fonction propre des pages

Chaque page doit établir un élément nécessaire de la genèse descriptive.

Elle doit répondre à :

> Quelle condition rend possible l'apparition d'une description ?

---

# Configuration rencontrée

## Fonction de la page

Établir le point de départ pré-descriptif de l'analyse.

La page doit montrer :

- qu'une description commence toujours à partir d'une situation rencontrée ;
- que cette rencontre n'est pas encore une description constituée ;
- que le monde apparaît d'abord comme une configuration de différences et de relations.

Elle doit distinguer :

- rencontre ;
- perception ;
- description.

Elle ne doit pas :

- supposer un objet déjà découpé indépendamment des pratiques.

---

# Couplage perception-action

## Fonction de la page

Établir la dynamique interactive par laquelle des différences deviennent pertinentes pour un organisme.

La page doit montrer :

- que percevoir implique une orientation pratique ;
- que l'action modifie la relation au milieu ;
- que la description trouve son origine dans une coordination active.

Elle ne doit pas :

- remplacer la page sur le principe du couplage perception-action de la section 01.

La différence est :

- section 01 : principe philosophique ;
- section 03 : fonctionnement descriptif.

---

# Configuration sémiotique

## Fonction de la page

Établir comment des différences perçues deviennent des différences partageables.

La page doit montrer :

- le passage de la distinction perceptive à l'inscription sémiotique ;
- la construction de signes, marques et différences communicables ;
- la médiation nécessaire entre expérience et description.

Elle ne doit pas :

- réduire la sémiotique à un simple langage verbal.

---

# Support descriptif

## Fonction de la page

Établir que toute description dépend de supports qui permettent son inscription, sa transmission et sa reprise.

La page doit distinguer :

- supports incorporés ;
- supports externes ;
- supports institutionnels.

Elle doit montrer que les descriptions existent dans des médiations matérielles et sociales.

Elle ne doit pas :

- développer les supports comme pratiques collectives spécialisées.

---

# Configuration descriptive

## Fonction de la page

Établir l'organisation relationnelle minimale d'une description.

La page doit montrer qu'une description n'est pas une simple phrase isolée mais une configuration comprenant :

- des distinctions ;
- des relations ;
- des critères ;
- des supports ;
- une position descriptive.

Elle ne doit pas :

- développer encore le régime descriptif complet.

---

# Description

## Fonction de la page

Établir le concept général de description dans Protokin.

La page doit définir :

- ce qu'est une description ;
- ce qu'elle rend possible ;
- pourquoi elle constitue le point d'entrée de l'analyse.

Elle doit maintenir la distinction entre :

- description ;
- représentation ;
- copie ;
- interprétation.

La description est une opération située de qualification d'une configuration.

---

# Fonctions descriptives

## Fonction de la page

Établir que la description possède plusieurs fonctions internes.

La page doit préparer l'analyse de :

- qualification ;
- assertion ;
- prédication ;
- catégorisation ;
- inscription.

Elle ne doit pas remplacer les pages consacrées à ces fonctions.

---

# Qualification

## Fonction de la page

Établir l'opération par laquelle une différence devient une propriété ou une caractérisation descriptive.

La page doit montrer :

- comment une qualité devient pertinente ;
- comment elle dépend de critères ;
- comment elle s'inscrit dans une pratique.

Elle ne doit pas :

- confondre qualification et jugement de valeur.

---

# Assertion

## Fonction de la page

Établir l'acte par lequel un locuteur engage une description comme pouvant être reprise, évaluée ou contestée.

La page doit introduire :

- l'engagement du locuteur ;
- la possibilité de justification ;
- la dimension publique de l'énoncé.

Elle prépare :

- engagements descriptifs ;
- responsabilité normative.

---

# Prédication

## Fonction de la page

Établir la structure relationnelle permettant d'attribuer une qualification à une configuration.

La page doit distinguer :

- l'acte linguistique ;
- la fonction descriptive ;
- la relation entre sujet descriptif et propriété attribuée.

Elle ne doit pas :

- réduire la prédication à la grammaire formelle.

---

# Catégories

## Fonction de la page

Établir les catégories comme instruments descriptifs permettant d'organiser les différences.

La page doit montrer :

- qu'une catégorie sélectionne des ressemblances pertinentes ;
- qu'elle dépend de critères d'application ;
- qu'elle appartient à un régime descriptif.

Elle ne doit pas :

- traiter les catégories comme des essences naturelles.

---

# Critères

## Fonction de la page

Établir les conditions d'application des catégories descriptives.

La page doit montrer :

- comment une catégorie devient applicable ;
- comment les communautés évaluent les cas ;
- comment les critères peuvent être contestés.

Elle prépare :

- recevabilité ;
- validité.

---

# Taxonomies

## Fonction de la page

Établir l'organisation hiérarchique ou relationnelle des catégories au sein d'un régime descriptif.

La page doit montrer :

- comment les catégories forment des systèmes ;
- comment elles organisent un domaine descriptif ;
- comment elles orientent l'enquête.

Elle ne doit pas :

- développer encore la notion de régime descriptif.

---

# Objet descriptif

## Fonction de la page

Établir l'objet tel qu'il apparaît à travers une configuration descriptive.

La page doit montrer :

- qu'un objet descriptif n'est pas simplement un objet naturel isolé ;
- qu'il est constitué dans une pratique de description ;
- qu'il possède une stabilité relationnelle.

Elle ne doit pas :

- nier l'existence d'une réalité résistante.

---

# Niveau descriptif

## Fonction de la page

Établir la distinction entre différents niveaux d'organisation des descriptions.

La page doit permettre d'éviter :

- les confusions de niveau ;
- les réductions entre niveaux.

Elle prépare :

- les diagnostics méthodologiques.

---

# Régime descriptif

## Fonction de la page

Établir les régimes descriptifs comme cadres de production, d'évaluation et d'organisation des descriptions.

La page doit montrer :

- qu'une description dépend d'un ensemble de critères ;
- qu'un régime détermine ce qui compte comme description recevable ;
- qu'il existe une pluralité de régimes.

Elle ne doit pas :

- développer encore les comparaisons entre régimes.

---

# Distinctions conceptuelles à maintenir

Toujours distinguer :

## Rencontre et description

Une configuration rencontrée n'est pas encore une description.

## Support et contenu descriptif

Un support permet une description sans être lui-même la description.

## Catégorie et objet

Une catégorie organise une description ; elle n'est pas nécessairement une propriété intrinsèque.

## Régime et description particulière

Un régime rend possibles des descriptions multiples.

---

# Contraintes spécifiques

Ne jamais :

- partir directement d'un objet constitué ;
- présenter les descriptions comme des copies du réel ;
- introduire la normativité avant les pratiques collectives ;
- confondre perception et connaissance scientifique.

Éviter :

- les formulations ontologiques ;
- les explications psychologiques individuelles ;
- les réductions linguistiques.

Une page de la section 03 est réussie si le lecteur peut répondre :

- Quelle condition descriptive cette page établit-elle ?
- Pourquoi cette condition est-elle nécessaire ?
- Quelle confusion permet-elle d'éviter ?
- De quels concepts dépend-elle ?
- Quels concepts ultérieurs rend-elle possibles ?
