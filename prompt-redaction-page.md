
# Prompt de création d'une page Protokin

## Rôle

Tu rédiges une page complète de documentation philosophique de niveau universitaire (Master / Doctorat) consacrée à Protokin.

Cette page appartient à une architecture documentaire globale.

Elle ne doit pas être rédigée comme un article indépendant, un essai philosophique ou une définition encyclopédique isolée.

Elle constitue un élément fonctionnel dans un réseau de dépendances conceptuelles.

Ton objectif est de construire une page qui :

- établit un concept précis ;
- explicite sa nécessité ;
- définit sa fonction ;
- distingue ses limites ;
- montre sa place dans l'architecture générale.

# Rédaction de la page

Après cette analyse, rédiger la page complète.

La page doit respecter la structure suivante :

---

# Titre de la page

## Fonction

Présenter immédiatement le rôle architectural du concept.

Format :

> Dans l'architecture de Protokin, [concept] désigne...

---

## Problème conceptuel inaugural

Présenter la difficulté théorique à laquelle répond le concept.

La page doit partir d'une nécessité.

Ne jamais commencer par une définition isolée.

---

## Définition fonctionnelle

Définir le concept selon sa fonction dans Protokin.

La définition doit préciser :

- ce que le concept permet d'analyser ;
- ce qu'il organise ;
- ce qu'il rend possible.

Ne pas produire :

- une essence ;
- une ontologie ;
- une théorie générale du réel.

---

## Dimensions principales

Présenter les propriétés nécessaires du concept.

Chaque dimension doit répondre à :

- Quelle fonction remplit-elle ?
- Pourquoi est-elle nécessaire ?
- Quelle relation entretient-elle avec les autres éléments ?

---

## Distinctions conceptuelles nécessaires

Présenter les différences avec les concepts voisins.

Format :

### [Concept] et [concept voisin]

La différence porte sur :

...

Cette distinction évite :

...

---

## Articulation dans l'architecture Protokin

Montrer la place du concept :

Concept antérieur ↓ Concept étudié ↓ Concept rendu possible

La page doit apparaître comme un nœud fonctionnel.

---

## Développement progressif

Développer le concept selon sa logique propre.

Utiliser :

- distinctions ;
- relations ;
- opérations ;
- conditions ;
- limites.

Éviter :

- accumulation historique ;
- catalogue d'auteurs ;
- généralités philosophiques.

---

## Exemples pédagogiques éventuels

Utiliser uniquement si nécessaire.

Les exemples doivent :

- illustrer une structure ;
- rendre visible une distinction ;
- montrer une application.

Ils ne doivent jamais remplacer l'analyse.

Fils rouges possibles :

- Le vélo est rouge ;
- Cette personne est dangereuse ;
- Cette personne est mauvaise ;
- Botaniste / bûcheron ;
- Patient aux urgences.

---

## Limites et vigilances

Préciser :

- ce que le concept ne signifie pas ;
- les erreurs possibles ;
- les réductions à éviter.

Inclure si nécessaire :

- risque d'ontologisation ;
- réduction causale ;
- confusion de niveau ;
- réification.

---

## Synthèse finale

Terminer par :

### Ce que cette page établit

...

### Ce qu'elle suppose

...

### Ce qu'elle rend possible

...

---

# Contraintes stylistiques finales

Le style doit être :

- analytique ;
- conceptuel ;
- rigoureux ;
- sobre ;
- pédagogique.

Privilégier :

- les fonctions ;
- les relations ;
- les distinctions ;
- les dépendances.

Éviter :

- les métaphores inutiles ;
- les affirmations absolues ;
- les formulations psychologiques ;
- les effets rhétoriques.

---

# Règle finale de rédaction

Une page Protokin réussie n'est pas une page qui contient beaucoup d'informations.

C'est une page qui accomplit exactement une opération architecturale :

> établir une fonction conceptuelle nécessaire dans la reconstruction de la grammaire des pratiques descriptives.
