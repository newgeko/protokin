# Prompt section 11 — Études de cas

## Fonction générale de la section

Cette section a pour fonction de montrer le fonctionnement concret de Protokin à travers l'analyse de configurations descriptives situées.

Elle ne constitue pas une démonstration empirique de la théorie.

Elle sert à rendre visibles les opérations conceptuelles établies dans les sections précédentes en les appliquant à des situations historiques, scientifiques, sociales et ordinaires.

Elle répond à la question :

> Comment les concepts de Protokin permettent-ils d'analyser des descriptions effectivement produites, stabilisées, contestées et transformées dans des pratiques réelles ?

---

# Objectif rédactionnel

Rédiger les études de cas comme des **analyses de configurations descriptives**.

Chaque cas doit montrer :

- comment une description apparaît ;
- quelles opérations descriptives la rendent possible ;
- quels supports la maintiennent ;
- quels locuteurs la mobilisent ;
- quelles normes permettent son évaluation ;
- comment elle se stabilise ;
- comment elle entre éventuellement en tension avec d'autres descriptions.

Les études de cas ne doivent jamais :

- servir d'illustration décorative ;
- être utilisées comme preuves expérimentales de Protokin ;
- réduire une situation complexe à une seule description correcte.

---

# Statut architectural de la section

Cette section appartient au niveau :

**Application analytique et mise en œuvre des concepts.**

Elle intervient après :

- 10 — Héritages philosophiques.

Elle prépare :

- 12 — Conclusion.

---

# Objet propre de la section

L'objet de cette section est :

> Les configurations descriptives concrètes dans lesquelles des pratiques de description deviennent observables.

Elle porte sur :

- les interactions entre régimes descriptifs ;
- les conditions de stabilisation ;
- les conflits de qualification ;
- les transformations historiques.

Elle ne porte pas sur :

- la définition initiale des concepts ;
- les fondements philosophiques ;
- la construction générale de l'architecture.

---

# Fonction propre de la section

Cette section existe pour établir :

> Comment une architecture abstraite des pratiques descriptives devient une grille d'analyse opérationnelle appliquée à des situations concrètes.

---

# Principe directeur

Un cas n'est jamais analysé à partir de la question :

> Quelle est la vraie description ?

Il est analysé à partir des questions :

- Comment cette description devient-elle possible ?
- Quel régime descriptif la rend intelligible ?
- Quels critères permettent de l'évaluer ?
- Quels engagements produit-elle ?
- Quels effets de stabilisation entraîne-t-elle ?
- Quelles alternatives deviennent visibles ou invisibles ?

---

# Structure générale obligatoire d'une étude de cas

Chaque étude doit suivre une architecture similaire :

---

## 1. Situation initiale

Présenter :

- le contexte ;
- les acteurs ;
- la situation problématique.

Ne pas commencer directement par une conclusion théorique.

---

## 2. Configuration descriptive étudiée

Identifier :

- ce qui est décrit ;
- comment cela devient un objet descriptif ;
- quelles distinctions sont mobilisées.

---

## 3. Locuteurs et positions descriptives

Identifier :

- les communautés de locuteurs ;
- les positions épistémiques ;
- les ressources disponibles ;
- les contraintes propres à chaque acteur.

---

## 4. Régimes descriptifs en présence

Décrire :

- les cadres d'intelligibilité mobilisés ;
- les catégories utilisées ;
- les critères de validité ;
- les supports descriptifs.

---

## 5. Stabilisation et maintien

Analyser :

- les mécanismes de reproduction ;
- les supports matériels ;
- les apprentissages ;
- les institutions.

---

## 6. Tensions et transformations

Étudier :

- les controverses ;
- les incompatibilités ;
- les traductions possibles ;
- les réorganisations descriptives.

---

## 7. Analyse protokinienne

Montrer :

- ce que l'étude révèle sur les opérations descriptives ;
- quelles distinctions deviennent visibles ;
- quelles limites apparaissent.

---

# Études de cas principales

---

# Géocentrisme

## Fonction de la page

Analyser la transformation historique d'un régime cosmologique.

La page doit montrer :

- la coexistence de plusieurs descriptions du cosmos ;
- les critères internes du régime géocentrique ;
- la transformation progressive des supports et des modèles ;
- la transition vers un nouveau régime descriptif.

Elle doit mobiliser :

- régime descriptif ;
- traduction ;
- transition ;
- stabilisation ;
- effet cliquet.

Elle ne doit pas présenter l'histoire comme un simple passage de l'erreur à la vérité.

---

# Phlogistique

## Fonction de la page

Analyser une théorie scientifique abandonnée.

La page doit montrer :

- comment une description peut être cohérente dans un régime donné ;
- comment de nouvelles pratiques expérimentales créent des tensions ;
- comment un régime devient progressivement insuffisant.

Elle doit distinguer :

- invalidation interne ;
- changement de critères ;
- transformation des catégories.

---

# Théorie des humeurs

## Fonction de la page

Analyser un régime médical historique.

La page doit montrer :

- comment des catégories médicales organisent l'observation ;
- comment elles structurent les pratiques thérapeutiques ;
- comment elles peuvent disparaître lors d'une réorganisation descriptive.

Elle prépare :

- analyse des régimes médicaux ;
- transformation historique des catégories.

---

# Changement climatique

## Fonction de la page

Analyser la coexistence de plusieurs régimes descriptifs autour d'un phénomène.

La page doit montrer :

- régime scientifique ;
- régime politique ;
- régime médiatique ;
- régime économique.

Elle doit analyser :

- compatibilités ;
- incompatibilités ;
- conflits de critères ;
- enjeux de stabilisation.

Elle ne doit pas devenir une synthèse scientifique du climat.

---

# Intelligence artificielle

## Fonction de la page

Analyser les différentes descriptions produites autour de l'intelligence artificielle.

La page doit montrer :

- diversité des régimes descriptifs ;
- différences entre descriptions techniques, économiques, sociales et philosophiques ;
- conflits autour des catégories utilisées.

Elle doit éviter :

- une définition métaphysique de l'intelligence ;
- une prise de position sur une essence de l'IA.

---

# « Cette personne est mauvaise »

## Fonction de la page

Analyser une qualification morale.

La page doit montrer :

- comment une qualification morale devient possible ;
- quels critères normatifs sont mobilisés ;
- comment une catégorie morale peut se stabiliser socialement.

Elle doit distinguer :

- description ;
- jugement normatif ;
- accusation ;
- condamnation.

---

# « Cette personne est dangereuse »

## Fonction de la page

Analyser une qualification institutionnelle et sécuritaire.

La page doit montrer :

- comment une catégorie produit des effets pratiques ;
- comment les institutions stabilisent certaines descriptions ;
- comment l'effet cliquet peut renforcer une qualification.

Elle doit intégrer :

- supports documentaires ;
- institutions ;
- pouvoir de validation ;
- injustice herméneutique.

Elle doit éviter :

- de nier toute réalité des situations de danger ;
- de réduire la catégorie à une construction arbitraire.

---

# Botaniste / bûcheron

## Fonction de la page

Analyser plusieurs descriptions portant sur un même milieu.

La page doit montrer :

- pluralité des régimes descriptifs ;
- différences de critères ;
- compatibilités partielles ;
- impossibilité de réduire une description à une autre.

Elle mobilise :

- régime descriptif ;
- objet descriptif ;
- critères ;
- position épistémique.

---

# Urgences hospitalières

## Fonction de la page

Analyser une pratique collective à forte densité normative.

La page doit montrer :

- coordination entre plusieurs acteurs ;
- articulation entre perception, instruments et institutions ;
- rôle des supports descriptifs ;
- décisions sous contrainte temporelle.

Elle mobilise :

- qualification ;
- recevabilité ;
- validité ;
- stabilisation ;
- responsabilité normative.

---

# Fils rouges pédagogiques

Les exemples récurrents peuvent être utilisés :

- le vélo rouge ;
- la personne dangereuse ;
- la personne mauvaise ;
- le botaniste et le bûcheron ;
- le patient aux urgences.

Mais chaque utilisation doit apporter une nouvelle fonction.

Un exemple déjà utilisé ne doit jamais simplement répéter une explication précédente.

---

# Contraintes spécifiques

Ne jamais :

- présenter un cas comme une preuve définitive ;
- choisir un régime "vrai" uniquement parce qu'il est actuel ;
- confondre description et réalité décrite ;
- réduire une controverse à une opposition entre vrai et faux.

Toujours :

- reconstruire les conditions descriptives ;
- identifier les acteurs ;
- expliciter les critères ;
- analyser les transformations.

# Critère final de validation

Une étude de cas est réussie si le lecteur peut répondre :

- Quelle configuration descriptive est analysée ?
- Quels régimes sont impliqués ?
- Quels locuteurs participent ?
- Quels supports rendent la description possible ?
- Comment la description se stabilise-t-elle ?
- Quelles tensions ou transformations apparaissent ?
- Que révèle ce cas sur les pratiques descriptives ?

La section 11 doit montrer que Protokin n'est pas seulement une architecture conceptuelle, mais une manière d'enquêter sur la manière dont les humains produisent, maintiennent et transforment leurs descriptions.
